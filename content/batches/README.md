# Планы пакетов

Планы создаёт content:batch --new <id> --section <section> --subsection <subsection>. Два прохода: scopePass и answerPass. Фиксируйте remaining и решения по фактическому результату. Baseline не обновляется при content:build. Инструкция: docs/content-workflow-v2.md из корня проекта.
