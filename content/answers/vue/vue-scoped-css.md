**Преобразованные селекторы без Shadow DOM.**

Компилятор добавляет атрибуты области и преобразует селекторы. Корневой элемент ребёнка может получать scoped-стили родителя для раскладки, но внутренняя разметка ребёнка обычно ими не покрывается. :deep() позволяет намеренно пройти в неё. Для контента слота предусмотрен :slotted(). Глобальные стили и наследуемые свойства всё ещё действуют. Содержимое v-html не получает обычные scoped-атрибуты.

### Пример и разбор

```vue
<style scoped>
.panel {
  color: navy;
}
.panel :deep(.editor-input) {
  border-color: navy;
}
</style>
```

Глубокий селектор привязывает родителя к внутреннему устройству редактора.

**Типичная ошибка:** Использовать :deep() повсеместно вместо публичных props, CSS-переменных и предусмотренных классов.

**Главная мысль:** Scoped изолирует селекторы сборкой, но не отменяет CSS-каскад.
