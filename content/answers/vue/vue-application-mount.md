**createApp, mount и граница приложения.**

createApp(App) создаёт экземпляр приложения. До mount можно подключить плагины через use, зарегистрировать общие компоненты и зависимости. mount связывает приложение с контейнером на странице; он не возвращает сам объект app. Несколько приложений на странице имеют отдельные настройки. Для гидратации серверной разметки используется createSSRApp, а не обычный клиентский старт.

### Пример и разбор

```js
import { createApp } from "vue"
import App from "./App.vue"
const app = createApp(App)
app.mount("#app")
```

В HTML должен существовать контейнер с id="app".

**Типичная ошибка:** Вызывать app.use после mount и ожидать, что уже созданные компоненты будут инициализированы заново.

**Главная мысль:** Настраивайте приложение до mount и различайте приложение и компонент.
