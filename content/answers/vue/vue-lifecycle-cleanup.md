**onMounted запускает работу после монтирования компонента на клиенте, когда доступен его DOM.** onUnmounted используют для снятия подписок, остановки таймеров и освобождения ресурсов экземпляра.

<!-- wishu:answer-block -->

- Хуки регистрируют синхронно в процессе setup, чтобы Vue связал их с экземпляром. После изменения реактивных данных DOM обновляется не обязательно немедленно; для ожидания завершения обновления используют nextTick. Mounted-хук не выполняет серверный рендеринг.

<!-- wishu:answer-block -->

### Уточнения и границы

onMounted вызывается на клиенте после монтирования DOM компонента и его синхронных детей, но не гарантирует готовности всех async-потомков. onUnmounted подходит для таймеров, внешних listeners и соединений. Регистрация хуков должна происходить синхронно в setup или вызываемом оттуда composable. onBeforeUnmount ещё имеет работающий экземпляр; onUpdated не предназначен для безусловного изменения состояния, запускающего новый рендер. В SSR mounted/unmounted не вызываются.

### Пример и разбор

```js
let timer
onMounted(() => {
  timer = setInterval(refresh, 30000)
})
onUnmounted(() => clearInterval(timer))
```

refresh - функция обновления; пример не подразумевает автоматическую отмену её уже начатого запроса.

**Типичная ошибка:** Регистрировать хук в setTimeout или освобождать только таймер, оставляя подписки того же компонента.

**Главная мысль:** Создание ресурса должно иметь симметричное освобождение у владельца.
