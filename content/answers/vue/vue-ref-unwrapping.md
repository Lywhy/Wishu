**Шаблон верхнего уровня, свойства объектов и элементы коллекций.**

В JavaScript ref обычно требует .value. В шаблоне ref верхнего уровня контекста разворачивается. В свойствах глубокого reactive-объекта refs также разворачиваются, но в элементах реактивного массива и значениях Map - нет. Обычный объект с вложенным ref не становится reactive только из-за помещения в контекст шаблона. Финальная текстовая интерполяция имеет дополнительное удобство разворачивания, на которое не следует переносить правила арифметических выражений.

### Пример и разбор

```js
const count = ref(1)
const state = reactive({ count })
const items = reactive([count])
console.log(state.count) // 1
console.log(items[0].value) // 1
```

В шаблоне {{ count + 1 }} работает для count верхнего уровня.

**Типичная ошибка:** Писать items[0] + 1, предполагая, что элемент массива уже является числом.

**Главная мысль:** Автоматическое разворачивание зависит от места доступа.
