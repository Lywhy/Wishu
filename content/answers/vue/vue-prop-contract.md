**Публичный контракт компонента и runtime-проверки.**

В runtime-объявлении defineProps задаются type, required, default и при необходимости validator. Для изменяемых объектов и массивов default обычно является фабрикой, чтобы экземпляры не делили один объект. Boolean props имеют специальное приведение: наличие атрибута может означать true. В TypeScript доступно типовое объявление, но нельзя одновременно задавать runtime-объект и типовой параметр одному вызову. Проверки props не заменяют проверку недоверенных данных на сервере.

### Пример и разбор

```js
const props = defineProps({
  title: { type: String, required: true },
  items: { type: Array, default: () => [] },
  disabled: Boolean,
})
```

Без items каждый экземпляр получает собственный массив.

**Типичная ошибка:** Писать default: [] или передавать disabled="false", ожидая логическое false.

**Главная мысль:** Prop должен иметь понятные тип, обязательность и начальное значение.
