**Динамический тип компонента и идентичность экземпляра.**

Встроенный component выбирает тип по :is. В <script setup> удобно передавать импортированный объект компонента. При смене типа прежний экземпляр размонтируется, а новый создаётся заново; возврат сам по себе локальное состояние не восстанавливает. Даже для одного типа изменение key принудительно создаёт другой экземпляр. Для сохранения нескольких экземпляров предусмотрен KeepAlive.

<!-- wishu:answer-block -->

### Пример и разбор

```vue
<component :is="activeTab === 'edit' ? Editor : Preview" :item="item" />
```

Editor и Preview здесь импортированы в script setup. Черновик внутри Editor потеряется при обычном переключении.

**Типичная ошибка:** Передавать произвольное имя импорта строкой и ожидать, что Vue найдёт его без регистрации.

**Главная мысль:** Переключение типа обычно пересоздаёт компонент; key управляет идентичностью.
