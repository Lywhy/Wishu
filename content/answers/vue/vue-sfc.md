### Уточнения и границы

Файл .vue объединяет template, script и style. Шаблон компилируется в функцию рендеринга. В <script setup> импорты и объявления верхнего уровня доступны шаблону; сам setup выполняется для каждого экземпляра. Обычный <script> имеет также модульную область, поэтому эти области нельзя считать одинаковыми. Несколько экземпляров получают независимые ref, объявленные в setup.

### Пример и разбор

```vue
<script setup>
import { ref } from "vue"
const count = ref(0)
</script>
<template>
  <button @click="count++">{{ count }}</button>
</template>
<style scoped>
button {
  font-weight: bold;
}
</style>
```

Два таких компонента содержат два отдельных счётчика.

**Типичная ошибка:** Считать, что scoped создаёт Shadow DOM или что все экземпляры разделяют переменные setup.

**Главная мысль:** SFC описывает компонент, а не отдельную страницу или singleton.
