**Файл .vue объединяет template, script и style.** Сборщик преобразует шаблон в функцию рендеринга. В `<script setup>` объявления верхнего уровня доступны шаблону, а код setup выполняется для каждого экземпляра компонента.

<!-- wishu:answer-block -->

- Область scoped у style ограничивает применение селекторов через преобразование сборщиком, а не создаёт Shadow DOM. Разделение на компоненты задаёт границы ответственности, но общий CSS и наследование всё равно требуют внимания.
