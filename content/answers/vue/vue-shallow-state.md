**Реактивность верхнего уровня для внешних или крупных структур.**

shallowRef отслеживает замену .value, сохраняя внутренний объект как есть. Это удобно для внешних экземпляров и больших неизменяемых структур. shallowReactive отслеживает только собственные свойства верхнего уровня, не превращая вложенные raw-объекты в Proxy. Если внутрь уже передан реактивный объект, shallow не снимает с него реактивность. Обычно проще заменять корень shallowRef; для осознанного уведомления после глубокой мутации существует triggerRef.

### Пример и разбор

```js
import { shallowRef } from "vue"
const rows = shallowRef([{ id: 1, done: false }])
rows.value = rows.value.map((row) => ({ ...row, done: true }))
```

Замена .value обновит потребителей; мутация raw-вложенности сама этого не гарантирует.

**Типичная ошибка:** Выбирать shallow как бесплатное ускорение, сохранив ожидание глубокой реактивности.

**Главная мысль:** Shallow требует явного обновления на отслеживаемой границе.
