**Текст, атрибуты и доверенная HTML-разметка.**

Интерполяция {{ value }} выводит текст с экранированием и не работает внутри атрибутов. v-bind, сокращённо :, вычисляет значение атрибута или prop. Без двоеточия значение является строковым литералом. v-html записывает HTML внутрь элемента; такой фрагмент не компилируется как Vue-шаблон. Для boolean-атрибута disabled важна привязка логического значения: строка "false" остаётся истинной.

### Пример и разбор

```vue
<button :disabled="busy" :title="hint">{{ label }}</button>
<Counter :initial="3" />
```

:initial передаёт число, тогда как initial="3" передал бы строку.

**Типичная ошибка:** Выводить пользовательский ввод через v-html без надёжной очистки; экранирование интерполяции здесь не применяется.

**Главная мысль:** Выбирайте привязку по назначению значения и границе доверия.
