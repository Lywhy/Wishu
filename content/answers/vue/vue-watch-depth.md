**Обход вложенности без автоматического снимка объекта.**

watch(reactiveObject, callback) наблюдает вложенные изменения. Getter () => state.user по умолчанию реагирует на замену user, а не каждую его вложенную мутацию; deep включает обход. При мутации вложенности oldValue и newValue могут указывать на тот же Proxy, потому что Vue не клонирует прошлое состояние. В Vue 3.5+ deep может быть числом для ограничения глубины. По возможности наблюдайте конкретное поле, чтобы не обходить большую структуру.

### Пример и разбор

```js
watch(
  () => state.user.name,
  (name, previous) => {
    console.log(previous, name)
  },
)
```

Здесь источник - строковое поле: старое и новое значения пригодны для сравнения.

**Типичная ошибка:** Использовать deep как универсальный diff и ожидать независимую копию oldValue.

**Главная мысль:** Глубокое наблюдение обнаруживает мутации, но не сохраняет историю объекта.
