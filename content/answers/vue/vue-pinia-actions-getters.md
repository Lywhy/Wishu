**Вычисления, команды и явные изменения состояния.**

Getters соответствуют computed, actions - методам и могут быть async. Pinia разрешает прямую запись в state и группирование через $patch; обязательных Vuex mutations здесь нет. Action полезен для доменного правила и общей обработки ошибок. В Option Store для this нужна обычная функция, не стрелка. Getter, возвращающий функцию с аргументом, не становится автоматически кешем всех результатов для всех аргументов.

### Пример и разбор

```js
const useCounter = defineStore("counter", {
  state: () => ({ count: 0 }),
  getters: { doubled: (state) => state.count * 2 },
  actions: {
    increment() {
      this.count++
    },
  },
})
```

store.doubled читают как свойство; store.increment() вызывают как действие.

**Типичная ошибка:** Отправлять запрос из getter или считать async action защищённым от конкурентных вызовов автоматически.

**Главная мысль:** Getter вычисляет значение, action выполняет действие с понятным результатом.
