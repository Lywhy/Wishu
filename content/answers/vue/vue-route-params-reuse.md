**Переиспользование экземпляра при изменении параметра маршрута.**

Если два адреса соответствуют тому же компоненту маршрута, Vue Router обычно сохраняет его экземпляр. Поэтому mounted не повторяется и запрос только в нём оставит старые данные. Наблюдайте getter конкретного params или применяйте onBeforeRouteUpdate, если нужно решить вопрос до подтверждения перехода. props: true может передать params как props и уменьшить зависимость страницы от router. Для запросов всё ещё нужна защита от гонок.

### Пример и разбор

```js
const route = useRoute()
watch(
  () => route.params.id,
  (id) => {
    selectedId.value = String(id)
  },
  { immediate: true },
)
```

Этот watcher реагирует на первоначальный параметр и последующие изменения, не наблюдая весь route.

**Типичная ошибка:** Без необходимости принудительно пересоздавать всё приложение через key вместо обработки изменившегося входа.

**Главная мысль:** Наблюдайте нужный параметр, если от него зависит загрузка.
