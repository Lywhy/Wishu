**Пакетирование обновлений и ожидание Vue DOM flush.**

Реактивное значение меняется синхронно, а DOM-обновления Vue группирует в очередь. Поэтому чтение DOM сразу после присваивания может вернуть прежний результат. await nextTick после изменения ожидает соответствующий цикл обновления DOM. Это не обещание завершения fetch, CSS-анимации или отрисовки кадра браузером. Для измерения элемента после конкретного watcher может быть удобен flush: "post".

### Пример и разбор

```js
import { nextTick } from "vue"
async function openEditor() {
  editing.value = true
  await nextTick()
  input.value?.focus()
}
```

Ссылка input относится к элементу, создаваемому условием editing.

**Типичная ошибка:** Заменять nextTick случайным setTimeout или ожидать от nextTick сетевого ответа.

**Главная мысль:** NextTick ожидает обновления Vue, а не завершения всей асинхронной работы.
