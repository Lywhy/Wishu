**Ограниченный императивный интерфейс ребёнка.**

Компонент с script setup закрыт по умолчанию для доступа через родительский template ref. defineExpose объявляет доступные методы и значения. Это полезно для focus, scrollTo или интеграции с редактором; бизнес-данные обычно удобнее передавать props/events. Ссылка доступна после mount и может быть null. Expose объявляют до await. Раскрытые refs на публичном экземпляре автоматически разворачиваются.

### Пример и разбор

```js
// В script setup ребёнка
const input = ref(null)
function focus() {
  input.value?.focus()
}
defineExpose({ focus })
```

Родитель после монтирования вызывает editor.value?.focus(), не меняя внутреннее состояние ребёнка напрямую.

**Типичная ошибка:** Раскрывать всё внутреннее состояние и связывать родителя с реализацией каждого поля.

**Главная мысль:** Expose оставляет небольшой публичный API для императивных операций.
