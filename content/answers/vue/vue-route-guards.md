**Навигационный контроль без подмены серверной авторизации.**

beforeEach выполняется перед подтверждением перехода. Return false отменяет его, объект адреса перенаправляет, отсутствие запрещающего результата разрешает продолжение; async guard может ожидать данные. Нужно исключить бесконечный redirect на login. beforeEnter относится ко входу в запись и не заменяет обработку смены params. onBeforeRouteLeave может предупредить о несохранённых данных. Скрытие страницы guard не запрещает прямой HTTP-запрос.

### Пример и разбор

```js
router.beforeEach((to) => {
  if (to.meta.requiresAuth && !auth.signedIn && to.name !== "login") {
    return { name: "login", query: { redirect: to.fullPath } }
  }
})
```

auth инициализируется для текущего приложения. Адрес возврата после входа тоже нужно проверять.

**Типичная ошибка:** Считать meta.requiresAuth серверной защитой или смешивать return и многократный вызов next.

**Главная мысль:** Guard управляет интерфейсом; доступ к данным проверяется сервером.
