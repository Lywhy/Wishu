**ref хранит значение в .value и подходит как для примитивов, так и для объектов.** reactive возвращает реактивный Proxy объекта; примитив напрямую передать как реактивный объект нельзя. В обычном шаблонном доступе ref верхнего уровня разворачивается автоматически.

<!-- wishu:answer-block -->

- Если заменить переменную с reactive другим объектом, потребители прежнего Proxy не переключатся автоматически. Для значения, которое удобно заменять целиком, часто выбирают ref. Автоматическое разворачивание ref имеет ограничения, например в массивах и коллекциях.

### Уточнения и границы

ref принимает примитивы и объекты; в JavaScript значение читается через .value. Объект внутри обычного ref также становится глубоко реактивным. reactive принимает объект и возвращает Proxy. При замене переменной с reactive потребители старого Proxy не переключаются автоматически. Менять вложенные поля и массивы во Vue 3 можно обычными присваиваниями: Vue.set для этого не нужен.

### Пример и разбор

```js
import { ref, reactive } from "vue"
const count = ref(0)
const form = reactive({ name: "" })
count.value++
form.name = "Анна"
const rows = ref([])
rows.value = [{ id: 1 }]
```

Замена rows.value уведомляет потребителей контейнера.

**Типичная ошибка:** Присваивать новый объект переменной reactive и ожидать переноса всех старых зависимостей.

**Главная мысль:** Ref удобен для заменяемого значения, reactive - для объекта со стабильной ссылкой.
