**Клиентская навигация и настройка сервера статики.**

createWebHistory использует обычные URL без #. При прямом запросе /users/42 веб-сервер должен вернуть index.html, чтобы клиентский router разобрал адрес. createWebHashHistory помещает маршрут во фрагмент, который серверу не отправляется, и обычно не требует такого fallback. При размещении в подпапке base сборщика и router должны совпадать. Fallback для SPA не должен перехватывать API и превращать отсутствие JS-файла в HTML-ответ.

<!-- wishu:answer-block -->

### Пример и разбор

```js
const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes,
})
```

Проверять нужно не только клик по ссылке, но и прямой URL, refresh и Back/Forward.

**Типичная ошибка:** Исправлять серверный 404 добавлением нового клиентского компонента без настройки отдачи index.html.

**Главная мысль:** Прямой вход по маршруту должен возвращать оболочку SPA.
