**Отслеживание чтений и уведомление при записи.**

Во время рендера, computed и реактивного эффекта чтения регистрируют зависимости. Proxy перехватывает доступ к свойствам reactive, а ref отслеживает .value. Запись уведомляет зависимые эффекты; Vue планирует обновление, а не перерисовывает всю страницу немедленно. Условные ветви влияют на набор прочитанных зависимостей. Обычная локальная переменная и изменение исходного raw-объекта вне Proxy не дают того же уведомления.

### Пример и разбор

```js
const enabled = ref(false)
const count = ref(0)
const label = computed(() => (enabled.value ? count.value : "выключено"))
```

Пока enabled ложен, getter не читает count. После включения count становится зависимостью.

**Типичная ошибка:** Считать, что Vue статически наблюдает за всеми переменными файла или за любым присваиванием в JavaScript.

**Главная мысль:** Реактивность связывает выполненное чтение с активным эффектом.
