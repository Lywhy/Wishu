**Локальное состояние ошибки и границы наблюдения Vue.**

Ожидаемые ошибки запроса обычно обрабатывают в action/composable с loading/error/data и возможностью повторить. HTTP-ошибку fetch определяют по response.ok: статус 404 сам по себе не отклоняет Promise. onErrorCaptured наблюдает ошибки потомков, app.config.errorHandler подходит для общего логирования. Возврат false из errorCaptured останавливает дальнейшее распространение ошибки. Ошибка загрузки async-компонента имеет свой fallback. Suspense не заменяет универсальную обработку ошибок.

### Пример и разбор

```js
const failed = ref(false)
onErrorCaptured((error, instance, info) => {
  failed.value = true
  reportError(error, info)
  return false
})
```

При failed шаблон должен убрать проблемного потомка и показать безопасный fallback, иначе возможен повтор ошибки.

**Типичная ошибка:** Рендерить того же падающего ребёнка внутри fallback или отправлять в лог чувствительные пользовательские данные.

**Главная мысль:** Ошибка должна иметь владельца, понятный UI и путь восстановления.
