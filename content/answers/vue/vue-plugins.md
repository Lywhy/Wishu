**Расширение конкретного приложения до монтирования.**

Плагин - функция установки либо объект с install(app, options). Он может зарегистрировать компоненты, директивы или зависимости через app.provide. app.use передаёт опции и не устанавливает один и тот же плагин многократно в одном приложении. Общие сервисы удобнее получать через явный inject, чем скрыто читать глобальное поле. Для SSR сервисы и изменяемое состояние должны учитывать отдельные приложения на запрос.

### Пример и разбор

```js
const apiPlugin = {
  install(app, client) {
    app.provide(apiKey, client)
  },
}
createApp(App).use(apiPlugin, apiClient).mount("#app")
```

apiKey - общий Symbol, apiClient - подготовленный клиент API.

**Типичная ошибка:** Создавать плагин только ради регистрации каждой локальной функции или делить пользовательское состояние всех SSR-запросов.

**Главная мысль:** Плагин настраивает приложение, а не заменяет локальные зависимости.
