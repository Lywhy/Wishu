**Источник состояния формы и особенности контролов.**

На текстовом input v-model связывает value и input, на checkbox/radio - checked и change, на select - value и change. Один checkbox обычно хранит boolean; несколько checkbox с общей моделью могут наполнять массив. :value позволяет передавать не только строки. .lazy переключает синхронизацию текста на change, .trim убирает пробелы, .number пытается преобразовать число, но пустой ввод остаётся пустой строкой.

<!-- wishu:answer-block -->

### Пример и разбор

```vue
<input v-model.trim="name" />
```

roles инициализируется массивом, selectedId - null.

**Типичная ошибка:** Ожидать, что value в HTML переопределит начальную модель, или считать .number полноценной валидацией.

**Главная мысль:** Начальное значение формы задаётся в реактивном состоянии.
