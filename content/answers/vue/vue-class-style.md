**Объектные и массивные привязки оформления.**

Привязка class принимает строку, объект с условиями и массив сочетаний. Её можно объединить со статическим class. Объект style задаёт CSS-свойства, обычно в camelCase; для размеров явно указывайте единицы. Производный набор классов можно вынести в computed. На компонентах передача class также зависит от fallthrough attrs и выбранного корня.

### Пример и разбор

```vue
<p
  class="message"
  :class="{ error: invalid, muted: busy }"
  :style="{ maxWidth: width + 'px' }"
>{{ text }}</p>
```

При изменении invalid Vue обновит соответствующий класс.

**Типичная ошибка:** Одновременно изменять classList вручную и управлять теми же классами из шаблона.

**Главная мысль:** Оформление выводится из состояния, а не меняется вручную параллельно Vue.
