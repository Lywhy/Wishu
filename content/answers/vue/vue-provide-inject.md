**Зависимости поддерева и ближайший провайдер.**

provide/inject передаёт данные через несколько уровней без технических промежуточных props. Провайдер может быть компонентом или приложением; при совпадении ключа выбирается ближайший предок. Symbol уменьшает риск коллизий. Переданный ref остаётся ref и сохраняет реактивность, а простой переданный примитив не превращается в живую ссылку. Удобно отдавать readonly-состояние и функцию изменения владельца.

### Пример и разбор

```js
// В setup провайдера; formKey экспортирован из общего модуля
provide(formKey, { name: readonly(name), setName })
// В setup потомка
const form = inject(formKey)
if (!form) throw new Error("Нет провайдера формы")
```

Контракт должен оговаривать поведение при отсутствии провайдера.

**Типичная ошибка:** Создавать Symbol заново на каждой стороне или использовать inject как бесконтрольный глобальный store.

**Главная мысль:** Inject получает зависимость ближайшего провайдера, сохраняя её контракт.
