**Локальные импорты и глобальная регистрация.**

В <script setup> импортированный компонент сразу доступен шаблону. В Options API локальная регистрация задаётся через components. Глобальная регистрация app.component делает компонент доступным внутри приложения, но скрывает зависимости и может мешать исключению неиспользуемого кода. В SFC удобно имя PascalCase; в шаблонах непосредственно в HTML нужно учитывать приведение имён тегов браузером к нижнему регистру.

<!-- wishu:answer-block -->

### Пример и разбор

```vue
<script setup>
import UserCard from "./UserCard.vue"
</script>
<template><UserCard :user="{ name: 'Анна' }" /></template>
```

Другим компонентам этот импорт сам по себе UserCard не регистрирует.

**Типичная ошибка:** Считать импорт родителя автоматической глобальной регистрацией для всего дерева.

**Главная мысль:** Зависимости компонента лучше видеть в его локальных импортах.
