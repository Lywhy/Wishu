**Computed описывает производное значение и кеширует результат до изменения прочитанных реактивных зависимостей.** Метод выполняется при вызове во время рендера и сам по себе такого кеша не предоставляет.

<!-- wishu:answer-block -->

- Getter computed должен быть чистым: не отправлять запросы и не менять другое состояние. Нереактивные значения, например Date.now(), сами не инвалидируют computed. Для синхронизации с внешним миром нужен watcher или обработчик, а не побочный эффект в вычислении.

### Уточнения и границы

computed возвращает ref с результатом getter и кеширует вычисление по прочитанным реактивным зависимостям. Метод вызывается при каждом его выполнении в рендере. Изменение Date.now() само не инвалидирует computed. Getter должен быть синхронным и чистым: запрос, мутация исходного массива через sort и запись в другое состояние ему не подходят. Для двустороннего преобразования возможен computed с get/set, но источник остаётся явно определённым.

### Пример и разбор

```js
import { ref, computed } from "vue"
const users = ref([])
const sorted = computed(() => [...users.value].sort((a, b) => a.name.localeCompare(b.name)))
```

Копия предотвращает изменение исходного массива во время вычисления.

**Типичная ошибка:** Делать async getter и ожидать, что computed автоматически станет состоянием загрузки Promise.

**Главная мысль:** Computed описывает данные, а не выполняет команду.
