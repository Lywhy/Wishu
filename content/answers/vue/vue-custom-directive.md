**Низкоуровневое поведение DOM без собственной разметки.**

Компонент отвечает за структуру и контракт UI, composable - за повторное использование реактивной логики, директива - за непосредственное поведение DOM-элемента. Хуки mounted, updated и unmounted получают элемент и binding. Значение доступно через binding.value, аргумент и модификаторы - через отдельные поля. Созданный listener или observer требует cleanup. Применение директивы к компоненту с несколькими корнями неоднозначно, поэтому обычно выбирают обычный элемент.

### Пример и разбор

```vue
<script setup>
const vFocus = { mounted: (el) => el.focus() }
</script>
<template><input v-focus /></template>
```

В script setup имя vFocus связывается с v-focus.

**Типичная ошибка:** Превращать директиву в скрытый компонент с собственным сложным деревом и бизнес-состоянием.

**Главная мысль:** Директива инкапсулирует DOM-операцию, а не весь интерфейс.
