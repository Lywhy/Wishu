**Явный событийный API без DOM-всплытия.**

defineEmits описывает события и возвращает emit. Аргументы после имени передаются обработчику. События компонентов не всплывают по дереву как DOM-события: промежуточный компонент должен переслать их явно. Объявленный listener исключается из fallthrough attrs. Если объявить click как событие компонента, родительский @click слушает emit("click"), а не автоматически нативный click корня. Runtime-validator предупреждает о неверном payload, но не является запретом выполнения emit.

### Пример и разбор

```js
const emit = defineEmits(["select"])
function choose(item) {
  emit("select", item.id)
}
```

Родитель: <Picker @select="id => selectedId = id" />.

**Типичная ошибка:** Ожидать автоматического получения события внука или дублировать нативный click и emit из-за неописанного контракта.

**Главная мысль:** Событие компонента слышит непосредственный слушатель его контракта.
