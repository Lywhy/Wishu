**Объектный литерал создаёт объект выражением в фигурных скобках.**

<!-- wishu:answer-block -->

### Как это работает

Можно явно задать пару key: value, использовать вычисляемый ключ [expression], записать метод method() {} или accessor. Если имя свойства совпадает с именем переменной, { x } сокращает запись { x: x }.

Shorthand читает текущее значение переменной при создании объекта и не создаёт живую связь с ней. Если значением является объект, копируется значение ссылки, поэтому вложенный объект остаётся общим.

Обычные свойства, созданные литералом, перечисляемы и конфигурируемы; data-свойства также допускают запись.

### Пример и его разбор

```javascript
let x = 1
const y = 2
const key = "label"
const point = {
  x,
  y,
  [key]: "A",
  sum() {
    return this.x + this.y
  },
}
x = 10
point.x // 1
point.label // "A"
point.sum() // 3
```

Литерал сразу описывает данные и поведение нового объекта. Сокращённая запись сохраняет текущее значение переменной, поэтому последующее присваивание x не меняет point.x. Вычисляемый ключ выбирается при создании, а метод sum читает поля того объекта, который стал получателем вызова.
