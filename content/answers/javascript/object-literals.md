**Объектный литерал создаёт объект выражением в фигурных скобках.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Можно явно задать пару key: value, использовать вычисляемый ключ [expression], записать метод method() {} или accessor.

- Если имя свойства совпадает с именем переменной, { x } сокращает запись { x: x }.

- Shorthand читает текущее значение переменной при создании объекта и не создаёт живую связь с ней.

- Если значением является объект, копируется значение ссылки, поэтому вложенный объект остаётся общим.

- Обычные свойства, созданные литералом, перечисляемы и конфигурируемы; data-свойства также допускают запись.
