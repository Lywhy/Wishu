**Для конечного графа простых объектов можно хранить посещённые узлы по ссылке и пропускать уже обработанные. Явный стек дополнительно позволяет не зависеть от глубины рекурсивного `call` stack.**

### Как это работает

Сначала определите рёбра графа. `Object.values` не включает все возможные виды ссылок: `Map`, `Set`, `Symbol`-свойства и внутренние слоты требуют собственного правила. Чтение `getter` или Proxy может выполнить код.

`WeakSet` не превращает потенциально бесконечный или изменяющийся граф в безопасный неограниченный обход. Для недоверенного входа нужны лимиты времени/размера и валидируемая модель.

### Пример и его разбор

```javascript
function countPlainNodes(root) {
  const seen = new WeakSet(),
    stack = [root]
  let count = 0
  while (stack.length) {
    const node = stack.pop()
    if (!node || typeof node !== "object" || seen.has(node)) continue
    seen.add(node)
    count++
    for (const child of Object.values(node)) stack.push(child)
  }
  return count
}
```

Перед добавлением дочерних значений узел попадает в seen, поэтому обратная ссылка на него не вызывает повторной обработки. Явный stack хранит работу без роста рекурсивной глубины. При этом `Object.values` задаёт конкретное правило рёбер: для `Map`, `Set` и скрытых ссылок его недостаточно. Сначала определяют модель графа, затем оценивают завершение и стоимость обхода.

### Типичная ошибка

> Применять рекурсивный обход всех values к любому неизвестному объекту без защиты от циклов.
