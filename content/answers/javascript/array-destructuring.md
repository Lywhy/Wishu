**В массивном шаблоне пустая позиция между запятыми пропускает очередное значение: const [first, , third] = values.**

<!-- wishu:answer-block -->

### Как это работает

Деструктуризация использует протокол итерации, поэтому подходит не только массивам, но и другим iterable. Она не удаляет пропущенные элементы из исходного массива.

Значение по умолчанию используется при полученном `undefined`, включая отсутствие элемента, но не при `null`. Rest-элемент ...rest собирает оставшиеся значения в новый массив и должен быть последним.

Полученные объектные значения не клонируются. Имена переменных не влияют на выбор позиции: важен сам шаблон.

### Пример и его разбор

```javascript
const values = [10, 20, 30, 40]
const [first, , third, ...rest] = values
first // 10
third // 30
rest // [40]
const [fallback = "нет"] = []
fallback // "нет"
values // [10, 20, 30, 40]
```

Пустая позиция шаблона всё равно продвигает итератор, но не создаёт привязку для второго значения. Поэтому third получает 30, а rest собирает оставшийся 40. Исходный values при этом не удаляет элементы. Default для fallback применяется к полученному `undefined` и не означает замену всех falsy-значений.
