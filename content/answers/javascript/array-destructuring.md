**В массивном шаблоне пустая позиция между запятыми пропускает очередное значение: const [first, , third] = values.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Деструктуризация использует протокол итерации, поэтому подходит не только массивам, но и другим iterable.

- Она не удаляет пропущенные элементы из исходного массива.

- Значение по умолчанию используется при полученном `undefined`, включая отсутствие элемента, но не при `null`.

- Rest-элемент ...rest собирает оставшиеся значения в новый массив и должен быть последним.

- Полученные объектные значения не клонируются.

- Имена переменных не влияют на выбор позиции: важен сам шаблон.
