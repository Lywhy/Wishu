**`some` проверяет, существует ли хотя бы один элемент, для которого предикат даёт truthy-значение.**

<!-- wishu:answer-block -->

### Как это работает

`every` проверяет, что предикат проходит для всех проверяемых элементов. Оба возвращают boolean, а не сами элементы; предикат получает значение, индекс и массив.

`some` останавливается при первом успехе, `every` - при первой неудаче. Для пустого массива `some` возвращает `false`, `every` - `true`: нет элемента, нарушающего условие.

Оба пропускают отсутствующие позиции обычного разрежённого массива. Они не ожидают `async`-предикат: возвращённый `Promise` сам по себе truthy, независимо от своего будущего результата.

### Пример и его разбор

```javascript
const values = [2, 4, 6]
values.some((value) => value > 5) // true
values.every((value) => value % 2 === 0) // true
;[].some(() => true) // false
;[].every(() => false) // true
```

`some` достаточно одного значения больше 5, а `every` должен не найти ни одного нечётного значения. Поэтому оба условия в первом массиве истинны по разным причинам. На пустом массиве существование подходящего элемента опровергается, а нарушения общего правила нет. Если бизнес-условие требует ещё и непустой список, длину проверяют отдельно.
