**some проверяет, существует ли хотя бы один элемент, для которого предикат даёт truthy-значение.**

### Что важно объяснить

- Every проверяет, что предикат проходит для всех проверяемых элементов.

- Оба возвращают boolean, а не сами элементы; предикат получает значение, индекс и массив.

- Some останавливается при первом успехе, every - при первой неудаче.

- Для пустого массива some возвращает false, every - true: нет элемента, нарушающего условие.

- Оба пропускают отсутствующие позиции обычного разрежённого массива.

- Они не ожидают async-предикат: возвращённый Promise сам по себе truthy, независимо от своего будущего результата.
