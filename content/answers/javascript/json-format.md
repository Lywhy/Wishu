**JSON - текстовый формат для объектов, массивов, строк, чисел, boolean и `null`.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Имена свойств и строки записываются в двойных кавычках; комментарии, trailing comma, `undefined` и функции в JSON недопустимы.

- JSON.parse читает текст, JSON.stringify создаёт JSON-текст из поддерживаемых значений.

- Сериализация может терять информацию: свойства со значениями `undefined`, function и symbol пропускаются, а такие элементы массива становятся `null`. `NaN` и бесконечности превращаются в `null`. `BigInt` и циклические ссылки по умолчанию вызывают ошибку; Date обычно превращается в строку через toJSON.

- Поэтому JSON не универсальный способ глубокого копирования.
