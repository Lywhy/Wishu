**`===` сравнивает без приведения типов, `==` допускает преобразования по правилам языка.** Разные объекты не становятся равными из-за одинакового содержимого.

<!-- wishu:answer-block -->

### Сравнение на примерах

| Выражение | Результат | Причина |
| --- | --- | --- |
| `0 === "0"` | `false` | Разные типы |
| `0 == "0"` | `true` | Строка приводится к числу |
| `null == undefined` | `true` | Специальное правило нестрогого равенства |
| `null === undefined` | `false` | Разные типы |
| `NaN === NaN` | `false` | Особое числовое значение |
| `+0 === -0` | `true` | Знак нуля не учитывается |

<!-- wishu:answer-block -->

### Выбор в обычном коде

- По умолчанию используйте `===`, чтобы сравнение не зависело от скрытых преобразований.
- Намеренное `value == null` проверяет `null` и `undefined`; необычный браузерный объект `document.all` - отдельный исторический случай.
- Для сравнения содержимого объектов нужен отдельный алгоритм, соответствующий модели данных.
