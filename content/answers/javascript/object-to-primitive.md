**При необходимости получить примитив язык сначала проверяет метод Symbol.toPrimitive.** Он получает подсказку `number`, `string` или `default` и должен вернуть примитив.

<!-- wishu:answer-block -->

### Порядок преобразования

- Без специального метода обычный путь с подсказкой number обычно пробует `valueOf`, затем `toString`.
- Для string порядок обратный: сначала `toString`, затем `valueOf`.
- Для большинства обычных объектов default обрабатывается как number; Date имеет собственную особенность.
- Если подходящий путь не вернул примитив, возникает `TypeError`.
- Подсказка number не требует обязательно вернуть Number: допустим другой примитив, а дальнейшее преобразование зависит от оператора.
