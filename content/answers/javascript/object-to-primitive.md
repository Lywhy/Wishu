**При необходимости получить примитив язык сначала проверяет метод Symbol.toPrimitive.** Он получает подсказку `number`, `string` или `default` и должен вернуть примитив.

<!-- wishu:answer-block -->

### Порядок преобразования

Без специального метода обычный путь с подсказкой number обычно пробует `valueOf`, затем `toString`. Для string порядок обратный: сначала `toString`, затем `valueOf`.

Для большинства обычных объектов default обрабатывается как number; Date имеет собственную особенность. Если подходящий путь не вернул примитив, возникает `TypeError`.

Подсказка number не требует обязательно вернуть Number: допустим другой примитив, а дальнейшее преобразование зависит от оператора.

### Пример и его разбор

```javascript
const price = {
  [Symbol.toPrimitive](hint) {
    return hint === "string" ? "100 ₽" : 100
  },
}
String(price) // "100 ₽"
Number(price) // 100
price + 20 // 120
```

В примере один объект поддерживает и человекочитаемое отображение, и арифметику. String передаёт подсказку string, а числовое преобразование и сложение выбирают другое представление. Метод должен вернуть примитив: после этого оператор продолжает работу уже с полученным значением по своим правилам.

### Типичная ошибка

> Возвращать объект из `Symbol.toPrimitive` или считать, что + всегда вызывает только toString.
