**DispatchEvent синхронно доставляет созданное событие подходящим обработчикам. Такое событие не является полным воспроизведением реального пользовательского взаимодействия и его платформенных разрешений.**

### Механизм и границы

IsTrusted сообщает о происхождении по правилам браузера, но не доказывает полномочия пользователя на сервере. Нельзя открывать доступ к данным только проверкой этого поля. CustomEvent.detail передаёт обычные данные без автоматического structured clone.

Бросок из event listener имеет свой путь сообщения об ошибке: внешний try/catch вокруг dispatchEvent не стоит считать универсальным перехватом всех listener-ошибок.
