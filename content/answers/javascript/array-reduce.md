**`reduce` последовательно вычисляет один результат из элементов.**

<!-- wishu:answer-block -->

### Как это работает

Callback получает аккумулятор, текущий элемент, индекс и массив; его возвращаемое значение становится аккумулятором следующего шага. Результатом может быть число, строка, объект или другая структура, а не обязательно сумма.

С initialValue вычисление начинается с заданного аккумулятора. Без него первый существующий элемент становится аккумулятором и не обрабатывается callback как текущий.

Если существующих элементов нет, без initialValue будет TypeError; с ним вернётся начальное значение. Пропуски не обрабатываются.

Начальное значение делает контракт и поведение на пустом массиве явными.

### Пример и его разбор

```javascript
const total = [10, 20, 30].reduce((sum, value) => sum + value, 0)
total // 60
;[].reduce((sum, value) => sum + value, 0) // 0
const quantities = [{ count: 2 }, { count: 3 }]
quantities.reduce((sum, item) => sum + item.count, 0) // 5
```

Аккумулятор начинается с 0 и последовательно становится 10, 30 и 60. На пустом массиве возвращается тот же начальный ноль, поскольку шагов нет. В quantities аккумулятор остаётся числом, хотя элементы являются объектами. Явное начальное значение задаёт этот контракт и предотвращает случайное использование первого объекта как готовой суммы.
