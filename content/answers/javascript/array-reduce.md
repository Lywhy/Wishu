**reduce последовательно вычисляет один результат из элементов.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Callback получает аккумулятор, текущий элемент, индекс и массив; его возвращаемое значение становится аккумулятором следующего шага.

- Результатом может быть число, строка, объект или другая структура, а не обязательно сумма.

- С initialValue вычисление начинается с заданного аккумулятора.

- Без него первый существующий элемент становится аккумулятором и не обрабатывается callback как текущий.

- Если существующих элементов нет, без initialValue будет TypeError; с ним вернётся начальное значение.

- Пропуски не обрабатываются.

- Начальное значение делает контракт и поведение на пустом массиве явными.
