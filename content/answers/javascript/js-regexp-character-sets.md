**Символьный класс выбирает допустимый элемент набора, а не последовательность из всех перечисленных знаков. Unicode property escapes помогают описать свойства вроде категории Letter в подходящем Unicode-режиме.**

<!-- wishu:answer-block -->

### Как это работает

\w и граница \b не являются универсальным словарём слов любого языка. Диапазон A-Z не включает все буквы Unicode. Флаг v расширяет возможности наборов и имеет свои правила; не заменяйте u на v без проверки семантики и поддержки.

Даже категория букв не является полноценной проверкой имени человека или идентификатора: комбинируемые знаки и предметные ограничения требуют отдельного решения.

### Пример и его разбор

```javascript
const letters = /^\p{L}+$/u
console.log(letters.test("Привет")) // true
// Для пользовательских имён одной категории Letter может быть недостаточно.
```

Категория Letter допускает кириллические буквы, в отличие от диапазона A-Z. Якоря требуют, чтобы весь ввод состоял из таких символов. При этом имя с комбинируемым знаком или допустимым дефисом потребует другого согласованного набора.

### Типичная ошибка

> Валидировать международный текст только через [A-Za-z] или считать \b универсальной границей слова.
