**`reverse` меняет порядок элементов в самом массиве и возвращает этот же массив. `toReversed` возвращает новый массив в обратном порядке, сохраняя исходный.**

<!-- wishu:answer-block -->

### Как это работает

Это позволяет выбрать, нужна ли мутация или новый результат. Оба метода переставляют значения без глубокого клонирования объектов.

У разрежённых массивов есть различие: `reverse` сохраняет пропуски как отсутствующие позиции, а `toReversed` записывает `undefined` в соответствующие позиции нового плотного массива. Получить новый массив можно и через [...array].reverse(), но важно понимать, что копия создаётся именно spread.

### Пример и его разбор

```javascript
const values = [1, 2, 3]
const reversed = values.toReversed()
reversed // [3, 2, 1]
values // [1, 2, 3]
const same = values.reverse()
same === values // true
values // [3, 2, 1]
```

После `toReversed` у программы одновременно существуют исходный порядок и новый обратный массив. `reverse` меняет именно values и возвращает ту же ссылку, поэтому проверка идентичности даёт true. Новая внешняя коллекция не означает независимости вложенных объектов: при дальнейшем изменении их свойств обе последовательности могут наблюдать один и тот же объект.
