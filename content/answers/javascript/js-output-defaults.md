Значение по умолчанию при деструктуризации используется только для undefined, в том числе отсутствующего свойства. null остаётся null. Оператор || выбирает правую часть для любого falsy-значения, включая 0, пустую строку и false. Оператор ?? использует правую часть только для null или undefined.

При настройке числового лимита или булевой опции сначала определите, являются ли 0 и false допустимыми значениями. От этого зависит правильный оператор.
