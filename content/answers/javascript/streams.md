**ReadableStream выдаёт последовательность чанков, WritableStream принимает их.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Это позволяет обрабатывать данные постепенно, не собирая весь результат в памяти.

- Reader или writer получает блокировку потока на время работы; read возвращает Promise с value и done, write сообщает о завершении записи чанка.

- PipeTo связывает чтение и запись с обработкой backpressure, ошибок и завершения по своему контракту.

- Отмена чтения, abort записи и освобождение блокировки - разные действия.

- Для ручной записи важно ожидать write, чтобы не создавать неограниченную очередь.

- Fetch response.body - один из примеров читаемого потока.
