**Модуль обычно вычисляется один раз для своей идентичности в соответствующем графе/среде. Разные записи, разрешающиеся к одному модулю, разделяют его состояние; другой URL может означать другую инстанцию.**

### Механизм и границы

Query-части и правила host имеют значение. Нельзя безоговорочно обещать один экземпляр на весь процесс, все Worker и все iframe: у них разные контексты и загрузчики.

Dynamic import возвращает пространство имён, а повторный вызов экспортированной функции всё равно выполняет её тело. Не путайте кеш модуля с кешем результатов функций или HTTP-кешем ресурса.
