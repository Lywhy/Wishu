**Каррирование преобразует функцию нескольких аргументов в цепочку функций по одному аргументу: f(a, b, c) превращается в f(a)(b)(c).**

### Как это работает

Частичное применение заранее фиксирует часть аргументов и возвращает функцию для остальных; она не обязана принимать их по одному. Прикладные библиотеки иногда называют curry более гибкий интерфейс, допускающий несколько аргументов за шаг, поэтому нужно смотреть контракт реализации. `bind` может частично применить начальные аргументы, одновременно задавая this.

Каррирование само по себе не является кешированием результата: оно меняет форму передачи аргументов.

### Пример и его разбор

```javascript
const add = (a, b, c) => a + b + c
const curriedAdd = (a) => (b) => (c) => add(a, b, c)
curriedAdd(1)(2)(3) // 6

const addOne = (b, c) => add(1, b, c)
addOne(2, 3) // 6: частичное применение
```

В curriedAdd каждый вызов фиксирует один аргумент и возвращает следующий шаг, пока не хватает данных для вычисления. AddOne сразу фиксирует только a, а остальные аргументы принимает вместе. Оба примера дают 6, но предоставляют разные интерфейсы использования. Никакого повторного использования готового результата здесь нет: это организация аргументов, а не мемоизация.
