**for объединяет инициализацию, условие продолжения и шаг; удобен для явного счётчика. while проверяет условие до тела и может не выполниться ни разу. do...while проверяет условие после тела, поэтому тело выполняется хотя бы один раз.**

### Как это работает

Для итерируемых значений есть for...of, для перечисляемых строковых ключей объекта - for...in. `forEach` - метод массива, а не отдельный цикл языка: break и continue внутри callback не управляют его обходом. Важно обеспечить достижение условия завершения и выбирать конструкцию под структуру данных.

### Пример и его разбор

```javascript
for (let i = 0; i < 3; i += 1) {
  console.log(i) // 0, затем 1, затем 2
}
let attempts = 0
do {
  attempts += 1
} while (attempts < 1)
```

Первый цикл явно меняет счётчик после каждого прохода и прекращается перед значением 3. Второй проверяет условие только после тела, поэтому одна попытка произойдёт даже при немедленном завершении. Выбор конструкции выражает намерение: известный диапазон, повторение до условия или получение значений из последовательности. Во всех случаях нужно обеспечить продвижение к завершению.
