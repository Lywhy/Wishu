**Обычный объект наследует `Object.prototype.toString`, который обычно возвращает строку вида "[object Object]".**

<!-- wishu:answer-block -->

### Как это работает

Встроенные типы могут переопределять метод: например, массив по умолчанию превращает элементы в строку с запятыми. Свой метод `toString` позволяет задать понятное текстовое представление и участвует в преобразовании объекта к примитиву по правилам языка.

`Object.prototype.toString`.call(value) вызывает именно базовый метод и может дать метку вроде "[object Array]". Однако `Symbol.toStringTag` позволяет повлиять на такую метку, поэтому это не универсальная достоверная проверка типа. `toString` не сериализует структуру объекта и не заменяет `JSON.stringify`; наличие `Symbol.toPrimitive` также может изменить правила преобразования.

### Пример и его разбор

```javascript
const user = {
  name: "Аня",
  toString() {
    return `Пользователь: ${this.name}`
  },
}
String(user) // "Пользователь: Аня"
Object.prototype.toString.call(user) // "[object Object]"
Object.prototype.toString.call([]) // "[object Array]"
```

String(user) в примере использует пользовательское текстовое представление, а явный вызов базового метода даёт стандартную метку объекта. Эти результаты отвечают разным задачам: первый удобен для вывода, второй описывает встроенную классификацию с оговорками. Ни один не сохраняет все поля для последующего восстановления объекта.
