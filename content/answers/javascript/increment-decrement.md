**Инкремент увеличивает значение на единицу, декремент уменьшает.**

### Как это работает

Префиксная форма ++x возвращает новое значение, постфиксная x++ - прежнее. В обоих случаях переменная изменяется.

Операторы работают с изменяемой целью присваивания и преобразуют значение к Number или `BigInt`. Их нельзя применять к литералу или переназначать через них const.

Побочные эффекты внутри сложных выражений ухудшают читаемость; отдельное изменение счётчика обычно понятнее.

### Пример и его разбор

```javascript
let value = 1
const before = value++ // before: 1, value: 2
const after = ++value // after: 3, value: 3
value-- // value: 2
```

В первой строке с value++ переменная уже увеличивается до 2, но присваиваемый результат выражения остаётся равным 1. В следующей строке ++value сначала получает 3 и отдаёт именно его. Таким образом, различие относится к значению выражения, а не к тому, произойдёт ли изменение переменной. Разделение изменения и использования обычно делает такой код понятнее.
