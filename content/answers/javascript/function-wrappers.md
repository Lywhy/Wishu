**Обёртка вызывает другую функцию, добавляя логику до, после или вместо части вызова.**

<!-- wishu:answer-block -->

### Как это работает

Функциональный декоратор принимает функцию и возвращает обёртку, например для логирования, проверки аргументов или измерения времени. Здесь речь о приёме работы с функциями, а не о синтаксисе декораторов классов.

Прозрачная обёртка должна передавать аргументы, сохранять нужный `this`, возвращать результат и не терять исключения. Для произвольного вызывающего `this` нужна обычная функция с fn.apply(`this`, args).

Обёртка не сохраняет автоматически name, `length`, возможность `new` и все свойства исходной функции; измерение `Promise` требует отдельно учитывать момент его завершения.

### Пример и его разбор

```javascript
function withCallCount(fn) {
  let calls = 0
  return function (...args) {
    calls += 1
    console.log("Вызов", calls)
    return fn.apply(this, args)
  }
}
const sum = withCallCount((a, b) => a + b)
sum(2, 3) // 5; также выводит счётчик
```

withCallCount создаёт состояние счётчика для одной обёртки и возвращает обычную функцию. Она добавляет логирование, затем передаёт исходной fn текущий `this` и аргументы и возвращает результат вызова. Если забыть этот `return`, внешние потребители получат `undefined` вместо результата. Для `Promise` отдельно различают время вызова и время завершения операции.
