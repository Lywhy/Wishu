**`querySelector` разбирает CSS-селектор. Произвольный id может содержать знаки, которые имеют в этой грамматике особый смысл, поэтому его нельзя всегда добавлять после # без обработки.**

### Как это работает

Для обычного поиска по точному id можно выбрать getElementById. При построении selector используйте CSS.escape для соответствующей части. Это не универсальное экранирование HTML, URL или полного произвольного selector-приложения.

Не создавайте сложный селектор из нескольких недоверенных фрагментов и не считайте один вызов escape достаточным без понимания границ.

### Пример и его разбор

```javascript
function byId(id) {
  return document.getElementById(id)
}
function bySelectorId(id) {
  return document.querySelector("#" + CSS.escape(id))
}
```

Первый вариант ищет точное имя без CSS-грамматики. Второй строит селектор, поэтому предварительно экранирует именно идентификатор. CSS.escape решает эту конкретную задачу и не подходит как универсальная защита строк для HTML, JavaScript или URL.

### Типичная ошибка

> Склеивать # с произвольным значением и считать любой id готовым селектором.
