**Плотным обычно называют массив, в котором каждой позиции от 0 до `length` - 1 соответствует элемент.**

<!-- wishu:answer-block -->

### Как это работает

У разрежённого массива часть индексных свойств отсутствует: это пропуски, а не записанные значения `undefined`. Поэтому `length` - не число реально существующих элементов.

У обычного изменяемого массива уменьшение `length` удаляет элементы за новой границей, а увеличение создаёт пропуски без заполнения значениями. Длина должна быть целым числом от 0 до 2^32 - 1.

Некорректное значение вызывает RangeError. Некоторые методы, например `Map` и `forEach`, пропускают отсутствующие позиции; итератор массива и `Array.from` обрабатывают их как `undefined`.

Это различие важно при копировании и обходе.

### Пропуск и унаследованный индекс

Для методов, использующих проверку наличия свойства, важна вся цепочка прототипов: позиция без собственного индексного свойства может быть найдена в прототипе. Поэтому учебное правило «`Map` пропускает дырки» относится к действительно отсутствующим индексам. `includes` читает отсутствующую позицию как `undefined`, тогда как `indexOf` пропускает отсутствующие свойства. Не добавляйте числовые свойства в Array.prototype ради исправления данных.

### Пример и его разбор

```javascript
const values = [10, 20]
values.length = 4
values.length // 4
2 in values // false
values[2] = undefined
2 in values // true
values.length = 1
values // [10]
```

Увеличение `length` до 4 оставляет позиции 2 и 3 без свойств. Запись `undefined` в позицию 2 создаёт свойство, что видно через in, хотя обычное чтение выглядело бы одинаково. Затем уменьшение `length` удаляет элементы за новой границей. Поэтому длина массива описывает диапазон индексов, а не количество реально сохранённых значений.
