**ECMAScript - стандарт языка, на котором основан JavaScript.**

### Как это работает

Он описывает синтаксис, типы, объекты и правила выполнения; DOM и многие браузерные API относятся к другим стандартам среды. ES6 и ES2015 - два названия одной редакции.

ES2015 принёс let/const, стрелки, классы, модули, `Promise`, `Map`/`Set`, `Symbol`, итераторы и генераторы. Это крупное обновление, но «самое важное» - оценка, а не техническое свойство.

Язык развивается ежегодно; наличие новой конструкции в стандарте не означает одинаковую поддержку всех API каждым runtime. Транспиляция синтаксиса и polyfill встроенной возможности решают разные задачи.

### Пример и его разбор

```javascript
const double = (value) => value * 2
const unique = new Set([1, 1, 2])
;[...unique].map(double) // [2, 4]
// DOM API, например document.querySelector, не определяются одним ECMA-262.
```

Пример объединяет несколько языковых возможностей: стрелку, `Set` и итерацию через spread. Они описываются стандартом ECMAScript. Document.querySelector относится уже к браузерной среде, поэтому версия языка и наличие DOM решают разные вопросы совместимости.
