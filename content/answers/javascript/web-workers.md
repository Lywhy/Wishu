**Dedicated Worker выполняет скрипт в отдельном агенте и может параллельно считать данные, не занимая JavaScript главного потока.**

<!-- wishu:answer-block -->

### Что важно объяснить

- У него нет window и доступа к дереву DOM страницы: интерфейс меняет главный поток по полученному результату.

- Доступны многие API для сети и обработки данных.

- Worker и страница обмениваются сообщениями через postMessage и message.

- Данные обычно структурированно клонируются; передача transferable, например ArrayBuffer, перемещает владение и отделяет буфер отправителя.

- Создание Worker и обмен имеют стоимость, поэтому он полезен для подходящей тяжёлой работы, а не каждого мелкого вызова.

- Когда работа больше не нужна, Worker можно завершить.
