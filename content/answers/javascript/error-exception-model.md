**Error - объект для описания проблемы; создание `new` Error само по себе не выбрасывает исключение.**

<!-- wishu:answer-block -->

### Как это работает

Исключение возникает при `throw` или ошибке операции и меняет обычный поток выполнения до подходящего обработчика. В JavaScript выбросить можно и не-Error, но стандартный объект удобнее для сообщения и диагностики.

Синтаксическая ошибка может помешать разобрать весь скрипт до запуска, поэтому try внутри этого же непарсящегося кода не спасает. Однако SyntaxError от `JSON.parse` возникает уже во время выполнения и перехватывается обычным try/catch.

Необработанная синхронная ошибка завершает текущий путь выполнения, но не обязательно весь браузер и все будущие задачи.

### Пример и его разбор

```javascript
const issue = new Error("описание") // пока не выброшена
try {
  JSON.parse("не JSON")
} catch (error) {
  console.log(error instanceof SyntaxError) // true в этом контексте
}
```

Создание issue не прерывает выполнение: это лишь объект с диагностикой. `JSON.parse` затем действительно выбрасывает SyntaxError, который перехватывается catch. В этом случае разбирается входная строка во время работы, поэтому ошибка отличается от невозможности разобрать сам текущий скрипт.
