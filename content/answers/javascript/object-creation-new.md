**Объект можно создать литералом {}, через `Object.create`(prototype) или вызовом конструктора с new.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Литерал удобен для обычных данных; `Object.create` задаёт прототип явно, в том числе `null`.

- Класс описывает конструктор и методы экземпляров.

- При обычном вызове конструктора через new создаётся объект с прототипом Constructor.prototype, а this конструктора указывает на него.

- Если конструктор явно возвращает объект, результатом становится этот объект; возвращаемый примитив обычно игнорируется.

- Классы требуют new, а стрелочные функции нельзя вызывать как конструкторы.
