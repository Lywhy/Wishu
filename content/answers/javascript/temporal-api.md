**Temporal разделяет разные понятия времени: Instant обозначает момент на временной шкале, PlainDate - календарную дату без времени и часового пояса, ZonedDateTime - дату и время в конкретном поясе.**

### Как это работает

Это помогает не подменять дату рождения мгновением в UTC или считать календарный день всегда ровно 24 часами. Основные значения неизменяемы: add и другие преобразования возвращают новый результат.

Для преобразования календарного времени в момент нужны явные правила часового пояса и неоднозначностей переходов. Поддержка пока различается между средами; проверяют целевые runtime и при необходимости используют подходящий polyfill.

Temporal не является уже везде доступной автоматической заменой любого Date.

### Пример и его разбор

```javascript
if (typeof Temporal !== "undefined") {
  const date = Temporal.PlainDate.from("2026-03-01")
  const next = date.add({ days: 1 })
  date.toString() // "2026-03-01"
  next.toString() // "2026-03-02"
}
```

PlainDate хранит календарную дату, поэтому прибавление дня не требует выбора часового пояса. Add возвращает новое значение, сохраняя исходную дату. Если задача описывает реальный момент встречи в определённом поясе, нужен другой тип и явные правила преобразования.
