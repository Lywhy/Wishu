**Результат: **[1, 2, 3]**. Callback немедленно возвращает Promise-объект, который является truthy.**

### Механизм и границы

Filter не ожидает результат Promise и не подменяет его будущим boolean. Для асинхронного условия сначала соберите результаты проверок, затем отфильтруйте по согласованным индексам либо используйте ограниченный async-конвейер.

Решите политику ошибок и параллельности; создание всех проверок сразу не всегда подходит по нагрузке.
