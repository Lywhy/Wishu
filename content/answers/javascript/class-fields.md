**Публичное поле field = expression создаёт собственное свойство экземпляра; поле без инициализатора получает `undefined`.**

### Как это работает

Выражение вычисляется заново для каждого экземпляра, поэтому items = [] создаёт независимый массив. Параметры constructor могут отдельно иметь значения по умолчанию.

Поля базового класса инициализируются до тела его constructor, поля потомка - после возврата super до следующих инструкций конструктора потомка. Поэтому вызов переопределённого метода из родительского конструктора может увидеть ещё не готовые поля потомка.

Инициализация поля использует определение свойства, а не обычное присваивание через унаследованный setter.

### Пример и его разбор

```javascript
class Basket {
  items = []
  label
}
const first = new Basket()
const second = new Basket()
first.items.push("JS")
second.items.length // 0
first.label // undefined
```

Каждый вызов `new` Basket вычисляет собственный массив items. Поэтому `push` у first не меняет second. Поле label существует со значением `undefined`, что отличается от полного отсутствия свойства при проверке собственного состояния объекта.
