**Публичное поле field = expression создаёт собственное свойство экземпляра; поле без инициализатора получает `undefined`.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Выражение вычисляется заново для каждого экземпляра, поэтому items = [] создаёт независимый массив.

- Параметры constructor могут отдельно иметь значения по умолчанию.

- Поля базового класса инициализируются до тела его constructor, поля потомка - после возврата super до следующих инструкций конструктора потомка.

- Поэтому вызов переопределённого метода из родительского конструктора может увидеть ещё не готовые поля потомка.

- Инициализация поля использует определение свойства, а не обычное присваивание через унаследованный setter.
