**delete удаляет собственное свойство объекта, если его дескриптор допускает удаление.**

<!-- wishu:answer-block -->

### Как это работает

Удаление отсутствующего свойства возвращает true. После удаления собственного свойства одноимённое унаследованное свойство может стать видимым. delete не освобождает память напрямую и не предназначен для удаления привязок let, const или var.

Удаление неконфигурируемого свойства возвращает `false` в нестрогом режиме и вызывает TypeError в строгом. delete array[index] оставляет пустое место и не уменьшает `length`; для удаления элемента со сдвигом используют, например, splice.

### Пример и его разбор

```javascript
const user = { name: "Аня" }
delete user.name // true
Object.hasOwn(user, "name") // false
const items = [10, 20]
delete items[0]
items.length // 2
0 in items // false
```

После удаления name объект остаётся тем же, но собственного свойства больше нет. Для массива аналогичное удаление убирает числовое свойство, сохраняя границу `length`, поэтому появляется пропуск. Это важно для последующих обходов: пропуск и элемент со значением `undefined` могут обрабатываться по-разному. Удаление свойства не означает немедленного освобождения памяти движком.
