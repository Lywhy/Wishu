**Navigator предоставляет информацию и некоторые возможности среды: язык, состояние соединения, регистрацию Service Worker и другие интерфейсы.**

### Что важно объяснить

- Конкретный API может требовать безопасный контекст, разрешение пользователя или поддержку браузера.

- UserAgent - ненадёжная основа для выбора поведения: строка может сокращаться или изменяться и не доказывает наличие функции.

- Лучше проверять необходимую возможность.

- Navigator.onLine не гарантирует доступность конкретного сервера: запрос может не пройти при формально активной сети.
