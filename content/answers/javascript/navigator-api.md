**Navigator предоставляет информацию и некоторые возможности среды: язык, состояние соединения, регистрацию Service Worker и другие интерфейсы.**

### Как это работает

Конкретный API может требовать безопасный контекст, разрешение пользователя или поддержку браузера. UserAgent - ненадёжная основа для выбора поведения: строка может сокращаться или изменяться и не доказывает наличие функции.

Лучше проверять необходимую возможность. Navigator.onLine не гарантирует доступность конкретного сервера: запрос может не пройти при формально активной сети.

### Пример и его разбор

```javascript
const language = navigator.language
const supportsWorkers = "serviceWorker" in navigator
const supportsClipboard = "clipboard" in navigator
// Наличие API не отменяет проверки разрешений и обработки ошибок вызова.
```

Проверки в примере отвечают только на вопрос о наличии точек входа. Даже существующий clipboard может отказать из-за разрешений или условий вызова. Поэтому после feature detection всё равно нужен отдельный путь обработки ошибки конкретной операции.
