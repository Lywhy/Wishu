**Rest-параметр ...items собирает оставшиеся фактические аргументы в настоящий массив.**

<!-- wishu:answer-block -->

### Как это работает

Параметры перед ним остаются отдельными, а при отсутствии оставшихся аргументов получается пустой массив. Rest работает и в обычных, и в стрелочных функциях.

Rest-параметр должен быть последним; после него не допускается завершающая запятая, и ему нельзя задать значение по умолчанию. В отличие от arguments, rest содержит только остаток аргументов и сразу поддерживает методы массива.

Та же запись ... при вызове - spread: он разворачивает значения, а не собирает их.

### Пример и его разбор

```javascript
function sum(label, ...values) {
  return { label, total: values.reduce((total, value) => total + value, 0) }
}
sum("итог", 2, 3) // { label: "итог", total: 5 }
sum("пусто") // { label: "пусто", total: 0 }
```

Первый аргумент sum попадает в label, а оставшиеся 2 и 3 образуют массив values. В пустом случае этот массив имеет длину ноль, и `reduce` возвращает явно заданный начальный итог 0. Rest не захватывает уже разобранные параметры и не требует преобразования из arguments, поэтому контракт функции виден прямо в её заголовке.
