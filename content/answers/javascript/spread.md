**Spread (...) разворачивает итерируемое значение в аргументы вызова или элементы массива.**

<!-- wishu:answer-block -->

### Как это работает

В объектном литерале он копирует собственные перечисляемые свойства источника, включая символьные. Это разные контексты: обычный объект можно распаковать в объект, но без итератора нельзя распаковать в массив.

Копирование поверхностное: вложенные объекты остаются общими. Прототип и неперечисляемые свойства не копируются; при совпадении ключей побеждает более поздняя запись.

Rest использует ту же запись ..., но собирает значения при объявлении параметров или деструктуризации.

### Пример и его разбор

```javascript
const values = [1, 2]
const all = [...values, 3]
Math.max(...all) // 3
const original = { nested: { value: 1 } }
const copy = { ...original, active: true }
copy.nested === original.nested // true
```

Разворачивание массива получает очередные значения через итератор, а объектный spread перебирает собственные перечисляемые свойства. Поэтому внешне одинаковые три точки описывают разные операции. В примере copy.nested и original.nested равны по ссылке: копирование поля не означает копирование вложенного объекта. Это важно при обновлении состояния и при передаче данных другому владельцу.
