**Layout, часто называемый reflow, определяет размеры и положение элементов.**

<!-- wishu:answer-block -->

### Как это работает

Paint формирует визуальное содержимое, после чего композиция может собрать слои. Изменение цвета обычно не требует той же работы с геометрией, что изменение размеров, но реальные затраты зависят от страницы и движка.

Если чередовать запись стиля и чтение геометрии, например offsetWidth, браузер может быть вынужден синхронно пересчитывать layout много раз. Полезно сначала собрать нужные измерения, затем выполнить изменения пакетом.

`requestAnimationFrame` помогает планировать визуальный шаг, но не запрещает принудительный layout, если внутри снова неправильно смешаны чтения и записи.

### Пример и его разбор

```javascript
function resizeItems(container, items) {
  const width = container.getBoundingClientRect().width // чтение один раз
  for (const item of items) {
    item.style.width = `${width}px` // затем записи
  }
}
```

Ширина контейнера измеряется один раз до всех записей. Это позволяет не чередовать изменение каждого item с новым запросом геометрии. Само назначение стиля может потребовать дальнейшей работы браузера, но программа не вынуждает пересчитывать её между каждой парой действий.
