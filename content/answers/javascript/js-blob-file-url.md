**Blob описывает неизменяемые бинарные данные с MIME-метаданными, File добавляет файловые сведения. Object URL даёт браузеру временную ссылку на ресурс, а не загружает файл на сервер.**

<!-- wishu:answer-block -->

### Как это работает

`ArrayBuffer` предоставляет память для работы через views; получение данных из Blob может быть асинхронным. Созданный object URL удерживает доступ к ресурсу, пока его не освободят или не закончится соответствующий срок среды.

Вызывайте revokeObjectURL, когда ссылка больше не нужна, но не слишком рано для ещё использующего её изображения или скачивания. Имя и MIME файла не доказывают доверенность содержимого.

### Пример и его разбор

```javascript
const blob = new Blob(["hello"], { type: "text/plain" })
const url = URL.createObjectURL(blob)
// url можно использовать для скачивания или отображения по контракту браузера.
// После завершения использования:
URL.revokeObjectURL(url)
```

Созданный URL ссылается на локальный Blob, а не на загруженный серверный файл. Revoke завершает доступ через эту ссылку, когда она больше не нужна. В интерфейсе владелец превью должен выбрать этот момент после окончания использования ресурса.

### Типичная ошибка

> Считать object URL постоянным адресом файла или забывать освобождать множество превью.
