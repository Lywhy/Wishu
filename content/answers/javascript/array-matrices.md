**Двумерный массив JavaScript обычно представляет собой массив строк-массивов: доступ к элементу выглядит как matrix[row][column].**

<!-- wishu:answer-block -->

### Как это работает

Язык не требует одинаковой длины строк, поэтому при обходе нужно учитывать фактическую длину каждой. Подходят вложенные for или for...of.

Array(rows).fill([]) записывает одну и ту же ссылку во все строки: изменение одной строки будет видно через остальные. Для независимых строк нужно создавать массив заново на каждом шаге, например `Array.from`({ `length`: rows }, () => Array(columns).fill(0)).

`fill` безопасен здесь для примитивного 0, но `fill`({}) снова разделит один объект между ячейками.

### Пример и его разбор

```javascript
const matrix = Array.from({ length: 2 }, () => Array(3).fill(0))
matrix[0][1] = 5
matrix[1][1] // 0
let total = 0
for (const row of matrix) {
  for (const value of row) total += value
}
total // 5
const sharedRows = Array(2).fill([])
sharedRows[0] === sharedRows[1] // true
```

Mapper `Array.from` вызывается отдельно для каждой строки и создаёт новый массив из трёх нулей. Поэтому изменение ячейки первой строки не затрагивает вторую, а вложенный обход получает сумму 5. `fill`([]) действует иначе: одно заранее созданное значение записывается несколько раз. Независимость строк нужно обеспечивать при создании, а не после обнаружения общей ссылки.
