**Двумерный массив JavaScript обычно представляет собой массив строк-массивов: доступ к элементу выглядит как matrix[row][column].**

<!-- wishu:answer-block -->

### Что важно объяснить

- Язык не требует одинаковой длины строк, поэтому при обходе нужно учитывать фактическую длину каждой.

- Подходят вложенные for или for...of.

- Array(rows).fill([]) записывает одну и ту же ссылку во все строки: изменение одной строки будет видно через остальные.

- Для независимых строк нужно создавать массив заново на каждом шаге, например `Array.from`({ length: rows }, () => Array(columns).fill(0)).

- Fill безопасен здесь для примитивного 0, но fill({}) снова разделит один объект между ячейками.
