**ASI вставляет точку с запятой по правилам грамматики, а не после любого переноса. Перенос после `return` может завершить возврат, а строка, начинающаяся с ( или [, иногда продолжает предыдущее выражение.**

### Как рассуждать

Сначала определите, может ли текущая конструкция грамматически продолжаться. Для `return`, `throw` и некоторых других форм действуют ограничения переноса. Нельзя исправить смысл программы надеждой на форматирование.

Используйте согласованный стиль и защитную точку с запятой перед неоднозначным началом выражения. Форматтер упорядочивает синтаксис, но не узнаёт намерение автора.

### Пример и его разбор

```javascript
function make() {
  return
  {
    ready: true
  }
}
// Возвращается undefined, объект не является операндом return.
const values = [1, 2]
;[3, 4].forEach((value) => console.log(value))
```

В make перенос строки завершает `return`, поэтому последующая запись не становится возвращаемым объектом. Защитная точка с запятой перед массивом в другой части примера не позволяет связать его с предыдущим выражением. Сначала определяется синтаксическая структура программы, и только затем выполнение; форматтер не может угадать другое намерение автора.

### Типичная ошибка

> Переносить значение `return` на следующую строку без открывающей скобки.
