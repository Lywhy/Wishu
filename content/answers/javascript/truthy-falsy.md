**Falsy-значения преобразуются в `false`: `false`, 0, -0, 0n, пустая строка, `null`, `undefined` и `NaN`.**

### Как это работает

Остальные значения truthy, включая [], {}, "0" и "`false`". В браузере существует историческое исключение - document.all, которое тоже falsy.

!value сначала приводит значение к boolean, затем инвертирует его. !!value инвертирует дважды и возвращает boolean, эквивалентный Boolean(value). Это проверка логической истинности, а не пустоты массива, объекта или строки из пробелов.

### Пример и его разбор

```javascript
!0 // true
!!"JS" // true
!![] // true
!!" " // true
Boolean(null) // false
```

В логическом контексте JavaScript проверяет само значение, а не наличие полезных элементов внутри него. Поэтому пустой массив и строка из пробела в примере дают `true` после двойного отрицания. Если условие означает «список не пуст», проверяют `length`; если «ввод содержит непробельный текст», сначала определяют правила очистки строки.
