**ArrayBuffer хранит бинарные данные, а TypedArray и DataView дают представления для чтения и записи.** Несколько представлений могут обращаться к одному буферу.

<!-- wishu:answer-block -->

### Выбор представления

| Инструмент | Назначение |
| --- | --- |
| ArrayBuffer | Сам блок байтов |
| Uint8Array, Float32Array и другие | Работа с элементами одного числового типа |
| DataView | Чтение разных числовых типов с явным порядком байтов |

<!-- wishu:answer-block -->

### Отличия от обычного массива

- Типизированный массив не является обычным Array.
- Его операции преобразуют значения согласно типу элементов.
- Изменения через одно представление видны через другое представление того же участка буфера.
- Для сетевого формата порядок байтов нужно задавать согласно протоколу.
