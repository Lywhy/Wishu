**Поверхностная копия создаёт новый внешний объект, но значения вложенных свойств копирует без рекурсивного клонирования.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Поэтому {...source} и `Object.assign`({}, source) оставляют ссылки на вложенные объекты общими.

- Присваивание copy = source вообще не создаёт новый объект: обе переменные получают ссылку на один.

- Глубокое копирование создаёт независимые копии поддерживаемых вложенных данных.

- Способ выбирают по типам и требуемому поведению: structuredClone подходит для многих структур данных, а нестандартные экземпляры могут требовать явного преобразования.

- Для иммутабельного обновления часто достаточно скопировать только изменяемую ветку, сохранив остальные ссылки; копировать весь граф необязательно.
