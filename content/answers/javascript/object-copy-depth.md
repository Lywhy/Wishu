**Поверхностная копия создаёт новый внешний объект, но значения вложенных свойств копирует без рекурсивного клонирования.**

<!-- wishu:answer-block -->

### Как это работает

Поэтому {...source} и `Object.assign`({}, source) оставляют ссылки на вложенные объекты общими. Присваивание copy = source вообще не создаёт новый объект: обе переменные получают ссылку на один.

Глубокое копирование создаёт независимые копии поддерживаемых вложенных данных. Способ выбирают по типам и требуемому поведению: structuredClone подходит для многих структур данных, а нестандартные экземпляры могут требовать явного преобразования.

Для иммутабельного обновления часто достаточно скопировать только изменяемую ветку, сохранив остальные ссылки; копировать весь граф необязательно.

### Пример и его разбор

```javascript
const original = { profile: { name: "Аня" } }
const shallow = { ...original }
shallow !== original // true
shallow.profile === original.profile // true
const updated = { ...original, profile: { ...original.profile, name: "Оля" } }
original.profile.name // "Аня"
updated.profile.name // "Оля"
```

Поверхностная копия создаёт новый внешний контейнер, но сохраняет ссылку на profile. Изменение profile через копию поэтому заметно и в оригинале. Чтобы независимо обновить конкретную ветку, копируют каждый контейнер на пути к изменяемому полю; остальные ветки могут продолжать совместно использовать прежние значения.
