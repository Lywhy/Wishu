**QuerySelector возвращает первый Element по CSS-селектору или `null`, querySelectorAll - статический NodeList совпадений.**

### Что важно объяснить

- GetElementById ищет элемент по ID без синтаксиса CSS.

- Запрос можно ограничить контейнером, чтобы не затрагивать другие части документа.

- Статический NodeList не обновляет состав после изменения DOM.

- Некоторые другие API, например getElementsByClassName, возвращают живую коллекцию.

- NodeList не обязательно массив, хотя обычно допускает for...of; `Array.from` даёт методы массива.

- Динамическую часть CSS-селектора нужно корректно экранировать через CSS.escape, если она не является готовым селектором.
