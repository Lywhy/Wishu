**Отдельного примитивного типа Int в JavaScript нет.**

### Как это работает

Number представляет числа двойной точности, в том числе дробные. Целые числа гарантированно точны в диапазоне от -(2^53 - 1) до 2^53 - 1. `BigInt` представляет целые произвольной точности в пределах ресурсов среды и записывается с суффиксом n или создаётся через `BigInt`.

В обычной арифметике смешивать `BigInt` и Number нельзя без явного преобразования. Деление `BigInt` отбрасывает дробную часть к нулю.

Большие исходные целые лучше читать из строки: создание `BigInt` из уже неточного Number не восстановит потерянные разряды. Преобразование в Number также может потерять точность.

### Пример и его разбор

```javascript
Number.MAX_SAFE_INTEGER // 9007199254740991
const large = BigInt("9007199254740993")
large + 1n // 9007199254740994n
5n / 2n // 2n
// large + 1; // TypeError
```

Строка передаёт все разряды исходного числа в `BigInt` без промежуточного округления Number. После этого сложение с 1n остаётся точной целочисленной операцией. Деление 5n на 2n возвращает 2n, потому что дробная часть не представляется. Для дробных величин `BigInt` не заменяет выбор масштаба и правила округления.
