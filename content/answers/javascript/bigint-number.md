**Отдельного примитивного типа Int в JavaScript нет.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Number представляет числа двойной точности, в том числе дробные.

- Целые числа гарантированно точны в диапазоне от -(2^53 - 1) до 2^53 - 1. `BigInt` представляет целые произвольной точности в пределах ресурсов среды и записывается с суффиксом n или создаётся через `BigInt`.

- В обычной арифметике смешивать `BigInt` и Number нельзя без явного преобразования.

- Деление `BigInt` отбрасывает дробную часть к нулю.

- Большие исходные целые лучше читать из строки: создание `BigInt` из уже неточного Number не восстановит потерянные разряды.

- Преобразование в Number также может потерять точность.
