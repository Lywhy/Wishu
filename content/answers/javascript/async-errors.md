**Необработанное исключение async-функции становится отклонением возвращаемого Promise.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Вызывающий код перехватывает его через await внутри try/catch или через catch.

- Try вокруг одного запуска без ожидания не перехватывает последующее отклонение.

- Внутри try запись return operation() передаёт Promise вызывающему коду, но локальный catch не ждёт его отказа.

- Return await operation() позволяет обработать отказ этим catch.

- Если восстановиться нельзя, ошибку передают дальше через throw; возврат из catch может случайно превратить отказ в успех.

- Ошибки отдельно запущенных операций требуют собственного обработчика.
