**`Symbol` создаёт уникальное примитивное значение.**

### Как это работает

Два вызова `Symbol`("id") дают разные символы; описание нужно для удобства отладки. Символы используют как ключи без случайных совпадений имён и как специальные протоколы, например `Symbol.iterator`.

`Symbol.for`(key) ищет символ в общем реестре и возвращает тот же символ для того же ключа. Символьные ключи не попадают в `Object.keys` и обычную JSON-сериализацию, но доступны через `Object.getOwnPropertySymbols` и Reflect.ownKeys.

Они не обеспечивают приватность.

### Пример и его разбор

```javascript
Symbol("id") === Symbol("id") // false
Symbol.for("id") === Symbol.for("id") // true
const id = Symbol("id")
const user = { [id]: 1, name: "Аня" }
Object.keys(user) // ["name"]
user[id] // 1
```

Описание «id» помогает человеку узнать символ, но не участвует в равенстве двух независимо созданных символов. Напротив, Symbol.for намеренно использует общий реестр по строковому ключу. Свойство user[id] читается по сохранённому символу, хотя `Object.keys` его пропускает. Такое исключение из обычного перечисления предотвращает некоторые конфликты имён, но не обеспечивает секретность.
