**DataView позволяет читать и записывать разные числовые форматы по байтовым смещениям с явным выбором порядка байтов. Это удобно для протокола, где структура не совпадает с одним TypedArray.**

### Механизм и границы

Little-endian и big-endian должны соответствовать формату данных. У методов с соответствующим параметром значение по умолчанию не означает «как у текущего процессора». Выход за границы вызывает ошибку по контракту DataView.

Сначала проверьте длину пакета и допустимые смещения, затем интерпретируйте значения. Типизированный view сам не валидирует весь протокол.
