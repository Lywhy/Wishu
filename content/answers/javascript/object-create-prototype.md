**`Object.create`(proto) создаёт новый объект с указанным внутренним прототипом без вызова конструктора.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Свойства proto не копируются: они доступны через цепочку наследования.

- Необязательный второй аргумент - карта дескрипторов собственных свойств, а не обычных значений.

- `Object.create`(`null`) создаёт объект без прототипа: он не наследует toString, hasOwnProperty и accessor __proto__ из `Object.prototype`.

- Это удобно для простого словаря строковых или символьных ключей без унаследованных имён.

- Проверять свойства можно через `Object.hasOwn`, а прототип - через `Object.getPrototypeOf`.

- Для произвольных типов ключей и готового API коллекции часто удобнее Map.
