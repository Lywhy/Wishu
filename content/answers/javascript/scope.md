**Область видимости определяет, где доступна привязка имени.**

<!-- wishu:answer-block -->

### Как это работает

JavaScript использует лексическую область видимости: доступ к внешним переменным зависит от места объявления функции в коде. При поиске имени проверяется текущая область, затем внешние.

let и const имеют блочную область видимости, var - функциональную или область скрипта. Верхний уровень ES-модуля образует собственную область.

Вложенная переменная может затенить внешнюю с тем же именем; это не изменяет внешнюю привязку.

### Пример и его разбор

```javascript
const name = "внешнее"
function show() {
  const name = "внутреннее"
  return name
}
show() // "внутреннее"
name // "внешнее"
```

В show поиск имени останавливается на ближайшей локальной переменной name, поэтому функция возвращает «внутреннее». Внешняя name остаётся прежней: затенение создаёт другую привязку, а не записывает новое значение в существующую. Место вызова функции не перестраивает цепочку областей; она определяется тем, где функция была создана.
