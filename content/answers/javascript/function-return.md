**Обычная функция, дошедшая до конца без `return`, возвращает `undefined`. `return` без выражения тоже возвращает `undefined` и завершает функцию.**

### Как это работает

У стрелки с телом-выражением значение возвращается автоматически, а при теле в фигурных скобках нужен явный return. Перенос строки сразу после `return` запускает автоматическую вставку точки с запятой: выражение на следующей строке уже не возвращается.

`async`-функция без `return` выполняет `Promise` со значением `undefined`; генератор без явного `return` завершает итерацию с value: `undefined`. При вызове через `new` результат определяется правилами конструктора.

### Пример и его разбор

```javascript
function noReturn() {
  const value = 1
}
noReturn() // undefined
const concise = () => 42
const block = () => {
  42
}
concise() // 42
block() // undefined
```

Локальная переменная value в noReturn не становится результатом автоматически: выполнение просто заканчивается с undefined. Стрелка concise возвращает 42 как значение своего выражения, а block вычисляет 42 внутри тела и отбрасывает результат. Поэтому выбор краткой или блочной формы меняет необходимость явного `return`, а не просто оформление кода.
