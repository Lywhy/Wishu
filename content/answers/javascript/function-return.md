**Обычная функция, дошедшая до конца без return, возвращает `undefined`. return без выражения тоже возвращает `undefined` и завершает функцию.**

<!-- wishu:answer-block -->

### Что важно объяснить

- У стрелки с телом-выражением значение возвращается автоматически, а при теле в фигурных скобках нужен явный return.

- Перенос строки сразу после return запускает автоматическую вставку точки с запятой: выражение на следующей строке уже не возвращается.

- Async-функция без return выполняет Promise со значением `undefined`; генератор без явного return завершает итерацию с value: `undefined`.

- При вызове через new результат определяется правилами конструктора.
