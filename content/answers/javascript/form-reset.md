**Form.reset восстанавливает значения контролов по умолчанию, а не обязательно очищает все поля.**

<!-- wishu:answer-block -->

### Как это работает

Начальное состояние связано с defaultValue, defaultChecked и соответствующими атрибутами. Возникает событие reset, которое можно отменить.

Метод не сбрасывает произвольное состояние приложения и не возвращает автоматически все свойства вроде disabled к прежнему значению. В управляемых React-полях нужно синхронизировать состояние отдельно.

Элемент с именем или ID reset может затенить метод формы, поэтому имена контролов нужно выбирать осознанно.

### Пример и его разбор

```javascript
const form = document.createElement("form")
const input = document.createElement("input")
input.defaultValue = "начальное"
form.append(input)
input.value = "изменено"
form.reset()
input.value // "начальное"
```

После изменения value вызов reset возвращает «начальное», потому что именно это хранится в defaultValue. Метод не анализирует состояние приложения и не выбирает пустую строку самостоятельно. Для управляемой формы её состояние и DOM должны восстанавливаться согласованно.
