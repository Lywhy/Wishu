**Form.reset восстанавливает значения контролов по умолчанию, а не обязательно очищает все поля.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Начальное состояние связано с defaultValue, defaultChecked и соответствующими атрибутами.

- Возникает событие reset, которое можно отменить.

- Метод не сбрасывает произвольное состояние приложения и не возвращает автоматически все свойства вроде disabled к прежнему значению.

- В управляемых React-полях нужно синхронизировать состояние отдельно.

- Элемент с именем или ID reset может затенить метод формы, поэтому имена контролов нужно выбирать осознанно.
