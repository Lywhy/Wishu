**Производительность оценивают по задаче: время загрузки, задержка взаимодействий, длительность задач, память и объём переданных ресурсов.**

### Как это работает

Core Web Vitals фокусируются на опыте: LCP описывает появление крупнейшего содержимого, INP - задержку взаимодействия до следующего отображения, CLS - неожиданные сдвиги раскладки. Хорошие ориентиры: LCP до 2,5 с, INP до 200 мс, CLS до 0,1 на 75-м процентиле полевых посещений с разделением классов устройств.

Лабораторная трасса помогает объяснить причину, но не заменяет реальные пользовательские данные. Один быстрый запуск на мощном компьютере не доказывает хорошую работу у пользователей.

### Пример и его разбор

```javascript
// Ориентиры Core Web Vitals, а не результат измерения этой страницы:
const targets = { LCP_ms: 2500, INP_ms: 200, CLS: 0.1 }
// Для итоговой оценки нужны полевые данные и 75-й процентиль.
```

Числа в targets являются ориентирами, а не измерениями данного интерфейса. Чтобы сравнить с ними продукт, нужны соответствующие пользовательские наблюдения. Хорошая оценка загрузки не компенсирует плохую отзывчивость или сдвиги: метрики отражают разные стороны опыта.
