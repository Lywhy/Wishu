**Выражение класса создаёт значение конструктора в месте вычисления.**

<!-- wishu:answer-block -->

### Как это работает

Его можно присвоить переменной, вернуть из функции или передать как аргумент. Оно может быть анонимным или иметь внутреннее имя, доступное внутри определения класса.

До инициализации const обращаться к переменной нельзя из-за TDZ. Объявление класса тоже не позволяет использовать его до инициализации, в отличие от обычного Function Declaration.

Внутреннее имя именованного выражения не создаёт отдельную внешнюю переменную; свойство name может быть выведено из контекста.

### Пример и его разбор

```javascript
const User = class InternalUser {
  static create() {
    return new InternalUser()
  }
}
const user = User.create()
user instanceof User // true
// InternalUser снаружи выражения не является отдельной привязкой.
```

Внутреннее имя InternalUser позволяет фабрике сослаться на свой конструктор, а внешний код использует User. Оба обозначают один класс внутри доступных областей. Создание выражения происходит при вычислении присваивания, поэтому обращаться к User до инициализации нельзя.
