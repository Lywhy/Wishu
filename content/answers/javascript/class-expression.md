**Выражение класса создаёт значение конструктора в месте вычисления.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Его можно присвоить переменной, вернуть из функции или передать как аргумент.

- Оно может быть анонимным или иметь внутреннее имя, доступное внутри определения класса.

- До инициализации const обращаться к переменной нельзя из-за TDZ.

- Объявление класса тоже не позволяет использовать его до инициализации, в отличие от обычного Function Declaration.

- Внутреннее имя именованного выражения не создаёт отдельную внешнюю переменную; свойство name может быть выведено из контекста.
