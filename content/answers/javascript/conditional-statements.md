**if...else выбирает ветвь по логической истинности условия. switch сопоставляет значение с case с использованием строгого сравнения и начинает выполнение с совпавшего case; default используется при отсутствии совпадения.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Без завершения ветви выполнение может перейти к следующему case.

- Условный оператор condition ? a : b - выражение, возвращающее результат одной из двух ветвей.

- Он удобен для короткого выбора значения.

- Для нескольких действий или сложных вложенных условий обычно понятнее if...else; вычисляется только выбранная ветвь.
