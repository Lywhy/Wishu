**if...else выбирает ветвь по логической истинности условия. switch сопоставляет значение с case с использованием строгого сравнения и начинает выполнение с совпавшего case; default используется при отсутствии совпадения.**

### Как это работает

Без завершения ветви выполнение может перейти к следующему case. Условный оператор condition ? a : b - выражение, возвращающее результат одной из двух ветвей.

Он удобен для короткого выбора значения. Для нескольких действий или сложных вложенных условий обычно понятнее if...else; вычисляется только выбранная ветвь.

### Пример и его разбор

```javascript
const score = 80
const result = score >= 60 ? "зачёт" : "повторить"
if (score >= 90) {
  console.log("отлично")
} else {
  console.log(result)
}
```

Тернарный оператор сначала получает значение «зачёт» из выбранной ветви, а if затем решает, какое действие выполнить. При score, равном 80, выполняется else и выводится уже подготовленный result. Такое разделение подчёркивает различие между выбором значения и управлением несколькими действиями. Неиспользуемая ветвь тернарного выражения не вычисляется.
