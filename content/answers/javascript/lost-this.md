**При передаче user.method передаётся значение функции без автоматической привязки к user.**

### Как это работает

Последующий вызов как callback подчиняется правилам вызывающего API: исходный объект сам по себе не сохраняется. Поэтому извлечённый метод может получить `undefined` или другой this.

Контекст сохраняют через `bind` или обёртку () => user.method(). Эти решения не полностью эквивалентны: `bind` фиксирует исходную функцию и объект, а обёртка заново читает свойство при каждом вызове.

Если callback нужно позже удалить, необходимо сохранить именно ту ссылку, которую передали при регистрации.

### Пример и его разбор

```javascript
const user = {
  name: "Аня",
  readName() {
    "use strict"
    return this?.name
  },
}
const detached = user.readName
detached() // undefined
const bound = user.readName.bind(user)
bound() // "Аня"
const wrapped = () => user.readName()
```

detached содержит ту же функцию метода, но её вызов больше не указывает на user. Bound-вариант закрепляет исходный объект и функцию, а wrapped при каждом вызове заново читает user.readName. Если метод позже заменить, эти способы могут начать вести себя по-разному. Поэтому сохранять контекст следует с учётом будущего изменения и удаления обработчика.
