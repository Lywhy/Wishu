**Function Declaration (FD) - самостоятельное объявление вида function sum() {}.**

<!-- wishu:answer-block -->

### Как это работает

Function Expression (FE) - функция как значение выражения, например const sum = function () {}. Выражение может быть анонимным или именованным.

Имя именованного FE доступно внутри самой функции, например для рекурсии; снаружи используется переменная, которой присвоен результат. FD в обычном теле функции доступно до своей строки.

FE создаётся при вычислении выражения: const и let до инициализации находятся в TDZ, а var до присваивания содержит `undefined` и ещё не может быть вызвана как функция. Анонимной функции движок может вывести свойство name из контекста; это не создаёт отдельную лексическую привязку имени.

Стрелочная функция - ещё одна форма выражения, а методы имеют свой синтаксис.

### Пример и его разбор

```javascript
declared() // "FD"
function declared() {
  return "FD"
}

const expression = function internal() {
  return "FE"
}
expression() // "FE"
const arrow = () => "стрелочная"
```

declared доступна до своей строки, потому что здесь используется объявление функции. Переменная expression получает функцию только при выполнении присваивания, а имя internal остаётся внутренним именем самой функции. Следовательно, важна не только запись function, но и её синтаксическая роль: отдельное объявление или вычисляемое выражение.
