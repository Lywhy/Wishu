**`NaN` - специальное значение типа number для неопределённого или непредставимого числового результата.**

<!-- wishu:answer-block -->

### Как это работает

Его можно получить, например, при Number("текст") или 0 / 0. Арифметические операции с `NaN` обычно распространяют его дальше.

`NaN` не равен самому себе через == и ===. `Number.isNaN`(value) проверяет именно значение `NaN` без преобразований.

Глобальная isNaN сначала преобразует аргумент в число, поэтому isNaN("текст") даёт `true`, хотя строка сама по себе не `NaN`.

### Пример и его разбор

```javascript
const result = Number("текст")
Number.isNaN(result) // true
Number.isNaN("текст") // false
isNaN("текст") // true
NaN === NaN // false
```

Number пытается разобрать «текст» как число и получает NaN. `Number.isNaN` различает это числовое значение и исходную строку, а глобальная isNaN сначала выполняет преобразование, поэтому даёт другой результат. Проверка через равенство не подходит: `NaN` специально не равен себе. Для валидного конечного числа может дополнительно понадобиться Number.isFinite.
