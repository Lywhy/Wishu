**`NaN` - специальное значение типа number для неопределённого или непредставимого числового результата.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Его можно получить, например, при Number("текст") или 0 / 0.

- Арифметические операции с `NaN` обычно распространяют его дальше.

- `NaN` не равен самому себе через == и ===.

- Number.isNaN(value) проверяет именно значение `NaN` без преобразований.

- Глобальная isNaN сначала преобразует аргумент в число, поэтому isNaN("текст") даёт true, хотя строка сама по себе не `NaN`.
