**`sort()` изменяет массив и без compareFn сравнивает строковые представления элементов по UTF-16.** Для чисел обычно нужен явный числовой компаратор.

<!-- wishu:answer-block -->

### Компаратор

- Отрицательное значение помещает a перед b.
- Положительное - после b.
- Ноль означает эквивалентность для сортировки.
- Компаратор должен задавать согласованный порядок, а не случайное или boolean-значение.

<!-- wishu:answer-block -->

### Нюансы

- Современный стандарт требует стабильной сортировки: равные элементы сохраняют исходный относительный порядок.
- `toSorted()` создаёт новый массив; `[...items].sort()` тоже отделяет верхний уровень.
- Для строк с языковыми правилами применяют `localeCompare` или настроенный `Intl.Collator`.
- Конкретная временная и пространственная сложность реализации sort стандартом не фиксируется.
