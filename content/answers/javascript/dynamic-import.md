**Import(specifier) возвращает `Promise` пространства имён модуля после его загрузки, связывания и выполнения.**

<!-- wishu:answer-block -->

### Как это работает

Он допускается в выражении и позволяет загрузить код по условию. Default-экспорт находится в namespace.default.

Ошибки загрузки и выполнения становятся отклонением Promise. Сборщик может выделить такой импорт в отдельный чанк, но детали зависят от конфигурации и анализируемости пути.

Повторный импорт того же модуля обычно использует модульный кеш; это не обещание повторно выполнить файл. Неограниченный динамический путь может осложнить сборку.

Import запускает побочные эффекты модуля при его выполнении, даже если экспорт затем не использован.

### Пример и его разбор

```javascript
async function loadFormatter() {
  const module = await import("./formatter.js")
  return module.format
}
// formatter.js должен существовать и экспортировать format.
// Вызывающий код обрабатывает отказ загрузки.
```

LoadFormatter ожидает завершения импорта, затем выбирает экспорт format из пространства имён. Отказ может произойти не только при скачивании: выполнение самого модуля тоже способно выбросить ошибку. Поэтому обработка загрузки должна охватывать весь возвращаемый Promise.
