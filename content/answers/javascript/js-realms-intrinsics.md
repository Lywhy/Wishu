**Realm имеет своё глобальное окружение и встроенные объекты. Массив другого окна может быть связан с другим Array.prototype, поэтому локальный `instanceof` Array не является универсальной межконтекстной проверкой.**

<!-- wishu:answer-block -->

### Как это работает

`Array.isArray` использует другой подход, но не каждый builtin имеет одинаковый универсальный helper. Для разных задач выбирайте brand-check, протокольную проверку или проверенный формат передачи.

`Object.prototype.toString` тоже не является неуязвимым валидатором: `Symbol.toStringTag` может влиять на представление. Не смешивайте realm с origin и правом доступа к другому окну.

### Пример и его разбор

```javascript
// При разрешённом доступе к другому окну:
// const foreign = new iframe.contentWindow.Array(1, 2)
// foreign instanceof Array может быть false.
// Array.isArray(foreign) остаётся подходящей проверкой массива.
```

Массив другого окна наследует его Array.prototype. Локальный `instanceof` проверяет другую цепочку и потому может вернуть `false`, хотя значение остаётся массивом. `Array.isArray` проверяет встроенную принадлежность, но такая проверка всё равно не валидирует тип и смысл каждого элемента.

### Типичная ошибка

> Использовать `instanceof` как полную валидацию любого значения из iframe или иной среды.
