**Обычная функция получает arguments - массивоподобный и итерируемый объект с фактически переданными аргументами и length.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Это не массив: собственных методов map и filter у него нет; для работы как с массивом можно использовать `Array.from`(arguments).

- Значения параметров по умолчанию не добавляются в arguments автоматически.

- Стрелка не создаёт собственного arguments, но может обратиться к arguments внешней обычной функции.

- Если такого имени во внешней области нет, обращение вызовет ReferenceError.

- В нестрогой функции с простыми параметрами arguments может быть связан с параметрами; в строгой функции и при rest, default или деструктуризации такой синхронизации нет.

- Для новых функций обычно нагляднее rest-параметры.
