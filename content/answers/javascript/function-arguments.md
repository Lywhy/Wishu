**Обычная функция получает arguments - массивоподобный и итерируемый объект с фактически переданными аргументами и length.**

<!-- wishu:answer-block -->

### Как это работает

Это не массив: собственных методов `Map` и `filter` у него нет; для работы как с массивом можно использовать `Array.from`(arguments). Значения параметров по умолчанию не добавляются в arguments автоматически.

Стрелка не создаёт собственного arguments, но может обратиться к arguments внешней обычной функции. Если такого имени во внешней области нет, обращение вызовет ReferenceError.

В нестрогой функции с простыми параметрами arguments может быть связан с параметрами; в строгой функции и при rest, default или деструктуризации такой синхронизации нет. Для новых функций обычно нагляднее rest-параметры.

### Пример и его разбор

```javascript
function outer(value) {
  const read = () => arguments[0]
  return read()
}
outer("JS") // "JS"
function collect() {
  return Array.from(arguments)
}
collect(1, 2) // [1, 2]
```

Стрелка read обращается не к собственному списку аргументов, а к arguments внешней outer. Поэтому возвращается исходное «JS», даже хотя сама стрелка вызывается без параметров. В collect преобразование `Array.from` уже создаёт обычный массив. Нужно различать фактически переданные аргументы, локальные параметры функции и их значения после инициализации.
