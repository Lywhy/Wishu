**Деструктуризация может объявлять привязки или присваивать значения уже существующим целям. В присваивании объектный шаблон в начале инструкции обычно заключают в скобки, чтобы отличить его от блока.**

<!-- wishu:answer-block -->

### Как это работает

Default срабатывает только для `undefined`, а не для null. Цели и выражения вычисляются по правилам соответствующей формы; `getter` и итератор могут выполнять пользовательский код.

Не воспринимайте шаблон как простое чтение всех полей заранее. Присваивание может изменить уже существующие переменные, а объявление const создаёт новые привязки с собственными ограничениями.

### Пример и его разбор

```javascript
let name = "старое"
;({ name = "по умолчанию" } = { name: undefined })
const [first, ...rest] = [1, 2, 3]
console.log(name, first, rest) // по умолчанию, 1, [2, 3]
```

Первая конструкция обновляет уже существующую name, а не объявляет ещё одну переменную. Исходное `undefined` активирует значение по умолчанию. В следующей строке const, напротив, создаёт новые first и rest. Скобки вокруг объектного присваивания помогают синтаксическому анализатору отличить шаблон назначения от начала блока инструкций.

### Типичная ошибка

> Ожидать default для `null` или писать объектное присваивание как самостоятельный блок.
