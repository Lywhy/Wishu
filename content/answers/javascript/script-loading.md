**Обычный классический script без async/defer в ходе парсинга приостанавливает разбор HTML ради загрузки и выполнения.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Для внешнего классического скрипта defer позволяет загрузку параллельно разбору и выполнение после него в порядке документа до DOMContentLoaded.

- Async выполняет готовый скрипт без гарантии порядка относительно других и может прервать разбор на время выполнения.

- Поэтому зависимые скрипты нельзя произвольно помечать async, а head сам по себе не делает скрипт плохим: важны режим и требуемый момент.

- Модули type="module" по умолчанию отложены; их async имеет собственную семантику готовности графа зависимостей.

- Defer не даёт ожидаемого эффекта для обычного inline-классического скрипта.

- Атрибут async не связан с ключевым словом async функции.
