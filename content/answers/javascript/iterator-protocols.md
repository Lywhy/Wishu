**Итератор - объект с методом next(), возвращающим объект с done и value.**

<!-- wishu:answer-block -->

### Как это работает

Итерируемый объект предоставляет метод [`Symbol.iterator`](<>), возвращающий итератор. Это разные роли: объект с одним next не становится автоматически пригодным для for...of.

Объект генератора выполняет обе роли: у него есть next, а [`Symbol.iterator`](<>) возвращает его самого. После исчерпания тот же генератор нельзя начать заново; новый вызов генераторной функции создаёт новый объект.

Пользовательский iterable может создавать свежий итератор для каждого обхода, например через генераторный метод.

### Пример и его разбор

```javascript
const range = {
  *[Symbol.iterator]() {
    yield 1
    yield 2
  },
}
;[...range] // [1, 2]
;[...range] // [1, 2]: каждый раз новый генератор
const iterator = range[Symbol.iterator]()
iterator[Symbol.iterator]() === iterator // true
```

range предоставляет фабрику итератора через `Symbol.iterator`: каждый вызов создаёт новый генератор, поэтому оба разворачивания дают полный список. Сам `Iterator` возвращает из своего `Symbol.iterator` уже себя, а не свежую последовательность. Эти две роли объясняют, почему повторный обход одного исчерпанного генератора отличается от повторного обхода iterable-фабрики.
