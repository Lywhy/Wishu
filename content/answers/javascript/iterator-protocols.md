**Итератор - объект с методом next(), возвращающим объект с done и value.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Итерируемый объект предоставляет метод [`Symbol`.iterator](), возвращающий итератор.

- Это разные роли: объект с одним next не становится автоматически пригодным для for...of.

- Объект генератора выполняет обе роли: у него есть next, а [`Symbol`.iterator]() возвращает его самого.

- После исчерпания тот же генератор нельзя начать заново; новый вызов генераторной функции создаёт новый объект.

- Пользовательский iterable может создавать свежий итератор для каждого обхода, например через генераторный метод.
