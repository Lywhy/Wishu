**filter возвращает новый массив всех элементов, для которых callback дал truthy-результат.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Если совпадений нет, возвращается пустой массив. find возвращает первый подходящий элемент и прекращает поиск; если совпадения нет, результат `undefined`.

- Предикат получает элемент, индекс и исходный массив.

- Ни один из методов сам по себе не клонирует найденные объекты: результат содержит исходные ссылки.

- Undefined у find может также означать реально найденный элемент с таким значением; если нужно отличать ситуации, помогает findIndex.

- В обычном разрежённом массиве filter пропускает отсутствующие позиции, а find посещает их со значением `undefined`.
