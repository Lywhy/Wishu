**`filter` возвращает новый массив всех элементов, для которых callback дал truthy-результат.**

### Как это работает

Если совпадений нет, возвращается пустой массив. `find` возвращает первый подходящий элемент и прекращает поиск; если совпадения нет, результат `undefined`. Предикат получает элемент, индекс и исходный массив.

Ни один из методов сам по себе не клонирует найденные объекты: результат содержит исходные ссылки. `undefined` у `find` может также означать реально найденный элемент с таким значением; если нужно отличать ситуации, помогает findIndex.

В обычном разрежённом массиве `filter` пропускает отсутствующие позиции, а `find` посещает их со значением `undefined`.

### Пример и его разбор

```javascript
const users = [
  { id: 1, active: true },
  { id: 2, active: true },
]
users.filter((user) => user.active).length // 2
users.find((user) => user.active).id // 1
users.filter((user) => user.id === 3) // []
users.find((user) => user.id === 3) // undefined
```

В примере обе записи удовлетворяют active, поэтому `filter` сохраняет обе исходные ссылки. `find` прекращает поиск уже на первом пользователе. Отсутствие совпадений выражается по-разному: пустым массивом или undefined. Выбирать метод нужно по требуемому результату и допустимости неоднозначности, если `undefined` само может быть законным элементом.
