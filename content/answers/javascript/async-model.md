**Синхронная операция заканчивается до перехода к следующей инструкции.**

### Что важно объяснить

- Асинхронная позволяет запустить работу или зарегистрировать ожидание, а результат обработать позже: например, после ответа сети, таймера или события.

- Неблокирующий подход позволяет продолжать другую работу, пока внешний результат ещё не готов.

- Web API - возможности браузера, а не часть самого ECMAScript: сеть, таймеры и события организует среда.

- Готовые продолжения возвращаются к JavaScript через её планирование.

- Асинхронность не гарантирует параллельный JavaScript и не делает тяжёлый синхронный расчёт дешёвым.

- Promise описывает будущий результат, но не переносит вычисление в другой поток.
