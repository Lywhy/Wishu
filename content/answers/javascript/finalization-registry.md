**`FinalizationRegistry` позволяет зарегистрировать необязательный callback после освобождения цели сборщиком мусора.** Время вызова не гарантировано, а сам callback может вообще не выполниться.

<!-- wishu:answer-block -->

### Что важно помнить

Регистрация не должна удерживать цель через другие ссылки, например замыкание callback или heldValue. HeldValue сохраняется для передачи callback; оно не должно ссылаться на цель.

Для обязательного закрытия ресурсов применяют явный контракт очистки, например `finally` и метод освобождения. Нельзя строить проверку корректности на ожидании конкретного запуска GC или финализатора.

### Пример и его разбор

```javascript
const registry = new FinalizationRegistry((key) => {
  console.log("Можно убрать необязательные данные:", key)
})
let target = { name: "temporary" }
registry.register(target, "cache-key")
target = null
// Нет гарантии, когда и будет ли вообще вызван callback.
```

После target = `null` программа лишь убирает одну сильную ссылку. Callback registry может выполниться позднее или не выполниться вообще, поэтому сообщение не является обещанным следующим шагом. Для обязательного закрытия ресурса нужен явный метод очистки.

### Типичная ошибка

> Освобождать в финализаторе обязательный ресурс или удерживать target внутри heldValue.
