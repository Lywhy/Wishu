**У обычного Promise нет универсального метода отмены.**

<!-- wishu:answer-block -->

### Что важно объяснить

- AbortController создаёт signal, который передают операции, поддерживающей отмену, например fetch.

- Abort запрашивает остановку; API должно само учитывать сигнал.

- Один signal можно использовать для связанных операций, но после отмены он не становится снова активным.

- Promise запроса при отмене обычно отклоняется AbortError, если не задана другая причина.

- Отмена не гарантирует, что сервер не успел обработать запрос, и не откатывает уже выполненные действия.

- В своём API нужно учитывать уже отменённый signal и освобождать обработчики после завершения; простой reject не останавливает внешнюю работу.
