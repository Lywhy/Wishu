**Генераторная функция объявляется через function*.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Её вызов возвращает объект генератора, не выполняя тело сразу. next() запускает или возобновляет выполнение до yield либо завершения и возвращает объект { value, done }. yield выдаёт промежуточное значение с done: false и сохраняет состояние функции.

- return завершает генератор с done: true и итоговым value; без return итоговое значение - `undefined`.

- Следующий next(value) передаёт значение внутрь приостановленного выражения yield.

- Аргумент самого первого next игнорируется, поскольку приостановленного yield ещё нет. for...of и spread используют выдаваемые значения, а финальное значение return не включают.

- yield допустим непосредственно в теле генератора, но не во вложенной обычной или стрелочной функции.

- Стрелочного синтаксиса генератора нет; внутри callback нельзя приостановить внешний генератор через yield.

- Генератор сам по себе не делает выполнение асинхронным.
