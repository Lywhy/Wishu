_*Генераторная функция function* создаёт управляемую последовательность выполнения. Её вызов возвращает генератор, а тело начинает выполняться при первом `next` и может приостанавливаться на `yield`._*

<!-- wishu:answer-block -->

### Как это работает

Каждый `next` продолжает выполнение до следующего `yield` или завершения. Результат имеет форму { `value`, `done` }: `yield` выдаёт промежуточное значение с `done`: false, а `return` завершает генератор с `done`: true и итоговым значением. Приостановка сохраняет локальное состояние, поэтому следующий вызов продолжает ту же работу.

Вызов `next`(`value`) также передаёт значение внутрь приостановленного выражения `yield`. На самом первом `next` передавать значение ещё некуда, поэтому его аргумент игнорируется. for...of и spread потребляют выдаваемые значения, но не включают финальное значение `return`.

### Пример и его разбор

```javascript
function* exchange() {
  const answer = yield "вопрос"
  return answer
}
const iterator = exchange()
iterator.next() // { value: "вопрос", done: false }
iterator.next(42) // { value: 42, done: true }
iterator.next() // { value: undefined, done: true }
```

Первый `next` в примере останавливается на `yield` и возвращает строку «вопрос». Следующий `next`(42) делает значение выражения `yield` равным 42: оно попадает в answer, после чего `return` завершает генератор. Ещё один `next` уже не запускает тело заново.

### Нюансы и типичные ошибки

`yield` допустим непосредственно в теле генератора, но не во вложенной стрелочной или обычной функции. Стрелочного синтаксиса генератора нет. Сам механизм приостановки также не означает асинхронность: `async`-генераторы имеют отдельный контракт.
