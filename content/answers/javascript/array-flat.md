**flat(depth) создаёт новый массив, раскрывая вложенные массивы до указанной глубины.**

<!-- wishu:answer-block -->

### Как это работает

По умолчанию depth равен 1; для конечной ациклической структуры flat(Infinity) раскрывает все уровни. Обычные объекты, `Set` и другие значения не разворачиваются как массивы.

Метод не меняет исходный массив и не выполняет глубокое клонирование элементов: объектные значения сохраняют исходные ссылки. Пропуски на обрабатываемых уровнях удаляются, но пропуски в массиве, оставшемся вложенным из-за ограничения глубины, сохраняются.

Для очень глубокой структуры или циклов не стоит считать flat универсальным безопасным обходчиком.

### Пример и его разбор

```javascript
const nested = [1, [2, [3]]]
nested.flat() // [1, 2, [3]]
nested.flat(2) // [1, 2, 3]
nested // [1, [2, [3]]]
const item = { id: 1 }
;[[item]].flat()[0] === item // true
```

При глубине 1 массив [3] остаётся вложенным, а глубина 2 раскрывает и его. Исходный nested не меняется. Проверка с item показывает, что плоская структура всё ещё хранит тот же объект: удаление уровней массивов не является глубоким копированием данных. Для циклической или недоверенной структуры необходимы отдельные ограничения обработки.
