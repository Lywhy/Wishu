**push добавляет аргументы в конец, unshift - в начало; оба изменяют массив и возвращают новую длину. pop удаляет последний элемент, shift - первый; они возвращают удалённое значение, а для пустого массива - `undefined`.**

### Что важно объяснить

- При изменениях в начале индексы оставшихся элементов сдвигаются.

- concat создаёт новый массив и не меняет исходный.

- Переданный обычный массив он разворачивает на один уровень, а push(array) добавляет его как один вложенный элемент.

- Для добавления отдельных элементов через push нужен spread: push(...array).

- Ни concat, ни передача элементов через spread не выполняют глубокое копирование вложенных объектов.
