**`push` добавляет аргументы в конец, `unshift` - в начало; оба изменяют массив и возвращают новую длину. `pop` удаляет последний элемент, `shift` - первый; они возвращают удалённое значение, а для пустого массива - `undefined`.**

### Как это работает

При изменениях в начале индексы оставшихся элементов сдвигаются. `concat` создаёт новый массив и не меняет исходный.

Переданный обычный массив он разворачивает на один уровень, а `push`(array) добавляет его как один вложенный элемент. Для добавления отдельных элементов через `push` нужен spread: `push`(...array).

Ни `concat`, ни передача элементов через spread не выполняют глубокое копирование вложенных объектов.

### Пример и его разбор

```javascript
const values = [2, 3]
values.push(4) // 3 - новая длина
values.unshift(1) // 4 - новая длина
values.pop() // 4 - удалённый элемент
values.shift() // 1 - удалённый элемент
values // [2, 3]
const merged = values.concat([4, 5])
merged // [2, 3, 4, 5]
values.push([4, 5])
values // [2, 3, [4, 5]]
```

После добавления и удаления с обоих концов values снова содержит [2, 3]. `concat` строит отдельную внешнюю последовательность, тогда как `push`([4, 5]) добавляет один элемент-массив. При выборе метода учитывают два разных результата: новое содержимое коллекции и непосредственно возвращаемое значение операции. Например, `push` отдаёт длину, а не сам массив.
