**В tag`текст ${value}` функция tag получает массив строковых частей и отдельные вычисленные значения.**

### Как это работает

Это не вызов с уже склеенной строкой. Тег может вернуть любой результат: строку, объект или другую структуру.

Strings.raw даёт исходные части с сохранёнными escape-последовательностями. Такой контракт используют для форматирования и предметных языков.

Сам синтаксис не гарантирует экранирование HTML или защиту SQL: безопасность зависит от реализации тега и дальнейшей передачи результата. Обычный шаблонный литерал, напротив, сразу формирует строку по стандартным преобразованиям.

### Пример и его разбор

```javascript
function describe(strings, ...values) {
  return { parts: [...strings], values }
}
const name = "Аня"
const result = describe`Привет, ${name}!`
result.parts // ["Привет, ", "!"]
result.values // ["Аня"]
```

Describe получает две текстовые части и отдельное значение name. Оно ещё не смешано с окружающим текстом, поэтому тег может сохранить структуру или применить предметные правила обработки. Само использование тега не гарантирует безопасность: её определяет реализация функции.
