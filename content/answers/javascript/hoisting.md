**Hoisting называют наблюдаемое поведение объявлений, которые подготавливаются до выполнения операторов своей области. Исходный код при этом не перемещается: нужно различать создание привязки, её инициализацию и последующее присваивание.**

### Как это работает

У `var` привязка заранее инициализирована значением `undefined`. Поэтому чтение до строки с присваиванием возможно, но будущего значения ещё нет. `let`, `const` и `class` ведут себя иначе: до инициализации доступ к их привязкам запрещён. Этот промежуток называют temporal dead zone, или TDZ.

`Function` Declaration в обычном теле функции подготавливается вместе со значением функции, поэтому её можно вызвать раньше объявления. `Function` Expression создаёт значение при вычислении выражения: возможность обратиться к переменной зависит от того, объявлена она через `var`, `let` или `const`.

### Пример и его разбор

```javascript
console.log(count) // undefined
var count = 1

{
  // console.log(value); // ReferenceError: TDZ
  let value = 2
}
```

Первое чтение `count` в примере даёт `undefined`, потому что подготовлено объявление `var`, но не выполнено присваивание 1. Чтение `value` перед `let`, если раскомментировать строку, завершилось бы `ReferenceError`. Даже `typeof` `value` не обходит TDZ.

### Нюансы и типичные ошибки

Фраза «`let` вообще не всплывает» скрывает причину ошибки. При разборе сначала найдите область, затем вид объявления и точку инициализации. Для функций в блоках дополнительно учитывают strict mode и исторические браузерные правила.
