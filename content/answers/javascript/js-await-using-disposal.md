**Await using позволяет дождаться асинхронного освобождения через поддерживаемый протокол. Выход из области может требовать ожидания cleanup, а не завершаться сразу после последнего бизнес-выражения.**

<!-- wishu:answer-block -->

### Механизм и границы

Это полезно для ресурсов, у которых закрытие само является асинхронной операцией. Синхронный dispose и асинхронный asyncDispose не являются взаимозаменяемым соглашением по любому имени метода.

Сначала зафиксируйте требования к поддержке и поведение при ошибке как основной работы, так и очистки. Await using не отменяет произвольную уже выполняющуюся операцию.
