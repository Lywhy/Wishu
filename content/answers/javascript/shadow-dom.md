**Shadow DOM подключает отдельное дерево к host-элементу через attachShadow.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Обычные селекторы документа не проходят внутрь него; стили изолируются с предусмотренными исключениями, например наследуемыми свойствами и CSS custom properties.

- Slot позволяет отображать переданные снаружи узлы в составе компонента.

- Это не граница безопасности.

- Mode: closed ограничивает обычное получение shadowRoot снаружи, но не делает данные защищёнными от кода страницы.

- События пересекают границу согласно composed, а target может переназначаться на host; composedPath помогает изучить доступный путь.

- Shadow DOM не равен virtual DOM.
