**void expression вычисляет выражение, включая его побочные эффекты, и возвращает `undefined` независимо от полученного значения.**

<!-- wishu:answer-block -->

### Как это работает

Например, void 0 всегда даёт `undefined`. void не подавляет исключения и не обрабатывает отклонение Promise.

Запись void asyncTask() может обозначать намеренное игнорирование результата для инструментов анализа, но обработку ошибки всё равно нужно предусмотреть. Это оператор JavaScript, а не одноимённая аннотация типа TypeScript.

### Пример и его разбор

```javascript
let count = 0
const result = void (count += 1)
count // 1
result // undefined
void 0 // undefined
```

Выражение count += 1 в примере сначала выполняет присваивание, поэтому count становится равным 1. Затем void отбрасывает полученный результат, и переменная result получает undefined. Следовательно, void не позволяет «не выполнять» опасную операцию: её побочные эффекты и возможные ошибки сохраняются. Для асинхронного вызова отбрасывание результата также не является обработкой отказа.
