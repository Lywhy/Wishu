**ES-модули задают зависимости через import/export и предоставляют живые привязки.** Импортированная переменная отражает обновления экспортирующего модуля, но не переназначается импортёром.

<!-- wishu:answer-block -->

### Как это работает

Именованный экспорт импортируется по имени; default можно назвать локально по-другому. Статические зависимости известны до выполнения тела модуля.

Модуль имеет собственную область и строгий режим. Нельзя переназначить импортированную привязку, но можно изменить доступный объект, если его API это разрешает.

Циклы зависимостей допустимы; проблема возникает при слишком раннем чтении неинициализированной привязки.

### Отдельно про среду

Разрешение путей, загрузка и кеширование зависят от окружения. В браузере модуль подключают через `type="module"`; CommonJS `require` не является другим синтаксисом той же самой модели.

### Пример и его разбор

```javascript
// counter.js
export let count = 0
export function increment() {
  count += 1
}
// main.js
// import { count, increment } from "./counter.js";
// increment(); console.log(count); // 1 - живая привязка
```

Increment меняет экспортированную привязку count, и импортёр при следующем чтении видит новое значение. Это отличается от разового копирования числа. Собственная область модуля ограничивает имена, но не запрещает побочные эффекты и изменение экспортированных объектов через доступный API.

### Типичная ошибка

> Считать import копией текущего значения или ожидать, что верхнеуровневый `this` модуля равен window.
