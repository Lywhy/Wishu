### Механизм и границы

Сложение запускает преобразование с default hint и затем складывает полученные числа. Шаблонная интерполяция требует строкового представления. Вычисляемое имя свойства проходит ToPropertyKey, где для этого объекта получается строковый ключ key.

Один и тот же объект не обязан преобразовываться одинаково во всех контекстах. Возвращаемое значение должно соответствовать примитивному контракту.
