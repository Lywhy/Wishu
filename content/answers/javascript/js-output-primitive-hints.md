Вывод по строкам: **default**, **5**, **string**, **key**, **string**, **`true`**.

### Как это работает

Сложение запускает преобразование с default hint и затем складывает полученные числа. Шаблонная интерполяция требует строкового представления. Вычисляемое имя свойства проходит ToPropertyKey, где для этого объекта получается строковый ключ key.

Один и тот же объект не обязан преобразовываться одинаково во всех контекстах. Возвращаемое значение должно соответствовать примитивному контракту.

### Как проверить рассуждение

Возвращаемый примитив определяет следующий шаг операции: сложение получает число, а имя свойства получает строку. Подсказка не является требованием вернуть конкретный объектный тип; метод обязан вернуть примитив, который дальнейший алгоритм обработает по своему контракту.

### Типичная ошибка

> Предполагать вызов только `toString` независимо от места использования объекта.
