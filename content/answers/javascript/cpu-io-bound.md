**CPU-bound задача ограничена стоимостью вычислений, например обработкой большого массива или изображений.**

### Как это работает

I/O-bound в основном ждёт внешнее действие: сеть, диск или другой источник. В одном сценарии могут быть обе фазы: загрузить данные, затем дорого их разобрать и преобразовать.

Параллельный запуск независимых запросов может сократить ожидание I/O, но `Promise.all` не распараллеливает синхронный JavaScript. Для вычислений нужны более подходящий алгоритм, меньше работы, разбиение или Worker.

Чрезмерная конкуренция запросов и копирование больших данных в Worker тоже могут стать новым ограничением.

### Пример и его разбор

```javascript
async function loadIndependent(loadUsers, loadSettings) {
  return await Promise.all([loadUsers(), loadSettings()])
}
// Это перекрывает независимое ожидание, но не выносит CPU-расчёт в Worker.
```

Оба загрузчика запускаются до ожидания `Promise.all`, поэтому независимые периоды сетевого ожидания перекрываются. Если каждый загрузчик сначала синхронно считает большой результат, эта часть всё ещё выполняется в том же потоке. Промисы сами не превращают вычисления в параллельные.
