**Аргументы JavaScript передаются по значению.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Для примитива копируется примитивное значение, а для объекта - значение ссылки на него.

- Поэтому две переменные могут обращаться к одному объекту, и изменение его свойств будет видно через обе.

- Переназначение параметра внутри функции меняет только локальную привязку и не переназначает переменную вызывающего кода.

- Формулировка «объекты передаются по ссылке» часто скрывает эту разницу.

- Деление на стек и кучу - деталь реализации движка, а не гарантированная языком модель хранения.
