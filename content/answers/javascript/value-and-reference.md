**Аргументы JavaScript передаются по значению.**

<!-- wishu:answer-block -->

### Как это работает

Для примитива копируется примитивное значение, а для объекта - значение ссылки на него. Поэтому две переменные могут обращаться к одному объекту, и изменение его свойств будет видно через обе.

Переназначение параметра внутри функции меняет только локальную привязку и не переназначает переменную вызывающего кода. Формулировка «объекты передаются по ссылке» часто скрывает эту разницу.

Деление на стек и кучу - деталь реализации движка, а не гарантированная языком модель хранения.

### Пример и его разбор

```javascript
const user = { name: "Аня" }
function change(value) {
  value.name = "Оля"
  value = { name: "Ира" }
}
change(user)
user.name // "Оля"
```

Параметр value получает копию ссылки, которой достаточно для обращения к общему user. Поэтому изменение name становится видно вызывающему коду. Следующее присваивание меняет только локальный value и не заменяет user новым объектом. Разделение изменения объекта и переназначения переменной объясняет результат без неточной формулы «передача по ссылке».
