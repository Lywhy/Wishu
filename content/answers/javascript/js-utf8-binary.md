**`TextEncoder` кодирует строку в UTF-8 байты, а `TextDecoder` декодирует байты согласно выбранной кодировке и опциям. Длина байтов не равна длине JS-строки.**

### Как это работает

При потоковом декодировании один символ может быть разделён границей чанков: сохраняйте состояние декодера через stream и завершайте его финальным flush. Fatal-режим позволяет считать ошибочную последовательность исключением вместо замены.

Btoa/atob работают с другой моделью двоичных строк и сами не являются универсальной UTF-8 обработкой текста.

### Пример и его разбор

```javascript
const bytes = new TextEncoder().encode("Привет")
console.log(bytes.length) // 12
const text = new TextDecoder("utf-8", { fatal: true }).decode(bytes)
console.log(text) // Привет
```

Шесть кириллических букв в примере кодируются двенадцатью UTF-8 байтами. Decoder восстанавливает исходный текст, а fatal делает некорректную последовательность ошибкой. При получении по частям нужно сохранить состояние между чанками, иначе граница может разрезать один символ.

### Типичная ошибка

> Декодировать каждый сетевой чанк отдельной новой строкой без сохранения частичных последовательностей.
