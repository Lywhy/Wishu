**`WeakRef` хранит слабую ссылку на подходящую цель, не удерживая её от сборки мусора одним своим существованием.**

<!-- wishu:answer-block -->

### Как это работает

Deref возвращает доступную цель или `undefined`, если она уже освобождена. В современных API допустимы объекты и незарегистрированные `Symbol`; обычные строки и числа не подходят.

Время сборки и освобождения не гарантируется, поэтому `WeakRef` нельзя считать детерминированным кешем или механизмом обязательного закрытия ресурса. Полученную из deref ссылку лучше сохранить на время работы.

`FinalizationRegistry` тоже не гарантирует своевременный callback; критическую очистку выполняют явно. Для метаданных известного объекта часто проще WeakMap.

### Пример и его разбор

```javascript
function readName(reference) {
  const object = reference.deref()
  return object ? object.name : "объект недоступен"
}
// new WeakRef(object) не позволяет предсказать, когда deref вернёт undefined.
```

Deref вызывается один раз, и результат сохраняется в локальной переменной перед чтением name. Если цели уже нет, функция выбирает запасной ответ. Такое ветвление является обязательной частью контракта слабой ссылки, а не исключительным сбоем программы.
