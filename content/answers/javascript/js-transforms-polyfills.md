**Трансформация может заменить синтаксис на совместимый код, а polyfill предоставляет доступную реализацию API там, где это возможно. Успешный разбор TypeScript/JS не доказывает наличие метода в браузере.**

<!-- wishu:answer-block -->

### Как это работает

Некоторые возможности требуют движковой или платформенной поддержки и не воспроизводятся полностью простой пользовательской функцией. Учитывайте target, bundler, загрузку polyfill и ограничения семантики.

Feature detection должна проверять подходящую возможность, а тесты - реальное поведение целевой среды. Ветка if не спасёт файл от неподдерживаемого синтаксиса, который parser не смог разобрать.

### Пример и его разбор

```javascript
const canGroup = typeof Object.groupBy === "function"
// Эта проверка относится к runtime-методу.
// Неподдерживаемый синтаксис using нельзя защитить одним if,
// если parser не способен разобрать весь файл.
```

CanGroup проверяет реализацию метода в работающей среде, а не обещание типов из редактора. Для нового синтаксиса ситуация другая: неподдерживающий parser не дойдёт до проверки if. Совместимость синтаксиса и доступность встроенного API настраивают отдельно.

### Типичная ошибка

> Выставить современный lib в tsconfig и считать реализацию API установленной.
