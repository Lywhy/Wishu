**Трансформация может заменить синтаксис на совместимый код, а polyfill предоставляет доступную реализацию API там, где это возможно. Успешный разбор TypeScript/JS не доказывает наличие метода в браузере.**

### Механизм и границы

Некоторые возможности требуют движковой или платформенной поддержки и не воспроизводятся полностью простой пользовательской функцией. Учитывайте target, bundler, загрузку polyfill и ограничения семантики.

Feature detection должна проверять подходящую возможность, а тесты - реальное поведение целевой среды. Ветка if не спасёт файл от неподдерживаемого синтаксиса, который parser не смог разобрать.
