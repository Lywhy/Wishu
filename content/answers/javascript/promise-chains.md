**Каждый `then` возвращает новый `Promise`; его итог определяется тем, что вернул или выбросил обработчик.** Цепочка работает только если передавать нужные значения и `Promise` дальше.

### Правила цепочки

Обычное значение из обработчика становится успешным результатом следующего Promise. Возвращённый `Promise` или thenable определяет последующий итог.

`throw` переводит следующий `Promise` в rejected. `catch` тоже возвращает `Promise`; возврат обычного значения восстанавливает успешную ветку.

`finally` обычно сохраняет исходный результат; выброшенная ошибка или возвращённый отклонённый `Promise` может заменить его отказом.

### Граница обработки отказа

В `promise.then(onFulfilled, onRejected)` второй обработчик получает отказ исходного Promise. Он не ловит исключение, выброшенное соседним `onFulfilled`: оно отклоняет возвращённый Promise. Для обработки этого нового отказа нужен следующий `catch`. Поэтому `then(success, failure)` и `then(success).catch(failure)` имеют разные границы обработки.

### Пример и его разбор

```javascript
Promise.resolve(2)
  .then((value) => value * 3)
  .then(() => {
    throw new Error("Сбой")
  })
  .catch(() => 10)
  .then((value) => console.log(value)) // 10
```

Первый обработчик преобразует 2 в 6, следующий создаёт отказ через `throw`, а `catch` возвращает 10 и тем самым восстанавливает успешную ветку. Последний `then` получает именно это значение. Каждый шаг формирует новый `Promise`, поэтому важно возвращать вложенную операцию: запуск без `return` отрывает её завершение от ожидаемой цепочки.

### Типичная ошибка

> Запускать `Promise` внутри `then` и не возвращать его, разрывая ожидаемую последовательность.
