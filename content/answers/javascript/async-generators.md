_*`async` function* создаёт асинхронный генератор: его next возвращает `Promise` результата итерации._*

<!-- wishu:answer-block -->

### Как это работает

В теле можно ожидать асинхронные операции через `await` и выдавать последовательные значения через yield. Потребитель использует for await...of либо явно ожидает next.

Это удобно для пагинации и потоков данных, когда следующий элемент появляется позже. Возвращаемое через `return` итоговое значение, как и у обычного генератора, не включается в обычный обход выдаваемых значений.

Нужно предусмотреть обработку ошибок и освобождение ресурсов при прекращении обхода; `async`-генератор не делает вычисления параллельными сам по себе.

### Пример и его разбор

```javascript
async function* pages(loadPage) {
  for (let page = 1; page <= 3; page += 1) {
    yield await loadPage(page)
  }
}
async function consume(loadPage) {
  for await (const data of pages(loadPage)) console.log(data)
}
```

Следующая страница загружается по мере продвижения потребителя через for await. Каждый шаг ожидает loadPage и выдаёт готовые данные, сохраняя состояние номера страницы внутри генератора. Это последовательный источник, а не автоматический параллельный загрузчик. Если потребитель прекращает обход, освобождение подписок или других ресурсов должно быть частью реализации генератора.
