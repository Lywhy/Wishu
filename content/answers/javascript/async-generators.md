**Async function* создаёт асинхронный генератор: его next возвращает Promise результата итерации.**

<!-- wishu:answer-block -->

### Что важно объяснить

- В теле можно ожидать асинхронные операции через await и выдавать последовательные значения через yield.

- Потребитель использует for await...of либо явно ожидает next.

- Это удобно для пагинации и потоков данных, когда следующий элемент появляется позже.

- Возвращаемое через return итоговое значение, как и у обычного генератора, не включается в обычный обход выдаваемых значений.

- Нужно предусмотреть обработку ошибок и освобождение ресурсов при прекращении обхода; async-генератор не делает вычисления параллельными сам по себе.
