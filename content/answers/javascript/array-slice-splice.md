**`slice`(start, end) возвращает поверхностную копию диапазона без изменения исходного массива; end не включается.**

### Как это работает

Без аргументов `slice`() копирует весь массив. `splice`(start, deleteCount, ...items) меняет исходный массив: удаляет указанное число элементов и вставляет новые, возвращая массив удалённых. Второй аргумент у этих методов имеет разный смысл.

`toSpliced` использует параметры редактирования как `splice`, но возвращает весь новый отредактированный массив и не меняет исходный. Это не массив удалённых элементов.

Отрицательные начальные позиции отсчитываются с конца. При работе с пропусками `slice` сохраняет их, а `toSpliced` создаёт плотный результат, записывая `undefined` в оставшиеся отсутствующие позиции.

Копирование вложенных объектов остаётся поверхностным.

### Пример и его разбор

```javascript
const values = [10, 20, 30, 40]
values.slice(1, 3) // [20, 30]
const edited = values.toSpliced(1, 2, 99)
edited // [10, 99, 40]
values // [10, 20, 30, 40]
const removed = values.splice(1, 2, 99)
removed // [20, 30]
values // [10, 99, 40]
```

`slice` в примере лишь выбирает позиции 1 и 2, ничего не удаляя. `toSpliced` возвращает полный изменённый вариант, сохраняя values. `splice` выполняет такую правку на оригинале, но возвращает только удалённые элементы. Различие второго параметра особенно важно: у `slice` это конечная граница, у `splice` и `toSpliced` - количество удалений.
