**Рекурсия - решение задачи через вызов той же функции или цепочки функций для меньшей подзадачи.**

### Как это работает

Базовый случай возвращает результат без нового рекурсивного вызова. Каждый шаг должен приближаться к нему; само наличие условия остановки не помогает, если аргументы никогда его не достигают.

Рекурсия естественна для деревьев, вложенных структур и алгоритмов «разделяй и властвуй». Обычные рекурсивные вызовы расходуют стек.

Для графа одной проверки листа недостаточно: циклы требуют отслеживания посещённых вершин. В примере допустимы только небольшие неотрицательные целые; на больших значениях Number теряет точность или переполняется.

### Пример и его разбор

```javascript
function factorial(n) {
  if (!Number.isInteger(n) || n < 0) {
    throw new RangeError("Нужно неотрицательное целое")
  }
  if (n === 0) return 1
  return n * factorial(n - 1)
}
factorial(5) // 120
```

factorial уменьшает n на единицу и останавливается при нуле, где возвращает готовое значение 1. После этого ожидающие вызовы последовательно умножают результаты, получая 120 для 5. Проверка аргумента важна: отрицательное или дробное значение не соответствует этому доказательству завершения. Для больших входов отдельно учитывают глубину стека и точность чисел.
