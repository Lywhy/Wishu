**Static создаёт поле или метод на самом классе-конструкторе, а не на его экземплярах.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Такие методы удобны для фабрик и операций, связанных с типом в целом.

- Вызывают их через Class.method(), а экземпляр не получает этот метод как обычный instance-метод.

- При вызове через класс this статического метода указывает на соответствующий конструктор, включая потомка при наследовании.

- Статические публичные члены могут наследоваться по цепочке конструкторов.

- Если метод использует приватный static-член базового класса, перенос вызова на потомка имеет дополнительные ограничения приватной принадлежности.
