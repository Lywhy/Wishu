**Static создаёт поле или метод на самом классе-конструкторе, а не на его экземплярах.**

<!-- wishu:answer-block -->

### Как это работает

Такие методы удобны для фабрик и операций, связанных с типом в целом. Вызывают их через Class.method(), а экземпляр не получает этот метод как обычный instance-метод.

При вызове через класс `this` статического метода указывает на соответствующий конструктор, включая потомка при наследовании. Статические публичные члены могут наследоваться по цепочке конструкторов.

Если метод использует приватный static-член базового класса, перенос вызова на потомка имеет дополнительные ограничения приватной принадлежности.

### Пример и его разбор

```javascript
class User {
  static kind = "user"
  static create(name) {
    return new this(name)
  }
  constructor(name) {
    this.name = name
  }
}
User.kind // "user"
User.create("Аня").name // "Аня"
new User("Оля").create // undefined
```

Create вызывается на User и создаёт экземпляр через `new` this. У экземпляра create отсутствует, поскольку поиск его обычных методов идёт по другой цепочке. При наследовании такая фабрика может создавать потомка, если его конструктор поддерживает переданные аргументы.
