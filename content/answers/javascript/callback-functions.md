**Callback - функция, переданная другому коду для последующего вызова в оговорённый момент, в том числе прямо в ходе текущего вызова.**

<!-- wishu:answer-block -->

### Как это работает

Принимать функцию может библиотечный метод или ваша собственная функция. Передать callback - это передать ссылку на функцию, а не обязательно вызвать её при передаче.

Аргументы, `this`, количество вызовов и использование результата определяются принимающим API. Например, `Map` передаёт элемент, индекс и массив.

Дополнительные данные можно зафиксировать в замыкании или bind. Передача функции с неожиданно совместимой сигнатурой опасна: `Map`(parseInt) передаст индекс как основание системы счисления, поэтому лучше явно описать нужный вызов.

### Пример и его разбор

```javascript
function transform(value, callback) {
  return callback(value, "результат")
}
transform(3, (number, label) => `${label}: ${number * 2}`)
// "результат: 6"
;["10", "11"].map((text) => Number.parseInt(text, 10)) // [10, 11]
```

transform сама определяет, что передать callback: число 3 и текстовую метку. Возвращённая callback строка становится результатом transform, потому что принимающая функция явно её возвращает. У `Map` контракт другой: он передаёт также индекс, поэтому parseInt лучше вызывать через обёртку с явно заданным основанием 10, не передавая метод напрямую.
