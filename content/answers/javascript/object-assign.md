**`Object.assign(target, ...sources)` копирует значения собственных перечисляемых строковых и символьных свойств в target.** Это поверхностная операция, изменяющая целевой объект.

### Assign и spread

| Свойство                   | `Object.assign`   | Объектный spread                                |
| -------------------------- | ----------------- | ----------------------------------------------- |
| Назначение                 | Переданный target | Новый объект литерала                           |
| Глубина                    | Поверхностная     | Поверхностная                                   |
| `getter` источника         | Может вызываться  | Может вызываться                                |
| `setter` в целевом объекте | Может вызываться  | Копируемое свойство создаётся как data property |

### На что обратить внимание

При конфликте более поздний источник заменяет значение. Вложенные объекты остаются общими ссылками.

Дескрипторы не копируются как дескрипторы. Ошибка во время assign может оставить target частично изменённым.

### Пример и его разбор

```javascript
const target = { theme: "light" }
const source = { nested: { enabled: true } }
const result = Object.assign(target, source, { theme: "dark" })
result === target // true
target.theme // "dark"
target.nested === source.nested // true
```

Assign последовательно записывает поля источников в переданный target и возвращает именно его. При одинаковом ключе побеждает более поздний источник, а вложенные объекты остаются общими. Это также операция чтения и записи: `getter` источника и `setter` цели могут выполниться, поэтому assign не всегда эквивалентен созданию объекта через spread.

### Типичная ошибка

> Считать `Object.assign` глубоким копированием или предполагать, что `setter` всегда ведёт себя как при spread.
