**`Object.assign(target, ...sources)` копирует значения собственных перечисляемых строковых и символьных свойств в target.** Это поверхностная операция, изменяющая целевой объект.

<!-- wishu:answer-block -->

### Assign и spread

| Свойство | Object.assign | Объектный spread |
| --- | --- | --- |
| Назначение | Переданный target | Новый объект литерала |
| Глубина | Поверхностная | Поверхностная |
| Getter источника | Может вызываться | Может вызываться |
| Setter в целевом объекте | Может вызываться | Копируемое свойство создаётся как data property |

<!-- wishu:answer-block -->

### На что обратить внимание

- При конфликте более поздний источник заменяет значение.
- Вложенные объекты остаются общими ссылками.
- Дескрипторы не копируются как дескрипторы.
- Ошибка во время assign может оставить target частично изменённым.
