**Чистая функция при одинаковых входных значениях даёт одинаковый результат и не создаёт наблюдаемых побочных эффектов.**

<!-- wishu:answer-block -->

### Как это работает

Она не изменяет переданные объекты или внешние переменные. Побочные эффекты включают запись в DOM, хранилище или файл, сетевые действия и логирование.

Чтение текущего времени, случайности или изменяемого внешнего состояния делает результат зависимым не только от аргументов. Изменение нового локального объекта, который не был доступен снаружи, само по себе не нарушает чистоту.

Побочные эффекты нужны приложениям; их удобно отделять от вычислений, а необходимые внешние данные передавать явно.

### Пример и его разбор

```javascript
function addItem(items, item) {
  return [...items, item]
}
const original = [1, 2]
const updated = addItem(original, 3)
original // [1, 2]
updated // [1, 2, 3]
```

addItem создаёт новый массив, поэтому original остаётся [1, 2], а updated получает дополнительный элемент. Важна не только неизменность аргументов: результат также не должен зависеть от скрытого времени или меняющегося внешнего состояния. Локальное создание и заполнение нового массива допустимо, если оно не изменяет наблюдаемое снаружи состояние.
