**В хвостовой рекурсии рекурсивный вызов - последняя операция на данном пути выполнения: его результат сразу возвращается без последующей работы. `return` n * factorial(n - 1) не хвостовой, поскольку после возврата ещё нужно умножение.**

### Как это работает

Аккумулятор позволяет перенести накопление результата в аргументы. Спецификация описывает proper tail calls для подходящих хвостовых вызовов в строгом коде, но реализации движков различаются.

Нельзя рассчитывать, что хвостовая запись автоматически устранит переполнение стека во всех целевых средах. Для переносимого решения с большой глубиной обычно используют цикл или явный стек; пример показывает форму, а не обещает неограниченную глубину.

### Пример и его разбор

```javascript
"use strict"
function factorialTail(n, accumulator = 1) {
  if (!Number.isInteger(n) || n < 0) {
    throw new RangeError("Нужно неотрицательное целое")
  }
  if (n === 0) return accumulator
  return factorialTail(n - 1, accumulator * n)
}
factorialTail(5) // 120
```

Аккумулятор хранит уже вычисленную часть произведения, поэтому после рекурсивного вызова функции больше нечего умножать. Это делает вызов хвостовым по форме. Однако сохранение стека зависит от поддержки proper tail calls целевым движком, а не от выбранного имени factorialTail. Для большой переносимой нагрузки ту же зависимость состояния обычно выражают циклом.
