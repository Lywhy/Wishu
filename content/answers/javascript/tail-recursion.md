**В хвостовой рекурсии рекурсивный вызов - последняя операция на данном пути выполнения: его результат сразу возвращается без последующей работы. return n * factorial(n - 1) не хвостовой, поскольку после возврата ещё нужно умножение.**

### Что важно объяснить

- Аккумулятор позволяет перенести накопление результата в аргументы.

- Спецификация описывает proper tail calls для подходящих хвостовых вызовов в строгом коде, но реализации движков различаются.

- Нельзя рассчитывать, что хвостовая запись автоматически устранит переполнение стека во всех целевых средах.

- Для переносимого решения с большой глубиной обычно используют цикл или явный стек; пример показывает форму, а не обещает неограниченную глубину.
