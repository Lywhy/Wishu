**fn.bind(thisArg, ...args) возвращает новую функцию, не вызывая исходную.**

<!-- wishu:answer-block -->

### Что важно объяснить

- При обычном вызове новой функции this будет привязан, а заранее переданные аргументы добавятся перед новыми.

- Повторный bind не заменяет this первой привязки, хотя может добавить ещё аргументы.

- У стрелки bind не меняет this, но может привязать аргументы.

- Если исходная функция допускает new, связанная обычно тоже допускает new: тогда привязанный this игнорируется в пользу нового экземпляра, а аргументы сохраняются.

- Для обработчиков важно хранить результат bind: каждый вызов bind создаёт новую ссылку.
