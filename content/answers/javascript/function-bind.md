**fn.bind(thisArg, ...args) возвращает новую функцию, не вызывая исходную.**

<!-- wishu:answer-block -->

### Как это работает

При обычном вызове новой функции `this` будет привязан, а заранее переданные аргументы добавятся перед новыми. Повторный `bind` не заменяет `this` первой привязки, хотя может добавить ещё аргументы.

У стрелки `bind` не меняет `this`, но может привязать аргументы. Если исходная функция допускает `new`, связанная обычно тоже допускает `new`: тогда привязанный `this` игнорируется в пользу нового экземпляра, а аргументы сохраняются.

Для обработчиков важно хранить результат `bind`: каждый вызов `bind` создаёт новую ссылку.

### Пример и его разбор

```javascript
function total(a, b) {
  return this.base + a + b
}
const withBase = total.bind({ base: 10 }, 2)
withBase(3) // 15
withBase.call({ base: 100 }, 3) // 15
```

Функция withBase уже хранит выбранный объект и первый аргумент 2. Последующий вызов добавляет 3 и получает 15. Попытка передать другой объект через `call` не переопределяет ранее связанный this. При использовании `bind` как обработчика нужно сохранить полученную функцию: повторный `bind` создаст другое значение, которое нельзя считать прежней подпиской.
