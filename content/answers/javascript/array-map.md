**map вызывает callback с элементом, индексом и исходным массивом, а возвращаемое значение callback помещает в новый массив на соответствующую позицию.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Это выбор для преобразования данных, например получения названий из массива объектов.

- Сам метод не переписывает исходный массив, но callback может сделать это своими действиями.

- Для плотного массива результат имеет ту же длину.

- Отсутствующие позиции разрежённого массива пропускаются и остаются пропусками результата.

- Если callback с блочным телом забывает return, для посещённых позиций записывается `undefined`.

- Map не ожидает Promise: async callback даёт массив Promise, который обычно объединяют через `Promise.all`.
