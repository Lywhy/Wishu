**`Map` вызывает callback с элементом, индексом и исходным массивом, а возвращаемое значение callback помещает в новый массив на соответствующую позицию.**

### Как это работает

Это выбор для преобразования данных, например получения названий из массива объектов. Сам метод не переписывает исходный массив, но callback может сделать это своими действиями.

Для плотного массива результат имеет ту же длину. Отсутствующие позиции разрежённого массива пропускаются и остаются пропусками результата.

Если callback с блочным телом забывает `return`, для посещённых позиций записывается `undefined`. `Map` не ожидает `Promise`: `async` callback даёт массив `Promise`, который обычно объединяют через `Promise.all`.

### Пример и его разбор

```javascript
const users = [{ name: "Аня" }, { name: "Оля" }]
const names = users.map((user) => user.name)
names // ["Аня", "Оля"]
users.length // 2
const missingReturn = [1, 2].map((value) => {
  value * 2
})
missingReturn // [undefined, undefined]
```

`Map` вызывает преобразование для каждого существующего элемента и записывает возвращённое значение в соответствующую позицию нового массива. Именно `return` callback определяет результат; изменение внешней переменной не заменяет его. Если возвращается объект, он не клонируется автоматически. Для асинхронного callback результатом будет массив `Promise`, который нужно ожидать отдельным механизмом.
