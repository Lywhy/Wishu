**Function создаёт функцию из строк параметров и тела: new Function("a", "b", "return a + b").**

<!-- wishu:answer-block -->

### Что важно объяснить

- Ключевое слово new необязательно.

- Полученная функция выполняет тело только при вызове, но строки разбираются уже при создании функции.

- Такая функция не замыкает локальное окружение места создания: её внешняя область - глобальная.

- Строгость вызывающего кода автоматически не наследуется; при необходимости директива должна быть в создаваемом теле.

- Выполнение строк с недоверенными данными опасно, а CSP может запрещать такой код.

- Обычно лучше обычная функция с явными параметрами.
