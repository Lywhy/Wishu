**Function создаёт функцию из строк параметров и тела: `new` Function("a", "b", "`return` a + b").**

<!-- wishu:answer-block -->

### Как это работает

Ключевое слово `new` необязательно. Полученная функция выполняет тело только при вызове, но строки разбираются уже при создании функции.

Такая функция не замыкает локальное окружение места создания: её внешняя область - глобальная. Строгость вызывающего кода автоматически не наследуется; при необходимости директива должна быть в создаваемом теле.

Выполнение строк с недоверенными данными опасно, а CSP может запрещать такой код. Обычно лучше обычная функция с явными параметрами.

### Пример и его разбор

```javascript
const sum = new Function("a", "b", "return a + b;")
sum(2, 3) // 5
// Предпочтительный вариант для известной операции:
const add = (a, b) => a + b
add(2, 3) // 5
```

В первом варианте параметры и тело сначала существуют как строки, которые конструктор разбирает как программу. Во втором тот же известный алгоритм уже явно записан в исходном коде. Результат обоих вызовов равен 5, но контракты доверия и области видимости различаются: Function не восстанавливает локальное окружение места своего создания.
