**Стандартные операции Set позволяют получать новые множества и проверять отношения: union, intersection, difference, symmetricDifference и предикаты подмножества или непересечения.**

### Механизм и границы

Элементы сравниваются по правилам Set; два разных объекта с одинаковыми полями не становятся одним элементом. Порядок результата и требования к set-like аргументу определяются конкретным методом.

Методы не являются математическими операторами над любыми массивами. При поддержке старой среды предусмотрите соответствующую реализацию, не изменяя исходный набор незаметно.
