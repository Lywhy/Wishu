**Стандартные операции `Set` позволяют получать новые множества и проверять отношения: union, intersection, difference, symmetricDifference и предикаты подмножества или непересечения.**

### Как это работает

Элементы сравниваются по правилам `Set`; два разных объекта с одинаковыми полями не становятся одним элементом. Порядок результата и требования к `Set`-like аргументу определяются конкретным методом.

Методы не являются математическими операторами над любыми массивами. При поддержке старой среды предусмотрите соответствующую реализацию, не изменяя исходный набор незаметно.

### Пример и его разбор

```javascript
const a = new Set([1, 2])
const b = new Set([2, 3])
console.log([...a.intersection(b)]) // [2]
console.log([...a.union(b)]) // [1, 2, 3]
console.log(a.size) // 2
```

Пересечение содержит только общую двойку, а объединение - все значения без повторов. Исходное a сохраняет размер 2, потому что операции создают новые множества. Такое поведение удобно для сравнения доступов и выбранных значений, но равенство объектов остаётся ссылочным. Перед использованием новых методов проверяют возможности конкретной среды.

### Типичная ошибка

> Считать одинаковые по содержимому объекты одинаковыми `Set`-элементами.
