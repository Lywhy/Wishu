**Объект - значение с собственной идентичностью и набором свойств.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Ключ обычного свойства - строка или `Symbol`; другие значения при обращении преобразуются к ключу.

- Значением свойства может быть любой тип, включая другой объект или функцию.

- Accessor-свойства вместо хранимого значения описывают доступ через get и set.

- Помимо собственных свойств, у обычного объекта есть внутренний прототип - другой объект или `null`.

- Унаследованные свойства доступны при чтении, но не становятся собственными.

- Два объекта с одинаковыми свойствами остаются разными объектами.

- Если нужны произвольные объекты как самостоятельные ключи, часто подходит Map: обычный объект не сохраняет такой ключ без преобразования.
