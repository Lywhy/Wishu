**Объект - значение с собственной идентичностью и набором свойств.**

<!-- wishu:answer-block -->

### Как это работает

Ключ обычного свойства - строка или `Symbol`; другие значения при обращении преобразуются к ключу. Значением свойства может быть любой тип, включая другой объект или функцию.

Accessor-свойства вместо хранимого значения описывают доступ через get и set. Помимо собственных свойств, у обычного объекта есть внутренний прототип - другой объект или `null`.

Унаследованные свойства доступны при чтении, но не становятся собственными. Два объекта с одинаковыми свойствами остаются разными объектами.

Если нужны произвольные объекты как самостоятельные ключи, часто подходит `Map`: обычный объект не сохраняет такой ключ без преобразования.

### Пример и его разбор

```javascript
const id = Symbol("id")
const user = { name: "Аня", [id]: 7 }
user[1] = "значение"
user["1"] // "значение": ключ преобразован в строку
user[id] // 7
;({ name: "Аня" }) === { name: "Аня" } // false
```

В примере числовой ключ становится строкой, а символьный сохраняет собственную идентичность. Два одинаково записанных литерала создают разные объекты, поэтому сравнение ссылок даёт false. Эта модель объясняет, почему объект подходит для записи с именованными полями, но его равенство не определяется совпадением содержимого.
