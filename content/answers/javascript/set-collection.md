**Set хранит уникальные значения любого типа и позволяет добавлять их через add, проверять has, удалять delete и узнавать число через size.**

### Что важно объяснить

- Коллекция итерируема и сохраняет порядок добавления. new Set(array) часто используют для удаления повторяющихся примитивов, а spread или `Array.from` возвращают результат в виде массива.

- Сравнение основано на SameValueZero: `NaN` считается равным `NaN`, а +0 и -0 не различаются.

- Объекты сравниваются по идентичности, поэтому два разных объекта с одинаковыми полями останутся отдельными значениями.

- Set не даёт индексного доступа как массив; set[0] не получает первый элемент коллекции.
