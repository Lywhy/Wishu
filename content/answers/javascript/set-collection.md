**`Set` хранит уникальные значения любого типа и позволяет добавлять их через add, проверять has, удалять delete и узнавать число через size.**

### Как это работает

Коллекция итерируема и сохраняет порядок добавления. `new` `Set`(array) часто используют для удаления повторяющихся примитивов, а spread или `Array.from` возвращают результат в виде массива. Сравнение основано на SameValueZero: `NaN` считается равным `NaN`, а +0 и -0 не различаются.

Объекты сравниваются по идентичности, поэтому два разных объекта с одинаковыми полями останутся отдельными значениями. `Set` не даёт индексного доступа как массив; `Set`[0] не получает первый элемент коллекции.

### Пример и его разбор

```javascript
const values = new Set([1, 1, 2, NaN, NaN])
values.size // 3
values.has(2) // true
;[...values] // [1, 2, NaN]
const item = { id: 1 }
new Set([item, item]).size // 1
new Set([{ id: 1 }, { id: 1 }]).size // 2
```

Два одинаковых числа и два `NaN` объединяются по правилам `Set`, но объекты с одинаковым id остаются разными, если были созданы отдельно. Повторное добавление той же ссылки item уже не увеличивает size. Поэтому удаление повторов через `Set` подходит только тогда, когда требуемая уникальность действительно совпадает с равенством значений коллекции.
