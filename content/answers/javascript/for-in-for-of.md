**for...in перебирает перечисляемые строковые ключи, включая унаследованные, но исключая символы.**

<!-- wishu:answer-block -->

### Как это работает

Для обработки только собственных ключей нужны `Object.keys`/`Object.entries` или проверка `Object.hasOwn`. Индексы массива при таком обходе тоже будут строками, а дополнительные свойства могут попасть в результат.

for...of получает значения через протокол итерации. Он подходит массивам, строкам, `Set`, `Map` и другим итерируемым объектам.

Обычный объект по умолчанию не итерируем; его пары удобно обойти через for...of `Object.entries`(obj). Для значений массива обычно выбирают for...of.

### Пример и его разбор

```javascript
const values = ["a", "b"]
for (const key in values) {
  console.log(key)
} // "0", "1"
for (const value of values) {
  console.log(value)
} // "a", "b"
for (const [key, value] of Object.entries({ name: "Аня" })) {
  console.log(key, value)
}
```

Ключи «0» и «1» из первого обхода являются строковыми именами свойств. Во втором обходе значения «a» и «b» предоставляет итератор массива. `Object.entries` превращает свойства обычного объекта в итерируемый массив пар, после чего for...of получает каждую пару. Такой явный выбор помогает не включить унаследованные или дополнительные свойства в обработку элементов.
