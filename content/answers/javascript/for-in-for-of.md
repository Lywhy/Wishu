**for...in перебирает перечисляемые строковые ключи, включая унаследованные, но исключая символы.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Для обработки только собственных ключей нужны `Object.keys`/`Object.entries` или проверка `Object.hasOwn`.

- Индексы массива при таком обходе тоже будут строками, а дополнительные свойства могут попасть в результат.

- for...of получает значения через протокол итерации.

- Он подходит массивам, строкам, Set, Map и другим итерируемым объектам.

- Обычный объект по умолчанию не итерируем; его пары удобно обойти через for...of `Object.entries`(obj).

- Для значений массива обычно выбирают for...of.
