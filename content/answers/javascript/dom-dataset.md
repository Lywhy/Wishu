**Data-* позволяет хранить небольшие пользовательские данные на HTML-элементе.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Dataset предоставляет доступ через DOMStringMap: data-user-id соответствует dataset.userId.

- Значения хранятся как строки, поэтому присваивание числа не сохраняет числовой тип.

- Для удаления используют delete element.dataset.key.

- Логические и числовые значения нужно преобразовывать по контракту данных: Boolean("false") даст true, поэтому для флага часто нужна явная проверка строки.

- Атрибуты доступны коду и инструментам страницы, поэтому они не подходят для секретов и не заменяют полноценное состояние приложения.
