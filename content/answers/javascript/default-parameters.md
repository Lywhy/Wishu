**Значение параметра по умолчанию используется, если аргумент не передан или равен `undefined`. `null`, false, 0 и пустая строка его не включают.**

### Что важно объяснить

- Инициализатор вычисляется при каждом вызове, когда нужен: например, литерал [] создаёт новый массив, а не один общий для всех вызовов.

- Параметры инициализируются слева направо: более поздний может использовать предыдущий.

- Инициализаторы имеют отдельную область, внешнюю по отношению к телу функции; объявления внутри тела им недоступны.

- Ссылка на ещё не инициализированный поздний параметр вызывает ReferenceError.
