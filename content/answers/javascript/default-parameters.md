**Значение параметра по умолчанию используется, если аргумент не передан или равен `undefined`. `null`, `false`, 0 и пустая строка его не включают.**

### Как это работает

Инициализатор вычисляется при каждом вызове, когда нужен: например, литерал [] создаёт новый массив, а не один общий для всех вызовов. Параметры инициализируются слева направо: более поздний может использовать предыдущий.

Инициализаторы имеют отдельную область, внешнюю по отношению к телу функции; объявления внутри тела им недоступны. Ссылка на ещё не инициализированный поздний параметр вызывает ReferenceError.

### Пример и его разбор

```javascript
function greet(name = "гость") {
  return `Привет, ${name}`
}
greet() // "Привет, гость"
greet(undefined) // "Привет, гость"
greet(null) // "Привет, null"
function pair(first, second = first) {
  return [first, second]
}
pair(3) // [3, 3]
```

Пропущенный аргумент и явное `undefined` включают значение «гость», но `null` остаётся переданным значением и попадает в текст. В pair второй параметр может прочитать уже инициализированный first. Это вычисление при входе в конкретный вызов, поэтому создание объекта в default не означает общего объекта для всех вызовов.
