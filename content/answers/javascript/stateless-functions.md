**В прикладном смысле функция без состояния не хранит собственные изменяемые данные между вызовами; нужные данные передаются через аргументы.**

### Как это работает

Локальные переменные, заново создаваемые при вызове, не делают функцию сохраняющей состояние. Счётчик в замыкании, наоборот, сохраняет его между вызовами.

Отсутствие собственного состояния не гарантирует чистоту: функция может обращаться к времени, сети или изменять переданный объект. Чистота дополнительно требует предсказуемого результата и отсутствия наблюдаемых побочных эффектов.

Термин stateless описывает организацию состояния, а не отдельный синтаксис языка.

### Пример и его разбор

```javascript
const increment = (value) => value + 1 // состояние передаётся явно
const currentTime = () => Date.now() // не чистая: зависит от времени
function createCounter() {
  let value = 0
  return () => ++value // состояние сохраняется в замыкании
}
```

increment получает всё нужное состояние явно через value. currentTime не хранит собственного счётчика, но его результат меняется вместе с внешним временем, поэтому функция не чистая. Возвращённая createCounter функция, напротив, намеренно хранит состояние в замыкании. Термины отвечают на разные вопросы: где живут данные и насколько предсказуемо вычисление.
