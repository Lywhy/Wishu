**&& вычисляет операнды слева направо и возвращает первый falsy-операнд.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Если все операнды truthy, возвращается последний.

- Результат не обязательно boolean: оператор сохраняет само значение выбранного операнда.

- После falsy-операнда остальные выражения не выполняются: это короткое замыкание.

- Например, условие может защитить вызов функции.

- Если необходим boolean, результат преобразуют через Boolean или !!.

- В JSX выражение count && `<Block />` при count равном 0 может отрисовать сам ноль.
