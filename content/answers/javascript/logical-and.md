**&& вычисляет операнды слева направо и возвращает первый falsy-операнд.**

<!-- wishu:answer-block -->

### Как это работает

Если все операнды truthy, возвращается последний. Результат не обязательно boolean: оператор сохраняет само значение выбранного операнда.

После falsy-операнда остальные выражения не выполняются: это короткое замыкание. Например, условие может защитить вызов функции.

Если необходим boolean, результат преобразуют через Boolean или !!. В JSX выражение count && `<Block />` при count равном 0 может отрисовать сам ноль.

### Пример и его разбор

```javascript
0 && "готово" // 0
"JS" && 42 // 42
let called = false
false && (called = true)
called // false
```

Первая проверка возвращает сам ноль: этого falsy-значения уже достаточно, чтобы остановить вычисление. Вторая доходит до 42, поскольку строка «JS» truthy. В последнем случае присваивание справа вообще не происходит, поэтому called остаётся false. Когда нужен именно логический результат, его получают отдельно через Boolean, не меняя правил короткого замыкания.
