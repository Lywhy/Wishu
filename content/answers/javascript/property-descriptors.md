**Дескриптор описывает поведение собственного свойства.**

<!-- wishu:answer-block -->

### Что важно объяснить

- У data-свойства есть value и writable, у accessor-свойства - get и set; смешивать эти два варианта нельзя.

- Общие флаги enumerable и configurable управляют перечислением и возможностью удаления или изменения конфигурации. `Object.getOwnPropertyDescriptor` читает дескриптор, `Object.defineProperty` создаёт или изменяет свойство и возвращает объект.

- writable: false запрещает обычное присваивание нового значения data-свойству, но не замораживает вложенный объект.

- Getter без setter - другой вариант свойства только для чтения. configurable: false запрещает удаление и большинство изменений дескриптора; у ещё writable data-свойства остаётся возможность изменить value и один раз отключить writable.

- При создании нового свойства через defineProperty пропущенные флаги равны false, а value по умолчанию - `undefined`.

- При изменении существующего свойства пропущенные настройки сохраняются.

- У обычного свойства литерала флаги изначально true.

- При запрещённом присваивании строгий режим вызывает TypeError; TypeScript readonly отдельно от этих механизмов работает на этапе проверки типов.
