**Мемоизация сохраняет вычисленный результат для входа и возвращает его повторно без нового вычисления.**

### Как это работает

Она полезна для дорогих повторяемых вычислений, когда результат определяется учтёнными входными данными. Если функция зависит от скрытого состояния, времени или побочных эффектов, обычное кеширование может изменить ожидаемое поведение.

Нужно определить все части ключа, правила сравнения, ограничение памяти и срок актуальности. В примере кешируется чистая синхронная одноаргументная функция; `Map` сравнивает объектные ключи по идентичности. has отличает отсутствие записи от кешированного `undefined`.

Кеш неограничен, не учитывает `this` и не предназначен как универсальное решение для `Promise` или нескольких аргументов; возвращаемые объекты также будут общими.

### Пример и его разбор

```javascript
function memoizeUnary(fn) {
  const cache = new Map()
  return (value) => {
    if (cache.has(value)) return cache.get(value)
    const result = fn(value)
    cache.set(value, result)
    return result
  }
}
const square = memoizeUnary((value) => value * value)
square(4) // 16
square(4) // 16 из кеша
```

Первый вызов square(4) вычисляет результат и записывает его под ключом 4. Второй находит запись и возвращает её без повторного fn. Использование has важно для функции, законно возвращающей `undefined`: такое значение тоже можно кешировать. Корректность зависит от полноты ключа и стабильности вычисления, а бесконечное хранение записей требует отдельной политики.
