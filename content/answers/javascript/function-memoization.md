**Мемоизация сохраняет вычисленный результат для входа и возвращает его повторно без нового вычисления.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Она полезна для дорогих повторяемых вычислений, когда результат определяется учтёнными входными данными.

- Если функция зависит от скрытого состояния, времени или побочных эффектов, обычное кеширование может изменить ожидаемое поведение.

- Нужно определить все части ключа, правила сравнения, ограничение памяти и срок актуальности.

- В примере кешируется чистая синхронная одноаргументная функция; Map сравнивает объектные ключи по идентичности. has отличает отсутствие записи от кешированного `undefined`.

- Кеш неограничен, не учитывает this и не предназначен как универсальное решение для Promise или нескольких аргументов; возвращаемые объекты также будут общими.
