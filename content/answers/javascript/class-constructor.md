**Constructor выполняет инициализацию при new.**

<!-- wishu:answer-block -->

### Как это работает

В синтаксисе одного класса допускается один constructor; несколько объявлений приводят к SyntaxError. Разные способы создания выражают параметрами, их проверкой или статическими фабриками, а не перегрузками как в некоторых других языках.

Если constructor не задан, у базового класса используется пустая инициализация, а производный по умолчанию передаёт аргументы в родительский. Собственный конструктор потомка должен вызвать super перед использованием `this`, если создаётся обычный экземпляр через родителя.

Значения полей инициализируются по отдельным правилам порядка.

### Пример и его разбор

```javascript
class User {
  constructor(name = "гость") {
    this.name = name
  }
  static guest() {
    return new User()
  }
}
class Admin extends User {}
new Admin("Аня").name // "Аня"
User.guest().name // "гость"
```

Admin не объявляет constructor, поэтому аргумент имени передаётся родителю автоматически. Фабрика guest использует тот же единственный конструктор, но выбирает другой сценарий создания. Так варианты инициализации выражаются обычными параметрами и методами без нескольких constructor в одном классе.
