**Логическое присваивание записывает значение только при подходящем условии и вычисляет ссылку левой части один раз. ||= реагирует на falsy, &&= на truthy, ??= только на `null` и undefined.**

### Как это работает

Это важно для `getter`/`setter`, Proxy и вычисляемого индекса с побочным эффектом. Конструкция не просто текстовая замена x = x || y: запись может вообще не произойти.

Выбор ??= сохраняет допустимые 0, `false` и пустую строку. Значение по умолчанию может быть вычислено лениво, если правая часть действительно понадобилась.

### Пример и его разбор

```javascript
let writes = 0
const state = {
  get value() {
    return 1
  },
  set value(next) {
    writes++
  },
}
state.value ||= 10
console.log(writes) // 0: присваивание не потребовалось.
const options = { retries: 0 }
options.retries ??= 3 // Ноль сохраняется.
```

`getter` возвращает truthy-значение 1, поэтому ||= не вычисляет ненужное присваивание и `setter` не вызывается. В options число 0 также остаётся прежним, но уже потому, что ??= проверяет только отсутствие через `null` или undefined. Такая семантика важна для свойств с побочными эффектами: чтение и запись не являются взаимозаменяемыми действиями.

### Типичная ошибка

> Заменять ??= на ||= в настройках, где ноль или `false` допустимы.
