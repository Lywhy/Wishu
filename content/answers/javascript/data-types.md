В JavaScript **8 типов данных: 7 примитивных и object**. Массивы и функции относятся к объектам; специальный результат `typeof fn === "function"` не делает функцию девятым типом.

### Примитивы и объекты

| Тип | Пример | Важный нюанс |
| --- | --- | --- |
| undefined | `undefined` | Значение отсутствует или не было присвоено |
| null | `null` | Явно заданное отсутствие значения |
| boolean | `true` | Два логических значения |
| number | `42`, `NaN` | Включает бесконечности и дробные числа |
| bigint | `42n` | Целые числа произвольной точности в пределах ресурсов |
| string | `"JS"` | Примитивное неизменяемое значение |
| symbol | `Symbol("id")` | Уникальный символ, пригодный для ключа |
| object | `{}`, `[]` | Объектная идентичность и свойства |

<!-- wishu:answer-block -->

### Что важно объяснить

- Примитивы неизменяемы; изменение переменной означает присваивание другого значения.
- Несколько переменных могут содержать ссылки на один объект.
- `typeof null` возвращает `"object"` по исторической причине, хотя `null` - примитив.
