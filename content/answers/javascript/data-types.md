**В JavaScript восемь типов: семь примитивных и `object`. К примитивам относятся `undefined`, `null`, `boolean`, `number`, `bigint`, `string` и `symbol`. Массивы и функции являются объектами, а не отдельными типами.**

### Как это работает

Различие важно для работы со значениями. Примитив неизменяем: операция над строкой создаёт новое значение, а присваивание меняет значение переменной. У объекта есть идентичность и изменяемые свойства. Поэтому две переменные могут указывать на один объект: изменение свойства через одну переменную будет видно через другую. Само присваивание при этом не создаёт копию объекта.

Оператор `typeof` помогает различать некоторые случаи, но не является полной системой проверки данных. Например, `typeof` `null` возвращает историческое значение "`object`", а для функции результат равен "function". Это особенности оператора: `null` остаётся примитивом, а функция - объектом с возможностью вызова.

### Пример и его разбор

```javascript
let text = "JS"
text = text + "!" // новое строковое значение
const first = { count: 1 }
const second = first
second.count = 2
console.log(first.count) // 2
console.log(typeof []) // "object"
console.log(Array.isArray([])) // true
console.log(typeof (() => {})) // "function"
```

В примере ниже сравните результаты `typeof` с описанной классификацией. Массив не становится отдельным типом из-за специального синтаксиса []; для его распознавания применяют `Array.isArray`. Проверяя данные, сначала определяют нужный контракт: достаточно ли типа или нужны ещё структура и ограничения значений.

### Нюансы и типичные ошибки

Не путайте неизменяемость примитива с запретом переназначить переменную. Переменная `let` может последовательно содержать разные строки; существующая строка при этом не изменяется.
