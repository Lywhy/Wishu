**ListFormat соединяет элементы по правилам языка и выбранного типа списка, включая союз или альтернативу. `join` использует один заданный разделитель и не знает грамматику языка.**

<!-- wishu:answer-block -->

### Как это работает

`formatToParts` помогает отдельно отобразить элементы и разделители без ненадёжного разрезания результирующей строки. Не вставляйте пользовательский текст в HTML через конкатенацию только потому, что он прошёл formatter.

Для машинного CSV или протокольного формата нужен свой контракт escaping; ListFormat предназначен для представления человеку.

### Пример и его разбор

```javascript
const formatter = new Intl.ListFormat("ru", { style: "long", type: "conjunction" })
const text = formatter.format(["HTML", "CSS", "JavaScript"])
// Локализованный список, а не машинный формат обмена.
```

Для HTML, CSS и JavaScript форматтер выбирает подходящие разделители и союз русского языка. В отличие от `join` он знает роль последнего элемента в списке. Полученный текст предназначен для человека; для передачи данных используют отдельный машинный формат.

### Типичная ошибка

> Использовать локализованный список вместо CSV или вручную ставить английский and для всех locale.
