**Явное преобразование задаётся напрямую: Number(value), String(value), Boolean(value).**

### Как это работает

Неявное выполняется по правилам операции: например, вычитание преобразует подходящие строки в числа, а сложение со строкой может выполнять конкатенацию. Объекты сначала преобразуются к примитивам через предусмотренные языком методы.

При [] == `false` логическое `false` преобразуется в 0. Массив преобразуется к примитивной пустой строке, затем "" - к 0, поэтому сравнение даёт true.

Это не проверка truthy/falsy: сам пустой массив в логическом контексте truthy, так что Boolean([]) равно true.

### Пример и его разбор

```javascript
Number("42") // 42
String(false) // "false"
"5" - 1 // 4
"5" + 1 // "51"
;[] == false // true
Boolean([]) // true
```

Сравните две операции над строкой «5»: вычитание запрашивает числовое преобразование, тогда как плюс допускает сборку строки. В сравнении пустого массива с `false` результат получается через правила равенства: `false` превращается в 0, массив - в пустую строку, затем она - в 0. Boolean([]) задаёт другой вопрос и потому возвращает true.
