**Явное преобразование задаётся напрямую: Number(value), String(value), Boolean(value).**

<!-- wishu:answer-block -->

### Что важно объяснить

- Неявное выполняется по правилам операции: например, вычитание преобразует подходящие строки в числа, а сложение со строкой может выполнять конкатенацию.

- Объекты сначала преобразуются к примитивам через предусмотренные языком методы.

- При [] == false логическое false преобразуется в 0.

- Массив преобразуется к примитивной пустой строке, затем "" - к 0, поэтому сравнение даёт true.

- Это не проверка truthy/falsy: сам пустой массив в логическом контексте truthy, так что Boolean([]) равно true.
