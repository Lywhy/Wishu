**`copyWithin`(target, start, end) перезаписывает часть массива значениями из другого диапазона этого же массива. Он меняет исходный массив, возвращает его и сохраняет `length`.**

### Как это работает

Сначала определяется исходный диапазон от start включительно до end исключительно. Затем его значения копируются начиная с target; если места до конца массива недостаточно, копирование обрезается. Отрицательные позиции отсчитываются от конца, а отсутствие end означает конец массива. В отличие от `splice`, элементы не вставляются со сдвигом.

Исходный диапазон и место назначения могут перекрываться. Метод сохраняет результат, соответствующий корректному копированию исходной последовательности, а не цепочке случайных перезаписей. Объекты при этом не клонируются: копируются ссылочные значения. Если исходная позиция является пропуском, соответствующее свойство назначения удаляется.

### Пример и его разбор

```javascript
const values = [1, 2, 3, 4, 5]
const result = values.copyWithin(1, 3)
values // [1, 4, 5, 4, 5]
values.length // 5
result === values // true
;[1, 2, 3, 4].copyWithin(1, 0, 3) // [1, 1, 2, 3]
```

В первом вызове примера диапазон с индексами 3 и 4 содержит 4 и 5. Он записывается на позиции 1 и 2, поэтому результат равен [1, 4, 5, 4, 5]. Проверка result === values показывает, что новый массив не создан. Последний вызов демонстрирует корректную работу перекрывающихся диапазонов.

### Нюансы и типичные ошибки

Используйте метод, когда нужна именно перезапись внутри массива. Для независимой копии или изменения состава со сдвигом требуются другие операции.
