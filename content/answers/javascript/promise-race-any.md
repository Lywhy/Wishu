**`Promise.race` принимает исход первого завершившегося входа: как успех, так и ошибку. `Promise.any` ждёт первый успешный вход и игнорирует отдельные отказы, пока остаётся шанс успеха.**

<!-- wishu:answer-block -->

### Как это работает

Если все отклонены, `any` отклоняется AggregateError с массивом причин. Race с пустым iterable остаётся pending, `any` с пустым iterable отклоняется AggregateError.

Ни один метод не отменяет проигравшие операции. Поэтому таймаут через race сам по себе не останавливает запрос: отмену поддерживаемой операции организуют отдельно через AbortSignal.

### Пример и его разбор

```javascript
async function firstSuccess() {
  return await Promise.any([
    Promise.reject(new Error("первый отказ")),
    Promise.resolve("доступный результат"),
  ])
}
// firstSuccess() выполнится строкой "доступный результат".
```

Первый отказ не завершает any из примера, потому что ещё есть возможность успешного результата. Поэтому вызывающая функция получает «доступный результат». Race в аналогичной ситуации принял бы первый наблюдаемый отказ. Победитель определяется политикой агрегатора, а освобождение ресурсов проигравших операций необходимо организовать отдельно, если API допускает отмену.
