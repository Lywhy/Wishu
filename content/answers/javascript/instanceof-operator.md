**Обычно value instanceof Constructor проверяет, встречается ли Constructor.prototype в цепочке прототипов value.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Поэтому это проверка связи с прототипом конструктора, а не универсальное определение типа.

- Поведение можно изменить через `Symbol`.hasInstance.

- Объекты из другого контекста, например iframe, могут иметь другие встроенные конструкторы, и instanceof Array для такого массива даст false.

- Для массива надёжнее `Array.isArray`.

- Изменение цепочки прототипов также может изменить результат instanceof.

- Проверка error instanceof Error полезна внутри одного realm, но может дать false для ошибки из другого окна или контекста.

- Она не доказывает, что произвольные внешние данные являются доверенной ошибкой с нужным контрактом.
