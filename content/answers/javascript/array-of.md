**`Array.of`(...items) создаёт массив из переданных аргументов как из элементов независимо от их числа и типов. `Array.of`(3) содержит один элемент 3.**

### Как это работает

Array() или `new` Array() с одним допустимым числовым аргументом трактует его как длину и создаёт пропуски, а не массив с этим числом. При нескольких аргументах Array тоже создаёт элементы, а при отсутствии - пустой массив.

Для явных известных значений обычно проще литерал [a, b]; `Array.of` удобен, когда нужен единый вызов без особого поведения одного числа. Для заполнения значениями по индексу чаще подходит `Array.from` с mapper.

### Пример и его разбор

```javascript
Array.of(3) // [3]
Array.of(1, 2) // [1, 2]
const holes = Array(3)
holes.length // 3
0 in holes // false
Array.of() // []
```

Единственное число 3 в `Array.of` становится обычным элементом. Конструктор Array с тем же аргументом вместо этого задаёт длину и оставляет позиции отсутствующими, что обнаруживает in. Это не три записанных undefined. Для известных литеральных элементов проще квадратные скобки, а для вычисляемого заполнения диапазона удобен `Array.from` с mapper.
