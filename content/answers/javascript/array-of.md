**`Array.of`(...items) создаёт массив из переданных аргументов как из элементов независимо от их числа и типов. `Array.of`(3) содержит один элемент 3.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Array() или new Array() с одним допустимым числовым аргументом трактует его как длину и создаёт пропуски, а не массив с этим числом.

- При нескольких аргументах Array тоже создаёт элементы, а при отсутствии - пустой массив.

- Для явных известных значений обычно проще литерал [a, b]; `Array.of` удобен, когда нужен единый вызов без особого поведения одного числа.

- Для заполнения значениями по индексу чаще подходит `Array.from` с mapper.
