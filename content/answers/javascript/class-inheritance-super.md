**Extends задаёт родителя класса и связывает цепочки прототипов экземпляров и конструкторов.**

<!-- wishu:answer-block -->

### Как это работает

Super(...) в конструкторе потомка вызывает родительский конструктор и инициализирует this. При обычном создании использовать `this` до super нельзя.

Super.method() обращается к методу родительского уровня, но вызывает его с текущим this. Это не отдельный родительский объект.

Наследование не копирует методы в каждый экземпляр; переопределение в потомке меняет поиск по цепочке. Повторный super() для той же инициализации недопустим.

### Пример и его разбор

```javascript
class User {
  constructor(name) {
    this.name = name
  }
  greet() {
    return this.name
  }
}
class Admin extends User {
  constructor(name) {
    super(name)
    this.role = "admin"
  }
  greet() {
    return `Admin: ${super.greet()}`
  }
}
new Admin("Аня").greet() // "Admin: Аня"
```

Super(name) инициализирует текущий экземпляр через User, после чего Admin добавляет role. В greet вызов super.greet использует имя того же экземпляра. Здесь не создаётся второй объект-родитель: меняется уровень поиска метода, но сохраняется получатель вызова.
