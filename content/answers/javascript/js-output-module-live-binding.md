**В main.mjs будут выведены **1**, затем **2**. Импортированная привязка отражает обновление экспорта, а не первоначальную копию.**

### Механизм и границы

Импортёр не может просто присвоить новое значение импортированной привязке. Сам экспортирующий модуль обновляет своё let, и последующие чтения видят результат.

Если бы импортёр сохранил `const snapshot = count`, snapshot был бы обычным отдельным примитивным снимком. Пример состоит из двух модулей, а не одного файла.
