**Window предоставляет окружение окна или вкладки: таймеры, навигацию и другие браузерные API.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Document представляет загруженный документ и его DOM, доступный через window.document.

- Это разные объекты: окно связано с окружением, document - с содержимым.

- В скриптах страницы window обычно доступен как глобальный объект через браузерный WindowProxy; globalThis позволяет обращаться к глобальному окружению переносимее.

- В Worker нет window и document.

- При навигации документ может смениться, поэтому ссылки на старые узлы не являются вечной моделью страницы.
