**`length` отражает число формальных параметров до первого параметра с default, не включая rest. Name может выводиться из контекста объявления. Они не проверяют число аргументов во время выполнения.**

### Как это работает

Деструктурирующий параметр считается одной позицией. `bind` и обёртки могут изменить метаданные, а сборщик - преобразовать имена. Поэтому протокол приложения нельзя бездумно строить на name либо использовать `length` как валидатор входа.

Реальное количество переданных аргументов относится к arguments.length или к выбранному rest-контракту.

### Пример и его разбор

```javascript
function example(a, b = 1, ...rest) {}
console.log(example.length) // 1
const handler = () => {}
console.log(handler.name) // handler
```

У example до первого default-параметра находится только a, поэтому `length` равен 1, хотя функция способна принять больше аргументов. Имя handler выводится из места присваивания стрелки. Эти метаданные удобны для диагностики, но не проверяют бизнес-контракт входа и могут измениться из-за обёрток, `bind` или преобразования исходного кода.

### Типичная ошибка

> Считать fn.length числом обязательных бизнес-аргументов или надёжным способом выбрать перегрузку.
