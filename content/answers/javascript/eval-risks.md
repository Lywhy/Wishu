**eval разбирает строку как JavaScript и выполняет её с возможностями текущей среды.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Если в строку попадают непроверенные данные, это позволяет внедрить произвольный код.

- Прямой eval также может читать локальные привязки, что затрудняет понимание зависимостей и оптимизацию.

- Для JSON используют JSON.parse, для доступа к свойству по имени - obj[key], для выбора действия - явный словарь функций. new Function тоже исполняет строку и не служит безопасной заменой для недоверенного ввода.

- Данные следует обрабатывать как данные, а не превращать в исполняемый код.
