**eval разбирает строку как JavaScript и выполняет её с возможностями текущей среды.**

<!-- wishu:answer-block -->

### Как это работает

Если в строку попадают непроверенные данные, это позволяет внедрить произвольный код. Прямой eval также может читать локальные привязки, что затрудняет понимание зависимостей и оптимизацию.

Для JSON используют `JSON.parse`, для доступа к свойству по имени - obj[key], для выбора действия - явный словарь функций. `new` Function тоже исполняет строку и не служит безопасной заменой для недоверенного ввода. Данные следует обрабатывать как данные, а не превращать в исполняемый код.

### Пример и его разбор

```javascript
const payload = JSON.parse('{"name":"Аня"}')
console.log(payload.name) // "Аня"
// JSON.parse разбирает данные, а не выполняет произвольный JavaScript.
```

`JSON.parse` в примере читает данные в ограниченном формате, а доступ payload[field] выбирает поле без создания программы из строки. Словарь actions аналогично ограничивает выбор заранее известными операциями; `Object.hasOwn` не допускает случайного обращения к унаследованному имени. Это замена модели выполнения, а не попытка «очистить» произвольный код перед eval.
