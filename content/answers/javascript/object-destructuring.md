**Объектный шаблон извлекает свойства по именам, а не по позиции.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Запись { name: displayName } создаёт переменную displayName, а не name.

- Значение по умолчанию используется только при `undefined`, включая отсутствующее свойство; `null` сохраняется.

- Вложенный шаблон требует существующего подходящего значения, поэтому для отсутствующего промежуточного объекта можно задать default.

- Rest собирает оставшиеся собственные перечисляемые свойства в новый объект; вложенные объекты не клонируются.

- Деструктуризация `null` или `undefined` без подходящей внешней защиты вызывает ошибку.
