**Оператор ?. прекращает непрерывную цепочку доступа и возвращает `undefined`, если значение перед ним равно `null` или `undefined`.**

<!-- wishu:answer-block -->

### Как это работает

Он поддерживает свойства, вычисляемые ключи и необязательный вызов: obj?.key, obj?.[key], fn?.(). Значения 0, `false` и пустая строка цепочку не останавливают.

Нужно защищать каждый потенциально отсутствующий промежуточный объект. Скобки могут прервать цепочку: (obj?.a).b обращается к b уже отдельно.

Оператор не спасает от необъявленного имени, не делает существующее невызываемое значение функцией и не допускается слева от обычного присваивания.

### Пример и его разбор

```javascript
const user = { profile: null }
user.profile?.name // undefined
const city = user.profile?.address?.city ?? "не указан"
const onSave = undefined
onSave?.() // undefined
```

В user существует объект, но его profile равен null. Защищённый доступ останавливается именно на этом уровне и даёт `undefined`, после чего ?? выбирает запасной текст. Необязательный вызов onSave также не выполняется, поскольку функции нет. Такая защита описывает допустимое отсутствие данных; она не должна скрывать нарушение обязательного контракта.
