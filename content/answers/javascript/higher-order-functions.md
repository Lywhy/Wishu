**Функция высшего порядка принимает другую функцию, возвращает функцию или делает и то и другое.**

<!-- wishu:answer-block -->

### Как это работает

Это возможно, потому что функции JavaScript - значения: их можно хранить в переменных, передавать и возвращать. Примеры - `Map`, `filter` и фабрики обёрток.

Не следует путать функцию высшего порядка с callback: первая принимает или создаёт функции, второй передаётся для вызова. Один объект функции может играть обе роли в разных местах программы.

Такой приём отделяет общий алгоритм от настраиваемого действия.

### Пример и его разбор

```javascript
function createMultiplier(factor) {
  return (value) => value * factor
}
const double = createMultiplier(2)
;[1, 2, 3].map(double) // [2, 4, 6]
```

createMultiplier возвращает функцию с настроенным factor и поэтому является функцией высшего порядка. `Map` также относится к этой категории: он принимает double и управляет её вызовами. Сама double в данном месте играет роль callback. Такое разделение позволяет один раз написать общий обход, а вычисление для каждого значения передать отдельно.
