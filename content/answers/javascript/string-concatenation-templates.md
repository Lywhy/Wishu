**Оператор + объединяет строки, если после преобразования к примитивам хотя бы один операнд является строкой.**

<!-- wishu:answer-block -->

### Как это работает

Операции выполняются слева направо: 1 + 2 + "3" даёт "33", а "1" + 2 + 3 - "123". Шаблонные литералы записываются в обратных кавычках, поддерживают переносы строк и вставку выражений через ${expression}.

Они удобны для читаемой сборки текста. Интерполяция сама по себе не экранирует HTML и не защищает SQL: безопасность зависит от того, куда передаётся строка.

### Пример и его разбор

```javascript
const name = "Аня"
const count = 3
const message = `Привет, ${name}! Вопросов: ${count}.`
1 + 2 + "3" // "33"
"1" + 2 + 3 // "123"
```

Переменная message создаётся вычислением выражений name и count внутри шаблона. Два следующих выражения показывают, почему порядок важен: после первого сложения либо уже есть число 3, либо строка «12», и дальнейший плюс продолжает соответствующую операцию. Шаблон обычно проще читать, однако он создаёт обычную строку и не знает правил безопасности её будущего получателя.
