**В JavaScript тип принадлежит значению, а переменная может в разное время содержать значения разных типов.**

<!-- wishu:answer-block -->

### Как это работает

Типы проверяются во время выполнения: операция может преобразовать значение, вернуть специальный результат или выбросить ошибку в зависимости от своих правил. Динамическая типизация и неявное преобразование - разные свойства языка.

Первое относится к типам во время выполнения, второе - к преобразованиям в операциях. const запрещает переназначение, но не вводит статический тип; TypeScript добавляет статическую проверку поверх JavaScript.

### Пример и его разбор

```javascript
let value = 42
typeof value // "number"
value = "готово"
typeof value // "string"
```

Сначала value содержит число, затем строку: оба присваивания допустимы, потому что объявление let не закрепляет за переменной единственный тип. `typeof` наблюдает тип текущего значения. При работе с внешними данными это означает необходимость проверить контракт до операции: возможность сохранить строку в переменную не гарантирует, что арифметика над ней имеет нужный смысл.
