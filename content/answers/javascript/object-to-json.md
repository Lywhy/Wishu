**Если у сериализуемого значения есть вызываемый метод toJSON, JSON.stringify сначала использует возвращаемое им представление.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Метод может вернуть объект, массив, примитив или `undefined`; JSON-текст создаёт сам stringify, поэтому возвращать готовую JSON-строку обычно не нужно. this указывает на сериализуемый объект, аргумент key - его имя в родителе, а у корневого значения это пустая строка.

- Так можно явно выбрать поля для отправки или определить формат значения.

- Например, Date использует toJSON для строкового представления даты.

- JSON.parse не восстанавливает методы, прототип класса и исходный объект автоматически.

- ToJSON меняет одну операцию сериализации и не служит общим запретом доступа к исключённым полям.
