**В пределах одного агента JavaScript выполняет обычный код последовательно в одном стеке вызовов.**

### Как это работает

Текущая задача не прерывается другой задачей JavaScript посередине. Сам браузер при этом многопоточный, а Workers создают отдельные агенты со своими стеками.

Долгий расчёт или бесконечный цикл в главном потоке задерживает обработчики, таймеры и обновление интерфейса. Пометка функции `async` не исправляет это: её синхронная часть по-прежнему занимает поток.

Нужны сокращение работы, разбиение на задачи или Worker. Даже бесконечная цепочка микрозадач способна не давать браузеру перейти к другим задачам.

### Пример и его разбор

```javascript
async function sum(values) {
  // Этот обход всё равно синхронно занимает текущий поток.
  let total = 0
  for (const value of values) total += value
  return total
}
// while (true) {} намеренно не выполняем: он заблокировал бы агент.
```

Вызов sum начинает выполнять цикл сразу и доходит до конца без точки ожидания. Объявление `async` меняет форму возвращаемого результата на `Promise`, но не отдаёт вычисление другому агенту. Пока этот цикл занимает главный поток, ввод и таймеры ждут. Для разгрузки требуется реально изменить организацию работы: сократить расчёт, уступать задачами или использовать Worker.
