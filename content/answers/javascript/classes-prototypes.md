**`class` позволяет описать конструктор, методы и другие элементы класса, сохраняя прототипную модель JavaScript. Экземпляр связан с `prototype` своего класса, а обычные методы доступны через эту связь.**

### Как это работает

При `new` создаётся экземпляр и выполняется его инициализация. Данные вроде name обычно находятся на самом экземпляре, а метод greet, объявленный в теле класса, находится в `User.prototype`. Поэтому нескольким экземплярам не требуется отдельная копия одной и той же функции метода. Когда своего свойства нет, поиск продолжается по прототипной цепочке.

Синтаксис класса не полностью тождественен произвольной функции-конструктору. Класс нельзя вызвать как обычную функцию без `new`; тело выполняется в строгом режиме, обычные методы неперечисляемы, а до инициализации объявления действует TDZ. `static`-элементы принадлежат самому конструктору, а не экземплярам.

### Пример и его разбор

```javascript
class User {
  constructor(name) {
    this.name = name
  }
  greet() {
    return this.name
  }
}
const user = new User("Аня")
Object.getPrototypeOf(user) === User.prototype // true
Object.hasOwn(user, "greet") // false
typeof User // "function"
```

В примере проверка прототипа даёт true, а `Object.hasOwn`(user, "greet") - false: метод найден через `User.prototype`. Результат `typeof` User равен "function", потому что класс представляет конструктор, но это не снимает требование вызывать его с `new`.

### Нюансы и типичные ошибки

Не переносите правило о методах на все элементы класса: публичные поля создаются на экземплярах, а private-элементы имеют отдельные ограничения доступа. Эти различия разобраны в профильных вопросах.
