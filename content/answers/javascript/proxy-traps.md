**new Proxy(target, handler) создаёт отдельный объект-посредник над объектом target.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Методы handler, называемые ловушками, перехватывают определённые операции: get - чтение, set - запись, has - оператор in, ownKeys - запрос ключей.

- Если ловушки нет, соответствующая операция передаётся цели по стандартным правилам.

- Reflect помогает передать операцию дальше с нужными аргументами.

- Например, Reflect.get(target, key, receiver) сохраняет receiver для getter; set должен сообщить boolean об успехе.

- Доступ напрямую к target обходит Proxy, вложенные объекты не становятся Proxy автоматически, а proxy !== target.

- Для некоторых встроенных объектов и приватных полей класса простой прокси не является прозрачной заменой.

- Ловушки обязаны соблюдать инварианты цели.

- Например, get не может выдавать другое значение собственного неконфигурируемого data-свойства, если оно недоступно для записи.

- Нарушение приводит к TypeError; Proxy позволяет настраивать операции в рамках правил, а не отменяет дескрипторы.
