**Canvas предоставляет поверхность рисования через контекст, например 2D.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Линии, текст и фигуры рисуются командами, но не становятся отдельными DOM-узлами с собственными обработчиками.

- При изменении сцены приложение обычно хранит её данные и перерисовывает нужное содержимое.

- Размер буфера canvas и размер через CSS различаются; для чёткости нужно учитывать плотность пикселей.

- Доступность, текстовые альтернативы и интерактивность нужно продумать отдельно.

- Canvas подходит графике и визуализации, но обычные формы и текстовый интерфейс часто удобнее оставлять DOM.
