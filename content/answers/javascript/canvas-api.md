**Canvas предоставляет поверхность рисования через контекст, например 2D.**

<!-- wishu:answer-block -->

### Как это работает

Линии, текст и фигуры рисуются командами, но не становятся отдельными DOM-узлами с собственными обработчиками. При изменении сцены приложение обычно хранит её данные и перерисовывает нужное содержимое.

Размер буфера canvas и размер через CSS различаются; для чёткости нужно учитывать плотность пикселей. Доступность, текстовые альтернативы и интерактивность нужно продумать отдельно.

Canvas подходит графике и визуализации, но обычные формы и текстовый интерфейс часто удобнее оставлять DOM.

### Пример и его разбор

```javascript
const canvas = document.createElement("canvas")
canvas.width = 200
canvas.height = 100
const context = canvas.getContext("2d")
if (context) {
  context.fillStyle = "blue"
  context.fillRect(10, 10, 80, 40)
}
```

FillRect меняет пиксели поверхности, но не создаёт отдельный прямоугольник в DOM. Если пользователь должен выбирать фигуры, приложение само хранит их координаты и определяет попадание. Доступное описание содержимого также приходится проектировать отдельно от команд рисования.
