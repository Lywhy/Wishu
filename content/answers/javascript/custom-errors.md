**Для обычной ошибки достаточно new Error(message); для узнаваемого доменного типа создают class extends Error, вызывают super и добавляют необходимые поля.**

### Что важно объяснить

- Name удобно задавать явно, а машинный code должен быть отдельным договорённым полем, а не результатом разбора message.

- Опция cause сохраняет исходную причину при добавлении контекста.

- Это лучше, чем безусловно выбрасывать новый Error и терять связь.

- В одном realm instanceof помогает различить подклассы; между realm и при сериализации нужна отдельная осторожность.

- Не следует помещать секреты в сообщения, предназначенные для журнала или пользователя.
