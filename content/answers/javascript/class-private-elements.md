**Имя с # объявляет приватный элемент класса, доступный только из кода, где это приватное имя определено.**

<!-- wishu:answer-block -->

### Как это работает

Это не строковое свойство: instance["#field"] не читает его, `Object.keys` его не показывает. Прямое обращение снаружи к необъявленному приватному имени - синтаксическая ошибка.

Подкласс не получает право обращаться к приватному имени родителя. Но методы родителя могут работать со своими приватными элементами на созданном экземпляре потомка.

Одинаковое #имя, объявленное потомком, обозначает другой элемент. Вызов приватного доступа на неподходящем объекте вызывает TypeError; простая смена прототипа не добавляет нужную приватную принадлежность.

### Проверка private brand

Внутри области, где объявлено приватное имя, выражение `#field in candidate` проверяет наличие именно этого приватного элемента. Оно не обращается к строке `"#field"` и не ищет её по прототипам. Для значения, не являющегося объектом, такая проверка выбрасывает TypeError, поэтому внешний ввод сначала нужно проверить. Это иной контракт, чем `instanceof`, зависящий от цепочки прототипов.

### Пример и его разбор

```javascript
class Counter {
  #value = 0
  next() {
    return ++this.#value
  }
}
class Child extends Counter {}
new Child().next() // 1: метод родителя имеет доступ
const counter = new Counter()
counter["#value"] // undefined: это другое, обычное имя свойства
```

Child использует next родителя, и код этого метода имеет право читать родительское #value. Обращение через строку «#value» ищет совсем другое обычное свойство и даёт undefined. Приватный элемент определяется объявлением и принадлежностью экземпляра, а не совпадением написания ключа.
