**Оба API хранят строковые пары ключ - значение и работают синхронно.**

### Что важно объяснить

- LocalStorage привязан к origin и обычно переживает перезапуск браузера; sessionStorage дополнительно разделён по сеансу верхнеуровневой вкладки и сохраняется при её перезагрузке.

- Новая вкладка не является общей изменяемой сессией sessionStorage с исходной.

- Объекты сериализуют явно, а ошибки доступа, квоты и разбора нужно обрабатывать.

- Данные могут быть очищены пользователем или политикой браузера; это не гарантированное бессрочное хранилище.

- Storage доступен JavaScript страницы и не подходит для секретов, защищаемых от XSS.

- Для больших структур и асинхронных транзакций часто выбирают IndexedDB.
