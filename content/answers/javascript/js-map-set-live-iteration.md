**Итераторы Map и Set не являются неизменяемым снимком. Удалённые до посещения записи могут быть пропущены, а новые записи могут быть замечены тем же обходом.**

<!-- wishu:answer-block -->

### Механизм и границы

Удаление и повторное добавление меняет положение записи относительно порядка вставки. Неосторожное добавление в собственном обходе может создать бесконечную работу.

Если нужен определённый набор на начало операции, заранее сформируйте подходящий массив записей. При этом сами объектные значения по-прежнему могут быть общими ссылками.
