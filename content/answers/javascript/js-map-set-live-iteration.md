**Итераторы `Map` и `Set` не являются неизменяемым снимком. Удалённые до посещения записи могут быть пропущены, а новые записи могут быть замечены тем же обходом.**

### Как это работает

Удаление и повторное добавление меняет положение записи относительно порядка вставки. Неосторожное добавление в собственном обходе может создать бесконечную работу.

Если нужен определённый набор на начало операции, заранее сформируйте подходящий массив записей. При этом сами объектные значения по-прежнему могут быть общими ссылками.

### Пример и его разбор

```javascript
const values = new Set([1, 2])
const seen = []
for (const value of values) {
  seen.push(value)
  if (value === 1) values.add(3)
}
console.log(seen) // [1, 2, 3]
```

Добавленная тройка становится видимой ещё до завершения того же обхода `Set`, поэтому seen содержит три значения. Это отличается от методов массива с заранее определённой границей длины. Если алгоритм должен обработать только начальный набор, его фиксируют заранее, понимая, что массив ссылок не замораживает состояние самих объектных элементов.

### Типичная ошибка

> Добавлять новые записи в текущий обход и ожидать фиксированного числа итераций.
