**Range описывает границы фрагмента DOM, а Selection представляет текущее выделение в документе. Offset у Text связан с позициями данных, а у Element - с границей между дочерними узлами.**

### Механизм и границы

Это важно для редакторов: число видимых графем не совпадает автоматически с UTF-16 смещением текстового узла. Изменение DOM может повлиять на живой диапазон и положение выделения.

Не восстанавливайте каретку только по произвольному глобальному индексу без модели текста и структуры. Для пользовательского редактирования нужна согласованная политика обработки композиции и мутаций.
