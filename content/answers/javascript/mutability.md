**Примитивы неизменяемы: операция со строкой или числом создаёт новое значение, а не меняет существующее.**

### Как это работает

Объекты обычно изменяемы: их свойства можно добавлять, удалять и обновлять. const ограничивает переназначение переменной, но не мутацию её объекта. Иммутабельное обновление создаёт новую структуру вместо изменения прежней.

Spread копирует только верхний уровень: вложенные объекты остаются общими. `Object.freeze` запрещает изменения собственных свойств самого объекта, но не замораживает вложенные объекты автоматически.

### Пример и его разбор

```javascript
const original = { nested: { count: 1 } }
const copy = { ...original }
copy.nested.count = 2
original.nested.count // 2
const updated = { ...original, nested: { ...original.nested, count: 3 } }
original.nested.count // 2
```

В примере spread создаёт новую внешнюю оболочку, но nested остаётся общим объектом. Поэтому изменение copy.nested.count видно и через original. Для независимого обновления конкретного пути создают новый объект на каждом изменяемом уровне, как в updated. Это позволяет сохранить прежний снимок данных, не обещая глубокую независимость всех остальных ветвей.
