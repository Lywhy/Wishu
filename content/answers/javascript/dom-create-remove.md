**Document.createElement создаёт элемент, ещё не подключённый к странице.**

### Что важно объяснить

- Append, prepend и другие методы вставляют узлы, remove удаляет узел из родителя.

- Уже существующий узел при вставке перемещается, а не автоматически копируется; для копии есть cloneNode.

- Для обычного текста используют textContent или текстовые узлы.

- Удаление из DOM не означает немедленного освобождения памяти: внешние ссылки, таймеры и подписки могут удерживать узел.

- Ресурсы компонента нужно очищать отдельно.

- DocumentFragment позволяет собрать группу узлов до вставки, но его пользу для производительности следует оценивать по реальной работе.
