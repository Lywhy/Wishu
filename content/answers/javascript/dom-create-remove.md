**Document.createElement создаёт элемент, ещё не подключённый к странице.**

<!-- wishu:answer-block -->

### Как это работает

`append`, prepend и другие методы вставляют узлы, remove удаляет узел из родителя. Уже существующий узел при вставке перемещается, а не автоматически копируется; для копии есть cloneNode.

Для обычного текста используют `textContent` или текстовые узлы. Удаление из DOM не означает немедленного освобождения памяти: внешние ссылки, таймеры и подписки могут удерживать узел.

Ресурсы компонента нужно очищать отдельно. DocumentFragment позволяет собрать группу узлов до вставки, но его пользу для производительности следует оценивать по реальной работе.

### Пример и его разбор

```javascript
function addNotice(container, text) {
  const notice = document.createElement("p")
  notice.textContent = text
  container.append(notice)
  return () => notice.remove()
}
```

Сначала создаётся отдельный p, затем `textContent` задаёт безопасное текстовое содержимое, и лишь `append` подключает узел к контейнеру. Возвращаемая функция удаляет именно этот узел. Если бы у уведомления были таймеры или внешние подписки, их пришлось бы освобождать дополнительно.
