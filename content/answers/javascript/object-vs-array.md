**Массив - специальный объект для упорядоченной последовательности.**

<!-- wishu:answer-block -->

### Что важно объяснить

- У него есть особая связь индексных свойств с length, методы вроде map и push и стандартный итератор значений.

- Обычный объект подходит для именованных полей, но автоматически не получает эти возможности.

- Индексы массива тоже являются строковыми ключами, а запись по новому индексу может увеличить length.

- Пропуск в массиве отличается от существующего элемента со значением `undefined`. `typeof` возвращает "object" для обоих вариантов; массив проверяют через `Array.isArray`.

- Добавлять произвольные поля массиву можно, но это обычно затрудняет понимание его роли.
