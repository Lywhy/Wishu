**Массив - специальный объект для упорядоченной последовательности.**

### Как это работает

У него есть особая связь индексных свойств с `length`, методы вроде `Map` и `push` и стандартный итератор значений. Обычный объект подходит для именованных полей, но автоматически не получает эти возможности.

Индексы массива тоже являются строковыми ключами, а запись по новому индексу может увеличить length. Пропуск в массиве отличается от существующего элемента со значением `undefined`. `typeof` возвращает "object" для обоих вариантов; массив проверяют через `Array.isArray`.

Добавлять произвольные поля массиву можно, но это обычно затрудняет понимание его роли.

### Пример и его разбор

```javascript
const list = ["a"]
list[3] = "d"
list.length // 4
1 in list // false: пропуск
const record = { 0: "a", length: 1 }
Array.isArray(list) // true
Array.isArray(record) // false
```

Запись по индексу 3 увеличивает длину массива до 4, но не создаёт элементы во всех пропущенных позициях. У обычного объекта поле `length` остаётся просто полем: оно не связывается автоматически с остальными ключами. Поэтому похожий внешний вид значений ещё не означает одинакового поведения при обходе и изменении.
