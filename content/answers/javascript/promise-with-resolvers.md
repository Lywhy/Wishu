**`Promise.withResolvers`() возвращает объект { `Promise`, resolve, reject }, вынося управление завершением из executor.**

<!-- wishu:answer-block -->

### Как это работает

Это эквивалент знакомой конструкции с сохранением resolve/reject из `new` `Promise`, а не новый тип `Promise` и не автоматическая отмена. Приём нужен для связывания событий или внешнего протокола с одним будущим результатом.

Повторные попытки завершения не меняют уже зафиксированный исход. Нужно очищать подписки и не оставлять ожидание без завершения.

Поддержку API проверяют в целевой среде; при необходимости возможна обычная конструкция `new` Promise.

### Пример и его разбор

```javascript
const { promise, resolve, reject } = Promise.withResolvers()
promise.then(console.log).catch(console.error)
resolve("готово")
// reject уже не изменит исход после принятия этого значения.
```

Объект из withResolvers разделяет ожидание и управление одним результатом: `Promise` передают потребителю, а resolve и reject оставляют владельцу события. Вызов resolve с готовым значением завершает показанный сценарий, и дальнейший reject не меняет исход. При использовании для подписок важно также снять обработчики и предусмотреть путь, если событие никогда не придёт.
