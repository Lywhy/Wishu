**`Promise.withResolvers`() возвращает объект { promise, resolve, reject }, вынося управление завершением из executor.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Это эквивалент знакомой конструкции с сохранением resolve/reject из new Promise, а не новый тип Promise и не автоматическая отмена.

- Приём нужен для связывания событий или внешнего протокола с одним будущим результатом.

- Повторные попытки завершения не меняют уже зафиксированный исход.

- Нужно очищать подписки и не оставлять ожидание без завершения.

- Поддержку API проверяют в целевой среде; при необходимости возможна обычная конструкция new Promise.
