**throw прекращает обычное выполнение и передаёт выброшенное значение ближайшему подходящему catch.**

### Что важно объяснить

- Выбросить можно любое значение, но Error и его подклассы дают понятное сообщение и стек. try содержит защищённый код, catch обрабатывает ошибку, finally обычно используют для освобождения ресурсов при выходе из конструкции.

- Синхронный try...catch не перехватывает ошибку из более позднего callback и отклонение Promise, который не ожидается.

- В async-функции try...catch вокруг await перехватывает отклонение ожидаемого Promise.

- Не следует бездумно подавлять ошибки или возвращать значение из finally: return или throw в finally может заменить предыдущий результат.

- Finally обычно выполняется и при return из try или catch, прежде чем управление окончательно покинет конструкцию.

- Если catch сам выбрасывает новую ошибку, она передаётся внешнему обработчику; этот же catch её повторно не перехватывает.

- Исключение или return из finally может заменить предыдущий исход.

- Завершение процесса или закрытие среды не даёт общей гарантии выполнения finally.
