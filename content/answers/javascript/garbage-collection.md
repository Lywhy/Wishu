### Как это работает

Недостижимый граф объектов может быть освобождён, даже если объекты ссылаются друг на друга. Поэтому сам цикл ссылок не доказывает утечку.

Движки используют разные оптимизации: поколения по возрасту объектов, маркировку и очистку, перемещение, инкрементальные и параллельные этапы. Это детали реализации, а не обязательный единый алгоритм ECMAScript.

Момент сборки не гарантируется; delete удаляет свойство, а не приказывает освободить объект. Частые выделения могут создавать нагрузку даже без утечки.

### Пример и его разбор

```javascript
function temporaryGraph() {
  const first = {}
  const second = { first }
  first.second = second
  // Граф не возвращается и не сохраняется снаружи.
}
// После вызова граф может стать недостижимым; точный момент GC не задан.
```

Объекты temporaryGraph ссылаются друг на друга, но после возврата функции внешний код их не удерживает. Такой цикл может быть собран целиком. Из этого не следует немедленное освобождение: момент и устройство сборки выбирает движок.
