**`join`(separator) - метод массива: преобразует элементы в строки и соединяет разделителем; по умолчанию это запятая. `split`(separator) - метод строки: разбивает её на массив частей.**

<!-- wishu:answer-block -->

### Как это работает

Разделителем `split` может быть строка или регулярное выражение; необязательный limit ограничивает количество полученных частей. Это не универсальные обратные операции.

После `join` теряются исходные типы, `null` и `undefined` дают пустые фрагменты, а разделитель может встретиться внутри элемента. `split` с пустой строкой делит по UTF-16-кодовым единицам, а не по пользовательским символам; для кодовых точек подходит `Array.from`, для графем нужен отдельный подход.

Эти методы не являются полноценным парсером CSV.

### Пример и его разбор

```javascript
const text = ["JS", "TS", "React"].join(" / ")
text // "JS / TS / React"
text.split(" / ") // ["JS", "TS", "React"]
;[1, null, undefined].join("|") // "1||"
"a,b,c".split(",", 2) // ["a", "b"]
```

В примере `join` сначала собирает «JS / TS / React», а `split` с тем же разделителем возвращает три названия. Это работает для выбранных строк, но не делает методы универсально обратными. При этом типы исходных элементов и границы, совпадающие с разделителем, могут потеряться. Поэтому такой конвейер удобен для понятного текстового формата, но не служит универсальным сериализатором данных. Для произвольных пользовательских символов отдельно учитывают Unicode.
