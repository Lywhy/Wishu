**join(separator) - метод массива: преобразует элементы в строки и соединяет разделителем; по умолчанию это запятая. split(separator) - метод строки: разбивает её на массив частей.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Разделителем split может быть строка или регулярное выражение; необязательный limit ограничивает количество полученных частей.

- Это не универсальные обратные операции.

- После join теряются исходные типы, `null` и `undefined` дают пустые фрагменты, а разделитель может встретиться внутри элемента.

- Split с пустой строкой делит по UTF-16-кодовым единицам, а не по пользовательским символам; для кодовых точек подходит `Array.from`, для графем нужен отдельный подход.

- Эти методы не являются полноценным парсером CSV.
