**`structuredClone` глубоко копирует поддерживаемый граф данных, включая циклические и общие ссылки.** Он не является универсальным способом клонировать поведение любого объекта.

<!-- wishu:answer-block -->

### Что сохраняется

Вложенные поддерживаемые объекты и массивы отделяются от оригинала. Циклы и повторные ссылки внутри копии сохраняют структуру графа.

Поддерживаются, например, `Date`, `Map`, `Set` и многие бинарные типы.

### Ограничения

Функции и значения `Symbol` не клонируются; неподдерживаемые значения могут привести к `DataCloneError`. Для обычного объекта не сохраняются произвольная цепочка прототипов, дескрипторы и accessor-функции; `getter` может быть прочитан как значение.

Transferable передаёт владение ресурсом вместо обычного копирования; исходный буфер отделяется. JSON-сериализация имеет другой набор ограничений и не заменяет structured clone.

### Пример и его разбор

```javascript
const original = { profile: { name: "Аня" }, createdAt: new Date("2024-01-01T00:00:00Z") }
original.self = original
const copy = structuredClone(original)
copy !== original // true
copy.profile !== original.profile // true
copy.self === copy // true
copy.createdAt instanceof Date // true
```

Клон сохраняет поддерживаемые типы и отношения внутри графа: Date остаётся датой, а циклическая self указывает на сам клон. При этом вложенный profile уже не совпадает с оригинальным по ссылке. Такая операция полезна для данных, но её контракт нельзя переносить на функции, DOM-узлы или произвольные экземпляры классов.

### Типичная ошибка

> Ожидать полноценный экземпляр собственного класса с методами после копирования.
