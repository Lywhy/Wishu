**Псевдомассивом обычно называют объект с `length` и доступом к элементам по индексным свойствам, но без обязательного наследования `Array.prototype`.**

### Как это работает

Он не обязан быть итерируемым. `Array.from` принимает iterable либо array-like и создаёт настоящий массив. Если есть итератор, используется он; иначе читаются позиции согласно length.

Второй аргумент `Array.from` - необязательное преобразование (value, index) => result. Отсутствующие позиции array-like становятся `undefined`, поэтому результат не разрежённый.

Для строки iterable перебирает Unicode-кодовые точки, а не всегда целые пользовательские символы. Копия поверхностная: объектные элементы остаются общими.

Spread, в отличие от `Array.from`, требует именно iterable.

### Пример и его разбор

```javascript
const arrayLike = { 0: "a", 1: "b", length: 2 }
const values = Array.from(arrayLike)
values // ["a", "b"]
Array.isArray(values) // true
Array.from({ length: 3 }, (_, index) => index) // [0, 1, 2]
Array.from(new Set([1, 1, 2])) // [1, 2]
```

`Array.from` может прочитать числовые свойства arrayLike по `length` и создать настоящий массив, хотя исходный объект не имеет методов Array. Mapper во втором примере строит значения по индексу без предварительного заполнения. `Set` предоставляет итератор, и в этом случае последовательность берётся из него. Копирование объектных элементов остаётся поверхностным.
