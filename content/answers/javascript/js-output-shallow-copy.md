Вывод: **1 Иван**, затем **2 Иван**, затем **`true`**. Вложенный объект user общий для обеих оболочек.

### Как это работает

Spread создаёт новый внешний объект и копирует значения его собственных перечисляемых свойств. Значение count - примитив; его замена не меняет source.count. Значение user - ссылка на объект; через обе ссылки меняется один и тот же объект.

Для независимого изменения имени достаточно скопировать нужный путь: `const copy = { ...source, user: { ...source.user, name: "Иван" } }`. Глубокое копирование всего графа для такого обновления не обязательно.

### Как проверить рассуждение

Если вместо изменения copy.user.name присвоить copy.user новый объект, source.user останется прежним. Это полезный способ различить изменение общего вложенного объекта и замену ссылки только в одной внешней оболочке.

### Типичная ошибка

> Принимать новую внешнюю ссылку за полностью независимую копию данных.
