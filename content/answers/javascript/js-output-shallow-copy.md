Spread создаёт новый внешний объект и копирует значения его собственных перечисляемых свойств. Значение count - примитив; его замена не меняет source.count. Значение user - ссылка на объект; через обе ссылки меняется один и тот же объект.

Для независимого изменения имени достаточно скопировать нужный путь: `const copy = { ...source, user: { ...source.user, name: "Иван" } }`. Глубокое копирование всего графа для такого обновления не обязательно.
