_*`yield`* делегирует итерацию и взаимодействие с вложенным итератором. Итоговое значение его завершения становится значением самого выражения `yield`_, а не обычным выданным элементом.**

<!-- wishu:answer-block -->

### Как это работает

Это отличается от простого for...of с `yield`: управление `throw` и `return` имеет собственные правила делегирования. Если нужного метода у подитератора нет, результат определяется протоколом, а не угадываемым перенаправлением.

Не путайте `return` подгенератора с одним из значений, которые spread добавит в массив.

### Пример и его разбор

```javascript
function* inner() {
  yield 1
  return 10
}
function* outer() {
  const result = yield* inner()
  yield result + 1
}
console.log([...outer()]) // [1, 11]
```

Inner выдаёт 1, а затем завершает работу значением 10. `yield`* получает это значение как результат выражения, и outer отдельно выдаёт 11. Поэтому spread собирает [1, 11], а не добавляет `return` внутреннего генератора как обычный элемент.

### Типичная ошибка

> Считать `yield`* текстовой заменой цикла, полностью равной любому ручному yield.
