**Индекс первого элемента равен 0.**

### Как это работает

Элемент читают или записывают через array[index]; обычный массив может содержать значения разных типов. Допустимый индекс массива - целое от 0 до 2^32 - 2; запись по индексу за текущей длиной увеличивает length.

Плотный массив создают, например, литералом [first, second]. При чтении отсутствующего индекса у обычного массива без одноимённого унаследованного свойства получается `undefined`.

Последний элемент удобно читать через array.at(-1) или array[array.length - 1]; у пустого массива результат `undefined`. Запись array[-1] обращается к обычному свойству с именем "-1", а не к последнему элементу.

Типы элементов полезно ограничивать договорённостью или TypeScript, хотя сам JavaScript этого не требует.

### Пример и его разбор

```javascript
const values = ["JS", 42, { active: true }]
values[0] // "JS"
values[1] = 43
values.at(-1) // { active: true }
values[values.length - 1] === values.at(-1) // true
values[10] // undefined
values[-1] // undefined
;[].at(-1) // undefined
```

Значение 0 выбирает первый элемент, тогда как at(-1) рассчитывает позицию относительно конца. Квадратные скобки с -1 такого расчёта не выполняют и обращаются к отдельному свойству. Чтение за пределами текущих элементов в обычном массиве даёт `undefined`, но это не проверяет допустимость индекса по контракту приложения. Пустой массив отдельно не имеет последнего элемента.
