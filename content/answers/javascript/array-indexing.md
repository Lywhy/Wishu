**Индекс первого элемента равен 0.**

### Что важно объяснить

- Элемент читают или записывают через array[index]; обычный массив может содержать значения разных типов.

- Допустимый индекс массива - целое от 0 до 2^32 - 2; запись по индексу за текущей длиной увеличивает length.

- Плотный массив создают, например, литералом [first, second].

- При чтении отсутствующего индекса у обычного массива без одноимённого унаследованного свойства получается `undefined`.

- Последний элемент удобно читать через array.at(-1) или array[array.length - 1]; у пустого массива результат `undefined`.

- Запись array[-1] обращается к обычному свойству с именем "-1", а не к последнему элементу.

- Типы элементов полезно ограничивать договорённостью или TypeScript, хотя сам JavaScript этого не требует.
