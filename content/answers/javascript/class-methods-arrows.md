**Метод method() {} в теле класса создаётся на прототипе и разделяется экземплярами; он неперечисляем.**

<!-- wishu:answer-block -->

### Как это работает

Стрелочное поле method = () => {} создаёт отдельную функцию на каждом экземпляре и захватывает его this. Обычное поле с function тоже собственное, но его `this` определяется вызовом.

В литерале объекта функция-свойство и краткая запись метода обычно являются собственными перечисляемыми свойствами. Для передачи классового метода отдельно может потребоваться `bind`, а стрелочное поле уже связано с экземпляром.

Это удобство имеет стоимость отдельных функций и не делает стрелку прототипным методом.

### Пример и его разбор

```javascript
class Counter {
  value = 0
  read() {
    return this.value
  }
  boundRead = () => this.value
}
const first = new Counter()
const second = new Counter()
first.read === second.read // true
first.boundRead === second.boundRead // false
```

Два экземпляра разделяют ссылку на read из прототипа, но получают разные boundRead. Стрелка удобна при передаче callback, потому что сохраняет `this` экземпляра. Это осознанный выбор между разделяемым методом и собственной функцией, а не две полностью одинаковые формы записи.
