### Как это работает

Сначала воспроизводят действие и записывают профиль, затем ищут длительные участки и частые повторения. Оптимизация редкого дешёвого выражения может не изменить общий результат.

Размер и форма данных важны: алгоритм с вложенным проходом может быстро расти при увеличении входа. Нужно сравнивать репрезентативные маленькие и большие случаи, учитывать выделения памяти и проверять итоговую корректность после изменения.

Асимптотика показывает рост, а профиль - фактическую стоимость в среде.

### Пример и его разбор

```javascript
function countPairs(items) {
  let count = 0
  for (const first of items) {
    for (const second of items) count += 1
  }
  return count
}
// Число шагов растёт как n²; это пример анализа, а не замер времени.
```

В countPairs внутренний цикл полностью повторяется для каждого внешнего элемента. При удвоении длины число итераций растёт примерно вчетверо. Это вывод об алгоритме; реальную длительность и вклад в пользовательский сценарий всё равно нужно измерять отдельно.
