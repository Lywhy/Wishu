**Callback hell - ситуация, когда последовательность зависимых операций оформляется глубоко вложенными callback.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Поток данных, обработка ошибок и завершение операции становятся трудными для чтения.

- Проблема связана с организацией управления, а не с самим существованием callback.

- Помогают именованные функции, выделение самостоятельных шагов и единый контракт ошибок.

- Если API возвращает Promise или корректно преобразован в него, цепочка then либо async/await делает последовательность явной.

- Независимые операции можно запускать параллельно через `Promise.all`, а зависимые нужно ожидать последовательно. await не превращает произвольный callback API в Promise API автоматически.
