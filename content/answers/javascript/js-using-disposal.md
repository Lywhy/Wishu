**Using регистрирует освобождаемый ресурс и вызывает поддерживаемый dispose-протокол при выходе из области, включая соответствующие пути `return` и throw. Это не то же самое, что уничтожение любого объекта сборщиком мусора.**

<!-- wishu:answer-block -->

### Как это работает

Ресурс должен выполнять нужный контракт `Symbol.dispose`; обычный объект с методом close сам не становится совместимым. Несколько ресурсов освобождаются в обратном порядке регистрации.

Синтаксис и API должны поддерживаться целевым инструментом и runtime. Не маскируйте необходимость закрыть сеть или файл надеждой на FinalizationRegistry.

### Пример и его разбор

```javascript
// Требует поддержки explicit resource management.
function work() {
  using resource = {
    [Symbol.dispose]() {
      console.log("освобождение")
    },
  }
  console.log("работа")
}
// После выхода из work выполняется dispose.
```

Resource предоставляет именно `Symbol.dispose`, поэтому выход из work вызывает освобождение после полезной работы. Обычного метода с названием close для такого контракта недостаточно. Освобождение привязано к области выполнения, а не к моменту, когда GC решит удалить объект.

### Типичная ошибка

> Ожидать вызова close у любого объекта, записанного в using.
