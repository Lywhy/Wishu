**Using регистрирует освобождаемый ресурс и вызывает поддерживаемый dispose-протокол при выходе из области, включая соответствующие пути return и throw. Это не то же самое, что уничтожение любого объекта сборщиком мусора.**

### Механизм и границы

Ресурс должен выполнять нужный контракт Symbol.dispose; обычный объект с методом close сам не становится совместимым. Несколько ресурсов освобождаются в обратном порядке регистрации.

Синтаксис и API должны поддерживаться целевым инструментом и runtime. Не маскируйте необходимость закрыть сеть или файл надеждой на FinalizationRegistry.
