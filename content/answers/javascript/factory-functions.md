**Фабричная функция - обычная функция, которая создаёт и возвращает объект.**

<!-- wishu:answer-block -->

### Как это работает

Для вызова не требуется `new`, а форму результата и способ создания определяет сама функция. Она может выбирать разные реализации и скрывать данные в замыкании.

Каждый вызов может создавать независимое состояние. При создании методов внутри фабрики обычно создаются новые функции; методы класса чаще разделяются через прототип.

Фабрика сама по себе не гарантирует приватность или независимость: возврат одного общего объекта будет разделять состояние между вызовами.

### Пример и его разбор

```javascript
function createCounter(start = 0) {
  let value = start
  return { next: () => ++value }
}
const first = createCounter()
const second = createCounter(10)
first.next() // 1
second.next() // 11
```

Два вызова createCounter создают разные value: первый начинается с 0, второй с 10. Возвращённые объекты скрывают доступ к этим переменным за методом next. Это решение не требует `new` и позволяет явно выбирать форму результата. Однако независимость здесь обеспечена созданием состояния внутри каждого вызова, а не самим названием «фабрика».
