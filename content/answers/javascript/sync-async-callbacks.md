**Синхронный callback вызывается до завершения принимающей операции: например, map вызывает функцию для элементов во время обхода.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Асинхронный callback вызывается позже по правилам API: например, обработчик setTimeout запускается отдельной задачей, а then - микрозадачей.

- Само слово callback не определяет время выполнения.

- async перед функцией означает возврат Promise, но не меняет правила принимающего API: до первого await тело начинает выполняться сразу. forEach не ожидает возвращённые Promise.

- Для последовательного ожидания подходит for...of с await, для параллельного - `Promise.all`(items.map(asyncCallback)).

- Ошибки позднего callback нельзя перехватить одним try...catch вокруг его регистрации.
