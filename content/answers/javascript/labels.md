**Метка записывается как label: statement и задаёт имя инструкции. break label может выйти из охватывающей помеченной инструкции, включая блок. continue label может продолжить только охватывающий цикл с этой меткой.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Метки полезны для явного выхода из нескольких вложенных циклов.

- Это не произвольный goto: нельзя перейти на любую строку или продолжить обычный блок.

- При сложной логике выделение функции с return часто делает намерение понятнее.
