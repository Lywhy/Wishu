**Метка записывается как label: statement и задаёт имя инструкции. break label может выйти из охватывающей помеченной инструкции, включая блок. continue label может продолжить только охватывающий цикл с этой меткой.**

### Как это работает

Метки полезны для явного выхода из нескольких вложенных циклов. Это не произвольный goto: нельзя перейти на любую строку или продолжить обычный блок.

При сложной логике выделение функции с `return` часто делает намерение понятнее.

### Пример и его разбор

```javascript
outer: for (const row of [
  [1, 2],
  [3, 4],
]) {
  for (const value of row) {
    if (value === 3) break outer
    console.log(value) // 1, затем 2
  }
}
```

Метка outer адресует внешний цикл, поэтому при обнаружении 3 прекращаются сразу оба обхода. Без метки break завершил бы лишь внутренний цикл, и обработка следующей строки могла бы продолжиться. Метки полезны для локального управления вложенностью, но не позволяют прыгнуть в произвольную точку программы или продолжить инструкцию, которая не является циклом.
