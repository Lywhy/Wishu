### Как это работает

`Map` и `filter` создают массивы по своему контракту, `forEach` предназначен для действий, цикл даёт явный контроль. Выбор сначала должен сохранять нужный смысл и понятность.

Цепочка методов может создавать промежуточные коллекции; для большого горячего участка объединённый проход иногда полезен. Но микрозамер на искусственных числах не доказывает выигрыш всего интерфейса.

Сравнивают эквивалентную работу на реальных размерах, учитывая прогрев, GC и различия сред, и оптимизируют подтверждённое узкое место.

### Пример и его разбор

```javascript
function selectedNames(users) {
  const result = []
  for (const user of users) {
    if (user.active) result.push(user.name)
  }
  return result
}
// Это один проход; его выигрыш относительно filter(...).map(...) нужно измерять.
```

SelectedNames выбирает активных пользователей и сразу записывает имена в итоговый массив. Так не создаётся промежуточная коллекция filter. Возможный выигрыш оценивают на эквивалентных данных; для небольшого негорячего участка понятность может оказаться важнее микроскопической разницы.
