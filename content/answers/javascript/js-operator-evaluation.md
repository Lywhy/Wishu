**Приоритет и ассоциативность определяют группировку выражения. Они не означают, что вызов справа выполнится раньше только из-за более сильного оператора.**

### Как это работает

Обычно операнды вычисляются слева направо, но short-circuit может полностью пропустить часть выражения. Скобки меняют группировку, а не превращают код в параллельное вычисление.

Смешивание ?? с && или || требует явных скобок по грамматике. Для сложных условий ясные промежуточные значения полезнее проверки знания таблицы приоритетов.

### Пример и его разбор

```javascript
const log = (value) => {
  console.log(value)
  return value
}
const result = log(1) + log(2) * log(3)
// Вызовы: 1, 2, 3; арифметический результат: 7.
const chosen = (null ?? false) || true
```

Вызовы log происходят в порядке 1, 2, 3, хотя умножение имеет больший приоритет. Приоритет задаёт группировку полученных значений: к 1 прибавляется произведение 2 и 3. Короткое замыкание отличается тем, что может не вычислить целую правую часть. Поэтому группировку и факт выполнения операнда нужно рассматривать отдельно.

### Типичная ошибка

> Утверждать, что умножение заставляет сначала вызвать функции его операндов.
