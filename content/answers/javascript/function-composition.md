**Композиция соединяет функции так, чтобы результат одной стал аргументом другой.**

<!-- wishu:answer-block -->

### Как это работает

В принятом здесь контракте compose(f, g)(x) равно f(g(x)): выполнение идёт справа налево. Pipe обычно называют аналогичный конвейер слева направо; названия и соглашения конкретной библиотеки нужно уточнять.

Ниже compose принимает синхронные одноаргументные функции и использует reduceRight. При пустом списке возвращается исходное значение.

Такая реализация не ожидает `Promise` и не сохраняет произвольный `this`; для асинхронного или многоаргументного конвейера нужен явно определённый другой контракт.

### Пример и его разбор

```javascript
const compose =
  (...functions) =>
  (value) =>
    functions.reduceRight((result, fn) => fn(result), value)

const trim = (text) => text.trim()
const upper = (text) => text.toUpperCase()
const normalize = compose(upper, trim)
normalize("  js  ") // "JS"
compose()(3) // 3
```

Объединённая функция сначала применяет правую операцию, а затем передаёт её результат следующей слева. Поэтому порядок аргументов compose описывает вложенность, а не очередь слева направо. В приведённой реализации каждая стадия синхронна и принимает одно значение; для `Promise` нужно отдельно определить ожидание, передачу ошибок и момент завершения конвейера.
