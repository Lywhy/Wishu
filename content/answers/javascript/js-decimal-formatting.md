**`toFixed` форматирует Number и возвращает строку. Он округляет уже существующее двоичное приближение, а не восстанавливает идеальное десятичное значение исходного ввода.**

<!-- wishu:answer-block -->

### Как это работает

Повторное Number(`toFixed`(...)) убирает формат, но не создаёт точную десятичную систему. Для вычислений с заданной точностью используйте согласованную модель минимальных единиц либо подходящую десятичную арифметику.

`Intl.NumberFormat` решает задачу отображения с локалью и валютой, а не является арифметическим движком. Не сравнивайте суммы по их локализованным строкам.

### Пример и его разбор

```javascript
const text = (12.3).toFixed(2)
console.log(text, typeof text) // "12.30", "string"
// Правила хранения и расчётов задаются до форматирования.
```

Text содержит «12.30» и имеет тип string: завершающий ноль является частью отображения. Если снова превратить результат в Number, формат исчезнет. Точность вычислений задают до этого шага, выбирая единицы хранения и правила арифметики.

### Типичная ошибка

> Использовать `toFixed` после каждого действия как доказательство точности денежных вычислений.
