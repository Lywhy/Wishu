**`var` объявляет переменную в области функции либо в глобальной области обычного скрипта. `let` и `const` ограничены лексической областью, например блоком. `const` дополнительно запрещает переназначать созданную привязку.**

### Как это работает

Объявление определяет не только место видимости, но и доступность значения во времени. Привязка `var` заранее получает `undefined`, а присваивание выполняется при достижении соответствующей строки. У `let` и `const` до инициализации действует TDZ: обращение к такой привязке вызывает `ReferenceError`.

`const` фиксирует связь переменной со значением, а не замораживает объект. Если значением является объект, его свойства по-прежнему можно изменять, пока отдельные ограничения объекта этого не запрещают. Переназначить саму переменную на другой объект уже нельзя.

### Пример и его разбор

```javascript
const user = { name: "Анна" }
user.name = "Ольга" // можно: изменяется объект
// user = {}; // TypeError: переназначение const

{
  let value = 1
}
// console.log(value); // ReferenceError: вне области блока
```

В примере изменение user.name допустимо: прежняя переменная продолжает указывать на тот же объект. Закомментированное user = {} меняло бы саму привязку и привело бы к ошибке. Переменная `value`, объявленная внутри блока, недоступна за его пределами.

### Нюансы и типичные ошибки

Практически начинают с `const` и выбирают `let`, когда нужно переназначение. У верхнеуровневых объявлений есть различия между обычным браузерным скриптом и ES-модулем; нельзя универсально считать любую глобальную переменную свойством `globalThis`.
