**Для простого документа можно запретить прокрутку корневого контейнера через overflow: hidden, например Tailwind-классом overflow-hidden.**

<!-- wishu:answer-block -->

### Как это работает

Важно блокировать фактический скролл-контейнер и после закрытия восстановить прежнее состояние, а не безусловно удалить чужую блокировку. Нужно учитывать сдвиг ширины при исчезновении полосы, особенности мобильных браузеров и несколько открытых диалогов.

Для вложенных блокировок полезен общий счётчик или механизм библиотеки диалогов. Управление прокруткой не заменяет удержание фокуса, доступное закрытие и восстановление фокуса модального окна.

### Пример и его разбор

```javascript
function lockPageScroll() {
  const root = document.documentElement
  const wasLocked = root.classList.contains("overflow-hidden")
  root.classList.add("overflow-hidden")
  return () => {
    if (!wasLocked) root.classList.remove("overflow-hidden")
  }
}
// Простой пример для одной блокировки; вложенные диалоги требуют общей координации.
```

Функция запоминает наличие класса до своей работы, чтобы при очистке не снять уже существовавшую блокировку. Это решает простой случай одного владельца. Для нескольких диалогов нужна общая координация, иначе закрытие одного окна может разблокировать страницу под другим.
