**Глобальная область и глобальный объект связаны, но не совпадают.**

<!-- wishu:answer-block -->

### Как это работает

В обычном браузерном скрипте верхнеуровневый var обычно создаёт свойство window, а let и const создают глобальные лексические привязки без таких свойств. В ES-модуле верхнеуровневые объявления ограничены модулем.

globalThis даёт доступ к глобальному объекту в разных средах. Присваивание необъявленному имени в нестрогом скрипте может создать глобальное свойство, а в строгом режиме и ES-модулях вызывает ReferenceError.

Избыточное общее изменяемое состояние усложняет поиск зависимостей; модули позволяют сделать их явными.

### Пример и его разбор

```javascript
// Верхний уровень ES-модуля
const localToModule = 1
Object.hasOwn(globalThis, "localToModule") // false
globalThis.wishuExample = 2
globalThis.wishuExample // 2
delete globalThis.wishuExample
```

В примере localToModule остаётся в области ES-модуля, поэтому собственного свойства с таким именем у globalThis нет. Напротив, явная запись globalThis.wishuExample создаёт общее свойство, которое затем удаляется. Эти операции имеют разные области влияния. Для обычного браузерного script правила верхнеуровневого var отличаются, поэтому среду нужно назвать до анализа результата.
