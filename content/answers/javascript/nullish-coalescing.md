**Оператор ?? возвращает правый операнд только тогда, когда левый равен `null` или `undefined`.**

### Как это работает

Значения 0, `false`, пустая строка и `NaN` сохраняются. || выбирает правый операнд при любом falsy-значении слева. Правый операнд вычисляется только при необходимости.

Непосредственно смешивать ?? с && или || без скобок нельзя: это синтаксическая ошибка. Скобки явно задают нужную группировку.

### Пример и его разбор

```javascript
0 ?? 10 // 0
0 || 10 // 10
"" ?? "нет текста" // ""
null ?? "нет значения" // "нет значения"
;(null ?? false) || "резерв" // "резерв"
```

Ноль и пустая строка в примере являются заданными значениями, поэтому ?? их сохраняет. Оператор || трактует ноль как falsy и заменяет его запасным значением. Практическое различие особенно заметно в настройках: лимит 0 может сознательно отключать функцию. Сначала определите, что означает отсутствие данных, затем выбирайте оператор.
