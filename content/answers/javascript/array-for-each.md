**forEach вызывает callback для существующих элементов и возвращает `undefined`.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Callback получает элемент, индекс и исходный массив; его возвращаемые значения не собираются.

- Это удобно, когда нужны действия для каждого элемента, а не новый массив результатов.

- Break и continue из callback не управляют обходом forEach, а return завершает только текущий вызов callback.

- Для управляемого выхода подходит for...of, для проверки условия - some или every.

- ForEach пропускает отсутствующие позиции и не ожидает Promise от async callback.

- Последовательные асинхронные действия обычно оформляют через for...of с await.
