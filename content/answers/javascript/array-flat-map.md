**`Map` сохраняет результат callback как один элемент, даже если это массив. `flatMap` выполняет преобразование и затем раскрывает возвращённые массивы ровно на один уровень: по смыслу это `Map`(callback).flat(1).**

### Как это работает

Можно вернуть пустой массив для удаления элемента, один элемент для замены или несколько для расширения результата. `flatMap` раскрывает именно массивы, а не любые iterable или массивоподобные объекты.

Более глубокие вложенные массивы остаются вложенными. Исходный массив сам метод не изменяет, но callback может мутировать доступные данные.

Как и `Map`, `flatMap` не ожидает `async` callback и не превращает `Promise` в готовые значения.

### Пример и его разбор

```javascript
const values = [1, 2]
values.map((value) => [value, value * 10]) // [[1, 10], [2, 20]]
values.flatMap((value) => [value, value * 10]) // [1, 10, 2, 20]
;[1, 2, 3].flatMap((value) => (value % 2 === 0 ? [] : [value])) // [1, 3]
;[1].flatMap(() => [[2, 3]]) // [[2, 3]]
```

`Map` оставляет массив, возвращённый callback, одним элементом, а `flatMap` переносит его элементы на верхний уровень. Пустой массив в результате callback ничего не добавляет, поэтому получается фильтрация. Последняя строка показывает предел раскрытия: ещё один вложенный уровень остаётся. Здесь меняется число элементов, но не выполняется произвольный рекурсивный обход.
