**Стрелочная функция берёт this из внешней лексической области и не создаёт собственного arguments.**

<!-- wishu:answer-block -->

### Что важно объяснить

- Её this нельзя заменить через call, apply или bind.

- Обычная функция получает this по правилам вызова.

- Стрелка допускает краткое тело-выражение с неявным возвратом; объект в таком теле оборачивают в скобки.

- Стрелки удобны для callback, которому нужен внешний this.

- Они не подходят как конструкторы с new, не могут быть генераторами и не годятся для метода, если this должен определяться объектом при вызове.

- Стрелочное поле экземпляра класса может намеренно захватывать this экземпляра - это другой случай, чем стрелка в литерале объекта.
