**IIFE - выражение функции, которое вызывается сразу после создания.**

<!-- wishu:answer-block -->

### Как это работает

Скобки позволяют интерпретировать function как выражение, а следующие () выполняют вызов. Результат можно сохранить в переменную; локальные привязки остаются внутри функции.

IIFE используют для одноразовой инициализации и создания закрытого окружения. До ES-модулей это был частый способ изоляции кода; теперь часть задач решают модули и блочная область let/const.

Возможна `async` IIFE, но её `Promise` и ошибки требуют такой же обработки, как у других `async`-вызовов.

### Пример и его разбор

```javascript
const counter = (function () {
  let value = 0
  return { next: () => ++value }
})()
counter.next() // 1
counter.next() // 2
```

Внешняя функция создаёт value один раз и сразу возвращает объект с next. После её завершения доступ к value сохраняет замыкание стрелки, поэтому последующие next продолжают один счётчик, а не запускают инициализацию заново. IIFE описывает немедленный вызов, тогда как сохранение состояния обеспечивается обычными правилами лексического окружения.
