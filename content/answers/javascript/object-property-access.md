**obj.name обращается к свойству с буквальным именем name. obj[key] вычисляет выражение key, поэтому подходит для динамических имён, строк с пробелами и символов.**

### Как это работает

Запись obj.key = value обновляет доступное для записи свойство либо, если правила объекта это допускают, создаёт новое собственное свойство. Метод можно добавить после создания, присвоив свойству функцию.

Для обычной функции `this` зависит от формы вызова, поэтому user.greet() получает user, а извлечённый greet - уже другой вызов. Запись не всегда создаёт свойство: унаследованный `setter` может перехватить её, а запрет расширения или readonly-свойство могут помешать присваиванию.

### Пример и его разбор

```javascript
const user = { name: "Аня" }
const key = "display name"
user[key] = "Анна"
user.greet = function () {
  return `Привет, ${this.name}`
}
user["display name"] // "Анна"
user.greet() // "Привет, Аня"
Object.hasOwn(user, key) // true
```

Точка удобна для известного имени, а квадратные скобки вычисляют ключ из выражения. Имя с пробелом поэтому читается через скобки. Метод можно добавить и после создания объекта: при вызове через объект обычная функция получает этот объект как `this`, а не запоминает его навсегда в момент присваивания.
