**obj.name обращается к свойству с буквальным именем name. obj[key] вычисляет выражение key, поэтому подходит для динамических имён, строк с пробелами и символов.**

### Что важно объяснить

- Запись obj.key = value обновляет доступное для записи свойство либо, если правила объекта это допускают, создаёт новое собственное свойство.

- Метод можно добавить после создания, присвоив свойству функцию.

- Для обычной функции this зависит от формы вызова, поэтому user.greet() получает user, а извлечённый greet - уже другой вызов.

- Запись не всегда создаёт свойство: унаследованный setter может перехватить её, а запрет расширения или readonly-свойство могут помешать присваиванию.
