**TTL задаёт время жизни ключа.** Eviction удаляет ключи согласно политике памяти при достижении заданных ограничений. Поэтому значение может исчезнуть раньше бизнес-срока кеша, если политика допускает вытеснение.

- Приложение должно корректно обрабатывать отсутствие кеша. Перезапись SET без нужных параметров может изменить прежний TTL, поэтому контракт команды проверяют явно. Кеш нельзя делать единственным хранилищем критичных данных без отдельного решения о надёжности.
