**String в Redis хранит байтовую последовательность, которая может представлять текст, сериализованный документ или другое поддерживаемое содержимое.** Redis не выводит бизнес-схему JSON автоматически из значения строки.

- Для подходящего целочисленного представления INCR выполняет атомарное увеличение. Получить значение через GET, увеличить на клиенте и вернуть SET - уже составная операция с возможной гонкой. Формат сериализации и версионирование значения задаёт приложение.
