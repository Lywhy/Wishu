**Sorted Set хранит уникальных участников с числовым score и поддерживает выборки по рангу и диапазону score.** Один участник не появляется несколько раз: повторное добавление может обновить его оценку.

- Одинаковые score разрешены и требуют понимания дополнительного порядка участников. Точность score ограничена его числовым представлением, поэтому его нельзя считать произвольным точным денежным типом. Для сложной бизнес-модели одного рейтинга недостаточно.
