**Goroutine - независимо выполняемая функция, которую планирует Go runtime. Это не обещание отдельного OS-потока для каждого вызова.**

<!-- wishu:answer-block -->

#### Как это работает

Запуск через go не заставляет вызывающую функцию ждать завершения. Для фоновой работы должны быть понятны владелец, сигнал остановки и способ дождаться результата. Заблокированная навсегда горутина способна удерживать память и ресурсы. Конкурентность описывает организацию независимых работ, а параллельность зависит также от ресурсов исполнения.

#### Пример

```go
done := make(chan struct{})
go func() {
    defer close(done)
    // Конечная работа.
}()
<-done // Явное ожидание завершения.
```

#### Разбор примера

Канал закрывается при выходе работника, а получатель дожидается этого события. Такой минимальный пример не передаёт ошибку и не отменяет работу; эти части добавляются по контракту задачи.

#### Типичная ошибка

> Запустить горутину без владельца и ожидать, что runtime автоматически остановит её при уходе пользователя со страницы.
