**Функция может вернуть несколько значений, обычно полезный результат и error. Вызывающий код явно решает, можно ли пользоваться результатом.**

<!-- wishu:answer-block -->

#### Как это работает

Ошибку проверяют до обращения к данным, если контракт не говорит иное. Именованные результаты являются локальными переменными, но не заменяют понятный return. Передача аргументов происходит по значению: даже указатель копируется как значение адреса, а не превращает вызов в передачу любой переменной по ссылке.

#### Пример

```go
func Divide(a, b int) (int, error) {
    if b == 0 { return 0, fmt.Errorf("деление на ноль") }
    return a / b, nil
}
// q, err := Divide(10, 2)
// Сначала проверяют err, затем используют q.
```

#### Разбор примера

Возврат `nil` сообщает об отсутствии ошибки. Целочисленное деление отбрасывает дробную часть; это часть контракта int, а не сбой функции. Для `fmt.Errorf` нужен импорт fmt.

#### Типичная ошибка

> Игнорировать err через _ и принять нулевой результат отказа за настоящий ответ.
