**Указатель хранит адрес значения, а разыменование даёт доступ к этому значению. Наличие указателя само по себе не доказывает размещение объекта в heap.**

<!-- wishu:answer-block -->

#### Как это работает

Компилятор анализирует, может ли значение пережить свою область использования. Возвращать указатель на локальную переменную допустимо: Go обеспечивает корректное время жизни. Присваивание указателя копирует адрес, поэтому несколько переменных могут изменять общий объект. `nil`-указатель требует проверки перед разыменованием.

#### Пример

```go
func Increment(value *int) {
    *value += 1
}
count := 2
Increment(&count)
// count == 3; параметр получил копию адреса count.
```

#### Разбор примера

Функция меняет значение по адресу, а не переменную-параметр вызывающего кода. Конкретное размещение памяти определяется компилятором и контекстом; из символа & его вывести нельзя.

#### Типичная ошибка

> Объявить любое использование указателя утечкой или доказательством heap allocation.
