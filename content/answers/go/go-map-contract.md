**Чтение отсутствующего ключа map возвращает нулевое значение. Дополнительный boolean отличает отсутствие от сохранённого zero value; запись в `nil` map вызывает panic.**

<!-- wishu:answer-block -->

#### Как это работает

Для записи создают map через `make` или литерал. Обычная map не предоставляет безопасную конкурентную запись без синхронизации. Даже наличие отдельных горутин для читателя и писателя не делает доступ безопасным. Порядок обхода map не является стабильным контрактом.

#### Пример

```go
scores := make(map[string]int)
scores["Анна"] = 0
value, exists := scores["Анна"]
missing, found := scores["Борис"]
// value=0, exists=true; missing=0, found=false.
```

#### Разбор примера

Оба числовых результата равны нулю, но только boolean показывает, был ли ключ. При общем доступе из нескольких горутин выбирают mutex, владение одной горутиной или другую подходящую структуру.

#### Типичная ошибка

> Проверять наличие по value != 0 либо записывать в map, объявленную только через var.
