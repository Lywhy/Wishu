**В языковой версии Go 1.22 и новее переменные, объявленные циклом, получают отдельные значения для итераций. Старое правило общего захвата нельзя безусловно применять к современному коду.**

<!-- wishu:answer-block -->

#### Как это работает

Существенна языковая версия пакета, обычно заданная go в go.mod. Правило для объявления := не означает, что внешняя переменная, которой присваивают через =, внезапно стала независимой. Общая память и указатели внутри элементов тоже не перестают разделяться.

#### Пример

```go
// Для пакета с языковой версией Go 1.22+.
callbacks := []func() int{}
for _, value := range []int{1, 2, 3} {
    callbacks = append(callbacks, func() int { return value })
}
// callbacks[0](), callbacks[1](), callbacks[2]() -> 1, 2, 3.
```

#### Разбор примера

Каждое замыкание получает переменную своей итерации. При заранее объявленном value и range с = замыкания обращались бы к общей переменной. Горутин в этом примере нет: он изолирует именно область видимости.

#### Типичная ошибка

> Выдать старый результат 3, 3, 3 без оговорки о версии и форме объявления.
