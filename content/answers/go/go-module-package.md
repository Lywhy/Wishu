**Пакет объединяет исходные файлы одной единицы компиляции, а модуль объединяет пакеты и задаёт путь и зависимости через go.mod.**

<!-- wishu:answer-block -->

#### Как это работает

Импорт использует путь пакета. Экспортируемые имена начинаются с заглавной буквы. package main с функцией main образует исполняемую программу; библиотечный пакет не обязан иметь точку входа. Путь модуля не является командой загрузки каждого файла при runtime: зависимости участвуют в сборке.

#### Пример

```go
// go.mod: module example.com/study
// Файл greeting/greeting.go:
package greeting

func Hello(name string) string {
    return "Привет, " + name
}
// Другой пакет импортирует example.com/study/greeting.
```

#### Разбор примера

Имя функции делает её доступной импортирующему пакету, а каталог задаёт часть пути импорта. Пример показывает библиотечный файл; комментарий `go.mod` не является содержимым того же Go-файла.

#### Типичная ошибка

> Считать каждый каталог отдельным модулем или ожидать экспорт имени hello с маленькой буквы.
