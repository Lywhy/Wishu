**Канал передаёт значения и координирует горутины. Буфер позволяет ограниченное число отправок без готового получателя; `select` выбирает готовую операцию.**

<!-- wishu:answer-block -->

#### Как это работает

Закрытие сообщает об отсутствии будущих отправок, а не удаляет уже накопленные значения. Получение через value, ok отличает закрытый исчерпанный канал. Отправка в закрытый канал вызывает panic. `nil`-канал блокирует соответствующий case, а default делает `select` неблокирующим и при неправильном цикле может создать busy loop.

#### Пример

```go
jobs := make(chan int, 1)
jobs <- 7
close(jobs)
first, ok1 := <-jobs
second, ok2 := <-jobs
// first=7, ok1=true; second=0, ok2=false.
```

#### Разбор примера

Первое получение извлекает сохранённое значение, хотя канал уже закрыт. Обычно закрывает канал отправляющая сторона, которая знает, что больше никто не отправит данные. Несколько отправителей требуют координации.

#### Типичная ошибка

> Закрыть канал из получателя, пока отправитель ещё может писать, или принять ноль за признак закрытия без ok.
