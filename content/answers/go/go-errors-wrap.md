**Обёртка через `fmt.Errorf` с %w сохраняет связь с исходной ошибкой. `errors.Is` ищет совпадение в цепочке, а `errors.As` - ошибку подходящего типа.**

#### Как это работает

Текст сообщения предназначен для человека и может меняться, поэтому бизнес-условия не стоит определять сравнением строк. Добавляйте контекст там, где он помогает понять операцию. Возврат внутренней ошибки клиенту HTTP и логирование полного стека - отдельные политики; секреты не должны становиться частью публичного сообщения.

#### Пример

```go
var ErrMissing = errors.New("запись не найдена")
err := fmt.Errorf("загрузка профиля: %w", ErrMissing)
if errors.Is(err, ErrMissing) {
    // Преобразовать ожидаемое отсутствие в нужный ответ API.
}
```

#### Разбор примера

Обёртка добавляет контекст, а проверка продолжает распознавать исходный sentinel. Формат %v оставил бы только текст. В файле нужны импорты errors и fmt; пример не выполняет реальный запрос.

#### Типичная ошибка

> Сравнить err.Error() с текстом либо потерять цепочку при замене %w на %v.
