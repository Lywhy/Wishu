**`defer` откладывает вызов до выхода из текущей функции. Его аргументы вычисляются в момент регистрации, а несколько отложенных вызовов выполняются в обратном порядке.**

<!-- wishu:answer-block -->

#### Как это работает

Это удобно для закрытия ресурса после успешного получения. `defer` внутри цикла сработает в конце функции, а не текущей итерации, поэтому множество открытых файлов может накопиться. Отложенное замыкание читает захваченные переменные при своём выполнении, что отличается от передачи уже вычисленного аргумента.

#### Пример

```go
value := 1
defer fmt.Println(value)
defer func() { fmt.Println(value) }()
value = 2
// При выходе из функции: сначала 2, затем 1.
```

#### Разбор примера

Замыкание зарегистрировано вторым и видит актуальное значение value. Первый вызов получил аргумент 1 заранее. Пример выполняется внутри функции и использует импорт fmt.

#### Типичная ошибка

> Ожидать, что `defer` выполнится сразу после блока if или завершения итерации.
