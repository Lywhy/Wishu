**Объявленная без инициализатора переменная получает нулевое значение своего типа. Краткое объявление := выводит тип и применяется внутри функций.**

<!-- wishu:answer-block -->

#### Как это работает

Для числа это 0, для bool - false, для строки - пустая строка, а указатели, slices, maps, channels и некоторые другие значения могут быть nil. Краткое объявление требует хотя бы одного нового имени в той же области. Вложенная область способна затенить прежнюю переменную, поэтому := и = не взаимозаменяемы.

#### Пример

```go
var count int
var ready bool
var title string
name := "Аня" // Внутри функции.
count = len(name)
// count, ready, title имеют начальные 0, false и "".
```

#### Разбор примера

Строка name содержит UTF-8, поэтому len измеряет байты, а не число видимых букв. Пример не обещает, что любой zero value уже готов к записи: `nil` map можно читать, но запись требует инициализации.

#### Типичная ошибка

> Случайно создать внутренний err через := и затем проверить другой err снаружи блока.
