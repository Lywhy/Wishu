**`Context` передаёт сигнал отмены, срок и данные области запроса через цепочку вызовов. Он не останавливает произвольный код принудительно.**

<!-- wishu:answer-block -->

#### Как это работает

Функция должна проверять `Done` или использовать API, которое поддерживает Context. После `WithCancel` или `WithTimeout` освобождают связанные ресурсы через cancel, даже если операция уже закончилась. В values не следует скрывать обязательные бизнес-аргументы: они остаются явными параметрами.

#### Пример

```go
ctx, cancel := context.WithTimeout(parent, time.Second)
defer cancel()
select {
case result := <-results:
    _ = result
case <-ctx.Done():
    return ctx.Err()
}
```

#### Разбор примера

Пример находится в функции, возвращающей error. Он прекращает ожидание канала при отмене, но сам производитель результата тоже должен иметь путь остановки, иначе его отправка может зависнуть.

#### Типичная ошибка

> Ожидать, что отмена `Context` сама убьёт горутину или откатит уже подтверждённую серверную запись.
