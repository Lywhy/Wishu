**Resize управляет доступным пользователю изменением размера коробки.** Для `textarea` вертикальное изменение часто помогает прочитать длинный ввод без лишней внутренней прокрутки.

<!-- wishu:answer-block -->

#### Как это работает

- Resize: vertical позволяет изменять высоту, `none` отключает ручное изменение. Ограничения min/max продолжают действовать.
- Применимость свойства зависит от элемента и `overflow`. Это не универсальная команда сделать любой inline-элемент растягиваемым.
- Разумно ограничить максимальную ширину контейнером, но не фиксировать поле под две строки только ради одинакового макета.
- Автоматическое увеличение по тексту - отдельное поведение; `resize` само не подгоняет высоту под содержимое.

#### Пример

```css
textarea {
  inline-size: 100%;
  box-sizing: border-box;
  min-block-size: 8rem;
  max-inline-size: 100%;
  resize: vertical;
}
```
