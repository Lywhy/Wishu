**Multicol делит единый поток содержимого на колонки.** Grid размещает элементы в ячейках; это разные модели даже при похожем изображении.

<!-- wishu:answer-block -->

#### Как это работает

- Текст в multicol читается вниз по колонке, затем продолжается в следующей. Это не сортировка карточек по строкам.
- Column-width задаёт предпочтительную ширину, `column-count` - число колонок с учётом остальных ограничений. Итог подстраивается под доступное место.
- Column-gap и `column-rule` оформляют промежуток и разделитель. Длинные блоки могут фрагментироваться, поэтому их разрывы нужно продумать.
- Для последовательности интерактивных карточек оцените порядок чтения и прокрутки: визуальная компактность не всегда означает удобство.

#### Пример

```css
.article {
  columns: 18rem;
  column-gap: 2rem;
}
.article h2 {
  break-after: avoid;
}
```
