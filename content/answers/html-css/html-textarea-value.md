**В обычном `HTML` начальный текст `textarea` задают между тегами.** Rows и `cols` подсказывают видимый размер, `maxlength` ограничивает длину ввода по правилам контрола.

<!-- wishu:answer-block -->

#### Как это работает

- Атрибут `value` в исходной HTML-разметке не является способом задать начальный текст `textarea`. Текущее DOM-свойство `value` после редактирования - отдельное состояние.
- Rows не ограничивает число строк данных: текст может прокручиваться. `CSS` может изменить отображаемые размеры.
- Отступы и переводы строк внутри разметки могут стать частью начального текста; для первого перевода строки после начального тега есть специальное HTML-правило.
- Контролу нужны `label` и `name` при отправке формы. Правила React для `value`/defaultValue имеют отдельный контракт.

#### Пример

```html
<label for="notes">Заметки</label>
<textarea id="notes" name="notes" rows="4" maxlength="500">Начальная заметка</textarea>
```
