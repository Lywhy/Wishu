**`:empty` проверяет структуру содержимого, а не то, видит ли человек что-нибудь на экране.** В распространённом реализованном поведении текстовый пробел уже мешает совпадению.

<!-- wishu:answer-block -->

#### Как это работает

- Комментарии не мешают `:empty`, а вложенный элемент мешает, даже если скрыт через `CSS`. Пустота не равна нулевой высоте.
- В спецификациях определение менялось в отношении whitespace. Не выводите поведение целевых браузеров только из формулировки новой редакции.
- Generated `content` через `::before` не становится обычным DOM-потомком и не заполняет элемент для этой проверки.
- Для состояния «список данных пуст» надёжнее использовать явное состояние приложения: форматирование шаблона пробелом не должно менять бизнес-логику.

#### Пример

```text
<div class="a"></div>
<div class="b"> </div>
<div class="c"><!-- комментарий --></div>
<!-- В распространённом поведении :empty совпадёт с a и c, но не b. -->
```
