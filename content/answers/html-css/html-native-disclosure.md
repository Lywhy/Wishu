**`details` с `summary` создаёт нативный раскрываемый блок с клавиатурным управлением.** Это хороший выбор для дополнительного пояснения, но не универсальная замена вкладкам или меню.

<!-- wishu:answer-block -->

#### Механизм и границы

- Первый `summary` служит видимым переключателем и названием. Состояние open - булево: `open="false"` всё ещё раскрывает блок.
- Одинаковый непустой `name` позволяет группировать `details` так, чтобы открытие одного закрывало другой в поддерживающих браузерах. Нельзя требовать такого поведения без учёта целевой среды.
- Не помещайте дополнительные конкурирующие действия внутрь `summary` без проверки взаимодействия. Для обязательного текста подумайте, уместно ли скрывать его по умолчанию.

#### Пример

```html
<details>
  <summary>Почему ответ неверный?</summary>
  <p>Специфичность сравнивается после происхождения и слоя.</p>
</details>
```
