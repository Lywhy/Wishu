**z-index сравнивается внутри контекста наложения.** Контексты образуют собственную иерархию: дочерний слой не может произвольным числом перепрыгнуть над контекстом родителя, который расположен ниже соседнего контекста.

- Новые контексты могут создавать, например, transform, opacity меньше единицы и некоторые сочетания position с z-index. Для диалога изучают всю цепочку предков; нативный dialog в top layer и портал решают другие аспекты размещения, чем увеличение локального z-index.

### Проверка цепочки контекстов
Проверьте transform, opacity, isolation и подходящие position/z-index у предков. Flex- и grid-элементы тоже имеют специальные правила z-index. Isolation: isolate может намеренно создать локальную область наложения. Top layer нативного модального dialog находится на другом уровне, чем обычная иерархия z-index. Portal меняет физическое место DOM, но не заменяет модальность и работу фокуса.
