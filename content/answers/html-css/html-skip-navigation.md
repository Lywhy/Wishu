**Skip link позволяет перейти через повторяющуюся шапку сразу к основному материалу.** Она должна быть доступна с клавиатуры и становиться видимой при фокусе, если скрыта в обычном состоянии.

<!-- wishu:answer-block -->

#### Как это работает

- Разместите ссылку рано в документе и задайте существующую цель. Main с уникальным `id` задаёт понятную точку перехода.
- Важно проверить не только прокрутку, но и продолжение клавиатурного обхода с нужной части страницы. Для фокусируемой цели при необходимости используют `tabindex="-1"` без добавления в обычную очередь Tab.
- Не скрывайте ссылку через `display`: `none`: тогда с клавиатуры её не найти. У фиксированной шапки учитывайте отступ прокрутки.

#### Пример

```html
<a class="skip-link" href="#main">К основному содержимому</a>
<header>...</header>
<main id="main" tabindex="-1"><h1>Вопросы</h1></main>
```
