**`time` обозначает дату, время или допустимую длительность, а `datetime` передаёт нормализованное значение.** Видимая подпись может быть локализованной.

<!-- wishu:answer-block -->

#### Как это работает

- Запись «7 ноября» удобна человеку, но не содержит однозначный год и формат. `datetime="2026-11-07"` даёт понятное значение календарной даты.
- Для момента времени указывают дату, время и при необходимости смещение. Чистая дата не становится автоматически моментом UTC.
- `time` не создаёт календарь, не форматирует текст и не обновляет часы. За ввод отвечает другой элемент, а за динамику - приложение.

#### Пример

```html
<p>
  Собеседование: <time datetime="2026-11-07T15:00:00+03:00"> 7 ноября в 15:00 по Москве </time>.
</p>
```
