**Normal flow - базовое размещение содержимого без специального позиционирования.** Relative сохраняет исходное место, `absolute` и `fixed` обычно выводят коробку из нормального потока.

<!-- wishu:answer-block -->

#### Как это работает

- Static - обычное позиционирование; top/left не дают ему смещения. Relative сдвигает отображение, не освобождая исходное место для соседей.
- Absolute располагается по правилам содержащего блока. Fixed часто связан с viewport, но отдельные свойства предков могут изменить эту базу.
- Sticky участвует в потоке и затем ограниченно смещается при прокрутке. Ни один из этих режимов не означает автоматического центрирования или правильного z-index.

#### Пример

```css
.label {
  position: relative;
  inset-block-start: 0.25rem;
}
/* Место в потоке сохраняется, сосед не поднимается в освободившуюся область. */
```
