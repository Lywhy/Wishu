**Явные треки задаются `grid-template-*`, неявные появляются, когда размещению не хватает этой сетки.** `grid-auto-*` управляют дополнительными треками и направлением автопозиционирования.

<!-- wishu:answer-block -->

#### Механизм и границы

- `grid-auto-rows` задаёт размер неявных строк. Если заданы две колонки, следующие элементы обычно создают дополнительные строки.
- `dense` разрешает заполнять ранее оставленные дырки более поздними элементами. Их визуальный порядок может перестать соответствовать DOM.
- Tab-порядок и чтение вспомогательными технологиями не обязаны следовать такому визуальному заполнению. Dense подходит для декоративной раскладки лучше, чем для смысловой последовательности шагов.

#### Пример

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  grid-auto-rows: minmax(8rem, auto);
  gap: 1rem;
}
.wide {
  grid-column: span 2;
}
```
