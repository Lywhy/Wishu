**and требует выполнения обоих условий, список через запятую означает альтернативы.** Диапазонный синтаксис позволяет явно задать открытые и закрытые границы ширины.

#### Механизм и границы

- (30rem <= `width` < 60rem) описывает диапазон без искусственного вычитания .01px. Соседние правила могут иметь намеренное пересечение или не пересекаться.
- У not важен синтаксис и область отрицания; скобки и отдельные условия помогают избежать ложного прочтения. Не воспринимайте строку как обычное JavaScript-выражение.
- Breakpoint выбирают по моменту, когда перестаёт работать содержимое, а не по списку моделей устройств. CSS-пиксели viewport не равны физическим пикселям дисплея.
- Для старой целевой среды сохраните совместимую форму `min-width`/`max-width` или преобразование при сборке.

#### Пример

```css
@media (30rem <= width < 60rem) {
  .cards {
    grid-template-columns: 1fr 1fr;
  }
}
@media print, (width < 30rem) {
  .optional-decoration {
    display: none;
  }
}
```
