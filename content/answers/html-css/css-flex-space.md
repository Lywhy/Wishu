Flex-basis задаёт исходную основу для расчёта, grow участвует в распределении свободного пространства, а shrink - в уменьшении при его нехватке. Это не обещание окончательной ширины независимо от содержимого и min/max.

<!-- wishu:answer-block -->

При сжатии учитывается не только коэффициент shrink, но и базовый размер: более крупные элементы могут отдавать больше места. Автоматические минимумы способны остановить сжатие.

Flex: 1 удобно для совместного распределения, но одинаковые коэффициенты не гарантируют одинаковый видимый размер при разных границах и содержимом. Для фиксированной панели отключайте нежелательное сжатие явно.

#### Чтение распространённых значений flex

`flex: none` разворачивается в `0 0 auto`: коробка не растёт и не отдаёт место через flex-shrink. `flex: auto` означает `1 1 auto`: основа учитывает auto-размер, а элемент может расти и сжиматься. `flex: 1` в браузерах обычно разворачивается в `1 1 0%`. Нулевая база и auto не одно и то же; при неопределённом размере контейнера различие `0%` и `0` тоже может иметь значение. Во всех вариантах продолжают действовать min/max и содержимое. Для фиксированной боковой панели задают размер и запрещают сжатие намеренно.

```css
.sidebar {
  flex: 0 0 16rem;
}
.content {
  flex: 1;
  min-inline-size: 0;
}
```
