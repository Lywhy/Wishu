**Текстовая декорация распространяется по специальным правилам через содержимое, а не просто наследуется как `color`.** Поэтому потомок не может обычным `none` отменить уже рисуемую декорацию предка.

<!-- wishu:answer-block -->

#### Механизм и границы

- Если подчёркивание задано ссылке, вложенный `span` с `none` обычно не отменяет её линию. Нужно изменить источник декорации или структуру.
- `text-underline-offset` и `text-decoration-thickness` помогают сделать ссылку читаемой. Цветовая разница не должна быть единственным способом обнаружить ссылку в тексте.
- `text-decoration` не создаёт отдельного DOM-содержимого. Для перечёркнутой старой цены или удалённого текста выбирают подходящую семантику, а не только визуальный эффект.

#### Пример

```css
a {
  text-decoration-line: underline;
  text-decoration-thickness: 0.08em;
  text-underline-offset: 0.15em;
}
a span {
  text-decoration: none;
}
/* Это не отменяет линию, заданную самой ссылке. */
```
