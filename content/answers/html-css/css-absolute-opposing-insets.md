**У обычного незамещаемого absolute-элемента с auto-шириной противоположные inset могут определить ширину между границами.** Это не означает, что left и right всегда сильнее явно заданной `width`.

<!-- wishu:answer-block -->

#### Как это работает

- При inset-inline: 1rem и auto `inline-size` коробка занимает доступное пространство между отступами с учётом собственной модели размеров.
- Если заданы обе стороны и фиксированная ширина, система может оказаться переограниченной. Разрешение конфликта зависит от направления и правил позиционирования.
- Замещаемые элементы и auto-margin имеют дополнительные правила. Сначала установите содержащий блок, затем анализируйте ограничения.
- Absolute не резервирует место в `normal` flow: растянутый фон не определяет автоматически высоту родителя.

#### Пример

```css
.parent {
  position: relative;
  min-block-size: 10rem;
}
.overlay {
  position: absolute;
  inset: 1rem;
}
/* Для обычной div-коробки auto-размеры заполняют область между границами. */
```
