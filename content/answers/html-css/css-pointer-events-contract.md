**`pointer-events`: `none` исключает элемент из обычного выбора цели указателем, но не отключает его семантику и клавиатурный фокус.** Это не замена `disabled`.

<!-- wishu:answer-block -->

#### Механизм и границы

- Указатель может попасть в элемент под ним. При этом фокусируемая кнопка всё ещё может быть достигнута Tab и активирована клавиатурой.
- Потомок может отдельно вернуть `pointer-events`: `auto`. Его событие проходит по обычному пути через предка, поэтому обработчик предка может сработать.
- Для недоступного действия используйте нативный `disabled` либо полный осознанный `aria-disabled` контракт. Для неинтерактивного поддерева рассмотрите inert по назначению.
- Свойство полезно, например, у чисто декоративного слоя, который не должен перехватывать клики.

#### Пример

```css
.decorative-overlay {
  position: absolute;
  inset: 0;
  pointer-events: none;
}
```
