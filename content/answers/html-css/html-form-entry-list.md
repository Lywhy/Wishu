Данные формы строятся по участвующим контролам и их name. Отключённые поля не отправляются, а readonly-поле подходящего типа обычно отправляется. Неотмеченные checkbox и radio не добавляют своё значение.

Повторяющиеся имена допустимы: для них используйте getAll, если читаете FormData. Состояние checked отличается от строкового value checkbox. Участвующая submit-кнопка может добавить собственные name/value; при программном построении FormData учитывайте переданного submitter.

Id связывает подпись и DOM-узел, но не заменяет name. Disabled не является защитой данных: запрос можно создать без вашего интерфейса. Для файлов нужна соответствующая кодировка формы или FormData при клиентской отправке.
