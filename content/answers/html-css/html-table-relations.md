Используйте table для табличных отношений данных, caption для названия и th для заголовков. scope помогает явно связать простой заголовок со строкой или столбцом.

<!-- wishu:answer-block -->

Семантика позволяет вспомогательным технологиям объяснять положение текущего значения. Для сложных многоуровневых таблиц может потребоваться явная связь headers/id; иногда полезнее упростить представление.

Таблица не предназначена для раскладки всей страницы. На узком экране горизонтальный скролл может сохранять отношения лучше, чем перестановка ячеек в несвязанные карточки. Дайте скроллируемой области понятный доступ и сохраняйте заголовки.

#### Минимальная таблица с заголовками двух направлений

`thead` и `tbody` группируют строки, но сами по себе не объявляют каждую ячейку заголовком. Для этого нужен `th`, а `scope` поясняет его отношение в простой таблице. В примере столбец задаёт тип показателя, строка - технологию. `caption` называет таблицу целиком. Семантические связи сохраняют смысл при чтении по ячейкам; CSS-границы их не создают.

```html
<table>
  <caption>
    Решённые задачи по технологиям
  </caption>
  <thead>
    <tr>
      <th scope="col">Технология</th>
      <th scope="col">Решено</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">HTML</th>
      <td>12</td>
    </tr>
  </tbody>
</table>
```
