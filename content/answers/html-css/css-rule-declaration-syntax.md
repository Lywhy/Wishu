**Селектор определяет, к каким элементам относится правило; декларация задаёт пару свойство: значение.** В блоке правила может быть несколько деклараций.

<!-- wishu:answer-block -->

#### Как это работает

- В .card { `color`: navy; } селектором является .card, свойством - `color`, значением - navy. Точка с запятой разделяет декларации.
- CSS-комментарий записывают через /* ... */. JavaScript-комментарий // не является обычным CSS-комментарием.
- Одна подходящая декларация не обязательно победит: к элементу могут подходить несколько правил, и конфликт разрешается каскадом.

#### Пример

```css
.card {
  color: navy;
  padding: 1rem;
}
/* Два свойства для элементов с классом card. */
```
