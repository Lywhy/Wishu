**Inline SVG является частью текущего DOM, а SVG в `img` используется как отдельный ресурс изображения.** `CSS` страницы не проходит внутрь `img` для выбора его path.

<!-- wishu:answer-block -->

#### Как это работает

- В inline SVG можно стилизовать отдельные фигуры классами и использовать `currentColor`. У `img` обычно управляют размером и внешней коробкой, а не внутренним деревом SVG.
- Для `img` используют `alt`. Информативному inline SVG нужно подходящее доступное имя, например связь с `title`; декоративный вариант можно скрыть от accessibility API.
- Встраивание произвольного SVG как разметки требует оценки доверия. Контекст изображения имеет другие ограничения; нельзя считать оба способа одинаковым выполнением активного документа.

#### Пример

```html
<svg viewBox="0 0 24 24" role="img" aria-labelledby="chart-title">
  <title id="chart-title">Рост результатов</title>
  <path d="M3 20L10 12L15 15L21 4" fill="none" stroke="currentColor"></path>
</svg>
```
