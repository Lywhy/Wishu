Современный doctype помогает браузеру выбрать standards mode. При его отсутствии или некоторых старых объявлениях возможен quirks mode с историческими отличиями поведения, в частности в CSS-макете.

<!-- wishu:answer-block -->

Doctype не является HTML-элементом и не загружает определение языка. Его размещают перед документом. Наличие doctype не проверяет валидность всей разметки: неправильная вложенность всё ещё может быть исправлена парсером.

При необъяснимых отличиях старой страницы проверяют режим документа, затем конкретную модель размеров и стили. Не пытайтесь компенсировать quirks mode набором случайных CSS-поправок.
