Content-visibility: auto позволяет браузеру откладывать часть работы рендеринга содержимого, когда оно не актуально для отображения. Это не удаляет DOM-узлы и не размонтирует React-компоненты.

<!-- wishu:answer-block -->

Оценка внутреннего размера через contain-intrinsic-size помогает уменьшить скачки при появлении содержимого. Свойство не отменяет создание элементов, загрузку приложения и любые подписки JavaScript.

Не смешивайте с display: none: auto предназначено для откладывания рендеринга при сохранении доступности содержимого. Измерения скрытого содержимого и некоторые особенности видимости требуют проверки на конкретном сценарии. Виртуализация решает другую задачу: уменьшает число смонтированных элементов.
