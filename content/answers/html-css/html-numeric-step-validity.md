**`min` и `max` ограничивают диапазон, `step` - допустимую сетку значений.** `maxlength` относится к длине текста у поддерживающих его типов, а не к количеству цифр в number.

<!-- wishu:answer-block -->

#### Механизм и границы

- Для number шаг по умолчанию равен 1. База шага определяется правилами типа, в частности `min`, затем атрибутом `value`, а при их отсутствии обычно нулём.
- При `min="0.1"` и `step="0.2"` подходят 0.1, 0.3 и 0.5; значение 0.2 попадает в диапазон, но не на шаг. `step="any"` убирает это ограничение, не отменяя `min`/`max`.
- Если значение является кодом с ведущими нулями, используйте строковое поле с `inputmode`. Денежные вычисления и серверные ограничения требуют отдельного решения точности.

#### Пример

```html
<label for="quantity">Количество с шагом 0,2 от 0,1</label>
<input id="quantity" name="quantity" type="number" min="0.1" max="10" step="0.2" />
```
