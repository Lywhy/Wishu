**Separate оставляет рамки ячеек раздельными, collapse разрешает общую границу по правилам конфликтов.** Это не только визуальное «убрать двойную линию».

<!-- wishu:answer-block -->

#### Как это работает

- Border-spacing задаёт расстояние между рамками в раздельной модели; в collapsed-модели он не создаёт обычные промежутки между ячейками.
- В collapse конфликтующие стили границы выбираются по специальным правилам. Не рассчитывайте получить две независимые линии от соседних `td`.
- Padding ячеек по-прежнему задаёт внутренние отступы. Эти настройки не заменяют семантику заголовков и не определяют алгоритм ширины таблицы.

#### Пример

```css
table {
  border-collapse: collapse;
}
th,
td {
  border: 1px solid #888;
  padding: 0.5rem;
}
```
