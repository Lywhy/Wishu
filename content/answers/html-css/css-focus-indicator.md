Focus-visible позволяет оформлять фокус, когда браузер определяет необходимость его явного показа. Это не точная проверка «только клавиатура»: используются эвристики и вид элемента.

Не удаляйте outline без равноценной замены. Hover не доступен как устойчивое действие на всех устройствах, поэтому важные контролы не должны появляться только при наведении. Media queries hover/pointer помогают адаптировать дополнительное поведение.

Индикатор должен быть виден на разных фонах и не обрезаться контейнером. Статус ошибки и выбора также не следует передавать одним цветом.
