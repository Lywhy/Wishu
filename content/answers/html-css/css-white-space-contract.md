**white-space управляет сохранением пробелов и переносами.** `normal` схлопывает пробелы и переносит строки, `nowrap` запрещает обычные переносы, `pre` сохраняет пробелы без обычного переноса, `pre-wrap` сохраняет их и разрешает перенос.

#### Механизм и границы

- Для отформатированного пользовательского текста `pre-wrap` часто удобен: Enter виден, но длинная строка может переноситься по обычным возможностям.
- Для непрерывного длинного токена может понадобиться `overflow-wrap`: anywhere. Сохранение пробелов само по себе не гарантирует отсутствие горизонтального переполнения.
- `break-spaces` имеет дополнительные правила сохранения завершающих пробелов и возможностей разрыва. Не подменяйте им обычный текст без понимания цели.
- HTML `pre` добавляет семантику предварительно форматированного текста, а CSS white-space управляет отображением любого подходящего элемента.

#### Пример

```css
.user-note {
  white-space: pre-wrap;
  overflow-wrap: anywhere;
}
.single-line {
  white-space: nowrap;
}
.code-block {
  white-space: pre;
  overflow-x: auto;
}
```

#### Пробел между inline-элементами может быть видимым интервалом

Перевод строки или пробел между inline/inline-block элементами в исходнике может стать межсловным промежутком при обычном схлопывании whitespace. Это не обязательно margin одного из элементов. Не устраняйте зазор случайным отрицательным margin или `font-size: 0` на общем текстовом контейнере. Для ряда интерфейсных элементов часто яснее Flexbox с `gap`: расстояние перестаёт зависеть от форматирования HTML. Для обычного текста пробел, наоборот, может быть необходим.

```html
<span>Первый</span> <span>второй</span>
<!-- Между словами намеренно присутствует текстовый пробел. -->
```
