**Многострочный clamp ограничивает отображаемые строки, а не сокращает сами данные.** Полный важный текст должен оставаться доступным понятным способом.

<!-- wishu:answer-block -->

#### Как это работает

- Для совместимого распространённого варианта используют -webkit-line-clamp вместе с `display`: -webkit-box и вертикальной ориентацией. Поддержку непредварённого синтаксиса проверяют отдельно.
- Один `text-overflow`: ellipsis не решает задачу нескольких строк. Нужны ограничения коробки и соответствующий механизм.
- На карточке короткое превью уместно, если есть переход к материалу. Не обрезайте единственное объяснение ошибки или условия согласия.
- Не делайте hover/`title` единственным способом узнать текст: нужны клавиатурный и сенсорный пути.

#### Пример

```css
.preview {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  overflow: hidden;
}
```
