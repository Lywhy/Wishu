До загрузки веб-шрифта браузер выбирает поведение согласно font-display и своим временным периодам. Замена запасного шрифта на основной может менять размеры строк и создавать сдвиги.

<!-- wishu:answer-block -->

Подберите подходящий fallback и его метрики. Size-adjust и метрические дескрипторы помогают согласовать отображение, но требуют осмысленных значений. Загружайте нужные начертания и подмножества вместо всех вариантов.

Preload полезен только для действительно ранней потребности и с правильным CORS-режимом. Font-display: swap не гарантирует отсутствие сдвигов и не делает шрифт бесплатным для сети.
