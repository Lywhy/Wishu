**`CSS px` - единица макета, а не обещание одного физического пикселя дисплея.** Device pixel ratio связывает CSS-пиксели с пикселями устройства в данном режиме.

<!-- wishu:answer-block -->

#### Как это работает

- У картинки шириной 100 `CSS px` на плотном экране может потребоваться больше растровых пикселей для чёткого изображения.
- `DPR` не сообщает размер устройства в сантиметрах и не определяет его роль. Масштабирование и среда отображения влияют на наблюдаемое соотношение.
- Для вариантов изображения передавайте браузеру srcset/sizes. Не увеличивайте CSS-ширину вдвое только потому, что нужен более чёткий ресурс.

#### Пример

```html
<img
  src="avatar-100.png"
  srcset="avatar-100.png 1x, avatar-200.png 2x"
  width="100"
  height="100"
  alt="Анна"
/>
```
