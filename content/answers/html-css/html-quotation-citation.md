**q обозначает короткую встроенную цитату, `blockquote` - отдельный цитируемый фрагмент, `cite` - название творческого произведения.** Это не три варианта красивого отступа.

<!-- wishu:answer-block -->

#### Как это работает

- Атрибут `cite` у `blockquote` может содержать URL источника, но сам по себе обычно не выводит видимую ссылку. Если человеку нужен источник, покажите его явно.
- Элемент `cite` не предназначен просто для любого имени автора. Название статьи, книги или другого произведения - подходящий случай.
- Внешнее оформление можно менять `CSS`: отступы и кавычки не являются единственной причиной выбрать эти элементы.

#### Пример

```html
<figure>
  <blockquote cite="https://example.com/article"><p>Цитируемый фрагмент.</p></blockquote>
  <figcaption>
    Из статьи <cite><a href="https://example.com/article">О доступности</a></cite>
  </figcaption>
</figure>
```
