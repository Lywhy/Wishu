**Text-transform меняет представление текста, а не нормализует данные приложения.** Визуальный uppercase не означает, что в DOM или отправляемом значении хранится та же строка.

<!-- wishu:answer-block -->

#### Как это работает

- Правила регистра зависят от языка: `lang` помогает применить соответствующие преобразования. Capitalize не является полноценным редактором заголовков.
- Если сервер требует каноническую форму кода, её обеспечивают явной обработкой и проверкой данных. `CSS` не заменяет этот контракт.
- Слишком длинный текст в верхнем регистре может ухудшить читаемость. Не используйте оформление как единственный признак значения поля.

#### Пример

```css
.short-label {
  text-transform: uppercase;
  letter-spacing: 0.03em;
}
/* Исходная строка приложения от этого не переписывается. */
```
