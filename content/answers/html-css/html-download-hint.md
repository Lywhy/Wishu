**`download` выражает намерение скачать ресурс и может предложить имя файла, но не является универсальной командой для любого URL.** Учитываются origin, заголовки ответа и политика браузера.

<!-- wishu:answer-block -->

#### Как это работает

- Для обычных ссылок атрибут предназначен для same-origin URL и поддерживаемых data:/blob: случаев. Нельзя им безусловно заставить скачать произвольный чужой сайт.
- Серверный Content-Disposition может влиять на имя и обработку ресурса. Имя также может быть скорректировано из-за ограничений файловой системы.
- Дайте человеку понятную подпись, формат и при необходимости размер. Не выдавайте переход на HTML-страницу за готовый PDF.

#### Пример

```html
<a href="/files/html-guide.pdf" download="html-guide.pdf"> Скачать памятку HTML (PDF) </a>
```
