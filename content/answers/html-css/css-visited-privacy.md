**Браузеры намеренно ограничивают `:visited` ради приватности истории.** Обычно разрешены только некоторые цветовые изменения, а вычисленные стили не раскрывают реальное посещённое состояние.

<!-- wishu:answer-block -->

#### Как это работает

- Нельзя надёжно изменить `display`, размеры или фон-картинку и затем измерить, была ли ссылка посещена. Прозрачность тоже ограничивается правилами защиты.
- `getComputedStyle` не является API чтения истории: браузер может возвращать значения как для непосещённой ссылки.
- Сопоставление посещений дополнительно зависит от политик браузера и контекста. Не используйте `:visited` для состояния «урок пройден» или учёта прогресса.

#### Пример

```css
a:link {
  color: #174a9c;
}
a:visited {
  color: #6b3584;
}
a:focus-visible {
  outline: 2px solid currentColor;
}
```
