**`@scope` ограничивает область совпадения селекторов.** При прочих равных выигрывает правило с ближайшим корнем области, но `proximity` не сильнее происхождения, важности, слоя или специфичности.

<!-- wishu:answer-block -->

#### Механизм и границы

- Запись `@scope` (.card) to (.nested) задаёт корень и исключённую нижнюю границу. Это помогает стилизовать содержимое без длинного префикса каждого селектора.
- Сам prelude области не добавляет специфичность внутреннему селектору. Явное `:scope` как псевдокласс имеет собственную специфичность.
- Ограничение совпадения не блокирует наследование: `color` от предка может дойти до исключённого поддерева. `@scope` не создаёт Shadow DOM и не является барьером безопасности.
- Используйте в поддерживающих средах или сохраняйте базовый вариант. При равных прежних критериях `proximity` сравнивается перед порядком правил в файле.

#### Пример

```css
@scope (.card) to (.nested-card) {
  p {
    color: navy;
  }
}
/* Вложенная .nested-card исключена из прямого совпадения p,
   но наследуемые значения через границу всё ещё возможны. */
```
