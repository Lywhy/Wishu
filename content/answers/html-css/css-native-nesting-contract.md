**Нативная вложенность разбирается браузером и использует & как ссылку на родительский селектор.** Это не текстовая подстановка Sass и не возможность произвольно дописывать часть имени класса.

<!-- wishu:answer-block -->

#### Механизм и границы

- `&:hover` задаёт состояние того же элемента, а & .title выбирает потомка. Пробел меняет отношение.
- Специфичность & определяется наиболее специфичной ветвью родительского списка, подобно `:is()`. Наличие ID в одной ветви может усилить правило для остальных.
- Нельзя считать &__title эквивалентом Sass-конкатенации .card__title. Для отдельного класса используйте явный селектор.
- Сверяйте синтаксис с целевыми браузерами или настройками преобразования: поддержка вложенности не означает поддержку любого синтаксиса препроцессора.

#### Пример

```css
.card,
#featured {
  & .title {
    color: navy;
  }
}
/* Вложенная ветвь получает специфичность наиболее сильного родителя: ID. */
.card {
  &:hover {
    border-color: navy;
  }
}
```
