**При заданной ширине таблицы fixed определяет раскладку колонок без анализа содержимого всех ячеек.** Auto учитывает содержимое; перенос и обрезание остаются отдельными решениями.

<!-- wishu:answer-block -->

#### Механизм и границы

- Для fixed важна определённая ширина таблицы. Ширины колонок могут задаваться col или первой строкой, а остаток распределяется по правилам алгоритма.
- Длинный URL не обязан расширить колонку при fixed: он может переполнить ячейку. Добавьте подходящий перенос, если нужно сохранить весь текст.
- Не превращайте таблицу данных в набор блоков ценой потери отношений заголовков. Горизонтальная прокрутка иногда лучше агрессивного удаления колонок.

#### Пример

```css
table {
  inline-size: 100%;
  table-layout: fixed;
  border-collapse: collapse;
}
th,
td {
  padding: 0.5rem;
  border: 1px solid #888;
}
td {
  overflow-wrap: anywhere;
}
```
