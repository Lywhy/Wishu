**Popover показывает немодальный элемент в top layer; showModal() у dialog создаёт модальное взаимодействие.** Сам по себе `popover` не блокирует остальную страницу и не превращает содержимое в доступное меню.

<!-- wishu:answer-block -->

#### Механизм и границы

- `popover="auto"` поддерживает закрытие снаружи и запросом закрытия, например Escape. У manual такого автоматического закрытия нет.
- popovertarget у кнопки позволяет открыть связанный элемент без ручного обработчика. У кнопки внутри формы всё равно явно задают `type="button"`.
- Нужные роли, имя и клавиатурное поведение зависят от содержимого: справка и сложное меню требуют разных контрактов. Top layer решает порядок отображения, а не семантику.
- Пример рассчитан на браузер с поддержкой Popover API; для требуемых старых сред нужен доступный альтернативный путь.

#### Пример

```html
<button type="button" popovertarget="help">Подсказка</button>
<div id="help" popover>Ответ можно изменить позже.</div>
```
