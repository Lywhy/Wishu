**`font-family` - упорядоченный список кандидатов, но выбор может происходить для разных символов отдельно.** Если выбранный шрифт не содержит нужный глиф, браузер ищет подходящую замену.

<!-- wishu:answer-block -->

#### Механизм и границы

- Загрузка семейства не гарантирует наличие кириллицы, эмодзи и всех знаков. Даже одна строка может сочетать несколько шрифтов с разными метриками.
- После выбора семейства учитываются `style`, weight и другие характеристики. Универсальное семейство вроде sans-serif задаёт запасной путь, а не конкретный файл.
- У `@font-face` можно разделять наборы через `unicode-range`. Это влияет на выбор и загрузку, но не переводит символы и не исправляет испорченную кодировку.
- Проверяйте фактически использованные шрифты в DevTools. Одна строка computed `font-family` не доказывает, какой файл нарисовал каждый символ.

#### Пример

```css
body {
  font-family: "Product Sans", system-ui, sans-serif;
}
/* Если Product Sans не содержит часть символов, возможен fallback по глифам. */
```
