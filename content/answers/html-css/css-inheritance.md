**Некоторые свойства, например color и font-family, обычно наследуются; размеры, margin и border обычно нет.** Наследование используется, когда каскад не задал элементу собственное значение наследуемого свойства.

<!-- wishu:answer-block -->

- inherit явно берёт вычисленное значение родителя, initial выбирает исходное значение из спецификации, unset действует как inherit для наследуемого свойства и initial для остальных. Исходное значение спецификации не обязательно совпадает со стилем браузера для конкретного HTML-тега.

<!-- wishu:answer-block -->

### Возврат к другому уровню

Unset выбирает наследование или initial по природе свойства. Revert откатывает влияние текущего происхождения каскада, поэтому может проявиться пользовательское или браузерное правило. Revert-layer откатывает влияние текущего слоя. Это не три способа взять одно универсальное «значение по умолчанию». Initial определяется спецификацией свойства, а не стилем тега из браузерного stylesheet.

<!-- wishu:answer-block -->

#### Почему unset не возвращает браузерное оформление кнопки

У border-style начальное значение none. После border: unset не стоит ждать стандартной рамки нативной кнопки: unset берёт initial для ненаследуемых свойств. Revert откатывает авторский origin и может проявить пользовательский или UA-стиль. Это не гарантирует один одинаковый внешний вид во всех браузерах.

```css
.unstyled-border {
  border: unset;
}
.ua-border {
  border: revert;
}
/* Два разных намерения: initial против отката происхождения. */
```
