**calc выполняет арифметику над CSS-значениями в рамках типа принимающего свойства.** Он позволяет сочетать, например, процент и длину, когда свойство допускает такое сочетание.

<!-- wishu:answer-block -->

#### Механизм и границы

- `inline-size`: calc(100% - 2rem) разрешает процент по базе ширины и вычитает длину. Это не строковая замена и не произвольный JavaScript внутри CSS.
- У + и - нужны пробелы: иначе токенизация может дать другое выражение. Несовместимые величины вроде длины плюс время не образуют допустимую ширину.
- Подстановка var() должна дать подходящее значение: отсутствие единиц у числа не превращает его автоматически в длину.
- `min`, `max` и clamp выбирают или ограничивают значения; calc описывает выражение. Новые возможности типизированных умножения/деления имеют отдельную поддержку, не обобщайте их на старые браузеры.

#### Пример

```css
.panel {
  --gap: 1rem;
  inline-size: calc(100% - 2 * var(--gap));
  margin-inline: var(--gap);
}
```
