**Date хранит нормализованное значение календарной даты вида YYYY-MM-DD, а отображение зависит от браузера и локали.** Datetime-local добавляет локальное время без часового пояса.

<!-- wishu:answer-block -->

#### Как это работает

- Не разбирайте видимый текст календарного виджета как контракт данных. Пустое поле имеет пустую строку, а не специальную дату.
- min и max задают допустимый диапазон в машинном формате. Формат 07.11.2026 для этих атрибутов не является заменой YYYY-MM-DD.
- Дата рождения и момент собеседования - разные модели. Для момента нужно отдельно определить часовой пояс и преобразование; datetime-local сам его не передаёт.
- Не превращайте date-only в UTC-момент без явной причины: последующее отображение в другом поясе может сдвинуть день.

#### Пример

```html
<label for="interview-date">Дата собеседования</label>
<input id="interview-date" name="date" type="date" min="2026-01-01" max="2026-12-31" />
```
