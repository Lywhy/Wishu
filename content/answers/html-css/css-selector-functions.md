:is и :not используют специфичность наиболее специфичного аргумента, :where имеет нулевую специфичность, а :has позволяет выбрать элемент по относительному селектору и также учитывает аргументы при специфичности.

<!-- wishu:answer-block -->

Полезно отделять задачу выбора элемента от задачи приоритета. :where подходит для мягких базовых правил. Случайный ID внутри списка :is может усилить весь селектор. :has не означает произвольный обход DOM из JavaScript: это CSS-условие, например для родителя с отмеченным контролом.

Специфичность применяется только после более ранних этапов каскада. Поэтому эти функции не отменяют происхождение, important и слои.
