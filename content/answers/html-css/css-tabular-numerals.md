**Font-variant-numeric: `tabular-nums` запрашивает цифры одинаковой ширины у поддерживающего это шрифта.** Это уменьшает движение при замене 1 на 8, не меняя всё семейство на monospace.

<!-- wishu:answer-block -->

#### Как это работает

- Шрифт должен иметь соответствующие глифы/возможности. Свойство не создаёт отсутствующий вариант автоматически.
- Одинаковая ширина цифр не резервирует место под изменение числа разрядов: переход 99 к 100 всё ещё увеличивает текст.
- Для устойчивого счётчика можно дополнительно задать минимальную ширину и выравнивание. Не используйте пробелы как надёжный способ выровнять финансовую таблицу.

#### Пример

```css
.timer {
  font-variant-numeric: tabular-nums;
  display: inline-block;
  min-inline-size: 5ch;
  text-align: end;
}
```
