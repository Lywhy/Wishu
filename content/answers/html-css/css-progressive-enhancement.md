@supports позволяет условно применять стили при поддержке указанной декларации или другой поддерживаемой проверки. Сначала создайте работающую основу, затем добавляйте улучшение.

<!-- wishu:answer-block -->

Проверка распознавания синтаксиса не доказывает отсутствие всех браузерных ошибок и соответствие бизнес-сценарию. Порядок каскада по-прежнему важен.

Для новых layout-возможностей базовый вариант должен сохранять порядок, доступ к действиям и чтение содержимого. Не делайте улучшение единственным способом увидеть ключевую информацию.
