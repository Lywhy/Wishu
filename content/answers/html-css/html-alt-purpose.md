**Alt заменяет смысл изображения, а не обязательно описывает каждый его пиксель.** Информативной картинке нужна полезная альтернатива, декоративной - пустой `alt`, функциональной - понятное назначение.

<!-- wishu:answer-block -->

#### Как это работает

- Если изображение - единственное содержимое ссылки, текст должен объяснять переход. «Логотип» менее полезно, чем название сайта, когда это ссылка на главную.
- Декоративное изображение с `alt=""` позволяет пропустить его. Отсутствие `alt` не равнозначно пустому: может озвучиваться имя файла.
- Сложному графику нужна краткая альтернатива и доступное подробное объяснение или таблица рядом. Не пытайтесь вместить все данные в одну длинную строку.
- Дублирующее изображение рядом с уже полной текстовой подписью может быть декоративным именно в этом контексте.

#### Пример

```html
<a href="/">
  <img src="logo.svg" alt="Wishu - главная" />
</a>
<img src="separator.svg" alt="" />
```
