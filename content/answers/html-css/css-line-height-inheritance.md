**Безразмерный `line-height` наследуется как коэффициент, который применяется к собственному размеру шрифта потомка.** Процент вычисляется относительно шрифта самого элемента и может наследоваться уже как длина.

<!-- wishu:answer-block -->

#### Механизм и границы

- У родителя с `font-size`: 16px и `line-height`: 150% вычисленная длина равна 24px. Потомок с `font-size`: 32px, наследующий её, может получить слишком тесные строки.
- При `line-height`: 1.5 тот же потомок использует коэффициент 1.5 со своим размером, то есть номинально 48px.
- Реальная line box зависит и от вложенного содержимого. Вертикальные `padding` у обычного inline не просто увеличивают высоту строки как `padding` блочного контейнера.
- Не фиксируйте высоту текстовой карточки под одну строку: zoom и пользовательские интервалы могут изменить требуемое место.

#### Пример

```css
.article {
  font-size: 1rem;
  line-height: 1.5;
}
.article h2 {
  font-size: 2rem;
}
/* При наследовании коэффициент применяется к font-size заголовка. */
```
