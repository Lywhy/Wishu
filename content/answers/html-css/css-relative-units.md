**rem зависит от размера шрифта корневого элемента.** em зависит от шрифта элемента, а в font-size - от шрифта родителя. Процент вычисляется относительно базы конкретного свойства: это не всегда просто ширина родителя.

- Viewport-единицы привязаны к размерам области просмотра; динамические dvh учитывают изменение видимой высоты мобильного браузера. Относительные единицы не обеспечивают адаптивность автоматически: нужны ограничения размеров и проверка масштабирования текста.

### Высота мобильного viewport
Svh ориентируется на малый вариант viewport, lvh - на большой, dvh следует динамическому изменению интерфейса браузера. Выбор влияет на стабильность блока при появлении адресной панели. Safe-area inset из env отвечает за другую границу: небезопасные для содержимого зоны устройства. Не запрещайте пользовательское масштабирование ради неподвижного макета.

```css
.screen { min-block-size: 100dvh; padding-block-end: env(safe-area-inset-bottom); }
```
