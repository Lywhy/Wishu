Роль сообщает, что это за элемент, имя позволяет отличить его от других, а описание добавляет инструкцию или пояснение. Например: роль «кнопка», имя «Удалить запись», описание последствий.

Предпочитайте видимый текст и нативные связи. Для поля используйте label, для кнопки - её содержимое. aria-labelledby связывает имя с существующим текстом, aria-describedby добавляет описание. aria-label полезен при отсутствии подходящего видимого текста, но может заменить вычисляемое имя; не задавайте его случайно иначе видимой подписи.

Role не реализует клавиатурное поведение. title не является надёжной заменой постоянного имени. Смотрите вычисленное имя в accessibility tree.
