**Комбинатор задаёт отношение между элементами.** Пробел ищет потомка любой глубины, > - прямого ребёнка, + - следующего соседнего элемента, ~ - любого последующего соседа.

<!-- wishu:answer-block -->

#### Механизм и границы

- Соседи должны иметь общего родителя и идти после первого элемента в DOM. + учитывает элементы, а не пробельные текстовые узлы между тегами.
- Сами комбинаторы не добавляют специфичности. Но избыточно длинная цепочка связывает стили с конкретной структурой и усложняет изменение разметки.
- Селектор .card.title означает один элемент с двумя классами. .card .title означает элемент .title внутри .card.

#### Пример

```css
.card > .title {
  margin-block: 0;
}
.label + .hint {
  color: #555;
}
input:checked ~ .details {
  font-weight: bold;
}
.card.selected {
  border-width: 2px;
}
```
