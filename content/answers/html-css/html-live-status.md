Область со статусом может объявлять изменения через accessibility API без переноса фокуса. Для обычного результата подходит role="status" с вежливой очередью, а alert используют для действительно срочного сообщения.

<!-- wishu:answer-block -->

Область желательно создать заранее, затем менять её содержимое. aria-atomic помогает читать сообщение целиком. Не делайте весь экран live region: поток обновлений станет шумным.

Фокус и объявление решают разные задачи. Для ошибки отправки может понадобиться фокус на первом неверном поле и связанный текст ошибки; для «сохранено» обычно достаточно спокойного статуса. Одна live region не гарантирует полную доступность сценария.
