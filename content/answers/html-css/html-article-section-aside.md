**article - самостоятельный материал, section - тематическая часть, aside - связанное, но вспомогательное содержимое.** Положение слева или справа этого не определяет.

<!-- wishu:answer-block -->

#### Механизм и границы

- Статья, отдельная публикация или самостоятельный комментарий могут быть article. Раздел внутри статьи с собственным заголовком - section.
- aside подходит для относящегося к материалу дополнительного пояснения. Важный основной текст не становится aside только из-за боковой колонки.
- Для контейнера оформления без тематического смысла используйте div. Не каждый section автоматически является отдельным landmark: важны доступное имя и отображение семантики в браузере.

#### Пример

```html
<article>
  <h1>Каскад CSS</h1>
  <section>
    <h2>Специфичность</h2>
    <p>...</p>
  </section>
  <aside>
    <h2>Историческая справка</h2>
    <p>...</p>
  </aside>
</article>
```
