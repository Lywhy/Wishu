**Каждая строка Flexbox распределяет свободное место независимо.** Поэтому растущие карточки последней строки не обязаны совпадать по ширине с колонками предыдущей.

<!-- wishu:answer-block -->

#### Механизм и границы

- `flex-wrap` разрешает перенос, но не создаёт единую двумерную сетку. Grow и shrink рассчитываются внутри отдельной линии.
- Если требуются одинаковые колонки по всему контейнеру, Grid часто точнее описывает задачу. Если важна последовательность элементов с независимым заполнением рядов, Flexbox уместен.
- Фиксированный basis и отключённый grow меняют результат, но требуют учёта `gap`, ограничений и узкой ширины. Это не универсальная замена Grid.

#### Пример

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.card {
  flex: 1 1 15rem;
}
/* Единственная карточка последней строки может растянуться на всю строку. */
```
