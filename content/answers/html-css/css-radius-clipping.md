**Border-radius закругляет собственную границу и фон коробки, но не является универсальным обрезанием всех потомков.** Для ограничения их рисования нужен подходящий clipping-контракт.

<!-- wishu:answer-block -->

#### Как это работает

- Overflow: hidden или clip может ограничить содержимое по закруглённой области, но меняет поведение переполнения. Выбирайте его осознанно.
- Если требуется только форма картинки, радиус можно задать непосредственно `img`. Это не обрежет соседний элемент и не создаст лишнюю scroll-границу родителя.
- Обрезание контейнера способно срезать тень, фокус или выпадающее меню. Красивый угол не должен ломать взаимодействие.

#### Пример

```css
.thumbnail {
  display: block;
  border-radius: 1rem;
}
.clipped-preview {
  border-radius: 1rem;
  overflow: clip;
}
/* Второй вариант намеренно обрезает внутреннее рисование. */
```
