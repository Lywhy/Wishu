**Ссылки на символы позволяют записать данные, которые иначе могут быть разобраны как HTML-синтаксис.** Например, `&lt;` показывает знак <, а `&amp;` - амперсанд.

<!-- wishu:answer-block -->

#### Механизм и границы

- Экранирование зависит от контекста. В заключённом в двойные кавычки атрибуте нужно корректно представить двойную кавычку; в тексте важна граница с разметкой.
- Для обычного вывода пользовательского текста предпочтителен безопасный текстовый API или штатное экранирование шаблонизатора. Экранирование HTML не делает произвольную строку безопасным URL, JavaScript или CSS.
- `&nbsp;` означает неразрывный пробел: он меняет переносы. Для визуальных отступов между блоками используют CSS, а не цепочки `&nbsp;`.

#### Пример

```html
<p>Условие: x &lt; 10 &amp;&amp; y &gt; 0.</p>
<p title='Кнопка "Сохранить"'>Подсказка</p>
<p>10&nbsp;км</p>
```
