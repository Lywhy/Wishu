**`grid-template-areas` называет прямоугольные участки сетки, а несколько элементов могут занимать одну область и перекрываться.** Для такого наложения не обязательно выводить элементы из потока через absolute.

<!-- wishu:answer-block -->

#### Механизм и границы

- Одинаковые имена должны образовывать прямоугольник; точка обозначает пустую ячейку. Разорванная или Г-образная область делает шаблон недопустимым.
- Размещение в одной ячейке удобно для текста поверх изображения. Порядок рисования и `z-index` нужно рассматривать отдельно от размеров трека.
- Изменение шаблона по media query меняет внешний макет, но не DOM-порядок и смысловую последовательность.

#### Пример

```css
.hero {
  display: grid;
}
.hero > img,
.hero > .caption {
  grid-area: 1 / 1;
}
.hero > img {
  width: 100%;
}
.hero > .caption {
  align-self: end;
  z-index: 1;
}
```
