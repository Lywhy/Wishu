**`display`: contents убирает собственную CSS-коробку элемента, позволяя коробкам потомков участвовать в родительском layout.** Сам DOM-элемент не удаляется.

<!-- wishu:answer-block -->

#### Механизм и границы

- Это помогает обёртке не мешать Grid/Flexbox. Её фон, `border` и размеры больше не работают как у обычной самостоятельной коробки.
- Селекторы и наследование продолжают учитывать DOM. Потомки не становятся фактическими детьми другого DOM-узла, а обработчики обёртки не исчезают из пути события.
- У браузеров были и остаются особенности отображения такой обёртки в accessibility tree. Проверяйте целевую комбинацию браузера и вспомогательной технологии, особенно для важных ролей.
- Для замещаемых и некоторых специальных элементов спецификация задаёт отдельное поведение. Не обобщайте пример обычного div на любой тег.

#### Пример

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
.layout-wrapper {
  display: contents;
}
/* Потомки wrapper участвуют в grid, но wrapper остаётся в DOM. */
```
