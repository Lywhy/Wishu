**Box-shadow строит тень от формы коробки, drop-shadow - от альфа-силуэта отрисованного содержимого.** Для PNG с прозрачными областями результат может существенно отличаться.

<!-- wishu:answer-block -->

#### Как это работает

- Box-shadow поддерживает spread и inset, а также набор теней. Drop-shadow имеет другой синтаксис и не является полной заменой этих возможностей.
- Filter применяется к результату рисования элемента и может создавать stacking context. Оцените порядок наложения и стоимость, а не только похожесть эффекта.
- Тени обычно не выделяют дополнительное место в потоке и могут обрезаться родителем. Для видимого фокуса нужен надёжный индикатор, включая специальные цветовые режимы.

#### Пример

```css
.card {
  box-shadow: 0 0.5rem 1.5rem rgb(0 0 0 / 0.15);
}
.transparent-logo {
  filter: drop-shadow(0 0.25rem 0.5rem rgb(0 0 0 / 0.3));
}
```
