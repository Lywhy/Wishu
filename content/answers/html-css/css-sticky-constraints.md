Sticky сохраняет участие в потоке и ограниченно смещается относительно подходящей области прокрутки. Для нужной оси требуется не-auto inset и пространство, в пределах которого элемент может перемещаться.

<!-- wishu:answer-block -->

Проверьте ближайшего предка с механизмом прокрутки, даже если этот предок фактически не прокручивается, размеры элемента и контейнера, растяжение grid/flex-элемента и конец содержащего блока. Sticky не превращает элемент в бесконечный fixed.

Залипающая шапка не должна закрывать фокус и переходы по якорям: для содержимого могут понадобиться scroll-margin или scroll-padding.
