**Media query выбирает стили по характеристикам среды, например ширине viewport или предпочтению уменьшенного движения.** Size container query позволяет компоненту реагировать на размер подходящего контейнера, а не всего окна.

<!-- wishu:answer-block -->

- Для запросов к размеру контейнера объявляют соответствующий container-type. Это удобно для карточки, которая должна вести себя по-разному в сайдбаре и в основной колонке при одинаковом viewport. Точки перелома выбирают по потребностям содержимого.

<!-- wishu:answer-block -->

### Подходящий предок
Size query оценивает подходящий query container у предков. Container-type: inline-size ограничивает соответствующую ось, а имя помогает выбрать нужный контейнер. Нельзя считать, что элемент автоматически стилизует сам себя по собственному размеру в том же запросе. Media query оставьте для среды и пользовательских предпочтений, а контейнерный запрос - для контекста размещения компонента.
