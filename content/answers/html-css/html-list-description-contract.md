**ul обозначает набор, ol - последовательность, где порядок значим, dl - группы названий и описаний.** Семантика списка не зависит от видимости маркеров.

<!-- wishu:answer-block -->

#### Механизм и границы

- Шаги установки обычно оформляют через ol. Набор доступных тем - через ul, если перестановка не меняет смысл.
- В dl элементы dt называют термин или характеристику, dd описывают её. Это подходит и для метаданных вроде «Автор - Анна».
- Прямые пункты ul и ol оформляют li; вложенный список помещают внутрь пункта. Не следует воспроизводить структуру только символами • и переводами строки.

#### Пример

```html
<ol>
  <li>Откройте вопрос.</li>
  <li>Сформулируйте ответ.</li>
</ol>
<dl>
  <dt>Раздел</dt>
  <dd>HTML и CSS</dd>
  <dt>Уровень</dt>
  <dd>Базовый</dd>
</dl>
```
