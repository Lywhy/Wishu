**Reset намеренно убирает часть исходного оформления, normalize согласует различия, сохраняя полезные настройки.** Конкретное поведение определяется выбранным набором правил, а не названием файла.

<!-- wishu:answer-block -->

#### Механизм и границы

- UA-стили дают заголовкам размеры, спискам маркеры и контролам узнаваемый вид. После сброса ответственность за видимость фокуса и состояния ложится на проект.
- `all`: `unset` - очень широкий сброс, который выбирает наследование или `initial` для многих свойств. Он не превращает элемент в семантически нейтральный div и не сбрасывает буквально всё, включая custom properties.
- Базовые правила удобно держать в раннем cascade layer, оставляя компонентам ясный путь переопределения. Не нужно повышать специфичность reset ради борьбы с компонентом.

#### Пример

```css
@layer reset, components;
@layer reset {
  *,
  *::before,
  *::after {
    box-sizing: border-box;
  }
  body {
    margin: 0;
  }
}
/* Сброс не удаляет индикатор фокуса и семантику контролов. */
```
