**Семантические элементы обозначают назначение частей документа.** main выделяет основное содержимое, nav - значимую навигацию, header - вводную часть страницы или раздела. Это помогает браузеру и вспомогательным технологиям интерпретировать структуру.

- section используют для тематически связанного блока, обычно с заголовком. Для контейнера без самостоятельного смысла подходит div. Наличие правильных тегов не заменяет логичный порядок заголовков и доступные названия повторяющихся областей.

### Структура и названия
Выбирайте уровень заголовка по структуре документа, а не нужному размеру шрифта. Для повторяющихся nav дайте различимые доступные имена, например «Основная навигация» и «По разделу». Section не становится осмысленной областью от одного тега: у неё должна быть тема и обычно заголовок. Не создавайте nav для каждого набора двух ссылок.
