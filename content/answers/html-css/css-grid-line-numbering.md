**Элементы Grid размещаются между линиями, а не «по номеру колонки».** `span` 2 занимает два трека, -1 обозначает последнюю линию явной сетки.

<!-- wishu:answer-block -->

#### Как это работает

- У трёх явных колонок четыре граничные линии. Запись 1 / 3 занимает первые два трека.
- Отрицательные номера отсчитываются от конца explicit grid. Дополнительные неявные колонки не превращают -1 в конец всей возможной сетки.
- Направление inline-оси влияет на то, где находится начало. Нельзя всегда считать линию 1 физическим левым краем.
- Для повторяемого макета можно именовать линии, но ошибочный номер способен создать неожиданные implicit tracks.

#### Пример

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
.full {
  grid-column: 1 / -1;
}
.wide {
  grid-column: span 2;
}
```
