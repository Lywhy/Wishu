**CSS обычно отбрасывает неподдерживаемую или ошибочную часть и продолжает разбор.** Но размер отброшенного фрагмента зависит от места ошибки.

<!-- wishu:answer-block -->

#### Механизм и границы

- Неизвестное свойство или недопустимое для него значение не отменяет все остальные декларации блока. Поэтому можно написать обычный вариант, затем улучшенный.
- Неверный селектор в обычном списке через запятую делает недействительным весь список. У `:is()` и `:where()` списки forgiving: неподдерживаемые ветви могут отбрасываться отдельно.
- Незакрытые скобки и строки способны изменить разбор большого последующего фрагмента. Автоматическое восстановление не означает, что любая опечатка безопасно изолирована.
- Ошибка после подстановки var() имеет отдельные правила: каскад уже прошёл, и предыдущая декларация не обязана восстановиться.

#### Пример

```css
.message {
  color: #075;
  color: not-a-color; /* декларация отброшена, остаётся #075 */
  padding: 1rem;
}
```
