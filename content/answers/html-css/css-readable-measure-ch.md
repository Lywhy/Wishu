**Ch связан с метрикой символа 0 в используемом шрифте, а не со средним размером любого символа.** Ограничение в ch помогает настроить ширину чтения, но не считает буквы.

<!-- wishu:answer-block -->

#### Как это работает

- В пропорциональном шрифте строка из i и строка из W занимают разную ширину. 60ch не означает одинаковое число символов на каждой строке.
- Max-inline-size ограничивает столбец, сохраняя возможность стать уже на маленьком экране. Не фиксируйте ширину без верхнего ограничения контейнером.
- Выбирайте длину строки вместе с размером, межстрочным интервалом и языком. Одно магическое число не обеспечивает удобство любого текста.

#### Пример

```css
.prose {
  max-inline-size: 65ch;
  margin-inline: auto;
  line-height: 1.6;
  overflow-wrap: anywhere;
}
```
