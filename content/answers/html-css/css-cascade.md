**Каскад учитывает происхождение и важность деклараций, каскадные слои, затем специфичность и другие условия разрешения равенства, включая порядок.** Поэтому более специфичный селектор не всегда побеждает правило из другого уровня каскада.

<!-- wishu:answer-block -->

- При равных условиях и специфичности выигрывает более поздняя декларация. !important меняет уровень приоритета, а не просто повышает специфичность. Важные декларации обращают приоритет слоёв; массовое использование !important усложняет управление стилями.

<!-- wishu:answer-block -->

### Порядок слоёв
Для обычных авторских деклараций поздний слой сильнее раннего, а обычные unlayered-правила сильнее layered. Для important порядок слоёв обращается: ранние слои получают преимущество, и important в слоях сильнее important вне слоёв. Inline-стили имеют отдельные правила; каскад также учитывает другие origins, transitions и animations.

```css
@layer reset, base, components;
@layer base { button { color: black; } }
@layer components { button { color: navy; } }
```
Специфичность сравнивается внутри уже выбранного уровня каскада, а не отменяет его.
