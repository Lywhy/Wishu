**Две колонки по 50% уже занимают всю базовую ширину, а `gap` добавляется между ними.** Доли fr распределяют оставшееся после фиксированных частей и промежутков место.

<!-- wishu:answer-block -->

#### Как это работает

- Для равных колонок с `gap` обычно подходит repeat(2, minmax(0, 1fr)). Нулевой минимум нужен, если содержимому разрешено сжиматься ниже его автоматического минимума.
- Процент и fr описывают разные намерения. Не всегда корректно лечить переполнение ручным вычитанием половины `gap` из каждой колонки.
- При длинном неразрывном содержимом проверяют ещё минимумы элементов и перенос текста: замена процентов не решает все причины переполнения.

#### Пример

```css
.grid {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 1rem;
}
```
