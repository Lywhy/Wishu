Prefers-color-scheme сообщает системное предпочтение, а color-scheme помогает браузеру выбрать подходящее оформление нативных элементов. Пользовательский выбор темы приложения может иметь собственный приоритет.

<!-- wishu:answer-block -->

Используйте смысловые токены, а не инверсию всех цветов. Проверяйте текст, границы, ошибки и фокус в обеих темах. В forced-colors браузер может заменить авторские цвета, поэтому полезны системные цвета и реальные border/outline вместо одной тени.

Color-scheme сам не перекрасит все ваши блоки в завершённую тему. Не отключайте forced-color-adjust без необходимости: можно лишить пользователя нужного контраста.
