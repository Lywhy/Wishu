Repeat сокращает описание треков, minmax задаёт диапазон размера, а auto-fit и auto-fill позволяют рассчитывать число повторений по доступному месту. Auto-fit схлопывает пустые повторённые треки, auto-fill сохраняет их.

Автоматическая минимальная ширина и жёсткая нижняя граница могут создавать переполнение. Для сжимаемой колонки полезен minmax(0, 1fr), а для карточек нужно учитывать очень узкий контейнер.

Grid не гарантирует правильный порядок чтения после визуального переупорядочивания. Сначала задайте осмысленный DOM-порядок, затем размещение.
