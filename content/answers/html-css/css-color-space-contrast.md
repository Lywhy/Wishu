**OKLCH позволяет задавать светлоту, насыщенность и тон, color-mix смешивает цвета в выбранном пространстве.** Ни один из этих механизмов сам по себе не гарантирует контраст текста с фоном.

<!-- wishu:answer-block -->

#### Механизм и границы

- Перцептивная светлота удобна для построения палитры, но одинаковый шаг L не равен выполнению конкретного требования контраста между любыми двумя цветами.
- Смешивание в oklab, oklch и sRGB даёт разные промежуточные цвета. Итог также зависит от прозрачности, нижних слоёв и преобразования в доступный gamut.
- Проверяют конечные пары текста и фона во всех состояниях. Для важных статусов добавляют текст или форму, а не только цвет.
- Для старой целевой среды задайте обычную цветовую декларацию перед улучшенной. Поддержка синтаксиса и качество конкретной палитры - разные проверки.

#### Пример

```css
.badge {
  color: #17365d;
  background: #e9eff7;
  background: color-mix(in oklab, #17365d 10%, white);
}
/* Контраст полученной пары всё равно нужно проверить. */
```
