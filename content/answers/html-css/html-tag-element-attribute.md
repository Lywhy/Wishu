**Тег - часть синтаксиса разметки, элемент - структурная единица документа, атрибут задаёт дополнительные сведения или настройки элемента.** Обычный элемент записывается начальным тегом, содержимым и конечным тегом.

<!-- wishu:answer-block -->

#### Как это работает

- В ссылке a имя элемента определяет смысл, `href` задаёт адрес, а текст становится содержимым. Атрибуты размещаются в начальном теге.
- Не все элементы имеют конечный тег: `img` и `input` - пустые элементы. Правила допустимой вложенности определяет `HTML`, а не визуальный размер.
- DOM-элемент после разбора не равен фрагменту исходной строки: браузер может исправить неправильную структуру.

#### Пример

```html
<a href="/study" class="navigation-link">Обучение</a>
<!-- a - имя; href и class - атрибуты; Обучение - текстовое содержимое. -->
```
