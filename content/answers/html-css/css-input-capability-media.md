**Hover/pointer описывают возможности основного указателя, any-hover/any-pointer - наличие подходящих указателей среди доступных.** Гибридное устройство может иметь и сенсорный экран, и мышь.

<!-- wishu:answer-block -->

#### Как это работает

- pointer: coarse означает невысокую точность основного указателя, fine - точный указатель. Это не надёжный тест «телефон или компьютер».
- any-hover: hover позволяет обнаружить хотя бы возможность наведения, но пользователь всё равно может сейчас пользоваться пальцем.
- Hover-эффекты должны дополнять доступное действие, а не быть единственным способом открыть меню или прочитать подсказку.
- Проверяйте размеры целей и клавиатурный сценарий независимо от этих запросов. Смена устройства ввода не должна уничтожать доступ к функции.

#### Пример

```css
@media (hover: hover) and (pointer: fine) {
  .card:hover {
    border-color: navy;
  }
}
/* Основное действие доступно и без этого улучшения. */
```
