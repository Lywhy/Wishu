Block формирует блочное участие в обычном потоке, inline участвует в строковом форматировании, а inline-block остаётся атомарным inline-уровневым блоком с собственными размерами. Это не различие по семантике HTML-тега.

<!-- wishu:answer-block -->

Для обычного нереплейсного inline width и height не работают как размеры блочного прямоугольника. Inline-block поддерживает размеры, но выравнивается в строке, в том числе по baseline, и может оставлять ожидаемый зазор снизу.

Современная модель display различает внешнюю и внутреннюю роли: например, inline-flex сочетает участие в строке и flex-layout внутри. Изменение display не превращает div в семантическую кнопку.
