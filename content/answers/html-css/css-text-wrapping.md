Для сохранения всего содержимого выбирайте перенос, например overflow-wrap: anywhere. Для однострочного сокращения нужен согласованный набор ограничений ширины, overflow и white-space; text-overflow сам не создаёт переполнение.

Word-break: break-all допускает более агрессивное разбиение и может ухудшить чтение обычных слов. Автоматические переносы через hyphens зависят от языка и поддержки словарей.

Проверьте min-inline-size flex/grid-элемента: он может не позволить коробке стать достаточно узкой. Важное содержание не должно быть доступно только по наведению на title.
