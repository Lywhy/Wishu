**List-style-position задаёт положение маркера относительно основной коробки пункта, `::marker` позволяет оформить сам маркер.** Это не обычный flex-элемент перед текстом.

<!-- wishu:answer-block -->

#### Как это работает

- Outside оставляет маркер снаружи основной коробки, inside включает его в начало содержимого. Это меняет поведение переноса многострочных пунктов.
- У `::marker` поддерживается ограниченный набор свойств, например цвет и параметры шрифта. Не все свойства обычного блока применимы к нему.
- Список остаётся смысловой структурой. При удалении стандартных маркеров проверьте доступную семантику в целевой среде, а не только визуальный вид.

#### Пример

```css
ul {
  list-style-position: outside;
  padding-inline-start: 1.5rem;
}
li::marker {
  color: #315ea8;
  font-weight: 700;
}
```
