**Flex-элемент может ограничивать сжатие автоматическим минимальным размером, зависящим от содержимого.** Длинная неразрывная строка или вложенный блок тогда выталкивает соседей, даже если flex-shrink разрешает сжатие.

- Для области, которой разрешено стать уже содержимого, часто нужен min-width: 0, в Tailwind - min-w-0. После этого задают подходящую стратегию переполнения: перенос, обрезку или скролл. Это решение не следует применять вслепую к каждому элементу.

### Вертикальный внутренний скролл
В flex-колонке автоматический минимум по высоте может не дать области сжаться, и вместо неё начнёт прокручиваться вся страница. По нужной оси разрешите сжатие через min-height: 0 / min-block-size: 0 и задайте overflow. У Grid при сжимаемых треках полезно различать minmax(0, 1fr) и автоматический минимум. Не добавляйте нули вслепую: сначала найдите элемент, которому разрешено стать меньше содержимого.
