**100vw привязан к viewport, а не к свободной ширине родительской коробки.** При классической вертикальной полосе прокрутки это может оказаться шире доступной области содержимого.

<!-- wishu:answer-block -->

#### Как это работает

- Для обычного блока внутри страницы часто подходит auto или 100% с понятным `box-sizing`, а не 100vw.
- Поведение зависит от режима scrollbars и ограничений viewport. Нельзя универсально вычитать фиксированные 17px.
- Дополнительными причинами бывают `margin` у `body`, `padding` при `content-box`, минимумы и длинные строки. Найдите реальную переполняющую коробку.
- Overflow-x: hidden может скрыть симптомы вместе с нужным содержимым, не исправив ошибку размеров.

#### Пример

```css
body {
  margin: 0;
}
.page {
  inline-size: 100%;
  box-sizing: border-box;
}
/* Для обычной полноширинной страницы часто не нужен 100vw. */
```
