**`HTML` описывает содержимое и его смысл, `CSS` - представление, JavaScript - программное поведение.** При этом у `HTML` уже есть нативные действия: ссылки переходят, формы отправляются, details раскрывается.

<!-- wishu:answer-block -->

#### Как это работает

- Важный материал и отношения между его частями должны быть понятны из документа, а не только из цвета и положения.
- `CSS` не ограничен украшением: он строит макет, адаптирует отображение и анимирует состояния. JavaScript может изменять DOM и данные, но не обязан заново реализовывать нативную кнопку.
- На собеседовании полезно объяснить не только три определения, но и выбор ответственности: переход - ссылка, действие - кнопка, расстояние между ними - `CSS`.

#### Пример

```html
<a href="/questions">Вопросы</a>
<button type="button">Проверить ответ</button>
<!-- Ссылка работает без обработчика; проверка требует логики приложения. -->
```
