Clamp(min, preferred, max) ограничивает предпочитаемое значение диапазоном. Для текста можно сочетать rem-компонент и зависимость от ширины, избегая бесконтрольного размера на краях.

<!-- wishu:answer-block -->

Значение только в vw может плохо реагировать на пользовательское увеличение текста. Rem-границы и относительная часть помогают, но не заменяют проверку zoom, длинных слов и доступной ширины.

Высота строки обычно должна поддерживать многострочный текст. Не фиксируйте контейнер строго под один размер заголовка и не обрезайте нужное содержание ради макета.
