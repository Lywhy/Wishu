**`lang` задаёт язык, `dir` - направление текста, `bdi` изолирует фрагмент с неизвестным направлением.** Это разные свойства документа: перевод на арабский не выполняется одним CSS-направлением.

<!-- wishu:answer-block -->

#### Механизм и границы

- Язык наследуется потомками; смену языка внутри страницы обозначают локальным `lang`. Он важен для произношения скринридером и языковых правил, включая переносы.
- `dir="auto"` выбирает направление по содержимому. Для имени пользователя в смешанном тексте `bdi` предотвращает нежелательное влияние двунаправленного алгоритма на соседнюю пунктуацию.
- CSS logical properties помогают макету следовать направлению. `lang` сам не включает RTL и не переводит содержимое.

#### Пример

```html
<html lang="ru">
  <body>
    <p>Автор: <bdi dir="auto">ليلى</bdi></p>
    <p lang="en">Read the documentation.</p>
  </body>
</html>
```
