**base href задаёт базовый URL для разрешения относительных адресов документа.** Это влияет не только на ссылки, но и на многие ресурсы и действия формы.

<!-- wishu:answer-block -->

#### Механизм и границы

- Без base адреса обычно разрешаются относительно URL документа. В документе учитывается первый base с href; его размещают в head до элементов с относительными URL.
- Даже `href="#help"` разрешается относительно базового URL. При внешнем base такой переход может уйти на другую страницу с фрагментом.
- base не изменяет origin самого документа и не предоставляет доступа к чужому origin. Динамическая смена базы не является надёжным способом управлять уже начавшимися загрузками.

#### Пример

```html
<head>
  <base href="https://example.com/docs/" />
  <title>Справочник</title>
</head>
<a href="intro.html">Введение</a>
<!-- Адрес: https://example.com/docs/intro.html -->
```
