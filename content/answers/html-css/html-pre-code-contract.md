**`code` обозначает программный текст, `pre` - предварительно форматированное содержимое.** Вместе они позволяют показать многострочный пример с сохранением пробелов и переводов строк.

<!-- wishu:answer-block -->

#### Как это работает

- Для короткого имени функции внутри предложения достаточно `code`. Для блока важна структура строк, поэтому `code` обычно помещают в `pre`.
- HTML-разбор всё равно действует: символы разметки нужно экранировать. Сам `code` не превращает вложенную строку в безопасный plain text.
- Подсветка синтаксиса не встроена автоматически. Она требует отдельного механизма, который должен сохранять читаемость и доступное содержимое.

#### Пример

```html
<p>Вызовите <code>save()</code>.</p>
<pre><code>&lt;button type="button"&gt;Сохранить&lt;/button&gt;</code></pre>
```
