**`progress` показывает выполнение работы, `meter` - измеренную величину в известном диапазоне, `output` - результат расчёта или действия.** Эти элементы не взаимозаменяемы по внешнему виду.

<!-- wishu:answer-block -->

#### Механизм и границы

- У `progress` отсутствие `value` означает неопределённый прогресс. Значение 0 означает известное начало; `min` у `progress` не задают.
- У `meter` есть `min`/`max` и дополнительные границы low/high/optimum: например, заполнение хранилища. Он не предназначен для загрузки файла.
- Каждому индикатору дайте доступное имя и понятную единицу. `output` может связываться с исходными контролами через for, но его текст не становится обычным отправляемым полем формы.

#### Пример

```html
<label for="upload">Загрузка</label>
<progress id="upload" max="100" value="40">40%</progress>
<label for="storage">Занято места</label>
<meter id="storage" min="0" max="100" value="75">75 из 100 ГБ</meter>
```
