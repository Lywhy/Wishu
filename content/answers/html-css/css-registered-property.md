**`@property` задаёт контракт custom property: допустимый синтаксис, наследование и начальное значение.** Это позволяет отличить число или угол от произвольной последовательности токенов.

<!-- wishu:answer-block -->

#### Механизм и границы

- `syntax` и `inherits` обязательны. Для типизированного `syntax` требуется подходящее `initial-value`, вычислительно независимое от окружения: например, 0deg, а не 1em.
- `inherits`: false не передаёт значение потомкам автоматически. Это полезно для локального параметра компонента, но меняет привычное поведение незарегистрированных --переменных.
- Зарегистрированные числовые или угловые значения могут плавно интерполироваться по своему типу. Регистрация не делает любую составную строку анимируемой.
- В примере --angle имеет тип угла. Для целевых старых браузеров сохраняют рабочий статический вариант; поддержку проверяют для всего используемого механизма.

#### Пример

```css
@property --angle {
  syntax: "<angle>";
  inherits: false;
  initial-value: 0deg;
}
.indicator {
  --angle: 30deg;
  transform: rotate(var(--angle));
}
```
