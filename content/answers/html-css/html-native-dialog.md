showModal() открывает dialog как модальное окно в top layer и делает остальную страницу неактивной для соответствующего взаимодействия. Атрибут open или show() сами по себе не создают ту же модальность.

<!-- wishu:answer-block -->

Задайте доступное имя, понятную кнопку закрытия и подходящий начальный фокус. Учитывайте Escape и событие cancel, а после закрытия - возврат к инициатору. Не вызывайте showModal без проверки текущего состояния при повторной синхронизации.

Нативный механизм снимает часть работы по модальности, но не выбирает за вас удачное содержимое и опасность действия. Диалог не должен закрываться так, что пользователь теряет несохранённые данные без понятного поведения.
