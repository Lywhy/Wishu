**p выбирает элементы по типу, .note - по классу, #main - по ID, * - любой подходящий элемент.** Для переиспользуемого оформления обычно подходят классы.

<!-- wishu:answer-block -->

#### Как это работает

- У элемента может быть несколько классов, разделённых пробелами. Один класс может использоваться многими элементами.
- ID должен быть уникальным в документе: он участвует не только в `CSS`, но и в ссылках, `label`/for и ARIA-связях. Дубли ID создают неоднозначность.
- Селектор ID имеет большую специфичность, чем класс. Это не повод оформлять все компоненты через ID.
- - не добавляет специфичность; дочерние элементы он выбирает только в соответствии с остальной структурой селектора.

#### Пример

```css
p {
  line-height: 1.5;
}
.note {
  padding: 1rem;
}
#main {
  scroll-margin-top: 4rem;
}
* {
  box-sizing: border-box;
}
```
