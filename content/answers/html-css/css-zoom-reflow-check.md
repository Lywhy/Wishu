**Увеличение меняет соотношение содержимого и доступного пространства.** Макет, который помещается при 100%, может скрыть подпись, кнопку или часть диалога при увеличении.

<!-- wishu:answer-block -->

#### Как это работает

- Проверьте длинные строки, многострочные кнопки и ошибки формы. Фиксированная высота текстового блока часто опаснее отсутствующего breakpoint.
- Для обычного материала нужны перенос и reflow. Некоторые двумерные данные, например таблицы, могут требовать отдельного прокручиваемого представления.
- Не исправляйте проблему уменьшением текста или запретом zoom. Снимайте необоснованные ограничения и сохраняйте доступ к действиям.
- Увеличение страницы и отдельное увеличение текста - не во всём одинаковые сценарии; полезно проверить оба доступных в целевой среде варианта.

#### Пример

```css
.action {
  min-block-size: 2.75rem;
  padding: 0.75rem 1rem;
  white-space: normal;
}
/* Минимум высоты вместо жёсткого height под одну строку. */
```
