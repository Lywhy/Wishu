**Процентной высоте нужна разрешимая база.** В обычном потоке `height`: 100% часто не даёт ожидаемого результата, если высота содержащего блока сама зависит от содержимого.

<!-- wishu:answer-block -->

#### Механизм и границы

- Цепочка процентов требует определённого размера на соответствующем этапе. Одного `min-height` у предка не всегда достаточно, чтобы процент потомка получил желаемую базу.
- Flexbox, Grid и абсолютное позиционирование имеют дополнительные правила определённости размеров. Нельзя выводить общий запрет процентов из одного обычного блочного примера.
- Для вертикального заполнения страницы часто проще описать layout через min-block-size контейнера и `flex`: 1 у основной части, чем протягивать `height`: 100% через все обёртки.

#### Пример

```css
.page {
  min-block-size: 100dvh;
  display: flex;
  flex-direction: column;
}
.page > main {
  flex: 1;
}
```
