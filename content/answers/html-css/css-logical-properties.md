Логические свойства описывают inline- и block-направления, а не фиксированные физические стороны. Это помогает поддерживать RTL и другие writing modes без полного дублирования стилей.

<!-- wishu:answer-block -->

Margin-inline-start соответствует началу строки, а inline-size зависит от направления письма. Это не означает, что физические свойства запрещены: для действительно физического положения они могут быть уместны.

Не смешивайте физическую и логическую запись одного намерения без понимания каскада: одно правило может перекрыть другое при смене направления.
