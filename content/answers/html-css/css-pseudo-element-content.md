**Псевдокласс выбирает элемент по условию, псевдоэлемент описывает часть его представления.** `:hover` - состояние, `::first-line` - первая строка, `::before` - генерируемый фрагмент перед содержимым.

<!-- wishu:answer-block -->

#### Механизм и границы

- `::before` и `::after` обычно требуют `content`. Они не являются обычными DOM-узлами, которые можно получить `querySelector` или снабдить собственным HTML-обработчиком.
- Декоративные кавычки и линии подходят для CSS-generated `content`. Критически важный текст, подпись кнопки или ошибка должны быть в доступном содержимом документа.
- Озвучивание generated `content` различается по браузерам и вспомогательным технологиям. Не следует обещать ни полную невидимость, ни надёжное чтение любого такого текста.

#### Пример

```css
.quote::before {
  content: "«";
}
.quote::after {
  content: "»";
}
a:hover {
  text-decoration-thickness: 2px;
}
```
