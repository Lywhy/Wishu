**template хранит разобранную заготовку DOM в `content`, не отображая её как обычное поддерево страницы.** Это отличается от div с `display`: `none`, у которого уже есть обычные потомки.

<!-- wishu:answer-block -->

#### Механизм и границы

- Содержимое доступно через `template.content` как `DocumentFragment`. Его обычно клонируют и вставляют в нужное место.
- После вставки узлы становятся обычной частью документа: начинают действовать соответствующие поведения и загрузки. Клонирование не переносит все произвольные состояния приложения или зарегистрированные обработчики.
- Template не является санитайзером: опасное содержимое не становится безопасным для последующей активации. У declarative Shadow DOM есть специальный контракт, не равный любой заготовке template.

#### Пример

```html
<template id="question-template">
  <article>
    <h2></h2>
    <p></p>
  </article>
</template>
<!-- Сценарий может клонировать template.content и заполнить текст. -->
```
