**Touch-action сообщает браузеру, какие жесты прокрутки и масштабирования он может обрабатывать.** Pointer-events определяет участие элемента в hit testing; это другой уровень.

<!-- wishu:answer-block -->

#### Как это работает

- У горизонтального перетаскивания pan-y может сохранить вертикальную прокрутку браузера, оставляя приложению горизонтальный жест. Это не готовая реализация drag.
- Когда браузер забирает жест, Pointer Events-сценарий может получить `pointercancel`. Его нужно обрабатывать как завершение/отмену взаимодействия.
- Решение учитывает цепочку подходящих предков. Изменение `touch-action` после начала жеста не обязано изменить уже принятое решение.
- Не ставьте `none` глобально без необходимости: это способно отключить полезное масштабирование и прокрутку.

#### Пример

```css
.horizontal-drag-surface {
  touch-action: pan-y;
}
/* Приложение отдельно реализует горизонтальное перетаскивание. */
```
