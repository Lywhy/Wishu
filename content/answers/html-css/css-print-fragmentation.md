_*`@media` print задаёт оформление для печати, а break-* управляет предпочтениями разбиения._* avoid просит избегать разрыва, но не может сделать блок выше страницы неделимым при любых условиях.

#### Механизм и границы

- Уберите ненужную навигацию, раскройте важный материал и снимите экранные ограничения высоты/`overflow`, которые иначе обрежут содержимое.
- `break-inside`: avoid подходит для коротких карточек; `break-after`: avoid помогает не оставлять заголовок без следующего текста. Итог зависит от ограничений фрагментации.
- Цветной фон может не печататься по настройкам пользователя. Смысл не должен зависеть только от заливки.
- Проверяют реальные preview разных браузеров и формат бумаги. Экранный screenshot не подтверждает корректную печать.

#### Пример

```css
@media print {
  nav,
  .actions {
    display: none;
  }
  .content {
    overflow: visible;
    block-size: auto;
  }
  h2 {
    break-after: avoid;
  }
  .short-example {
    break-inside: avoid;
  }
}
```
