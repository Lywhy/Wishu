Subgrid позволяет вложенной grid-области использовать треки родительской сетки по выбранной оси. Независимая вложенная grid рассчитывает собственные треки и не обязана выровнять строки с соседними карточками.

<!-- wishu:answer-block -->

Это полезно для карточек, где заголовки, описания и кнопки должны выравниваться несмотря на разную длину текста. Элемент должен занимать подходящие треки родителя. По другой оси можно сохранить независимое определение.

Subgrid не заменяет все вложенные layout и не создаёт связь между произвольными удалёнными сетками. Для целевой матрицы браузеров предусмотрите базовое представление.
