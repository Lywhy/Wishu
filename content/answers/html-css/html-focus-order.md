Нативные интерактивные элементы уже участвуют в клавиатурном обходе. tabindex="0" добавляет элемент в естественный порядок, tabindex="-1" обычно позволяет программный фокус без включения в последовательный Tab-обход.

<!-- wishu:answer-block -->

Избегайте положительных tabindex: они создают отдельный порядок, который трудно поддерживать. Структура DOM должна соответствовать смыслу чтения, даже если CSS визуально переставляет элементы.

После открытия модального окна или смены важного контекста задайте понятную точку фокуса, а при закрытии верните фокус к инициатору, если он существует. Не переводите фокус при каждом рендере. Составные виджеты иногда используют roving tabindex и стрелки, но этот паттерн требует полного контракта клавиатурного взаимодействия.
