**Запись T = Default задаёт тип по умолчанию, когда аргумент типа не указан и контекст вывода не предоставил другой выбор.** Default должен удовлетворять `extends`, если ограничение есть. Обязательные параметры типа не размещают после параметров с default.

#### Как это работает

Это значение уровня типов, а не значение параметра функции в runtime. Generic default может сделать публичный API удобнее, но слишком широкий default способен скрыть потерю точности. Для generic-функции сначала стоит понять, что может быть выведено из её аргументов.

#### Пример

```typescript
interface Box<T = string> {
  value: T
}
const text: Box = { value: "JS" }
const number: Box<number> = { value: 42 }
type Pair<A, B = A> = [A, B]
const pair: Pair<number> = [1, 2]
```

#### Разбор примера

У text параметр не указан и выбирается string. В `number` явный аргумент заменяет default, а у `Pair<number>` второй параметр по умолчанию повторяет первый. Ни один из этих defaults не подставляет данные в value и не инициализирует отсутствующий элемент пары.
