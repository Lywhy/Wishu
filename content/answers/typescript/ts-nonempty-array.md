Тип `readonly [T, ...T[]]` описывает последовательность как минимум с одним элементом. Для обычного массива нужно отдельно проверить длину и установить соответствующий контракт.

<!-- wishu:answer-block -->

#### Как это работает

Первый элемент такого кортежа имеет тип T, в отличие от произвольного чтения обычного массива при noUncheckedIndexedAccess. Предикат ниже обосновывается реальной проверкой length, а не утверждением «здесь точно что-то есть».

`readonly`-контракт ограничивает мутацию через эту ссылку, но другая ссылка на тот же изменяемый массив может его опустошить. Для длительной гарантии владейте неизменяемым снимком или явно ограничьте внешние изменения.

#### Пример

```typescript
function isNonEmpty<T>(items: readonly T[]): items is readonly [T, ...T[]] {
  return items.length > 0
}
function firstLabel(items: readonly string[]) {
  if (!isNonEmpty(items)) return "Нет элементов"
  return items[0].toUpperCase()
}
```

#### Разбор примера

IsNonEmpty проверяет length и устанавливает наличие первой позиции. После успешного вызова firstLabel читает строку без non-`null` assertion. Но такое доказательство относится к текущему состоянию: если другой владелец опустошит общий массив, прежний вывод может перестать соответствовать runtime.

#### Типичная ошибка

> Подменять проверку длины приведением items as [T, ...T[]].
