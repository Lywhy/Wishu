**Опция позволяет TypeScript учитывать JSON-модуль и выводить его форму. Допустимая runtime-загрузка, атрибуты импорта и формат модулей остаются вопросами выбранного host и конвейера.**

<!-- wishu:answer-block -->

#### Как это работает

Тип известного JSON-файла не является валидатором будущего JSON-ответа сервера. Если в данных важны литеральные значения, не считайте вывод из JSON безусловным эквивалентом as const.

Согласуйте правила TypeScript с Node.js, браузером или bundler, который действительно загрузит ресурс.

#### Пример

```typescript
// При подходящем проекте:
// import settings from "./settings.json"
// Checker знает форму файла; runtime может требовать другую
// форму загрузки или import attributes.
```

#### Разбор примера

Settings в примере обозначает известный файл, форму которого checker может прочитать при сборке. Это отличается от будущего ответа fetch с произвольным содержимым. Перед переносом импорта между bundler и нативным runtime нужно сверить поддерживаемый синтаксис и правила загрузки.

#### Типичная ошибка

> Использовать `resolveJsonModule` как решение всех проблем JSON-импорта.
