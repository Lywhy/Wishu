**T `extends` Constraint означает, что допустимые T должны быть совместимы с ограничением.** Это позволяет использовать нужные члены в реализации, например length. Не соответствующий ограничению аргумент вызывает статическую ошибку; runtime-проверка из `extends` не генерируется.

#### Как это работает

Ограничение должно выражать минимально необходимое требование. Если точный T не связывает вход и результат, часто достаточно простого объектного параметра без generic. Лишнее `extends` object запрещает полезные примитивы, а чрезмерно широкий контракт не даёт нужных операций. Уточнять надо потребность алгоритма, а не угадываемый вид всех будущих данных.

#### Пример

```typescript
function longest<T extends { length: number }>(first: T, second: T): T {
  return first.length >= second.length ? first : second
}
const result = longest([1], [2, 3]) // number[]
// longest(1, 2) не проходит ограничение length.
```

#### Разбор примера

Longest может читать length благодаря ограничению и возвращает один из исходных аргументов, сохраняя полный T. Она не создаёт новый минимальный объект только с length. Поэтому дополнительные свойства конкретного аргумента не теряются из обещанного результата.
