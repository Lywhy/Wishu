`override` сообщает, что член должен переопределять существующий член базового класса. При `noImplicitOverride` компилятор требует явно указывать это намерение для соответствующих переопределений.

<!-- wishu:answer-block -->

#### Как это работает

Если родительский метод переименуют или удалят, `override` помогает обнаружить, что дочерний метод больше не переопределяет его. Типы членов при этом всё равно должны быть совместимы: ключевое слово не разрешает произвольно сузить допустимый контракт.

`override` удаляется при преобразовании и не вызывает super автоматически. Реальная цепочка вызовов остаётся частью реализации. Это инструмент контроля эволюции иерархии, а не механизм множественного наследования.

#### Пример

```typescript
class Base {
  format(value: string): string {
    return value
  }
}
class Trimmed extends Base {
  override format(value: string): string {
    return super.format(value).trim()
  }
}
```

#### Разбор примера

Trimmed явно переопределяет format и сам вызывает super.format. Если убрать вызов super, `override` не выполнит его автоматически. При переименовании базового метода ключевое слово поможет заметить, что ожидаемая связь иерархии была нарушена.

#### Типичная ошибка

> Думать, что `override` сам вызывает реализацию родителя или снимает проверку совместимости.
