**Для обычного T `T | never` сохраняет T, `T & unknown` сохраняет T, а `T | unknown` даёт unknown. `any` ведёт себя особенно и способен разрушать полезные ограничения.**

<!-- wishu:answer-block -->

#### Как это работает

`never` описывает отсутствие возможного значения; `unknown` требует доказать допустимую операцию. `any` не является просто ещё одним аккуратным верхним типом: многие выражения с ним теряют проверку.

Не переносите таблицу обычных типов на conditional types механически: дистрибутивность `never` и ветвление по `any` разбираются отдельно.

#### Пример

```typescript
type A = string | never // string
type B = string & unknown // string
type C = string | unknown // unknown
type D = string | any // any
```

#### Разбор примера

В A добавление `never` не даёт новых значений. В B пересечение с `unknown` не добавляет ограничений, а C скрывает конкретную строковую информацию за неизвестным значением. D принципиально отличается: `any` не требует дальнейшего доказательства операций и тем самым ослабляет проверку.

#### Типичная ошибка

> Объяснять `any` как безопасный синоним unknown.
