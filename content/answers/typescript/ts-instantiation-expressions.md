**Instantiation expression специализирует подходящие generic-сигнатуры значения. Само по себе оно не вызывает функцию и не создаёт результат её выполнения.**

<!-- wishu:answer-block -->

#### Как это работает

Это позволяет получить специализированную функцию без дополнительной обёртки. Проверяйте, какие сигнатуры перегруженного значения остаются совместимыми с заданными параметрами.

В runtime такая специализация не добавляет проверку входных данных. Возможность появилась в TypeScript 4.7.

#### Пример

```typescript
function box<T>(value: T) {
  return { value }
}
const stringBox = box<string>
const item = stringBox("ready")
// stringBox(1) // Ошибка типов.
```

#### Разбор примера

StringBox остаётся функцией, но её видимый вход ограничен string. Объект item появляется только после вызова с «ready». Такая специализация удобна для передачи готового callback, однако не оборачивает его дополнительной runtime-проверкой.

#### Типичная ошибка

> Ожидать, что `box<string>` уже возвращает объект box.
