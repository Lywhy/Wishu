**Выражение «строгая типизация» используют неоднозначно: оно не является точным названием одной функции TypeScript.** Strict - конкретный флаг, включающий семейство более строгих проверок, например strictNullChecks и noImplicitAny. Отдельные проверки этого семейства можно переопределить, а состав и детали зависят от версии компилятора.

- Отключение strict может скрыть реальные пути к ошибкам, но включение не запрещает явное `any` и не гарантирует полную корректность. NoUncheckedIndexedAccess и exactOptionalPropertyTypes включаются отдельно. Use strict JavaScript регулирует runtime-поведение и не равен строгой статической проверке TypeScript.

### Как читать ошибки строгого режима
При useUnknownInCatchVariables перехваченное значение нужно сузить перед чтением message: JavaScript позволяет бросить не только Error. noImplicitThis выявляет this без достаточного контекста, strictBindCallApply помогает проверять связанные вызовы, а strictPropertyInitialization относится к полям классов. Состав strict-семейства проверяйте по используемой версии.

NoUncheckedIndexedAccess и exactOptionalPropertyTypes включаются отдельно. Не отключайте всё семейство ради одного места: сначала выясните, какой контракт не доказан и можно ли выразить его точнее.
