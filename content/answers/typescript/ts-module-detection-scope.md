**Не каждый файл автоматически является отдельным модулем в любой конфигурации. Script-файлы могут вносить объявления в общую глобальную область, что создаёт неожиданные конфликты.**

<!-- wishu:answer-block -->

#### Как это работает

На классификацию влияют синтаксис и `moduleDetection`, а в современных режимах также контекст среды. Для явно модульного намерения может использоваться export {}, если это согласуется с форматом файла.

Такое изменение области типов не является runtime-реализацией глобального API.

#### Пример

```typescript
// utilities.ts
export {}
const localName = "value"
// localName теперь локален модульной области этого файла.
```

#### Разбор примера

Export {} делает модульное намерение utilities явным, и localName перестаёт участвовать в общей script-области. Это помогает устранить конфликт имён без переименования несвязанных локальных переменных. Однако итоговый формат модуля всё равно должен соответствовать реальному конвейеру запуска.

#### Типичная ошибка

> Считать любой файл отдельным модулем без проверки moduleDetection.
