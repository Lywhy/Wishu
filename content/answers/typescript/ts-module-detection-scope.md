**Не каждый файл автоматически является отдельным модулем в любой конфигурации. Script-файлы могут вносить объявления в общую глобальную область, что создаёт неожиданные конфликты.**

<!-- wishu:answer-block -->

#### Механизм и границы

- На классификацию влияют синтаксис и moduleDetection, а в современных режимах также контекст среды.
- Для явно модульного намерения может использоваться export {}, если это согласуется с форматом файла.
- Такое изменение области типов не является runtime-реализацией глобального API.

#### Пример

```typescript
// utilities.ts
export {}
const localName = "value"
// localName теперь локален модульной области этого файла.
```
