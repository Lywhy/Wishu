**`declare` global расширяет глобальную область типов, а `module` augmentation - объявления существующего модуля.** Оба механизма уточняют типовой контракт уже существующего API и не создают runtime-реализацию. Для правильного расширения важны модульный контекст файла и выбранная область объявления.

#### Как это работает

Ambient-декларация не присваивает значение в runtime. Реализация должна действительно предоставить обещанный член; optional полезен, если он может отсутствовать. Глобальные расширения воздействуют на весь проект и могут конфликтовать с библиотеками, поэтому нужно выбирать узкое имя и область, а при возможности предпочитать явный импорт.

#### Выбор области расширения

`declare global` расширяет глобальное окружение из модульного файла. `module` augmentation расширяет существующий модуль по его спецификатору; для него важен модульный контекст файла, например импорт расширяемого пакета.

```typescript
// В файле-модуле, а не в глобальном script-контексте:
export {}
declare global {
  interface Window {
    appVersion?: string
  }
}
```

Расширение не создаёт runtime-реализацию, не позволяет произвольно заменить несовместимое поле и не служит универсальным способом переопределить default export. Если библиотека действительно добавляет метод, соответствующее выполнение кода должно быть обеспечено отдельно.

#### Если после добавления .d.ts исчезли экспорты

Проверьте, не создали ли вы самостоятельный ambient `module` вместо augmentation. Для расширения существующего интерфейса задайте модульный контекст и точный спецификатор. Типовое расширение не создаёт runtime-метод.

```typescript
import "./service"
declare module "./service" {
  interface Options {
    trace?: boolean
  }
}
// ./service должен действительно экспортировать расширяемый Options.
```

#### Пример

```typescript
export {}
declare global {
  interface Window {
    wishuVersion?: string
  }
}
// Только реальная запись создаёт значение в браузере:
window.wishuVersion = "development"
```

#### Разбор примера

Интерфейс Window разрешает optional wishuVersion, но значение появляется только на строке присваивания. Export {} задаёт модульный контекст для `declare` global. Если объявить поле обязательным, а соответствующую инициализацию забыть, компилятор будет опираться на контракт, который окружение фактически не обеспечивает.
