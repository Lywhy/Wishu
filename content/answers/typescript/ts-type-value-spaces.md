**TypeScript различает контексты значений и типов. Некоторые объявления, например класс, создают сущности в обоих пространствах; type alias сам по себе не создаёт runtime-значение.**

<!-- wishu:answer-block -->

#### Как это работает

В `const item: User` имя после двоеточия описывает тип. В `new User()` требуется реальный конструктор. `typeof` в позиции типа связывает тип с уже существующим значением.

Совпадение написания не означает, что можно вызвать интерфейс или применить `instanceof` к удалённому типу.

#### Пример

```typescript
interface Token {
  value: string
}
const Token = (value: string): Token => ({ value })
const item: Token = Token("ready")
```

#### Разбор примера

После двоеточия Token означает интерфейс, а справа от равенства Token обозначает вызываемую функцию. Они не конфликтуют, потому что занимают разные пространства. После преобразования интерфейс исчезнет, но функция останется; именно она действительно создаёт объект с полем value.

#### Типичная ошибка

> Писать `instanceof` `interface` и ожидать runtime-проверку.
