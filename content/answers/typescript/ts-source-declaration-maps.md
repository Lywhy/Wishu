**Source `map` связывает сгенерированный JavaScript с исходным кодом для подходящих инструментов. `declaration` `map` связывает декларации с исходниками и полезен для навигации по библиотекам.**

<!-- wishu:answer-block -->

#### Как это работает

Карта не восстанавливает runtime-типы и не является проверкой корректности JS-результата. Для потребителя важна доступность тех файлов и путей, на которые ссылается карта.

Публикацию исходников, карт и содержимого sourcesContent выбирают осознанно как часть поставки.

#### Пример

```json
{
  "compilerOptions": {
    "sourceMap": true,
    "declaration": true,
    "declarationMap": true
  }
}
```

#### Разбор примера

`sourceMap` нужен для пути от JS к его исходнику, а `declarationMap` для пути от объявления API к определению. В пакете полезность второй карты зависит от доступности исходников потребителю. Само включение обоих флагов не доказывает, что соответствующие файлы попали в поставку.

#### Типичная ошибка

> Ожидать от `declarationMap` изменения runtime-обработки ошибок.
