**Source map связывает сгенерированный JavaScript с исходным кодом для подходящих инструментов. Declaration map связывает декларации с исходниками и полезен для навигации по библиотекам.**

<!-- wishu:answer-block -->

#### Механизм и границы

- Карта не восстанавливает runtime-типы и не является проверкой корректности JS-результата.
- Для потребителя важна доступность тех файлов и путей, на которые ссылается карта.
- Публикацию исходников, карт и содержимого sourcesContent выбирают осознанно как часть поставки.

#### Пример

```typescript
// Упрощённая часть compilerOptions:
// { "sourceMap": true, "declaration": true, "declarationMap": true }
// Реальная схема зависит от того, кто создаёт JavaScript и декларации.
```
