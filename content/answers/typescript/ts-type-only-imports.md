`import type` и типовые экспорты предназначены только для системы типов и удаляются из JavaScript. При verbatimModuleSyntax обычные импорты и экспорты сохраняются по правилам выбранного модульного формата, а помеченные type удаляются явно.

<!-- wishu:answer-block -->

Это делает зависимость runtime от синтаксиса более предсказуемой. Если модуль должен выполниться ради регистрации или другого побочного эффекта, оставьте отдельный импорт вида `import "./register.js"`: типовой импорт не обязан его загружать.

Один class может существовать и как тип экземпляра, и как значение конструктора. Его type-only импорт подходит для аннотаций, но не для new или instanceof. VerbatimModuleSyntax также не является автоматическим переводчиком любого ESM-синтаксиса в CommonJS при несовместимой конфигурации.
