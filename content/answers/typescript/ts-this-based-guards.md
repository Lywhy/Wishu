**Метод может объявить предикат для `this` и сообщить checker, какое состояние объекта доказано при true. Проверка должна действительно обеспечивать обещанные поля и инварианты.**

<!-- wishu:answer-block -->

#### Как это работает

Это полезно для контейнеров с необязательным содержимым и состояниями готовности. Обычный `boolean` без подходящего вывода не обязательно создаёт такой же контракт вызывающего кода.

Прежние ограничения guards сохраняются: ошибочное is может сделать последующий код небезопасным.

#### Пример

```typescript
class Holder {
  value?: string
  hasValue(): this is this & { value: string } {
    return this.value !== undefined
  }
}
const holder = new Holder()
if (holder.hasValue()) holder.value.toUpperCase()
```

#### Разбор примера

HasValue проверяет состояние текущего holder, поэтому внутри успешной ветви value рассматривается как string. Метод не заполняет поле и не переводит объект в готовое состояние сам. Если другая ссылка сможет удалить значение позднее, прежнюю проверку нельзя считать вечной гарантией.

#### Типичная ошибка

> Объявлять готовность экземпляра без проверки всех обещанных полей.
