`skipLibCheck` пропускает проверку содержимого `declaration` `files`, но не делает все библиотечные типы `any` и не отменяет их использование при проверке вашего кода.

#### Как это работает

Он может сократить работу checker и временно скрыть конфликты деклараций. Однако несовместимые копии типов или неточное описание API от этого не исчезают. Если причина в нескольких версиях пакета типов, исправляйте граф зависимостей, а не считайте отсутствие диагностики исправлением контракта.

Это не пропуск runtime-проверок и не отключение проверок собственных .ts-файлов. Не связывайте флаг с обещанием определённого ускорения: эффект зависит от проекта.

Пример опции, не отключающей проверку собственного TypeScript-кода:

```json
{
  "compilerOptions": {
    "skipLibCheck": true
  }
}
```

#### Разбор примера

Включённая опция убирает часть работы над внутренней согласованностью деклараций, но вызовы библиотеки в приложении продолжают использовать их сигнатуры. Поэтому неверный аргумент своего кода не становится допустимым автоматически. Конфликт версий типов нужно расследовать независимо от временного подавления диагностики.

#### Типичная ошибка

> Считать `skipLibCheck` полным отключением типизации библиотек или исправлением конфликтов версий.
