**Тип пишется после всего шаблона деструктуризации. Запись двоеточия внутри самого шаблона обычно переименовывает извлекаемую переменную, а не задаёт ей тип.**

<!-- wishu:answer-block -->

#### Как это работает

В `{ name: localName }` создаётся локальная переменная localName. Для большой формы используйте именованный тип параметра.

Default для отдельного свойства и default для всего аргумента решают разные случаи отсутствия данных.

#### Пример

```typescript
type User = { name: string; age?: number }
function greet({ name: localName, age = 0 }: User) {
  return localName + ": " + age
}
```

#### Разбор примера

LocalName является новым именем извлечённого name, а аннотация User относится ко всему аргументу. Значение age = 0 обрабатывает пропущенное поле, но не разрешает вообще не передавать объект. Для второго сценария нужно отдельно задать default всего параметра.

#### Типичная ошибка

> Писать `{ name: string }` и считать `string` обозначением типа параметра.
