**Рекурсивный тип ссылается на себя через вложенную структуру.** Generic-параметр позволяет сохранять один контракт данных на каждом уровне дерева. Такая модель удобна для узлов, вложенных документов и рекурсивных значений, а не только для рекурсивных функций.

#### Как это работает

Рекурсивное описание не гарантирует, что runtime-граф ацикличен или его обход завершится. У вычислений сложных рекурсивных типов есть ограничения глубины и стоимости; неограниченные условные преобразования могут привести к ошибке чрезмерной инстанциации. Полезно ограничивать задачу и давать именованные промежуточные типы.

#### Пример

```typescript
type Tree<T> = {
  value: T
  children: Tree<T>[]
}
const tree: Tree<string> = {
  value: "root",
  children: [{ value: "leaf", children: [] }],
}
```

#### Разбор примера

`Tree<string>` сохраняет строковый тип value и у корня, и у каждого потомка. Пустой children обозначает лист, но сама рекурсивная форма не запрещает присоединить ссылку на уже посещённый узел. Для обхода произвольного графа нужна отдельная стратегия циклов и глубины.
