**В TSX запись, начинающаяся с `<T>`, может пересекаться с JSX-синтаксисом. Дополнительная запятая в списке параметров типа делает намерение generic-стрелки явным.**

<!-- wishu:answer-block -->

#### Как это работает

Для одного параметра обычно используют `<T,>`; это синтаксический приём, а не другой вид generic. Обычная function `declaration` также позволяет избежать этой неоднозначности.

Не подменяйте ограничение типа произвольным `extends` только ради парсера, если оно меняет допустимые значения.

#### Пример

```tsx
// В файле .tsx:
const identity = <T,>(value: T): T => value
function same<T>(value: T): T {
  return value
}
```

#### Разбор примера

Запятая после T снимает неоднозначность для TSX-парсера, сохраняя обычную универсальную функцию identity. Same показывает альтернативную запись без такой неоднозначности. Не стоит добавлять `extends` object ради синтаксиса: это изменило бы допустимые входы, исключив примитивы.

#### Типичная ошибка

> Искать ошибку в generic-логике, когда проблема находится на уровне парсинга JSX.
