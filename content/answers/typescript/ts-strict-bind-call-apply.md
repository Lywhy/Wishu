**Проверка помогает сопоставлять аргументы call/apply/bind с известной сигнатурой функции. Эти методы не должны автоматически превращать типизированный вызов в произвольные `any`-аргументы.**

<!-- wishu:answer-block -->

#### Как это работает

Нужна конкретная сигнатура; информация уже могла быть потеряна через `any` или слишком широкий тип Function. `this`-параметр описывается отдельно и не становится первым runtime-аргументом обычного вызова.

Правила runtime-привязки у стрелок остаются правилами JavaScript, типовой флаг их не меняет.

#### Пример

```typescript
function format(this: { prefix: string }, value: number) {
  return this.prefix + value.toFixed(0)
}
const render = format.bind({ prefix: "№" })
render(10)
// render("10") // Не соответствует number.
```

#### Разбор примера

Bind фиксирует объект с prefix, а возвращённая render сохраняет требование числового value. Поэтому вызов со строкой обнаруживается на этапе проверки. Если исходную format заранее превратить в `any`, компилятору уже не на что опираться для восстановления точной сигнатуры.

#### Типичная ошибка

> Ожидать восстановление строгой сигнатуры после превращения функции в any.
