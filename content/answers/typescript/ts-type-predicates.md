**Сигнатура value is T сообщает, что при true проверяемый параметр соответствует T.** Функция возвращает boolean во время выполнения, а компилятор использует заявленную связь для сужения. В некоторых простых случаях современные версии TypeScript умеют вывести предикат автоматически.

<!-- wishu:answer-block -->

- Явно заявленный предикат нужно реализовать честно: компилятор не доказывает полноту всех необходимых проверок произвольного объекта. Для сложных входных данных лучше системная валидация по схеме. Ошибочный guard, возвращающий true без проверки, способен сделать дальнейший доступ небезопасным.

### Предикат после filter
TypeScript 5.5 добавил вывод предикатов для подходящих простых функций без явно заданного возвращаемого типа: с одним return, без изменения параметра и с проверкой, связанной с его сужением. Явная аннотация результата boolean может скрыть эту более точную связь.

```typescript
const values: (number | undefined)[] = [0, 1, undefined]
const present = values.filter((value) => value !== undefined) // number[] в TS 5.5+.
const truthy = values.filter((value) => !!value)
// truthy-проверка дополнительно отбрасывает корректный 0.
```
Для чисел !! не выражает чистое исключение undefined: ложная ветвь может означать и 0. Не подменяйте доменную проверку удобным, но неточным guard.
