**Поддерживающий package exports режим разрешения выбирает ветвь по доступным условиям и формату обращения. Декларации должны соответствовать именно выбранной runtime-точке входа.**

<!-- wishu:answer-block -->

#### Механизм и границы

- Порядок и структура conditions имеют значение; не заменяйте проверку реального потребителя чтением одного поля types.
- TypesVersions и exports не являются двумя независимыми слоями, которые всегда применяются последовательно: выбранный алгоритм может изменить использование этих полей.
- Проверяйте ESM/CJS-потребителей и поддерживаемые версии, а не только импорт внутри монорепозитория.

#### Пример

```typescript
// Фрагмент package.json, а не универсальный шаблон поставки:
// { "exports": { ".": { "types": "./dist/index.d.ts", "default": "./dist/index.js" } } }
// Формат декларации должен соответствовать формату JS-входа.
```
