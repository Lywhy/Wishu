**Предикат value is `number` обещает, что `false` исключает number. Проверка `typeof` вместе с ограничением величины этого не гарантирует: большое число тоже вернёт false.**

<!-- wishu:answer-block -->

#### Как это работает

Checker доверяет явно написанному is и не доказывает полноту вашей бизнес-проверки. Дополнительное условие можно оставить обычным `boolean` либо выразить отдельным проверяемым результатом, не сужая ложную ветвь неправильно.

Особенно опасны такие guards в partition-подобных API, которые используют оба результата.

#### Пример

```typescript
function small(value: string | number): boolean {
  return typeof value === "number" && Math.abs(value) < 10
}
// Нельзя честно заменить boolean на value is number:
// small(100) === false, хотя 100 - number.
```

#### Разбор примера

Small возвращает `false` и для строки, и для числа 100. Если объявить результат как is `number`, ложная ветвь ошибочно сочтёт 100 строкой. Обычный `boolean` честно выражает предметное условие, не обещая неверного исключения целого типа.

#### Типичная ошибка

> Считать любую проверку над числом корректным предикатом number.
