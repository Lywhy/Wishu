**TypeScript добавляет к JavaScript статическую систему типов: инструменты анализируют допустимые операции до выполнения.** JavaScript при этом остаётся динамическим языком во время работы программы. Аннотация описывает ожидаемый контракт, но не превращает переменную в проверяемый runtime-контейнер.

#### Как это работает

При преобразовании обычные аннотации, `interface` и псевдонимы типов удаляются. Некоторые конструкции, например обычный `enum`, создают JavaScript-код. Проверка типов и преобразование могут выполняться разными инструментами; успешная обработка файла сборщиком не обязательно означает запуск type checking. Внешние данные требуют проверки во время выполнения.

#### Пример

```typescript
function double(value: number): number {
  return value * 2
}
// После удаления аннотаций остаётся обычная JS-функция.
// Вызов с неверными данными из внешнего JS сам по себе не получает runtime-проверку.
```

#### Разбор примера

В double аннотация `number` позволяет обнаружить неверный вызов в проверяемом TypeScript-коде, но после её удаления функция просто умножает полученное значение. Если аргумент приходит из внешнего JavaScript или сети, контракт нужно обеспечить отдельно. Поэтому сборка приложения и проверка типов являются разными шагами, даже когда инструмент объединяет их одной командой.
