**Conditional type выбирает тип X или Y по тому, совместим ли проверяемый тип с U.** Это позволяет выразить зависимость результата преобразования от формы входного типа. Вычисление происходит в системе типов и не создаёт if в JavaScript.

#### Как это работает

Generic-проверка может оставаться отложенной до подстановки конкретного типа. Union, `any` и `never` имеют важные особые случаи; для union с голым параметром включается дистрибутивность. Нужен отдельный runtime-код, если реальное поведение функции тоже зависит от значения.

#### Пример

```typescript
type IsString<T> = T extends string ? true : false
type First = IsString<"JS"> // true
type Second = IsString<number> // false
type IdOf<T> = T extends { id: number } ? number : never
```

#### Разбор примера

Литерал «JS» соответствует `string`, поэтому First выбирает `true` на уровне типов. `number` этому условию не соответствует и даёт false. Эти результаты не являются вызовами функции: для проверки фактического неизвестного значения нужно отдельно написать исполняемое условие.
