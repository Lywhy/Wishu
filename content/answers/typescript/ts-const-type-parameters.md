`const T` в параметрах generic-функции просит предпочесть более точный const-подобный вывод для непосредственно переданных выражений. Возможность появилась в TypeScript 5.0.

<!-- wishu:answer-block -->

Это позволяет API принимать литерал без постоянного as const у вызывающего кода. Ограничение должно принимать желаемый readonly-тип; иначе вывод может откатиться к более широкому ограничению.

Уже потерянная точность не восстанавливается: если переменная заранее получила тип string[], const-параметр не узнает её прежнюю конкретную длину и значения. Он также не замораживает данные во время выполнения. В TSX синтаксис generic-стрелки иногда нужно отличать от JSX, например через `<T,>` или подходящий extends.
