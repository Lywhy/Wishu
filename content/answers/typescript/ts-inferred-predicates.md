**Начиная с TypeScript 5.5 некоторые простые проверки позволяют вывести предикат автоматически. Например, исключение `undefined` может дать массив оставшегося типа без ручного is.**

<!-- wishu:answer-block -->

#### Как это работает

Документированные условия включают единственный возврат без неявных возвратов, отсутствие изменения параметра и `boolean`-выражение, связанное с его уточнением. Явная аннотация `boolean` может убрать возможность вывода предиката.

Проверка `!!value` для `number` | `undefined` не означает точное исключение `undefined`: ложная ветвь допускает и 0.

#### Пример

```typescript
const values: (number | undefined)[] = [0, 1, undefined]
const present = values.filter((value) => value !== undefined)
// В TS 5.5+ здесь number[].
```

#### Разбор примера

Проверка value !== `undefined` сохраняет допустимый ноль и исключает только отсутствие. Компилятор может выразить эту связь в результате filter. Truthiness отвечала бы на другой вопрос и удалила бы 0, поэтому выбор предиката должен следовать требованиям данных, а не краткости записи.

#### Типичная ошибка

> Использовать truthiness-фильтр, когда ноль является допустимым значением.
