**У пустого литерала нет элементов, из которых можно вывести нужный предметный тип. В частности, при строгой конфигурации поле объекта без другого контекста может получить never[].**

<!-- wishu:answer-block -->

#### Механизм и границы

- Поведение отдельно объявленного изменяемого массива и массива в поле объекта не обязано совпадать: вывод может использовать разные правила.
- Задавайте тип состояния или контейнера на границе создания. Это полезнее последующих as и any.
- Не выводите универсальное правило «любой [] - never[]»: важны контекст и настройки проверки.

#### Пример

```typescript
type State = { items: string[] }
const state: State = { items: [] }
state.items.push("first")
// Без State у поля items может не быть контекста для string.
```
