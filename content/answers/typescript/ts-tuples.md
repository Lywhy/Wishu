**Кортеж задаёт типы определённых позиций и более точную информацию о длине: [`string`, `number`] отличается от массива элементов `string` | number.** Метки позиций помогают читать контракт, но не создают runtime-поля. Значение остаётся обычным массивом JavaScript.

#### Как это работает

Кортеж может иметь optional-элементы, rest и readonly. Обычный изменяемый кортеж не следует считать runtime-массивом с незыблемой длиной: мутации всё ещё требуют осторожности. Для передачи фиксированного списка аргументов кортеж обычно точнее, чем произвольный массив.

#### Пример

```typescript
type Entry = [name: string, score: number]
const entry: Entry = ["Аня", 10]
const name = entry[0] // string
const pair = [10, 20] as const // readonly [10, 20]
type Log = [message: string, ...codes: number[]]
```

#### Разбор примера

Entry сохраняет знание, что в позиции 0 находится имя, а в позиции 1 оценка. Массив (`string` | `number`)[] потерял бы эту связь. Метка name помогает подсказкам редактора, но значение entry по-прежнему является обычным массивом без отдельного свойства name.
