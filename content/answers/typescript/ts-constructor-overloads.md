**Перед телом constructor можно указать несколько сигнатур допустимых аргументов.** Реализация остаётся одной и должна корректно обработать каждый объявленный вариант. Это не возможность создать несколько runtime-методов constructor в классе.

#### Как это работает

Сигнатура реализации не добавляет самостоятельную внешнюю перегрузку. В теле нужно сузить union и инициализировать нужные поля на всех путях. Если набор случаев усложняется, именованные статические фабрики могут яснее выразить различные способы создания.

#### Пример

```typescript
class Identifier {
  value: string
  constructor(value: string)
  constructor(value: number)
  constructor(value: string | number) {
    this.value = String(value)
  }
}
const first = new Identifier("a")
const second = new Identifier(1)
```

#### Разбор примера

Identifier принимает строку или число через две публичные сигнатуры, затем одна реализация приводит значение к строке. Поэтому first и second имеют один тип экземпляра. Перегрузки задают допустимые входы, а нормализация в теле обеспечивает единое внутреннее состояние.
