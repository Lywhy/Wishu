**Опция помогает обнаруживать неразрешённые side-effect imports, которые иначе могли оставаться без ожидаемой диагностики. Для ресурсов нужны согласованные типовые декларации и реальный загрузчик.**

<!-- wishu:answer-block -->

#### Как это работает

Wildcard-декларация сообщает checker о формате импорта, но не создаёт файл и не подключает CSS в браузере. Чем шире объявление `*.css`, тем меньше оно доказывает о существовании конкретного ресурса.

Эта проверка не заменяет bundler и не подтверждает все пути доставки ресурсов.

#### Пример

```typescript
// imports.d.ts
declare module "*.css" {}
// app.ts
// import "./theme.css"
// Файл должен реально обрабатываться средой сборки.
```

#### Разбор примера

Декларация *.css разрешает класс ресурсных импортов, но не различает существующий theme.css и опечатку в его имени. За фактическую загрузку отвечает сборщик. Поэтому такая декларация полезна как типовая адаптация, но не является проверкой наличия каждого CSS-файла.

#### Типичная ошибка

> Считать wildcard-декларацию доказательством наличия любого указанного файла.
