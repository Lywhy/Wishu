**Type создаёт псевдоним типа: объекта, union, кортежа или другого выражения.** Interface объявляет объектный контракт с полями и сигнатурами. Для обычной формы объекта оба часто дают похожую структурную проверку.

<!-- wishu:answer-block -->

- Interface можно расширять и объединять повторными объявлениями имени. Type alias повторно открыть таким способом нельзя, но можно построить новый тип через пересечение или другой оператор. Для union и преобразований нужен type; для расширяемого публичного объектного контракта часто удобен interface. Выбор должен отражать контракт, а не ожидание runtime-объекта: оба обычно удаляются.
