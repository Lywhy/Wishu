**Generic описывает алгоритм через параметр типа, сохраняя связь между аргументами и результатом.** В отличие от `any`, конкретная информация не теряется: для массива чисел результат first связан с number. Типовой параметр не является runtime-значением и не позволяет создать объект через new T.

#### Как это работает

Параметр часто выводится из аргументов и контекста, но его можно задать явно. Компилятор проверяет реализацию для допустимых T, поэтому произвольные операции без ограничения недоступны. В примере учитывается пустой массив: результат T | `undefined`. Generic полезен для реальной связи типов, а не как украшение любой функции.

#### Пример

```typescript
function first<T>(items: readonly T[]): T | undefined {
  return items[0]
}
const number = first([1, 2, 3]) // number | undefined
const empty = first<string>([]) // string | undefined
```

#### Разбор примера

First сохраняет связь типа элемента с результатом, но честно оставляет `undefined` для пустого массива. Вызов со `string` задаёт тип вручную, не создавая строку в пустом массиве. Если функция вернула бы `any`, вызывающая сторона потеряла бы и эту связь, и необходимость учитывать отсутствие элемента.
