**Можно описать допустимые примитивы, массивы и строковые словари рекурсивным типом. Но такая модель не доказывает отсутствие циклов, допустимость каждого числа или нужную бизнес-схему.**

<!-- wishu:answer-block -->

#### Как это работает

Date, `bigint` и функции не являются просто тем же JSON-значением; обычно нужен транспортный DTO. Тип `number` не отделяет NaN и Infinity от других чисел.

Проверяйте данные на границе и явно выбирайте сериализуемое представление. As JsonValue не исправляет объект.

#### Пример

```typescript
type JsonValue = string | number | boolean | null | JsonValue[] | { [key: string]: JsonValue }
const payload: JsonValue = { id: "u1", active: true }
// Тип не доказывает ацикличность произвольного графа.
```

#### Разбор примера

Payload укладывается в рекурсивную форму строкового словаря с примитивными значениями. Однако `number` в этой модели допускает также NaN, а ссылки объектов могут образовать цикл. Поэтому для гарантированной передачи нужны ограничения чисел, проверка графа и предметная схема сверх одной совместимости с JsonValue.

#### Типичная ошибка

> Считать рекурсивный тип полноценным runtime-валидатором и детектором циклов.
