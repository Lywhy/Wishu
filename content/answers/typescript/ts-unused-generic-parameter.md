**Если T не влияет на структуру типа, разные подстановки могут остаться совместимыми. Одного имени параметра недостаточно для номинальной защиты.**

<!-- wishu:answer-block -->

#### Механизм и границы

- Контейнер должен действительно связывать T с хранимыми данными или операциями.
- Если задача - различать идентификаторы одной формы, нужен осмысленный бренд, а не пустой generic.
- Не добавляйте фиктивные runtime-поля без понимания, где нужна только типовая метка и где реальное состояние.
- Проверки неиспользуемых параметров типа могут отдельно диагностировать лишний T; это не отменяет смысл структурного сравнения.

#### Пример

```typescript
interface Empty<T> {}
const a: Empty<string> = {}
const b: Empty<number> = a
interface Box<T> {
  value: T
}
// Box<string> и Box<number> уже имеют разные value.
```
