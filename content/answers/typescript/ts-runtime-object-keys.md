Статический тип может скрывать дополнительные свойства реального объекта. Поэтому обещание, что каждый ключ Object.keys входит в keyof видимого типа, в общем случае неверно.

<!-- wishu:answer-block -->

### Причина
Объект с полями id и secret можно передать в функцию, принимающую только `{ id: number }`. Внутри Object.keys всё равно увидит оба поля, хотя `keyof` параметра содержит только id. Кроме того, Object.keys возвращает собственные перечисляемые строковые ключи: символы пропускаются, а числовые имена представлены строками.

### Безопасный подход
Для известного списка полей передавайте явный readonly-кортеж ключей. Утверждение типа в локальном typedKeys допустимо только при дополнительно обеспеченном контракте формы; оно не становится универсальным доказательством.
