**Объединяемые интерфейсы могут сформировать общий набор сигнатур. Добавленная декларация способна изменить доступные вызовы и вывод результата, поэтому расширение надо проверять как изменение API.**

<!-- wishu:answer-block -->

#### Как это работает

Совместимость обычных полей и объединение перегрузок подчиняются разным правилам. Порядок групп и приоритет специализированных сигнатур имеют значение; нельзя считать merge простым неупорядоченным набором.

Декларации не создают другую runtime-реализацию: реальная функция должна выполнять новые обещания.

#### Пример

```typescript
interface Parse {
  (value: string): string
}
interface Parse {
  (value: "id"): number
}
declare const parse: Parse
const result = parse("id") // number по специализированному контракту.
// Реальная функция должна действительно соответствовать декларациям.
```

#### Разбор примера

После объединения Parse вызов с точным литералом «id» получает специализированный результат number. Реальная функция должна поддерживать это исключение из общего строкового поведения. Добавление декларации меняет доступный контракт вызова, поэтому не является только безобидным расширением документации.

#### Типичная ошибка

> Считать `declaration` merging безусловно безопасным добавлением документации.
