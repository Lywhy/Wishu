allowJs позволяет включать JavaScript-файлы в проект TypeScript, а checkJs включает сообщения проверки для таких файлов. JSDoc описывает параметры и контракты там, где нет TypeScript-синтаксиса.

<!-- wishu:answer-block -->

Для отдельного файла можно использовать ts-check. Стратегия миграции может начинаться с публичных границ и постепенно уточнять слабые контракты. Аннотации JSDoc по-прежнему не валидируют внешние данные во время выполнения.

Не путайте включение файла в проект и его строгую проверку. При преобразовании JS настройте outDir либо используйте noEmit, чтобы не пытаться перезаписывать исходники. Конкретные JSDoc-конструкции зависят от поддерживаемого инструмента; это не предложение вставлять TypeScript-аннотации прямо в .js.
