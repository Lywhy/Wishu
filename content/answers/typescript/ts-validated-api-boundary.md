Параметр типа у `request<T>()` сам не проверяет серверный ответ. Более честный API принимает parser из unknown в T: результат становится T только после успешной проверки.

<!-- wishu:answer-block -->

Generic связывает возвращаемый тип с переданной функцией проверки. Сам parser должен быть корректен: компилятор не доказывает правдивость вручную написанного утверждения или предиката. Можно использовать runtime-схему, из которой выводится тип, чтобы уменьшить расхождение схемы и аннотации.

Отдельно обрабатывайте HTTP-ошибку, синтаксис JSON и несоответствие структуры. Эти ошибки возникают на разных границах. Смена контракта сервера не становится безопасной только из-за совпадения имени интерфейса в клиенте.
