**Conditional type может проверить форму кортежа и ввести типы его частей через infer. Для пустой последовательности нужна явно выбранная ветвь результата.**

<!-- wishu:answer-block -->

#### Как это работает

`readonly`-вход надо учитывать в шаблоне, иначе подходящий по значениям `readonly`-кортеж может не совпасть. Обычный массив произвольной длины не обещает наличие первого элемента, как непустой кортеж.

Сложная рекурсия требует условия завершения и понятного контракта для rest и optional-позиций.

#### Пример

```typescript
type Head<T extends readonly unknown[]> = T extends readonly [infer H, ...unknown[]] ? H : never
type Tail<T extends readonly unknown[]> = T extends readonly [unknown, ...infer R] ? R : []
type First = Head<readonly ["a", 1]> // "a"
```

#### Разбор примера

`readonly`-кортеж с первым элементом «a» соответствует шаблону Head, и H получает этот литерал. Для Tail оставшиеся позиции собираются отдельно. Пустой кортеж не соответствует непустому шаблону, поэтому выбранные `never` и [] являются явной политикой отсутствия результата.

#### Типичная ошибка

> Забывать `readonly` или считать [] и T[] непустыми кортежами.
