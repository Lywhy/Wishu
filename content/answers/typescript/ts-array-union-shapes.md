**В первом случае каждый элемент может быть A или B. Во втором значение должно соответствовать одному из массивных контрактов целиком: массиву A либо массиву B.**

<!-- wishu:answer-block -->

#### Как это работает

Не путайте union контейнеров с контейнером union-элементов. Для методов над union массивов детали вывода зависят от сигнатур и версии TypeScript; это не меняет смысл самих двух моделей.

Если данные по условию смешанные, моделируйте смешанный массив явно, а не обходите проверку приведением.

#### Пример

```typescript
type Mixed = (string | number)[]
type Homogeneous = string[] | number[]
const mixed: Mixed = ["a", 1]
const strings: Homogeneous = ["a", "b"]
// const invalid: Homogeneous = ["a", 1]
```

#### Разбор примера

Массив mixed содержит оба вида значений и подходит только модели с union у элемента. Strings соответствует однородной строковой ветви Homogeneous. Выбор модели задаёт, что должен гарантировать поставщик данных, а не только какие методы удобно вызвать в потребителе.

#### Типичная ошибка

> Считать обе записи взаимозаменяемыми при описании набора данных.
