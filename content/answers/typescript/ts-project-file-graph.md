**`files`/`include` выбирают начальные входы, а зависимости могут добавить другие файлы. `rootDir` и `outDir` описывают размещение выходной структуры и не являются универсальными фильтрами входа.**

<!-- wishu:answer-block -->

#### Как это работает

`Exclude` влияет на поиск через `include`, но не гарантирует исключение файла, который импортирован из проверяемого кода. `rootDir` не обязан менять тот набор файлов, который вы представляете папкой проекта.

Для неожиданного попадания файла в программу исследуйте граф и разрешение импортов, а не только маску exclude.

#### Пример

```json
{
  "include": ["src"],
  "exclude": ["src/legacy"],
  "compilerOptions": {
    "rootDir": "src",
    "outDir": "dist"
  }
}
```

#### Разбор примера

`Exclude` убирает legacy из начального поиска, но зависимость из src может вернуть файл в проверяемую программу. Поэтому неожиданное включение объясняют путём импорта. Изменение `outDir` не разрывает такую связь: оно меняет размещение результата, а не архитектуру зависимостей.

#### Типичная ошибка

> Считать `Exclude` запретом любого импорта исключённой папки.
