**Files/include выбирают начальные входы, а зависимости могут добавить другие файлы. RootDir и outDir описывают размещение выходной структуры и не являются универсальными фильтрами входа.**

<!-- wishu:answer-block -->

#### Механизм и границы

- Exclude влияет на поиск через include, но не гарантирует исключение файла, который импортирован из проверяемого кода.
- RootDir не обязан менять тот набор файлов, который вы представляете папкой проекта.
- Для неожиданного попадания файла в программу исследуйте граф и разрешение импортов, а не только маску exclude.

#### Пример

```typescript
// tsconfig.json
// { "include": ["src"], "exclude": ["src/legacy"] }
// Импорт src/legacy из другого файла всё равно может включить его в граф.
// rootDir/outDir решают другую задачу.
```
