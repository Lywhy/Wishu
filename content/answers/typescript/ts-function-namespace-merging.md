**Некоторые объявления могут объединяться и описывать значение с дополнительными членами. Например, `namespace` после функции позволяет связать её вызов и именованные свойства, но это не то же самое, что только удаляемый интерфейс.**

<!-- wishu:answer-block -->

#### Как это работает

Допустимы определённые комбинации и порядок объявлений; не любые два одноимённых объявления можно объединить. Обычный `namespace` с исполняемым содержимым требует соответствующего emit, что важно для type stripping и erasableSyntaxOnly.

Для нового API отдельные экспорты или явное создание свойств функции могут быть понятнее.

#### Пример

```typescript
function format(value: number) {
  return value.toFixed(0)
}
namespace format {
  export const unit = "items"
}
const text = format(1) + " " + format.unit
// Пример предполагает конвейер, поддерживающий namespace emit.
```

#### Разбор примера

Format вызывается как функция и одновременно предоставляет unit как свойство значения. `namespace` с экспортированной константой требует реального создания этого свойства при преобразовании. Поэтому паттерн нельзя переносить в режим простого стирания типов как безусловно удаляемую декларацию.

#### Типичная ошибка

> Считать `namespace` всегда удаляемой группировкой типов.
