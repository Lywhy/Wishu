**Объектный тип только с необязательными свойствами не обязательно принимает любой непустой объект. При отсутствии общих свойств TypeScript может обнаружить вероятную ошибку выбора контракта.**

<!-- wishu:answer-block -->

#### Как это работает

Это дополнительная защитная проверка, а не требование заполнить каждое optional-поле. Пустой объект обычно допустим. Добавлять фиктивное поле или as только для обхода диагностики - плохое исправление.

Проверьте опечатку, назначение входа и действительно ли API должен принимать произвольный словарь.

#### Пример

```typescript
type Options = { timeout?: number }
const unrelated = { retries: 3 }
// const options: Options = unrelated // Нет общих свойств.
const empty: Options = {}
```

#### Разбор примера

Unrelated не содержит timeout или другого общего поля, поэтому проверка может распознать вероятно перепутанный объект. Empty при этом корректен: необязательность не отменяется. Правильное исправление состоит в уточнении назначения retries и timeout, а не в добавлении фиктивного значения ради совместимости.

#### Типичная ошибка

> Ожидать совместимость любого объекта с типом из необязательных полей.
