**`readonly` T[] и `ReadonlyArray<T>` задают один и тот же контракт массива без записи по индексу и мутирующих методов вроде push.** Читающие методы и методы, создающие результат, доступны. Изменяемый массив можно передать функции, которая обещает только читать его.

#### Как это работает

Обратное присваивание `readonly`-массива изменяемому в общем случае запрещено. Это не runtime-заморозка: другой владелец изменяемой ссылки может менять массив, а вложенные объекты не становятся `readonly` автоматически. Для собственной изменяемой копии подходит spread или slice с обычными правилами поверхностного копирования.

#### Пример

```typescript
function total(values: readonly number[]): number {
  return values.reduce((sum, value) => sum + value, 0)
}
const values: ReadonlyArray<number> = [1, 2]
const copy: number[] = [...values]
copy.push(3)
total(values) // 3
```

#### Разбор примера

Total читает `readonly`-последовательность и не требует права её изменять. Copy создаёт новую внешнюю коллекцию, поэтому `push` не затрагивает values. Если бы элементы были объектами, их ссылки остались бы общими: `readonly`-массив и глубокая неизменяемость являются разными контрактами.
