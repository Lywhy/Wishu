**Index signature может ограничивать ключи строковым шаблоном, например `data-${string}`. Это позволяет оставить динамическую область, не открывая любой строковый ключ.**

<!-- wishu:answer-block -->

#### Как это работает

Обычные явно объявленные поля описываются рядом с шаблонной областью. Шаблон ограничивает форму имени, но не валидирует содержимое суффикса по бизнес-правилам.

Проверка применяется к типовой модели; внешние JSON-данные всё равно требуют runtime-проверки.

#### Пример

```typescript
interface Attributes {
  id: string
  [key: `data-${string}`]: string
}
const attrs: Attributes = { id: "card", "data-state": "open" }
```

#### Разбор примера

Attributes разрешает известное поле id и отдельную область имён data-. Значение data-state проходит этот шаблон, но обычный произвольный ключ этим контрактом не объявляется. Если суффикс должен принадлежать конечному набору, одного `string` в шаблоне уже недостаточно.

#### Типичная ошибка

> Считать строковый шаблон полноценным парсером имени.
