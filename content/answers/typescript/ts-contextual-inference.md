**Тип параметра может поступать из места использования функции. Если вынести callback в переменную без аннотации, тот же контекст не переносится автоматически.**

<!-- wishu:answer-block -->

#### Как это работает

В `map` тип элемента известен из массива, поэтому параметр callback получает тип без повторной записи. Сначала проверяется само объявление отдельно вынесенной функции. При `noImplicitAny` отсутствие контекста может стать ошибкой.

Аннотируйте границу переиспользуемой функции; не добавляйте `any` только ради устранения сообщения.

#### Пример

```typescript
const names = ["Анна", "Иван"]
const lengths = names.map((name) => name.length)
const size = (name: string) => name.length
const same = names.map(size)
```

#### Разбор примера

В первом `map` компилятор уже знает тип names и использует его для параметра name. Вынесенная size проверяется как отдельное объявление, поэтому её граница описана явно. Последующий вызов `map` не переписывает задним числом контракт функции, который должен быть понятен и для других мест использования.

#### Типичная ошибка

> Ожидать, что будущий вызов всегда типизирует ранее объявленный callback.
