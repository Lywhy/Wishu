**Тип параметра может поступать из места использования функции. Если вынести callback в переменную без аннотации, тот же контекст не переносится автоматически.**

<!-- wishu:answer-block -->

#### Механизм и границы

- В `map` тип элемента известен из массива, поэтому параметр callback получает тип без повторной записи.
- Сначала проверяется само объявление отдельно вынесенной функции. При noImplicitAny отсутствие контекста может стать ошибкой.
- Аннотируйте границу переиспользуемой функции; не добавляйте any только ради устранения сообщения.

#### Пример

```typescript
const names = ["Анна", "Иван"]
const lengths = names.map((name) => name.length)
const size = (name: string) => name.length
const same = names.map(size)
```
