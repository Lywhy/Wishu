**Имя класса в позиции типа обычно описывает экземпляр. `typeof` от значения класса описывает конструктор и статические члены, а не поля отдельного созданного объекта.**

<!-- wishu:answer-block -->

#### Как это работает

Функция, принимающая экземпляр, не получает автоматически возможность вызвать new. Generic-класс имеет параметризованные экземпляры; статическое значение конструктора рассматривается отдельно.

Для извлечения экземпляра из подходящего конструктора есть InstanceType.

#### Пример

```typescript
class User {
  static role = "user"
  constructor(public name: string) {}
}
const C: typeof User = User
const value: User = new C("Анна")
type Item = InstanceType<typeof User>
```

#### Разбор примера

C содержит класс как значение, поэтому через него можно вызвать new и обратиться к static role. Value содержит созданный экземпляр с name. `InstanceType` извлекает вторую форму из первой, не выполняя создание объекта самостоятельно.

#### Типичная ошибка

> Передавать User вместо `typeof` User в контракте new.
