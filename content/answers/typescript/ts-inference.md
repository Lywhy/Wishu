**TypeScript выводит тип из инициализатора, возвращаемых выражений и контекста использования.** Callback с известным ожидаемым типом часто получает тип параметра без отдельной аннотации. Повторять очевидный тип каждой локальной переменной обычно не требуется.

<!-- wishu:answer-block -->

- Изменяемые значения могут расширяться от литерала к общему типу: let count = 1 обычно получает number, const count = 1 - литерал 1. Явная аннотация полезна для публичного контракта, допустимых будущих присваиваний и проверки возвращаемого результата. As const сохраняет литеральную точность, но не выполняет runtime-заморозку.

### Контекст и расширение
Тип параметра callback часто приходит из ожидаемой сигнатуры. Самостоятельная функция без такого контекста не обязательно получит подходящий тип параметра. Даже у const-переменной изменяемое свойство объектного литерала может расшириться до string: const фиксирует привязку переменной, а не все её поля.

```typescript
const handlers: { read: (value: number) => string } = {
  read: (value) => value.toFixed(2),
}
const request = { method: "GET" } // method обычно string.
const exactRequest = { method: "GET" } as const // method: "GET".
```
