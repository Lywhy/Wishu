**Tsconfig определяет проект TypeScript: `compilerOptions`, входные файлы и связь с другими конфигурациями.** `include`, `Exclude` и `files` влияют на исходный набор, но импортированный файл может попасть в программу через зависимости. `extends` позволяет наследовать настройки.

#### Как это работает

`target` задаёт уровень преобразования синтаксиса, lib - доступные декларации встроенных API, `module` и `moduleResolution` - правила модулей и их поиска. Добавление lib не устанавливает polyfill. `noEmit` оставляет проверку без генерации JS. Конкретные параметры выбирают под runtime и сборщик; наличие tsconfig не означает, что каждый инструмент автоматически проверяет типы.

#### Пример

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM"],
    "strict": true,
    "noEmit": true
  },
  "include": ["src"]
}
```

#### Разбор примера

В конфигурации примера ES2022 определяет целевой уровень синтаксиса, а DOM добавляет сведения о браузерных интерфейсах. При запуске того же результата вне браузера document из-за этого не появится. `noEmit` оставляет TypeScript задачу проверки: преобразование и упаковку в таком проекте должен выполнять другой шаг.
