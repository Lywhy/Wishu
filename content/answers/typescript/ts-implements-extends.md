**`implements` проверяет, что экземпляры класса соответствуют интерфейсу или подходящему объектному типу.** Он не копирует методы и не создаёт недостающие поля. `extends` реально связывает классы через наследование JavaScript и позволяет использовать super.

#### Как это работает

Класс может реализовать несколько контрактов, но не получить от них готовую реализацию. `implements` не подставляет автоматически контекстные типы всем параметрам тела метода: реализацию всё равно нужно корректно аннотировать. Статические члены не проверяются обычным контрактом экземпляра.

#### Пример

```typescript
interface Named {
  name: string
}
class User implements Named {
  name = "гость"
}
class Admin extends User {
  role = "admin"
}
new Admin().name // "гость": реальное наследование
// implements само по себе не создало бы name.
```

#### Разбор примера

User сам создаёт name и лишь проверяет соответствие Named. Admin получает существующее поведение через `extends`, поэтому новый экземпляр действительно имеет имя. Замена `extends` на `implements` потребовала бы заново обеспечить нужные поля и методы, поскольку контракт не содержит реализации.
