**Кортеж сохраняет позиционные сведения, но извлечение через T[`number`] даёт union типов элементов. Это не тот же тип, что сам упорядоченный набор.**

<!-- wishu:answer-block -->

#### Как это работает

Length фиксированного кортежа может быть числовым литералом; optional-позиции создают несколько возможных длин. `keyof` кортежа включает не только собственные позиции, но и массивные члены, поэтому его нельзя без уточнения считать списком индексов.

Динамический `number`-индекс теряет точную связь конкретной позиции и её значения.

#### Пример

```typescript
type Pair = readonly [string, number]
type Size = Pair["length"] // 2
type Item = Pair[number] // string | number
type First = Pair[0] // string
```

#### Разбор примера

Pair[0] отвечает на вопрос о первой позиции, а Pair[`number`] забывает порядок и оставляет два возможных типа. Length отдельно сохраняет число 2. Поэтому для передачи аргументов функции нужен сам кортеж, а для обработки любого его элемента может быть достаточно полученного union.

#### Типичная ошибка

> Использовать T[`number`] там, где нужно сохранить порядок аргументов.
