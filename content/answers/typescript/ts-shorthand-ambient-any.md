**Короткое ambient-объявление модуля может разрешить его использование без полезного описания экспортов. Исчезновение ошибки о типах не означает появления проверенного API.**

<!-- wishu:answer-block -->

#### Как это работает

Для используемых экспортов задавайте реальные параметры и результаты, соответствующие runtime-библиотеке. Если данные результата ещё неизвестны, честный `unknown` с дальнейшей проверкой безопаснее обещания произвольной структуры.

Проверьте наличие официальных типов или подходящей декларации, прежде чем добавлять глобальную заглушку.

#### Пример

```typescript
// Слишком широкая заглушка:
// declare module "legacy-api";
// Более содержательный контракт, если он соответствует библиотеке:
declare module "legacy-api" {
  export function load(id: string): Promise<unknown>
}
```

#### Разбор примера

Подробное объявление load сохраняет требование строкового id, но честно оставляет ответ unknown. Потребитель обязан проверить данные перед чтением полей. Короткая заглушка скрыла бы эту необходимость за `any`, хотя реальная библиотека от добавления .d.ts никак не изменилась.

#### Типичная ошибка

> Считать любую заглушку .d.ts завершённой типизацией зависимости.
