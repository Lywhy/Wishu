**Явный список исходников и выбор tsconfig через -p задают разные способы запуска. Нельзя предполагать, что переданный файл будет проверен с теми же настройками, что и весь проект.**

<!-- wishu:answer-block -->

#### Механизм и границы

- В TS 5.x явные входные файлы не означали автоматическое применение найденного tsconfig.
- В TS 6.0 поведение при наличии конфигурации изменено: предусмотрена диагностика и явный механизм игнорирования config. Учитывайте точную версию.
- Для проверки реального проекта указывайте его конфигурацию и исследуйте итоговые параметры; пример-файл может зависеть от других файлов и глобальных типов.

#### Пример

```typescript
// Команды для самостоятельной диагностики:
// tsc -p tsconfig.json --showConfig
// tsc -p tsconfig.json --noEmit
// Они не исполнялись при подготовке вопроса.
```
