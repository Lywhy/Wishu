**Рекурсивному преобразованию нужны ограниченная область входов и достижимое условие завершения. Явный бюджет глубины помогает сделать контракт предсказуемее вместо бесконечного уточнения произвольной структуры.**

<!-- wishu:answer-block -->

#### Как это работает

Распределение по union способно многократно расширить работу на каждом шаге. Хвостовая форма некоторых conditional types оптимизируется, но это не отменяет лимиты и не гарантирует одинаковый предел для любой версии.

При диагностике сначала уменьшайте пример и упрощайте модель; обход лимитов хитрым as не доказывает корректность результата.

#### Пример

```typescript
type Unwrap<T, Depth extends unknown[] = []> = Depth["length"] extends 8
  ? T
  : T extends readonly (infer U)[]
    ? Unwrap<U, [...Depth, unknown]>
    : T
type Item = Unwrap<string[][]> // string
```

#### Разбор примера

Каждый снятый уровень массива добавляет элемент в Depth. Для `string`[][] достаточно двух шагов, после чего условие массива уже не выполняется. При достижении восьми шагов helper возвращает оставшийся T, сознательно ограничивая точность вместо обещания бесконечного преобразования.

#### Типичная ошибка

> Обещать один универсальный числовой лимит рекурсии для всех компиляторов и форм типов.
