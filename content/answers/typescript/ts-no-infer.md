`NoInfer<T>` запрещает использовать соответствующую позицию как источник кандидатов для вывода T, сохраняя последующую проверку совместимости с уже выбранным типом. Встроенный utility доступен с TypeScript 5.4.

<!-- wishu:answer-block -->

В примере набор цветов определяет C, а запасной цвет должен только проверяться относительно этого набора. Без управления выводом второй аргумент может расширить предполагаемый union и случайно разрешить значение, которого нет в списке.

NoInfer не отключает проверку и не заменяет runtime-проверку принадлежности массиву. Если входной список уже имеет широкий тип string[], точный конечный набор из него вывести нельзя.
