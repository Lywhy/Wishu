**NoEmit отключает обычный вывод JavaScript и деклараций. NoEmitOnError связывает emit с диагностикой. Успешное преобразование TS другим инструментом само по себе не доказывает прохождение type checking.**

#### Механизм и границы

- Type stripping и проверка типов - разные задачи; они могут выполняться разными командами.
- Если приложение продолжает запускаться после ошибки checker, разберите весь конвейер, а не делайте вывод по наличию JS.
- Включайте проверку нужного проекта в процесс подготовки результата, учитывая настройки и версию инструментов.
- Файлы кеша инкрементальной проверки, например .tsbuildinfo, имеют отдельные правила и не являются исполняемым JS-результатом.

#### Пример

```typescript
// Разделённые стадии:
// 1. Проверка контракта TypeScript без JS-emit.
// 2. Сборка JavaScript выбранным инструментом.
// 3. Runtime-проверка поведения.
// Успех одной стадии не заменяет остальные.
```
