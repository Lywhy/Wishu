**Нужно связать конкретный ключ K с типом T[K]. Два независимых union - `keyof` T и T[`keyof` T] - позволяют передать значение другого поля.**

<!-- wishu:answer-block -->

#### Как это работает

Generic-параметр ключа выбирается по конкретному аргументу вызова. Если сам K уже является union, гарантии надо оценивать отдельно: параметр не превращает любой динамический ввод в доказанную пару.

Для набора изменений хорошо подходит union коррелированных записей, а не два раздельных массива ключей и значений.

#### Пример

```typescript
function set<T, K extends keyof T>(object: T, key: K, value: T[K]) {
  object[key] = value
}
const user = { name: "Анна", age: 20 }
set(user, "age", 21)
// set(user, "age", "21") // Не number.
```

#### Разбор примера

В конкретном вызове K выбирается как «age», поэтому T[K] требует `number` и отклоняет «21». Для заранее объединённого динамического ключа нужно заново оценить связь с выбранным значением. Generic-подпись не является универсальным доказательством любой пары, пришедшей из внешнего ввода.

#### Типичная ошибка

> Считать общий union значений проверкой конкретного выбранного поля.
