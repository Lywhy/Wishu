Храните соответствие «имя события → кортеж аргументов» в одном типе. Generic-ключ связывает выбранное имя с сигнатурой конкретного обработчика.

#### Как это работает

Два независимых union вроде `EventName` и `User | Error` теряют корреляцию: компилятор может разрешить неверное сочетание. Индексирование по связанному K сохраняет её на публичной границе.

В реализации хранилища разнородных слушателей может потребоваться узкая адаптационная граница. Не превращайте всё хранилище и все вызовы в `any` ради удобства. Отдельно определите runtime-поведение: порядок, отписка, исключения и изменение списка во время рассылки не следуют из одного интерфейса.

#### Пример

```typescript
type Events = {
  saved: [id: string, revision: number]
  failed: [error: Error]
}
interface EventBus {
  on<K extends keyof Events>(name: K, listener: (...args: Events[K]) => void): () => void
}
declare const bus: EventBus
bus.on("saved", (id, revision) => console.log(id, revision))
// bus.on('failed', (id: string) => {}) // Несовместимый обработчик.
```

#### Разбор примера

Выбор saved задаёт listener со строковым id и числовой revision. Failed требует Error вместо этих двух параметров. EventBus описывает только контракт: `declare` const bus не создаёт реализацию, которая обеспечит доставку, отписку и согласованное поведение при исключении обработчика.

#### Типичная ошибка

> Описать имя события и payload двумя независимыми union и потерять допустимые пары.
