**Разные параметры типа описывают независимые роли, например ключ и значение либо два элемента пары.** Использование одного T вместо A и B может необоснованно потребовать одинаковый тип. Каждый параметр должен выражать нужную связь, а не просто усложнять подпись.

- Вывод обычно учитывает аргументы для каждого параметра. Ограничения через extends могут связать их дополнительно, например K extends `keyof` T. Порядок явных аргументов типов соответствует объявлению; TypeScript не выбирает один произвольный параметр для ручного задания без учёта остальных и их default.
