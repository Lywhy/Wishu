**Этот режим помогает ограничить код синтаксисом, который можно удалить без собственной runtime-семантики TypeScript. `enum`, parameter properties и ряд `namespace`-сценариев требуют иной обработки, чем простая аннотация.**

<!-- wishu:answer-block -->

#### Как это работает

Возможность появилась в TS 5.8; конкретная среда запуска также имеет собственную матрицу поддержки. Флаг не является преобразователем и не гарантирует наличие новых JavaScript API в runtime.

Проверять надо одновременно синтаксис, пути импортов, формат модулей и доступные возможности среды.

#### Пример

```typescript
// Аннотация стирается:
function id(value: string): string {
  return value
}
// Parameter property требует отдельного преобразования:
// class User { constructor(public name: string) {} }
```

#### Разбор примера

У id достаточно убрать аннотации, чтобы осталось то же поведение JavaScript. Parameter property дополнительно подразумевает создание поля из аргумента, поэтому требует трансформации. Настройка проверяет допустимость такого синтаксиса для выбранного подхода, но сама не выполняет альтернативный emit.

#### Типичная ошибка

> Выдавать проверку стираемости за полную настройку запуска приложения.
