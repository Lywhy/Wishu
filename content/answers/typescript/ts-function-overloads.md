**Перегрузки задают несколько допустимых контрактов вызова перед одной реализацией.** Сигнатура реализации должна быть совместима с ними, но сама по себе не является дополнительной публичной перегрузкой. Это одна JavaScript-функция, а не выбор разных тел по runtime-типу.

- Реализация должна реально различать и обрабатывать варианты. Аргумент union может не соответствовать ни одной узкой перегрузке, даже если реализация его принимает. Если достаточно единой формы с union, она часто проще; перегрузки полезны, когда нужно выразить разные зависимости входа и результата.

<!-- wishu:answer-block -->

### Как выбрать форму API
- Один результат и общая обработка альтернативных входов: начните с union.
- Результат связан с точным входным типом: рассмотрите generic.
- Несколько действительно разных форм вызова и соответствующих результатов: перегрузки могут быть яснее.

Аргумент string | number не обязан соответствовать отдельным перегрузкам только string и только number. Если такой вызов нужен публично, его контракт нужно выразить явно. Не добавляйте десятки перегрузок вместо одной понятной связи типов.
