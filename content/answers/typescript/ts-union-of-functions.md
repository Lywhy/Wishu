**Если значение может быть одной из нескольких функций, безопасный аргумент должен подходить каждой возможной реализации. Это отличается от одной функции, которая сама обещает обработать весь union.**

<!-- wishu:answer-block -->

#### Как это работает

Для несовместимых областей аргументов общее допустимое значение может свестись к never. Дискриминируйте контейнер с функцией или измените API, сохранив связь варианта и параметра.

Приведение аргумента к `never` только скрывает проблему: оно не выбирает правильную runtime-функцию.

#### Пример

```typescript
type One = ((value: string) => string) | ((value: number) => number)
type Both = (value: string | number) => string | number
const stringify: Both = (value) => String(value)
// One не обещает обработать любой string | number.
```

#### Разбор примера

Both гарантирует, что одна реализация справится и со строкой, и с числом. One такого обещания не даёт: в конкретный момент там может находиться функция только для чисел. Поэтому произвольный `string` | `number` нельзя безопасно передать в One без сохранения связи с выбранной реализацией.

#### Типичная ошибка

> Лечить невозможный вызов через as never.
