**Public доступен снаружи и используется по умолчанию.** Protected ограничивает доступ кодом класса и наследников с дополнительными правилами совместимости. Private TypeScript ограничивает доступ рамками класса при статической проверке и влияет на совместимость типов.

Эти варианты не следует смешивать с readonly, который ограничивает запись, а не определяет круг читающего кода.

### Происхождение private-членов

Два независимо объявленных класса с одинаково названным private-членом не становятся совместимыми только из-за одинаковой видимой формы. Наследник сохраняет происхождение члена базы; это важное исключение из упрощённого объяснения структурной модели.

```typescript
class A {
  private tag = 0
  read() {
    return this.tag
  }
}
class B {
  private tag = 0
  read() {
    return this.tag
  }
}
// const item: A = new B() // Разное происхождение private tag.
```
