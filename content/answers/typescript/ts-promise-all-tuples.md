**Если вход представлен кортежем, тип результата может сохранить отдельный тип каждой позиции. В широком массиве связь индекса и конкретной задачи уже потеряна.**

<!-- wishu:answer-block -->

#### Как это работает

`readonly`-кортеж удобно получить через `as const`, если это соответствует модели данных. `Awaited` описывает разрешение отдельного значения, а форма контейнера сохраняет позиционную связь.

Это не добавляет ограничение параллельности, отмену или типизацию всех отказов: речь только о статической форме результатов.

#### Пример

```typescript
const jobs = [Promise.resolve("name"), Promise.resolve(1)] as const
async function run() {
  const [name, count] = await Promise.all(jobs)
  return name.toUpperCase() + count.toFixed(0)
}
```

#### Разбор примера

Jobs сохраняет две позиции: обещание строки и обещание числа. `Promise.all` переносит эту связь в результат, поэтому name и count получают разные методы. При заранее расширенном массиве обещаний сведения о конкретном индексе исчезли бы, даже если значения фактически остались такими же.

#### Типичная ошибка

> Ожидать восстановление точного кортежа из произвольного массива.
