**T[] и `Array<T>` обозначают обычный массив элементов T.** Для смешанных значений задают union элемента: (string | number)[], а не string[] | number[], который означает выбор одного из двух видов массива. Двумерная структура записывается как T[][] или `Array<Array<T>`>.

- Тип массива не фиксирует длину и одинаковое число столбцов строк. При чтении произвольного индекса возможен runtime-`undefined`; noUncheckedIndexedAccess отражает это для непроверенного доступа. Для фиксированных позиций с разными типами нужен кортеж. Аннотация не запрещает внешнему непроверенному коду изменить реальные данные.
