**Подходящий homomorphic mapped type умеет преобразовать элементы кортежа, сохраняя его позиционную структуру и модификаторы. Произвольное переименование ключей не обязано сохранять тот же контракт.**

<!-- wishu:answer-block -->

#### Как это работает

Шаблон `[K in keyof T]` полезен для преобразования элементов без ручного перечисления позиций. Добавление as к ключам меняет задачу и может заставить обрабатывать массивные члены как объектные свойства.

Не проверяйте только один пример с двумя полями: учитывайте `readonly`, массивы и кортежи разной формы.

#### Пример

```typescript
type Promised<T> = { [K in keyof T]: Promise<T[K]> }
type Pair = Promised<readonly [string, number]>
// readonly [Promise<string>, Promise<number>]
```

#### Разбор примера

Promised сохраняет две позиции Pair и `readonly`, оборачивая тип каждого элемента в Promise. Это полезно для позиционных вычислений. Если вместо такой формы произвольно переназначить все ключи через as, задача уже может стать созданием обычного объекта со свойствами, а не кортежа.

#### Типичная ошибка

> Считать всякий mapped type отображением кортежа в кортеж.
