**Долгий JavaScript callback, синхронный I/O или большое синхронное преобразование данных занимают основной поток.** Даже если запрос начался асинхронно, тяжёлый JSON.parse после его завершения выполняется синхронно.

- Разделение работы на части или worker помогает по конкретному профилю нагрузки. Простое добавление async к функции не меняет место выполнения её синхронного тела. Следят за задержкой event loop, а не только общей загрузкой CPU.
