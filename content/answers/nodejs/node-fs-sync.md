**Синхронная файловая операция удерживает JavaScript-поток до завершения.** Пока она выполняется в основном потоке сервера, другие запросы не могут продвинуть свои JavaScript-обработчики.

- Асинхронный API позволяет не блокировать поток на ожидании I/O, но большой файл всё равно потребляет память. Для больших объёмов выбирают поток. При инициализации до начала обслуживания короткая синхронная операция может иметь другой профиль риска.
