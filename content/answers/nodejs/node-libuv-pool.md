**Некоторые асинхронные операции Node, включая многие файловые, отдельные DNS-вызовы и часть криптографии, используют пул рабочих потоков libuv.** Многие сетевые операции обслуживаются иначе, через возможности ОС: не весь async-код отправляется в этот пул.

- Долгая задача пула может увеличить очередь других пользователей пула. Увеличение размера не является универсальным исправлением: измеряют конкуренцию, CPU и лимиты среды. Пул libuv не равен worker_threads для пользовательского JavaScript.
