**Buffer представляет последовательность байтов и используется при работе с файлами, сетью и бинарными протоколами.** Строка JavaScript и её байтовое кодирование - разные представления; число UTF-16 code units не обязано совпадать с размером UTF-8.

- Преобразование требует подходящей кодировки. Buffer.alloc инициализирует память, а allocUnsafe требует корректно записать все доступные данные до выдачи наружу. Ошибки с размерами и неполной записью могут раскрыть посторонние байты.
