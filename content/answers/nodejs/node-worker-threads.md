**Worker threads позволяют выполнять JavaScript в отдельных потоках одного процесса и полезны для CPU-интенсивных вычислений.** Для обычного сетевого I/O перенос запроса в worker часто не даёт выигрыша, потому что Node уже обслуживает его асинхронно.

- Обмен сообщениями и перенос либо копирование данных имеют стоимость. Для частых заданий обычно используют ограниченный пул, а не новый worker на каждую операцию. Это Node API, отличающееся от Web Worker в браузере.
