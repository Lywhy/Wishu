**HashMap использует хеш для выбора области хранения, затем сравнение ключей для поиска нужной записи.** Разные ключи могут иметь одинаковый хеш: коллизии обрабатываются внутри структуры и сами по себе не означают перезапись чужого значения.

- Ожидаемая стоимость базовых операций близка к константной при подходящем распределении, но не является безусловной гарантией для любого входа. Обычный HashMap не потокобезопасен и не гарантирует порядок. Изменяемый ключ с нестабильным hashCode ломает ожидаемый поиск.
