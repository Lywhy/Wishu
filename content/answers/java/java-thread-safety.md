**Volatile обеспечивает определённые гарантии видимости и порядка для чтения и записи поля.** Count++ состоит из чтения, вычисления и записи; два потока могут прочитать одно значение и потерять одно обновление.

<!-- wishu:answer-block -->

- Для атомарного счётчика подходит AtomicInteger, для связанного изменения нескольких полей - подходящая синхронизация или другой протокол владения. Потокобезопасная коллекция также не превращает произвольную цепочку её операций в атомарную транзакцию.
