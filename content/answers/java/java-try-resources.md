**Try-with-resources закрывает объявленные AutoCloseable-ресурсы при выходе из блока, в том числе при исключении.** Несколько ресурсов закрываются в обратном порядке их инициализации.

<!-- wishu:answer-block -->

- Если тело и close выбрасывают исключения, исходное исключение тела остаётся основным, а ошибка закрытия добавляется как suppressed. Это помогает не потерять причину операции и надёжнее ручного закрытия только в успешной ветке.
