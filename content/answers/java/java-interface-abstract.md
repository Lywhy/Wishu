**Interface задаёт роль и контракт; класс может реализовать несколько интерфейсов.** Абстрактный класс подходит для общей реализации и состояния связанной иерархии, но класс наследуется только от одного класса.

<!-- wishu:answer-block -->

- Интерфейсы могут содержать default и static методы, поэтому утверждение «в интерфейсе никогда нет реализации» неверно. Наследование выбирают по отношению подстановки, а для переиспользования независимого поведения часто удобнее композиция.
