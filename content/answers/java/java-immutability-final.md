**Final у переменной запрещает повторно присвоить ей другое значение после инициализации.** Если она ссылается на изменяемый объект, его содержимое всё ещё можно менять через доступные методы.

<!-- wishu:answer-block -->

- Неизменяемый объект требует контроля всех путей изменения: закрытых полей, корректного конструктора, отсутствия мутирующего API и защитных копий изменяемых данных. Record также не гарантирует глубокую неизменяемость объектов внутри компонентов.
