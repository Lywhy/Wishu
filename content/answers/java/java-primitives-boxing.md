**Примитивы, например int и boolean, хранят значения соответствующего типа.** Integer и Boolean - ссылочные типы, которые могут быть `null` и используются, например, в обобщённых коллекциях. Autoboxing и unboxing добавляют преобразования между ними.

<!-- wishu:answer-block -->

- Распаковка `null` приводит к NullPointerException. Сравнение двух Integer через == сравнивает ссылки и может дать обманчивый результат из-за кеширования некоторых объектов. Для значения используют подходящий equals или явную примитивную модель.
