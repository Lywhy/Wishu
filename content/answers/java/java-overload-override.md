**Перегрузка создаёт методы с одним именем и разными списками параметров; подходящая сигнатура выбирается по правилам компиляции.** Один лишь другой возвращаемый тип не образует корректную перегрузку.

- Переопределение задаёт реализацию наследуемого экземплярного метода; вызов зависит от фактического класса объекта. Аннотация Override помогает обнаружить ошибку сигнатуры. Static-методы скрываются, а не участвуют в такой динамической диспетчеризации.
