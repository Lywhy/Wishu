**Equals определяет логическое равенство, если класс его переопределяет.** Для равных по equals объектов hashCode обязан совпадать; одинаковый hashCode не доказывает равенство. По умолчанию `Object.equals` использует идентичность экземпляра.

- Если переопределён equals, согласованно переопределяют hashCode. Поля, определяющие равенство ключа HashMap, не следует менять, пока ключ находится в коллекции: поиск может перестать находить запись в ожидаемой корзине.
