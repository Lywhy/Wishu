**В Java аргументы передаются по значению.** Для объекта копируется значение ссылки: метод получает доступ к тому же объекту, но отдельную локальную переменную, содержащую ссылку.

<!-- wishu:answer-block -->

- Изменение доступного поля объекта может быть видно вызывающему коду. Присваивание параметру new Object не меняет переменную вызывающего. Поэтому метод swap, просто переставляющий два параметра-ссылки, не переставляет переменные снаружи.
