**List хранит последовательность с позиционным доступом и допускает повторения.** Set выражает множество уникальных элементов по правилам конкретной реализации. Map связывает ключ с одним значением и не является подтипом Collection.

- Порядок, допустимость `null`, стоимость операций и потокобезопасность зависят от реализации. HashSet не обещает порядок вставки, а TreeSet использует сравнение для определения эквивалентности. Выбор делают по операциям и контракту, а не только знакомому имени.
