Children может содержать один узел, массивы, текст и другие допустимые React-значения. API Children работает со структурой переданных узлов, но не выполняет пользовательские компоненты, чтобы исследовать их будущий результат.

<!-- wishu:answer-block -->

Нельзя надёжно определить через children, сколько DOM-элементов нарисует вложенный компонент. Children.toArray помогает нормализовать переданную структуру, но не является рендерером дерева.

CloneElement заменяет или добавляет props элемента, однако такой скрытый поток данных трудно сопровождать. Для коллекции с предметными данными понятнее явный массив объектов, а для настройки представления - именованные props или render prop. Не меняйте переданный элемент мутацией.
