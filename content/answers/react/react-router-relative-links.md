**Относительная ссылка разрешается по маршрутной иерархии либо выбранной path-семантике, а не по файловой папке компонента.**

<!-- wishu:answer-block -->

### Механизм и границы

- Вложенный layout и сегменты маршрута могут отличаться от количества частей URL.

- В React Router различайте режим relative="route" и relative="path" там, где это значимо. Проверяйте поведение splat для своей версии, а не собирайте ../ на глаз.

### Пример

```jsx
<>
  <Link to="settings">Настройки</Link>
  <Link to=".." relative="path">
    Выше по URL
  </Link>
</>
```

### Типичная ошибка

Считать каждый .. переходом к каталогу исходников или всегда ровно к одному route-layout.
