**Относительная ссылка разрешается по маршрутной иерархии либо выбранной path-семантике, а не по файловой папке компонента.**

<!-- wishu:answer-block -->

#### Как это работает

Вложенный layout и сегменты маршрута могут отличаться от количества частей URL. В React Router различайте режим relative="route" и relative="path" там, где это значимо. Проверяйте поведение splat для своей версии, а не собирайте ../ на глаз.

#### Пример

```jsx
<>
  <Link to="settings">Настройки</Link>
  <Link to=".." relative="path">
    Выше по URL
  </Link>
</>
```

#### Разбор примера

Settings вычисляется из текущего маршрутного контекста, а .. с relative path поднимается по URL-сегменту. Количество route-уровней не всегда совпадает с количеством сегментов. Поэтому структуру ссылки проверяют вместе с конфигурацией маршрута, а не папкой файла.

#### Типичная ошибка

Считать каждый .. переходом к каталогу исходников или всегда ровно к одному route-layout.
