**useRef возвращает стабильный объект с полем current.** Значение сохраняется между рендерами, но изменение current не запрашивает рендер. Ref подходит для DOM-узла, идентификатора таймера или другого служебного значения.

<!-- wishu:answer-block -->

- Если значение должно отображаться в интерфейсе, обычно нужен state. Чтение или запись ref во время рендера, кроме предсказуемой инициализации, нарушает модель чистого вычисления. Работать с ref следует в обработчиках и эффектах.
