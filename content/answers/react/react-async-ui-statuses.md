**Пустой успешный список, ожидание ответа и ошибка - разные пользовательские состояния, даже если во всех сейчас нет строк.**

<!-- wishu:answer-block -->

#### Как это работает

Храните статус операции отдельно от содержимого результата. При повторной загрузке можно сохранить полезные старые данные, явно обозначив обновление. Пустой массив сам по себе не доказывает завершение запроса.

#### Пример

```jsx
if (status === "pending") return <Loading />
if (status === "error") return <Retry />
return rows.length ? <List rows={rows} /> : <Empty />
```

#### Разбор примера

Сначала определяется исход операции и лишь затем интерпретируется rows. Empty показывается только после успешного ответа без записей. Поэтому отсутствие строк во время ожидания или ошибки не выдаётся пользователю за завершённый пустой поиск.

#### Типичная ошибка

Показывать «Ничего не найдено» до завершения первого запроса.
