### Механизм и границы

- Храните статус операции отдельно от содержимого результата.

- При повторной загрузке можно сохранить полезные старые данные, явно обозначив обновление. Пустой массив сам по себе не доказывает завершение запроса.

### Пример

```jsx
if (status === "pending") return <Loading />
if (status === "error") return <Retry />
return rows.length ? <List rows={rows} /> : <Empty />
```

### Типичная ошибка

Показывать «Ничего не найдено» до завершения первого запроса.
