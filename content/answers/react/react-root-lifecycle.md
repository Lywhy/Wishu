**`createRoot` используют для клиентского дерева без серверного React-HTML, `hydrateRoot` - для подключения к соответствующей серверной разметке.** `root.unmount` завершает работу конкретного React-корня.

<!-- wishu:answer-block -->

#### Как это работает

Обычно SPA создаёт один корень и дальше обновляет дерево через props и state, а не создаёт корень на каждый рендер. При встраивании React в чужую страницу может быть несколько независимых корней. Context и локальное состояние не становятся общими между ними автоматически.

Если внешний код удаляет контейнер, сначала корректно размонтируйте корень, чтобы React выполнил очистку. После `root.unmount` прежний объект корня не используют для нового render.

#### Пример

```jsx
const root = createRoot(container)
root.render(<Widget />)
// При окончательном удалении виджета внешним приложением:
root.unmount()
// При исходном серверном React-HTML вместо createRoot:
// const root = hydrateRoot(container, <Widget />)
```

#### Разбор примера

Один root используется до окончательного удаления Widget. Unmount запускает очистку React-дерева до того, как внешний владелец забудет контейнер. Для последующего нового виджета создают новый корень, а серверный HTML изначально подключают через hydrateRoot.

#### Типичная ошибка

Запустить `createRoot` поверх серверного HTML и ожидать корректного сохранения и гидратации этой разметки.
