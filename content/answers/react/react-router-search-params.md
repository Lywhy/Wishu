**Создайте новую копию URLSearchParams, измените нужный ключ и передайте её setter, сохранив остальные параметры.**

<!-- wishu:answer-block -->

#### Как это работает

Setter выполняет навигационное обновление URL. Сам объект параметров изменяемый, поэтому не мутируйте его в render. Повторяющиеся ключи требуют getAll; пустое значение и отсутствие ключа могут иметь разный смысл.

#### Пример

```jsx
setSearchParams((previous) => {
  const next = new URLSearchParams(previous)
  next.set("topic", "react")
  return next
})
```

#### Разбор примера

Новая копия сохраняет поиск и сортировку, меняя только topic. Setter публикует обновлённый URL, а не просто мутирует локальный объект. При зависимом номере страницы его также нужно осмысленно сбросить, чтобы новый фильтр не оставил пустой результат.

#### Типичная ошибка

Заменить параметры объектом из одного поля и потерять поиск, сортировку и страницу.
