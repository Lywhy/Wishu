**Во время IME-композиции Enter может подтверждать ввод символа, а не намерение отправить форму.**

#### Как это работает

Пользовательский onKeyDown должен учитывать isComposing нативного KeyboardEvent и правила выбранной платформы. Нативный submit предпочтительнее ручного перехвата каждого Enter. Для сложного редактора отдельно тестируйте реальное поведение нужных браузеров и способов ввода.

#### Пример

```jsx
function handleKeyDown(event) {
  if (event.nativeEvent.isComposing) return
  if (event.key === "Enter" && event.ctrlKey) submitDraft()
}
```

#### Разбор примера

Во время композиции обработчик не трактует Enter как прикладную команду. После неё Ctrl+Enter может вызвать submitDraft по установленному контракту. Такая проверка не заменяет испытание клавиатурного поведения в целевых браузерах и доступной модели формы.

#### Типичная ошибка

Перехватить любой Enter и прервать ввод иероглифа отправкой незавершённого текста.
