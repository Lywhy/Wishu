**lazy откладывает загрузку кода компонента до первого использования.** Загрузчик возвращает Promise модуля с default-компонентом; React кеширует загрузку. Suspense показывает fallback, пока поддерживаемый ресурс в дочернем дереве не готов.

<!-- wishu:answer-block -->

- Обычный fetch внутри `useEffect` не активирует Suspense автоматически. Для данных нужна интеграция с поддерживающим механизмом или use со стабильным Promise. lazy объявляют на уровне модуля, иначе можно создавать новый тип компонента и терять состояние. Ошибка загрузки передаётся подходящей Error Boundary.

### Границы по пользовательскому ожиданию
Размещайте fallback вокруг значимой независимой области, сохраняя навигацию и полезный контекст. Общий ресурс может требовать совместного показа, независимые панели - вложенных границ. При подходящем transition или deferred value можно оставить уже показанное содержимое видимым, обозначив его устаревание.

Граница не обязана запускать запрос раньше и не устраняет waterfall сама по себе. [Расположение loading-границы в Next.js](/questions/next-loading-streaming) - применение этого контракта во фреймворке. [React: Suspense](https://react.dev/reference/react/Suspense).
