**Wildcard-маршрут может показать fallback для пути, который не сопоставился с известными маршрутами.**

<!-- wishu:answer-block -->

#### Как это работает

Вложенный fallback относится к своей области маршрутов. В SPA такой экран сам по себе не меняет уже полученный HTTP-статус документа; для настоящего серверного 404 нужен серверный механизм.

#### Пример

```jsx
<Routes>
  <Route path="/tasks" element={<Tasks />} />
  <Route path="*" element={<NotFound />} />
</Routes>
```

#### Разбор примера

Wildcard выбирает NotFound после отсутствия известного клиентского совпадения. Уже полученный index.html мог иметь HTTP 200, и React не меняет этот прошлый ответ. Для серверного статуса нужно обрабатывать запрос в соответствующей серверной архитектуре.

#### Типичная ошибка

Считать клиентский экран 404 доказательством HTTP-статуса 404 от хостинга.
