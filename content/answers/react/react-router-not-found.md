**Wildcard-маршрут может показать fallback для пути, который не сопоставился с известными маршрутами.**

<!-- wishu:answer-block -->

### Механизм и границы

- Вложенный fallback относится к своей области маршрутов.

- В SPA такой экран сам по себе не меняет уже полученный HTTP-статус документа; для настоящего серверного 404 нужен серверный механизм.

### Пример

```jsx
<Routes>
  <Route path="/tasks" element={<Tasks />} />
  <Route path="*" element={<NotFound />} />
</Routes>
```

### Типичная ошибка

Считать клиентский экран 404 доказательством HTTP-статуса 404 от хостинга.
