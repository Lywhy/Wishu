**React сравнивает следующее значение state с текущим через `Object.is` и может пропустить обновление при равенстве.**

<!-- wishu:answer-block -->

### Механизм и границы

- Мутация объекта с последующей передачей той же ссылки не сообщает о новом снимке.

- React иногда может вызвать компонент перед пропуском потомков; не стройте корректность на точном числе вызовов функции.

### Пример

```jsx
setUser((previous) => ({ ...previous, name: "Анна" }))
// Новый объект, а не user.name = 'Анна'; setUser(user).
```

### Типичная ошибка

Менять объект на месте и считать setter командой принудительной перерисовки.
