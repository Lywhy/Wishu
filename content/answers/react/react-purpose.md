**React - библиотека для построения интерфейсов из компонентов.** Компонент описывает, что должно быть показано при текущих props и state. После обновления данных React вычисляет новое представление и применяет необходимые изменения к среде отображения.

<!-- wishu:answer-block -->

- При декларативном подходе мы описываем желаемый результат, например открытый диалог, вместо последовательности команд поиска и изменения DOM. React сам по себе не задаёт маршрутизацию, хранение серверных данных или архитектуру backend.
