Подтверждённая запись и редактируемый черновик имеют разных владельцев и сроки жизни. Новые props не должны автоматически затирать несохранённый ввод без выбранной политики.

<!-- wishu:answer-block -->

Определите базовую ревизию, признак изменений и действия при внешнем обновлении: сохранить draft, предложить перезагрузить или выполнить предметное слияние. При смене сущности key может осмысленно сбросить локальную форму, но при обновлении той же записи это может уничтожить работу.

После успешной отправки согласуйте draft с принятой версией. Ошибка сети должна оставить введённое значение. Проверка конфликтов параллельного редактирования окончательно решается серверным контрактом, а не одним React state.
