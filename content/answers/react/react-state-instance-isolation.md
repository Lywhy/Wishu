**Два узла одного типа компонента имеют разные позиции в дереве и отдельные ячейки state.**

<!-- wishu:answer-block -->

### Механизм и границы

- Общая функция компонента не делает её экземпляры общим хранилищем.

- Чтобы счётчики отражали одно значение, поднимите состояние к общему владельцу и передайте props. Импортированная глобальная переменная имеет другой срок жизни.

### Пример

```jsx
return (
  <>
    <Counter />
    <Counter />
  </>
)
// Изменение первого локального count не меняет второй.
```

### Типичная ошибка

Считать имя компонента ключом единственного общего состояния.
