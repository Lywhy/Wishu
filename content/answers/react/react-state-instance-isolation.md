**Два узла одного типа компонента имеют разные позиции в дереве и отдельные ячейки state.**

<!-- wishu:answer-block -->

#### Как это работает

Общая функция компонента не делает её экземпляры общим хранилищем. Чтобы счётчики отражали одно значение, поднимите состояние к общему владельцу и передайте props. Импортированная глобальная переменная имеет другой срок жизни.

#### Пример

```jsx
return (
  <>
    <Counter />
    <Counter />
  </>
)
// Изменение первого локального count не меняет второй.
```

#### Разбор примера

Оба Counter используют одну функцию компонента, но React связывает их state с разными позициями. Нажатие первого изменяет только его локальное значение. Общий счётчик требует общего владельца, а не совпадающего имени хука или компонента.

#### Типичная ошибка

Считать имя компонента ключом единственного общего состояния.
