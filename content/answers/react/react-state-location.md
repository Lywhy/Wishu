**Props делают зависимости явными и подходят для близких компонентов.** Context удобен для данных, нужных в разных ветвях, например темы или текущего пользователя. Он передаёт значение, но сам не задаёт стратегию обновлений или кеширования.

- Внешний store полезен при сложных общих переходах и подписках на отдельные части данных. Серверные данные дополнительно требуют кеша, повторных запросов и инвалидирования. Выбор начинают с владельца и жизненного цикла данных, а не с помещения всего состояния в глобальное хранилище.
