**Location.state - состояние записи клиентской истории, а не общедоступная часть URL и не долговечная серверная запись.**

<!-- wishu:answer-block -->

### Механизм и границы

- Его можно использовать для контекста перехода, но прямое открытие ссылки или новый пользователь не обязаны иметь этот контекст.

- Не храните там единственный ID, без которого страницу невозможно восстановить. Секреты также не становятся защищёнными из-за отсутствия в адресной строке.

### Пример

```jsx
<Link to="/questions/42" state={{ returnTo: "/session" }}>
  Открыть
</Link>
// Без state страница всё равно должна уметь показать вопрос 42.
```

### Типичная ошибка

Требовать location.state для любой прямой ссылки и ломать обновление или внешнюю навигацию.
