**Location.state - состояние записи клиентской истории, а не общедоступная часть URL и не долговечная серверная запись.**

<!-- wishu:answer-block -->

#### Как это работает

Его можно использовать для контекста перехода, но прямое открытие ссылки или новый пользователь не обязаны иметь этот контекст. Не храните там единственный ID, без которого страницу невозможно восстановить. Секреты также не становятся защищёнными из-за отсутствия в адресной строке.

#### Пример

```jsx
<Link to="/questions/42" state={{ returnTo: "/session" }}>
  Открыть
</Link>
// Без state страница всё равно должна уметь показать вопрос 42.
```

#### Разбор примера

ReturnTo помогает вернуться в контекст подборки, но сам вопрос определяется путём /questions/42. Поэтому прямое открытие остаётся работоспособным без state. Состояние истории не является общедоступной частью скопированной ссылки и не служит границей секретности.

#### Типичная ошибка

Требовать location.state для любой прямой ссылки и ломать обновление или внешнюю навигацию.
