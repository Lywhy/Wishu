**State провайдера живёт столько, сколько сохраняется его идентичность в дереве маршрутов.**

<!-- wishu:answer-block -->

### Механизм и границы

- Layout над дочерними страницами может сохранять данные при переходе между ними; провайдер внутри сменяемой страницы может пересоздаваться.

- Поднятие слишком высоко сохраняет и то, что должно завершаться: например, приватную сессию при logout. Выберите scope по данным, не только по удобству доступа.

### Пример

```jsx
<ProjectProvider key={projectId}>
  <ProjectLayout />
</ProjectProvider>
// Смена проекта намеренно завершает прежний scope.
```

### Типичная ошибка

Постоянно менять key провайдера либо хранить пользовательское состояние бесконечно в корне.
