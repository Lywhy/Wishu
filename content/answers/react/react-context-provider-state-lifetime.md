**State провайдера живёт столько, сколько сохраняется его идентичность в дереве маршрутов.**

#### Как это работает

Layout над дочерними страницами может сохранять данные при переходе между ними; провайдер внутри сменяемой страницы может пересоздаваться. Поднятие слишком высоко сохраняет и то, что должно завершаться: например, приватную сессию при logout. Выберите scope по данным, не только по удобству доступа.

#### Пример

```jsx
<ProjectProvider key={projectId}>
  <ProjectLayout />
</ProjectProvider>
// Смена проекта намеренно завершает прежний scope.
```

#### Разбор примера

ProjectId определяет время жизни ProjectProvider. При смене проекта прежний scope намеренно завершается, а переход между его дочерними страницами может сохранять данные. Использование постоянно меняющейся версии в key уничтожало бы состояние слишком часто.

#### Типичная ошибка

Постоянно менять key провайдера либо хранить пользовательское состояние бесконечно в корне.
