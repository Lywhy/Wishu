**Data Router координирует конкурирующие навигации и может отменить устаревшее клиентское ожидание, но сервер мог уже начать обработку запроса.**

<!-- wishu:answer-block -->

#### Как это работает

Loader должен передавать request.signal поддерживающей сети; произвольный fetch без signal не получает отмену сам. Отмена клиентского запроса не гарантирует отмену серверной мутации. Для важных записей нужны серверная версия, идемпотентность или другой предметный протокол.

Отличайте выбор актуального UI от гарантии порядка операций на сервере.

#### Пример

```jsx
async function loader({ request, params }) {
  const response = await fetch("/api/users/" + params.id, { signal: request.signal })
  if (!response.ok) throw response
  return response.json()
}
```

#### Разбор примера

Signal передаётся из навигационного request в fetch, чтобы внешний запрос участвовал в отмене. Проверка response.ok отдельно обрабатывает HTTP-ошибку. Это согласует актуальность клиентского экрана, но не откатывает уже обработанное сервером действие.

#### Типичная ошибка

Считать, что новый переход гарантированно остановил прежний POST на сервере.
