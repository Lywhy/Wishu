**Повторная загрузка должна различать начальную пустоту и обновление уже полезных данных, сохраняя понятный путь восстановления.**

<!-- wishu:answer-block -->

### Механизм и границы

- Можно оставить последний успешный результат и отдельно показать refresh-error.

- Новая попытка получает собственную идентичность запроса. Устаревший отказ не должен перезаписать успех новой попытки; кнопка retry не должна молча стирать пользовательские фильтры.

### Пример

```jsx
const refreshing = status === "pending" && data !== null
return (
  <>
    <Results rows={data ?? []} />
    {refreshError && <Retry onClick={reload} />}
  </>
)
```

### Типичная ошибка

Сбрасывать весь экран до пустоты при каждом retry или применять позднюю ошибку прежней попытки.
