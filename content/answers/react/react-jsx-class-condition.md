**`className` должен получить готовую строку; условные части удобно явно собирать из нужных имён классов.**

#### Как это работает

Логическое выражение внутри шаблонной строки может превратить false в текст. Для простого случая подходит тернарный оператор; для нескольких классов - принятая в проекте функция объединения. Это не меняет существование DOM-элемента.

#### Пример

```jsx
const className = ["card", selected ? "selected" : null].filter(Boolean).join(" ")
return <div className={className} />
```

#### Разбор примера

Массив включает selected только при истинном условии, после чего filter удаляет отсутствующий фрагмент. Join получает только реальные имена классов. Это меняет оформление существующего div, но не управляет его размонтированием и не сбрасывает состояние вложенных компонентов.

#### Типичная ошибка

Написать строковую интерполяцию логического && и получить ненужный класс false.
