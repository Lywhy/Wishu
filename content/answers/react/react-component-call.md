**`<Panel />` передаёт React описание компонента, а `Panel()` немедленно вызывает JavaScript-функцию.** При прямом вызове React не получает отдельную границу компонента и его хуки оказываются частью вызова текущего родителя.

<!-- wishu:answer-block -->

### Как это работает

- React должен управлять вызовами компонентов, чтобы связывать с ними состояние, идентичность и диагностику.

- Условный вызов функции с хуками способен нарушить порядок хуков родителя. То, что простой компонент без хуков пока работает как функция, не делает этот шаблон корректной архитектурой.

- Обычные функции форматирования и расчёта вызывать можно. Если функция использует хуки, оформляйте её как пользовательский хук и соблюдайте его правила.

### Пример

```jsx
function Page({ visible }) {
  return visible ? <Panel /> : null
}
function Panel() {
  const [open, setOpen] = useState(false)
  return <button onClick={() => setOpen((v) => !v)}>{String(open)}</button>
}
```

### Типичная ошибка

Вызывать `visible && Panel()` и ожидать, что хуки Panel изолированы от родительского компонента.
