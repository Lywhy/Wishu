**Fragment объединяет несколько элементов в дереве React без дополнительного DOM-узла.** Это полезно, когда лишний div нарушает семантику или влияет на layout.

<!-- wishu:answer-block -->

- Сокращённая форма <>...</> не принимает key. Если один элемент списка состоит из нескольких соседних узлов, используется явный `<Fragment key={id}>`. Правила стабильности ключа остаются такими же, как у обычного элемента списка.
