**Fragment объединяет несколько элементов в дереве React без дополнительного DOM-узла.** Это полезно, когда лишний div нарушает семантику или влияет на layout.

#### Как это работает

Сокращённая форма <>...</> не принимает key. Если один элемент списка состоит из нескольких соседних узлов, используется явный `<Fragment key={id}>`. Правила стабильности ключа остаются такими же, как у обычного элемента списка.

#### Пример

```tsx
import { Fragment } from "react"

function Glossary({ terms }) {
  return (
    <dl>
      {terms.map((term) => (
        <Fragment key={term.id}>
          <dt>{term.name}</dt>
          <dd>{term.description}</dd>
        </Fragment>
      ))}
    </dl>
  )
}
```

#### Разбор примера

Каждая запись terms создаёт пару dt и dd, но ключ относится к общей группе Fragment. В DOM лишнего контейнера не появляется, сохраняя семантику dl. Сокращённая форма фрагмента не подошла бы, поскольку не позволяет записать этот key.

#### Типичная ошибка

> Считать сокращённый <>...</> подходящим для keyed-элемента списка. Для key нужен явный Fragment.
