**Разделяйте эффекты, если они синхронизируют независимые внешние процессы.** Общая зависимость не обязана запускать заново работу, которой это значение не нужно.

<!-- wishu:answer-block -->

### Как это работает

- У соединения с комнатой и заголовка документа разные причины обновления. Изменение темы не должно переподключать чат только потому, что код оказался рядом.

- У каждого эффекта должны быть собственные зависимости и симметричная очистка создаваемых ресурсов.

- Не дробите один процесс искусственно: создание соединения и его disconnect должны оставаться связанными. Критерий разделения - самостоятельный жизненный цикл, а не длина функции.

### Пример

```jsx
useEffect(() => {
  const connection = connect(roomId)
  return () => connection.disconnect()
}, [roomId])
useEffect(() => {
  document.title = title
}, [title])
```

### Типичная ошибка

Собрать несвязанные подписки в одном эффекте, а затем исключать зависимости, чтобы не запускать лишнюю часть.
