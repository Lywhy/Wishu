**Обычный `set` выполняет merge на одном уровне.** Вложенные объекты не сливаются глубоко автоматически; их обновляют с сохранением нужных полей.

<!-- wishu:answer-block -->

#### Как это работает

- Если новое значение зависит от текущего, используйте функцию `set`(state => ...). Для обычного объекта создавайте новые ссылки изменяемых ветвей.
- Set({ profile: { name } }) заменит profile, а не сохранит все его старые поля. Нужно явно включить прежний profile.
- Replace: true заменяет весь state и может удалить функции действий. Не используйте его как сокращение обычного частичного обновления.

#### Пример

```typescript
set((state) => ({
  profile: { ...state.profile, name: nextName },
}))
// Остальные поля profile сохраняются явно.
```

#### Разбор примера

Внешний объект обновления содержит только profile, поэтому остальные верхнеуровневые поля сохраняются благодаря merge. Внутри profile этого автоматизма нет: spread явно переносит его прежние поля и заменяет name. Получаются новые ссылки изменённой ветви, по которым selectors распознают обновление. Прямая запись в прежний profile испортила бы старый снимок даже при последующем вызове set.

#### Типичная ошибка

> Изменить state.profile.name напрямую и считать объект новым из-за вызова set.
