**JSX - расширение синтаксиса JavaScript для описания дерева элементов.** Сборщик преобразует JSX в вызовы JSX runtime. Выражения JavaScript помещаются в фигурные скобки; пользовательские компоненты начинаются с заглавной буквы.

<!-- wishu:answer-block -->

#### Как это работает

Это не HTML-строка: теги закрываются, class записывается как `className`, а обработчик передаётся функцией. Интерполяция строки создаёт текст, а не исполняемую HTML-разметку. dangerouslySetInnerHTML требует отдельно обеспечить доверенность или очистку содержимого.

#### Пример

```tsx
function Welcome({ name, onHello }) {
  return (
    <button className="rounded-lg px-4 py-2" onClick={onHello}>
      {name}
    </button>
  )
}
```

#### Разбор примера

Welcome передаёт onHello как функцию, а name как текстовое содержимое кнопки. Строка `className` управляет оформлением. Эти значения участвуют в обычном JavaScript-вычислении JSX, поэтому вызов обработчика прямо при построении элемента означал бы уже другое поведение.

#### Типичная ошибка

> Воспринимать JSX как HTML-строку и смешивать вставку текста с небезопасной вставкой произвольной HTML-разметки.
