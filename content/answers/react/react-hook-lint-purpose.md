**Проверки хуков помогают сохранить порядок вызовов и корректные реактивные зависимости, а не только единый стиль.**

<!-- wishu:answer-block -->

### Механизм и границы

- Нарушение порядка связывает состояние с неправильным вызовом. Пропущенная зависимость сохраняет устаревшее замыкание.

- Предупреждение исправляют изменением структуры кода. Исключения вроде API use не переносят на обычные хуки.

### Пример

```jsx
// Вместо условного вызова useEffect:
useEffect(() => {
  if (!enabled) return
  return subscribe()
}, [enabled])
```

### Типичная ошибка

Массово отключить правило зависимостей вместо разбора причины повторной синхронизации.
