**Во время render React вызывает компоненты и вычисляет следующее дерево элементов.** Во время commit применяет изменения к DOM и обновляет refs. Повторный вызов компонента сам по себе не означает, что соответствующий DOM-узел изменился.

- Рендер должен быть чистым: без запросов, подписок и изменения внешних данных. React может повторить вычисление или отбросить его результат. Обработчики событий и эффекты дают отдельные места для действий, которые не являются вычислением представления.
