**Во время render React вызывает компоненты и вычисляет следующее дерево элементов.** Во время commit применяет изменения к DOM и обновляет refs. Повторный вызов компонента сам по себе не означает, что соответствующий DOM-узел изменился.

<!-- wishu:answer-block -->

#### Как это работает

Рендер должен быть чистым: без запросов, подписок и изменения внешних данных. React может повторить вычисление или отбросить его результат. Обработчики событий и эффекты дают отдельные места для действий, которые не являются вычислением представления.

#### Пример

```tsx
function Greeting({ name }) {
  return <h1>{name}</h1>
}
// Повторное вычисление с тем же name не требует менять текст DOM.
```

#### Разбор примера

Одинаковое значение name может привести к повторному вычислению Greeting без изменения текста DOM. Поэтому счётчик вызовов функции не является счётчиком реальных изменений страницы. Публиковать внешнее действие на основании самого факта такого вызова нельзя.

#### Типичная ошибка

> Выполнить сетевую запись во время render: попытка вычисления может повториться или не попасть в commit.
