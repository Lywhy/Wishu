**useImperativeHandle задаёт значение, которое родитель получает через ref.** Вместо полного DOM-узла компонент может открыть только необходимые методы, например focus или scrollToEnd, и скрыть устройство внутренней разметки.

- Зависимости должны включать реактивные значения, используемые при создании handle. Для управления открытием диалога обычно понятнее декларативный prop open; императивный API оставляют для действий вроде фокусировки, которые трудно выразить обычными данными.
