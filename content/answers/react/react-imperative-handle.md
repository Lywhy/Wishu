**`useImperativeHandle` задаёт значение, которое родитель получает через ref.** Вместо полного DOM-узла компонент может открыть только необходимые методы, например focus или scrollToEnd, и скрыть устройство внутренней разметки.

<!-- wishu:answer-block -->

#### Как это работает

Зависимости должны включать реактивные значения, используемые при создании handle. Для управления открытием диалога обычно понятнее декларативный prop open; императивный API оставляют для действий вроде фокусировки, которые трудно выразить обычными данными.

#### Пример

```tsx
function SearchField({ ref }) {
  const inputRef = useRef(null)
  useImperativeHandle(ref, () => ({ focus: () => inputRef.current?.focus() }), [])
  return <input ref={inputRef} />
}
```

#### Разбор примера

Родитель получает объект только с focus, а внутренний inputRef остаётся деталями компонента. Метод читает current в момент команды, когда узел уже может существовать. Добавление читаемого state внутрь handle потребовало бы также пересмотреть зависимости его создания.

#### Типичная ошибка

> Раскрыть весь внутренний DOM и состояние вместо небольшого устойчивого API действительно нужных команд.
