**Ref нужен для императивной команды существующему DOM-узлу: установить фокус, прокрутить или измерить его.**

<!-- wishu:answer-block -->

#### Как это работает

State описывает, что показать; вызов focus работает с уже показанным узлом. Не меняйте React-управляемые children через ref ради синхронизации UI. Для условного узла дождитесь commit.

#### Пример

```jsx
function revealSelected() {
  selectedRef.current?.scrollIntoView({ block: "nearest" })
}
```

#### Разбор примера

RevealSelected отправляет команду уже существующему элементу и выбирает ближайшую прокрутку. Выбранная запись должна отдельно присутствовать в декларативном UI. Если она появляется после setter, команду связывают с моментом прикрепления узла.

#### Типичная ошибка

Хранить DOM-узел в state только для вызова команды или пытаться прокрутить ещё не созданный элемент.
