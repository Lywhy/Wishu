**Разные submit-кнопки могут задавать намерение через name/value или через данные submitter; это не требует нескольких несогласованных форм.**

<!-- wishu:answer-block -->

#### Как это работает

`FormData`, созданная только по форме, не обязана включать данные нажатой кнопки. Современный конструктор с submitter учитывает её, но поддерживаемую среду нужно проверить. Для формы React/Router действие задавайте через поддерживаемый контракт; Enter может иметь иной путь выбора submitter.

#### Пример

```jsx
<>
  <button type="submit" name="intent" value="draft">
    Черновик
  </button>
  <button type="submit" name="intent" value="publish">
    Опубликовать
  </button>
</>
```

#### Разбор примера

Обе кнопки отправляют одну форму, но выражают разные intent. Обработчик или Action должен получить именно активный submitter по поддерживаемому контракту. Это позволяет не дублировать всю форму ради черновика и публикации.

#### Типичная ошибка

Читать только `onClick` и терять семантику отправки с клавиатуры.
