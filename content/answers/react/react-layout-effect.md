**`useLayoutEffect` выполняется после изменения DOM, но до следующей отрисовки браузера.** Он нужен, когда измерение узла и корректировка представления должны произойти до того, как пользователь увидит кадр, например при позиционировании подсказки.

#### Как это работает

Его работа и синхронные обновления задерживают отображение, поэтому для подписок и обычной синхронизации предпочтителен `useEffect`. Нельзя полагаться на `useEffect` как на гарантированное событие строго после paint во всех случаях. Эффекты не выполняются при серверном рендеринге.

#### Пример

```tsx
useLayoutEffect(() => {
  const node = tooltipRef.current
  if (node) setHeight(node.getBoundingClientRect().height)
}, [])
// Пример предполагает стабильный узел; геометрия не зависит от height.
```

#### Разбор примера

Высота читается у уже созданного узла, а состояние обновляется до показа соответствующего кадра. Такое измерение может понадобиться для правильной позиции подсказки. Но длительная работа в этом месте задержит отображение, поэтому обычную сетевую подписку сюда не переносят.

#### Типичная ошибка

> Использовать блокирующий layout-effect для любого запроса или синхронизации, которой не нужно завершаться до paint.
