**Размонтирование завершает жизнь дерева и даёт эффектам освободить созданные ресурсы.**

<!-- wishu:answer-block -->

#### Как это работает

Testing Library может подключать автоматический cleanup в поддерживаемой конфигурации; проверьте настройку runner. Очистка DOM не сбрасывает сама глобальные stores, mocks и fake timers. Эти ресурсы изолируют отдельно.

#### Пример

```jsx
afterEach(() => {
  cleanup()
  vi.restoreAllMocks()
})
```

#### Разбор примера

Cleanup завершает React-дерево, а restoreAllMocks восстанавливает подменённые методы. Общий store и режим таймеров не обязаны сброситься этими двумя вызовами. Их жизненный цикл задают отдельно под реальную тестовую инфраструктуру.

#### Типичная ошибка

Считать новый render гарантией пустого общего store или отсутствия старой подписки.
