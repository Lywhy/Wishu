**Локальные эффекты двух компонентов не координируют запросы автоматически; для общего результата нужен общий владелец или кеш с осмысленным ключом.**

<!-- wishu:answer-block -->

#### Как это работает

Ключ должен учитывать все параметры ответа, включая допустимый scope пользователя. Дедупликация одновременного Promise отличается от времени жизни кеша и политики refetch. Не делайте глобальный кеш приватных SSR-данных без изоляции.

#### Пример

```jsx
const key = ["user", accountId, userId]
// Интеграция данных использует этот контракт для общего ресурса.
```

#### Разбор примера

AccountId включён в ключ вместе с userId, поэтому одинаковый локальный ID разных аккаунтов не смешивает данные. Сам массив key ещё не реализует кеш. Его сравнение, время жизни и безопасность определяются используемой интеграцией.

#### Типичная ошибка

Считать совпадение URL достаточным ключом для данных разных аккаунтов.
