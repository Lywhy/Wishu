**Виртуализация пересоздаёт видимые строки при прокрутке, поэтому важные данные строки должны иметь владельца вне временного DOM.**

<!-- wishu:answer-block -->

#### Как это работает

Используйте стабильные ключи данных и храните выбор/черновики по ID. Продумайте фокус и доступную навигацию: элемент с фокусом может уйти за окно. Overscan уменьшает некоторые скачки, но не заменяет контракт состояния и семантику списка.

#### Пример

```jsx
const draftsById = { [editedId]: draft }
// Временная строка читает draftsById[row.id], а не единственную позиционную ячейку.
```

#### Разбор примера

DraftsById связывает ввод с editedId, поэтому строка может исчезнуть из окна и вернуться с тем же черновиком. Текущая позиция прокрутки для этого не подходит. Управление фокусом требует отдельно учитывать реальное отсутствие соответствующего DOM-узла.

#### Типичная ошибка

Хранить незаписанный черновик только в state виртуальной строки и потерять его при прокрутке.
