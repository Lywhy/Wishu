**Булевым атрибутам в JSX передают логические значения.** Например, `disabled={false}` оставляет кнопку доступной; строка `"false"` не эквивалентна логическому `false`.

<!-- wishu:answer-block -->

#### Как это работает

Для нативных boolean props передавайте boolean. Само наличие disabled в JSX означает true. Это правило не следует переносить на aria-* автоматически: ARIA имеет собственные строковые значения, например aria-expanded="false".

#### Пример

```jsx
<>
  <button disabled={saving}>Сохранить</button>
  <button disabled={false}>Доступна</button>
</>
```

#### Разбор примера

Saving передаётся как boolean и действительно управляет недоступностью первой кнопки. Вторая явно получает false и остаётся доступной. Преобразование false в строку изменило бы смысл prop, поэтому визуально похожий текст не заменяет правильный тип значения.

#### Типичная ошибка

Преобразовать boolean через String и передать результат в disabled.
