**Для изменения одной записи верните новый массив, заменив объект только у совпавшего ID.**

<!-- wishu:answer-block -->

### Механизм и границы

- Map сохраняет порядок и позволяет оставить неизменённые записи с прежними ссылками.

- Копирование массива через spread не копирует вложенные объекты: изменение row.name всё ещё мутирует прежний снимок.

### Пример

```jsx
setRows((previous) =>
  previous.map((row) => (row.id === editedId ? { ...row, name: nextName } : row)),
)
```

### Типичная ошибка

Скопировать только массив, а затем изменить объект, который остался общим с прежним state.
