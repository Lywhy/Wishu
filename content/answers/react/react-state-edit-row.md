**Для изменения одной записи верните новый массив, заменив объект только у совпавшего ID.**

<!-- wishu:answer-block -->

#### Как это работает

Map сохраняет порядок и позволяет оставить неизменённые записи с прежними ссылками. Копирование массива через spread не копирует вложенные объекты: изменение row.name всё ещё мутирует прежний снимок.

#### Пример

```jsx
setRows((previous) =>
  previous.map((row) => (row.id === editedId ? { ...row, name: nextName } : row)),
)
```

#### Разбор примера

Map сохраняет позицию каждой записи, заменяя лишь совпавший объект. Spread внутри этой ветви нужен отдельно от копирования массива. Для изменения вложенного поля пришлось бы также заменить соответствующий внутренний объект.

#### Типичная ошибка

Скопировать только массив, а затем изменить объект, который остался общим с прежним state.
