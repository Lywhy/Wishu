**`useState`(createInitialValue) передаёт функцию-инициализатор, которую React использует при создании состояния.** Вариант `useState`(createInitialValue()) вычисляет вызов при каждом рендере, хотя новое начальное значение после первого рендера игнорируется.

<!-- wishu:answer-block -->

- Инициализатор должен быть чистым; StrictMode в разработке может вызвать его повторно. Новые props сами по себе не переинициализируют state. Для сброса по смене сущности можно использовать key, если нужно пересоздать всё локальное состояние.
