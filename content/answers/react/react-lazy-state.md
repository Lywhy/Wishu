**`useState`(createInitialValue) передаёт функцию-инициализатор, которую React использует при создании состояния.** Вариант `useState`(createInitialValue()) вычисляет вызов при каждом рендере, хотя новое начальное значение после первого рендера игнорируется.

<!-- wishu:answer-block -->

#### Как это работает

Инициализатор должен быть чистым; StrictMode в разработке может вызвать его повторно. Новые props сами по себе не переинициализируют state. Для сброса по смене сущности можно использовать key, если нужно пересоздать всё локальное состояние.

#### Пример

```tsx
const [rows, setRows] = useState(() =>
  Array.from({ length: 1000 }, (_, id) => ({ id, selected: false })),
)
```

#### Разбор примера

Функция создаёт тысячу строк при инициализации конкретной ячейки состояния. Её чистота позволяет безопасно повторить вычисление при проверках разработки. После mount новые входные props не станут автоматически новыми `rows`: сброс требует отдельного намерения.

#### Типичная ошибка

> Передать buildInitialState() и выполнять дорогой расчёт при каждом render, хотя результат нужен только для инициализации.
