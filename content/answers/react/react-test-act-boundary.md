**act помогает применить связанные с действием обновления React перед проверкой результата.** Предупреждение часто означает, что тест завершил ожидание раньше наблюдаемого изменения.

<!-- wishu:answer-block -->

### Как это работает

- Testing Library оборачивает многие стандартные операции в act. Обычно сначала нужен корректный await пользовательского действия или `findBy`, а не дополнительная обёртка вокруг каждой строки.

- Для ручного вызова внешней подписки или продвижения таймера, вызывающего state update, может понадобиться явный await act.

- act не ожидает всю будущую сеть и не исправляет неправильный cleanup. Проверяйте наблюдаемый результат и не скрывайте console.error ради зелёного отчёта.

### Пример

```jsx
await act(async () => {
  externalSource.emit({ connected: true })
})
expect(screen.getByText("Подключено")).toBeVisible()
// externalSource - управляемая тестовая подписка.
```

### Типичная ошибка

Подавить warning без ожидания результата или оборачивать только assertion вместо действия, вызывающего обновление.
