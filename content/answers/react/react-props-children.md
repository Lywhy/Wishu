**Props передают данные от родителя ребёнку.** Для принимающего компонента это доступный только для чтения снимок входа: нельзя изменять props или вложенные объекты, принадлежащие родителю. Для изменения данных ребёнок вызывает переданный callback.

- children содержит вложенное содержимое JSX. Благодаря ему контейнер может отвечать за оформление, а вызывающий компонент - за содержимое. Значения по умолчанию через деструктуризацию применяются при `undefined`, но не при `null`.
