**Props передают данные от родителя ребёнку.** Для принимающего компонента это доступный только для чтения снимок входа: нельзя изменять props или вложенные объекты, принадлежащие родителю. Для изменения данных ребёнок вызывает переданный callback.

<!-- wishu:answer-block -->

#### Как это работает

children содержит вложенное содержимое JSX. Благодаря ему контейнер может отвечать за оформление, а вызывающий компонент - за содержимое. Значения по умолчанию через деструктуризацию применяются при `undefined`, но не при `null`.

#### Пример

```tsx
function Panel({ title = "Раздел", children }) {
  return (
    <section>
      <h2>{title}</h2>
      {children}
    </section>
  )
}
```

#### Разбор примера

Panel определяет рамку и заголовок, а children оставляет вызывающему коду выбор содержимого. Пропущенный title получит «Раздел», но явный null default не активирует. Компонент не должен менять полученные данные, чтобы сообщить родителю об изменении.

#### Типичная ошибка

> Изменять переданный объект props внутри потомка и создавать скрытый второй источник состояния.
