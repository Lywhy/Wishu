**NavLink нужен, когда ссылка должна отражать активность маршрута; Link выполняет обычный клиентский переход.**

<!-- wishu:answer-block -->

#### Как это работает

Состояние isActive можно использовать для оформления и доступного обозначения текущей области. Для корневой ссылки подумайте о точном совпадении через end, чтобы она не выглядела активной для всех вложенных путей.

#### Пример

```jsx
<NavLink to="/tasks" end className={({ isActive }) => (isActive ? "active" : "")}>
  Задачи
</NavLink>
```

#### Разбор примера

NavLink вычисляет isActive по совпадению маршрута, а end ограничивает пример точным путём tasks. При переходе в дочернюю задачу такое решение может снять выделение. Если меню должно оставаться активным для всего раздела, контракт активности выбирают иначе.

#### Типичная ошибка

Сравнивать только строковые префиксы вручную и ошибаться на похожих именах путей.
