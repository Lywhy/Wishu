**NavLink нужен, когда ссылка должна отражать активность маршрута; Link выполняет обычный клиентский переход.**

<!-- wishu:answer-block -->

### Механизм и границы

- Состояние isActive можно использовать для оформления и доступного обозначения текущей области.

- Для корневой ссылки подумайте о точном совпадении через end, чтобы она не выглядела активной для всех вложенных путей.

### Пример

```jsx
<NavLink to="/tasks" end className={({ isActive }) => (isActive ? "active" : "")}>
  Задачи
</NavLink>
```

### Типичная ошибка

Сравнивать только строковые префиксы вручную и ошибаться на похожих именах путей.
