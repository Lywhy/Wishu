**React сравнивает старое и новое value провайдера через `Object.is`.** При изменении значения компоненты, читающие этот Context, получают обновление. memo не блокирует доставку нового контекста компоненту-потребителю.

<!-- wishu:answer-block -->

#### Как это работает

Новый объект value={{ user, logout }} на каждом рендере может вызывать обновления даже при неизменных данных. При подтверждённой проблеме стабилизируют объект и callback, разделяют независимые контексты или используют store с выборочной подпиской. Это не отменяет рендеры, вызванные другими причинами.

#### Пример

```tsx
const value = useMemo(() => ({ user, logout }), [user, logout])
return <SessionContext.Provider value={value}>{children}</SessionContext.Provider>
```

#### Разбор примера

Memoизированный объект сохраняет ссылку, пока user и logout не меняются. Это устраняет обновление Context из-за одного лишь нового литерала. Сам logout тоже должен иметь осмысленную стабильность; memo потребителя не блокирует настоящее изменение прочитанного контекста.

#### Типичная ошибка

> Обернуть потребителя в memo и ожидать, что это заблокирует обновление прочитанного Context.
