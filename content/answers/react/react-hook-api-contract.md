**Пользовательский хук возвращает обычное значение JavaScript: объект удобен для именованных полей, кортеж - для компактного устойчивого набора.**

<!-- wishu:answer-block -->

#### Как это работает

Не возвращайте каждый внутренний setter, если потребителю достаточно команды. Независимые вызовы хука не разделяют локальное состояние автоматически; возвращаемый объект не является отдельным store.

#### Пример

```jsx
function useToggle(initial = false) {
  const [value, setValue] = useState(initial)
  const toggle = () => setValue((previous) => !previous)
  return { value, toggle }
}
```

#### Разбор примера

Объект с value и toggle позволяет потребителю обращаться к понятным именам. Внутренний setter скрыт, поэтому хук сам определяет допустимое действие. Если toggle понадобится как зависимость другой синхронизации, стабильность возвращаемой функции следует спроектировать отдельно.

#### Типичная ошибка

Заставить потребителя знать порядок десяти элементов массива или менять внутреннее состояние без правил хука.
