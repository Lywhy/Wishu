React cache создаёт мемоизированную функцию для Server Components и позволяет разделять результат при совпадающих аргументах в соответствующем серверном контексте. Это не браузерный hook и не универсальный кеш между запросами.

<!-- wishu:answer-block -->

Создавайте обёртку один раз и переиспользуйте её, а не вызывайте cache заново в каждом компоненте. Аргументы сравниваются по правилам идентичности, поэтому новый объект параметров может означать другой ключ. Ошибка вычисления тоже может кешироваться в данном контексте.

UseMemo связан с вычислениями конкретного экземпляра компонента при рендере, а долговременный кеш данных требует отдельной стратегии и инвалидирования. Обычный Vite SPA не получает RSC-контекст от одного импорта cache.

<!-- wishu:answer-block -->

React инвалидирует кеш мемоизированных функций для каждого серверного запроса. Долговременное хранение и межзапросное кеширование - другой контракт.
