**Для выбора интерфейса используют обычные условия JavaScript, тернарный оператор и &&.** `null`, `undefined` и boolean не создают видимый текст. Число 0 при этом отображается, поэтому выражение count && `<List />` при нулевом count выведет 0.

<!-- wishu:answer-block -->

#### Как это работает

Лучше явно выражать условие: count > 0 && `<List />`. Возврат `null` скрывает содержимое компонента, но не удаляет сам компонент из дерева родителя и не является универсальным способом сбросить его состояние.

#### Пример

```tsx
function Results({ count }) {
  return count > 0 ? <p>Найдено: {count}</p> : <p>Ничего не найдено</p>
}
```

#### Разбор примера

Results явно выбирает одну из двух ветвей по сравнению `count > 0`. При нуле отображается понятное пустое состояние, а не число 0 от логического &&. Выбор содержимого не следует путать с идентичностью самого компонента и временем жизни его состояния.

#### Типичная ошибка

> Использовать `count && <List />` и неожиданно вывести 0. Для числового условия нужен явный boolean, например count > 0.
