**Провайдер передаёт значение только своему поддереву, а соседний компонент находится вне этой области.**

<!-- wishu:answer-block -->

#### Как это работает

Провайдер, возвращённый самим компонентом, также не меняет значение `useContext`, вызванного выше внутри этого же компонента. Поднимите провайдер над всеми нужными потребителями либо явно передайте данные.

#### Пример

```jsx
return (
  <>
    <User.Provider value={user}>
      <Profile />
    </User.Provider>
    <Toolbar />
  </>
)
// Toolbar не получает user от этого провайдера.
```

#### Разбор примера

Profile является потомком User.Provider, а Toolbar соседним узлом вне его области. Для общей сессии провайдер нужно поднять над обеими ветвями. Добавление вызова createContext в Toolbar не подключило бы его к прежнему объекту Context.

#### Типичная ошибка

Искать провайдер ниже вызова `useContext` или в соседней ветке.
