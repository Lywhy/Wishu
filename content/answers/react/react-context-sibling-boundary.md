**Провайдер передаёт значение только своему поддереву, а соседний компонент находится вне этой области.**

<!-- wishu:answer-block -->

### Механизм и границы

- Провайдер, возвращённый самим компонентом, также не меняет значение `useContext`, вызванного выше внутри этого же компонента.

- Поднимите провайдер над всеми нужными потребителями либо явно передайте данные.

### Пример

```jsx
return (
  <>
    <User.Provider value={user}>
      <Profile />
    </User.Provider>
    <Toolbar />
  </>
)
// Toolbar не получает user от этого провайдера.
```

### Типичная ошибка

Искать провайдер ниже вызова `useContext` или в соседней ветке.
