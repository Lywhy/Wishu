**Состояние рассматривается как неизменяемый снимок.** Изменение существующего объекта ломает предыдущие снимки; передача той же ссылки setter может быть пропущена по `Object.is`. Вместо мутации создают новое значение.

- Spread копирует только один уровень, поэтому для вложенного изменения копируется каждый объект по пути к полю. Для массива удобны map, filter и немутирующие методы. Иммутабельность нужна также для корректной работы мемоизации и отладки.
