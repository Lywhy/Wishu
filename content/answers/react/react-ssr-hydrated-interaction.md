**Серверный HTML делает содержимое видимым, а гидратация подключает к нему React-поведение и состояние.**

<!-- wishu:answer-block -->

### Механизм и границы

- Нативная ссылка может работать и без React, тогда как onClick-кнопка требует подключения обработчика.

- Видимость не доказывает готовность интерактивности. Первый клиентский вывод должен согласовываться с серверным.

### Пример

```jsx
hydrateRoot(container, <App initialData={data} />)
// initialData должна соответствовать серверному HTML.
```

### Типичная ошибка

Считать появление HTML моментом завершения клиентской инициализации.
