**Серверный HTML делает содержимое видимым, а гидратация подключает к нему React-поведение и состояние.**

<!-- wishu:answer-block -->

#### Как это работает

Нативная ссылка может работать и без React, тогда как `onClick`-кнопка требует подключения обработчика. Видимость не доказывает готовность интерактивности. Первый клиентский вывод должен согласовываться с серверным.

#### Пример

```jsx
hydrateRoot(container, <App initialData={data} />)
// initialData должна соответствовать серверному HTML.
```

#### Разбор примера

`initialData` должен воспроизвести уже показанную разметку, после чего React подключает соответствующее поведение. Наличие красивой кнопки в HTML ещё не доказывает готовность её onClick. Нативные ссылки и формы при этом имеют собственное браузерное поведение.

#### Типичная ошибка

Считать появление HTML моментом завершения клиентской инициализации.
