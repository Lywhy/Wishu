**Для независимых React-корней identifierPrefix помогает разделить генерируемые `useId`, а при гидратации prefix должен совпадать с серверным.**

<!-- wishu:answer-block -->

#### Как это работает

Внутри каждого корня также должно совпадать исходное дерево. Префикс не исправляет случайное ветвление клиента и сервера и не заменяет ID данных. Два отдельных root без согласованной стратегии могут конфликтовать в общем документе.

#### Пример

```jsx
hydrateRoot(container, <Widget />, { identifierPrefix: "sidebar-" })
// Сервер для этого дерева использует тот же identifierPrefix.
```

#### Разбор примера

Префикс sidebar- должен использоваться и при серверном создании этого дерева. Он разделяет пространство `useId` соседних корней. Даже одинаковый prefix не исправит разные условные ветви и порядок элементов между первым серверным и клиентским render.

#### Типичная ошибка

Раздать разные prefix на сервере и клиенте и ожидать, что `useId` автоматически сопоставит значения.
