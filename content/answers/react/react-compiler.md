**React Compiler анализирует компоненты и хуки при сборке и автоматически мемоизирует подходящие вычисления, функции и представление.** Это уменьшает необходимость вручную добавлять memo, `useMemo` и `useCallback`.

<!-- wishu:answer-block -->

#### Как это работает

Компилятор должен быть подключён в сборку; одного обновления пакета React недостаточно. Он опирается на чистоту рендера и правила хуков, не исправляет неверные зависимости и не устраняет сетевые задержки или чрезмерный объём DOM автоматически. Если оптимизация пропущена, сначала изучают причину и корректность кода.

#### Пример

```tsx
function Totals({ rows }) {
  const total = rows.reduce((sum, row) => sum + row.price, 0)
  return <output>{total}</output>
}
// Compiler должен быть отдельно подключён к сборке.
```

#### Разбор примера

Visible остаётся обычным чистым вычислением, из которого compiler может построить оптимизированный код. Результат зависит от реально подключённого преобразования. Если его нет, пример всё равно корректен: оптимизация не должна становиться условием правильного состояния.

#### Типичная ошибка

> Полагаться на оптимизацию для корректности логики или считать compiler подключённым просто из-за установки React.
