**Если Suspense вынужден скрыть уже показанный контент, React очищает layout-эффекты скрываемого дерева и запускает их снова при показе.**

<!-- wishu:answer-block -->

### Механизм и границы

- Это позволяет измеряющей логике не считать скрытый DOM нормальным видимым состоянием.

- Cleanup должен освобождать наблюдатели и связанные интеграции; повторный setup не обязан означать потерю всей бизнес-модели компонента.

- Transition/deferred могут сохранить показанное содержимое в подходящем сценарии, но не отменяют необходимость корректного жизненного цикла эффекта.

### Пример

```jsx
useLayoutEffect(() => {
  const subscription = observeVisibleLayout(nodeRef.current)
  return () => subscription.disconnect()
}, [])
// Setup и cleanup должны выдерживать повторное подключение.
```

### Типичная ошибка

Считать [] обещанием единственного setup и оставлять измерительную подписку после скрытия дерева.
