**Фигурные скобки JSX принимают выражение, которое вычисляет значение, а if и for являются инструкциями.**

<!-- wishu:answer-block -->

#### Как это работает

Условие можно вынести до return или выразить тернарным оператором. Для списка обычно используют map. Произвольное количество инструкций поместите в обычную функцию; не превращайте сложный JSX в нечитаемую цепочку условий.

#### Пример

```jsx
const content = error ? <ErrorMessage /> : <Results />
return <main>{content}</main>
```

#### Разбор примера

Content вычисляется до return обычным выражением с двумя вариантами. JSX затем подставляет готовое описание в main. Если выбор требует нескольких шагов и инструкций, их можно оставить в теле функции, сохранив само представление читаемым.

#### Типичная ошибка

Пытаться написать {if (ready) ...} непосредственно как содержимое JSX.
