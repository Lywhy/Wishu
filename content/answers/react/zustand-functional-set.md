**Функциональный set нужен, когда новое значение вычисляется из актуального предыдущего снимка, особенно при переиспользуемом action.**

<!-- wishu:answer-block -->

#### Как это работает

Объектный set подходит для уже известного значения. Не изменяйте прежний снимок внутри updater без immer middleware. Совпадение синтаксиса с React-setter не означает одинаковые правила merge.

#### Пример

```jsx
const configuration = {
  increment: () => set((state) => ({ count: state.count + 1 })),
}
```

#### Разбор примера

Updater получает актуальный снимок в момент set и вычисляет следующий count. Два последовательных вызова increment поэтому увеличат значение дважды, не опираясь на захваченную старую переменную. Если новое значение уже известно, например выбранная тема, объектной формы set достаточно. Обычный Zustand объединяет результат на верхнем уровне, но вложенные объекты и массивы всё равно требуют новых ссылок.

#### Типичная ошибка

Захватить count один раз вне action и постоянно прибавлять к устаревшему значению.
