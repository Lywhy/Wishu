**Outlet обозначает место дочернего совпавшего маршрута внутри layout.**

<!-- wishu:answer-block -->

#### Как это работает

Родитель может показывать общую навигацию, а дочерний маршрут - содержимое этой области. Наличие вложенного Route без Outlet не заставляет React автоматически вставить его рядом с JSX родителя.

#### Пример

```jsx
function Layout() {
  return (
    <>
      <Header />
      <Outlet />
    </>
  )
}
;<Route element={<Layout />}>
  <Route path="tasks" element={<Tasks />} />
</Route>
```

#### Разбор примера

Layout сохраняет Header и выделяет место для Tasks через Outlet. Вложенная запись Route описывает соответствие, но сама не выбирает позицию DOM-вставки. Без Outlet общая оболочка могла бы отображаться, оставляя дочерний экран невидимым.

#### Типичная ошибка

Не добавить Outlet и искать причину отсутствия страницы в загрузке данных.
