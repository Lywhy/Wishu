**В callback map с телом в фигурных скобках нужен явный return; иначе получится массив undefined.**

<!-- wishu:answer-block -->

#### Как это работает

Круглые скобки после стрелки позволяют неявно вернуть JSX-выражение. key нужен непосредственному элементу результата, но добавление key не исправляет отсутствующий return.

#### Пример

```jsx
return items.map((item) => <li key={item.id}>{item.title}</li>)
```

#### Разбор примера

Краткое тело стрелки сразу возвращает li для каждого item. При блочном теле тот же JSX потребовал бы return. Если callback вернёт undefined, корректные ключи не помогут: в результате вообще не будет описаний строк для отображения.

#### Типичная ошибка

Написать item => { `<li />` } и ожидать, что JSX будет возвращён автоматически.
