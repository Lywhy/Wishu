**React Compiler может автоматически мемоизировать часть корректного кода, поэтому ручную мемоизацию оценивают с учётом реальной сборки и измерений.**

<!-- wishu:answer-block -->

#### Как это работает

Сначала убедитесь, что compiler включён для нужного участка и не пропускает его из-за нарушения правил. Ручные `useMemo`/`useCallback` могут оставаться полезными на границе API или в непокрытом коде, но не должны служить гарантией корректности хранения ресурса.

Сравнивайте один сценарий до/после; не удаляйте всю мемоизацию механически. Версия компилятора, конфигурация и совместимость библиотеки являются условиями результата.

#### Пример

```jsx
// Сначала проверяют работу compiler и измерения.
const visible = items.filter((item) => item.enabled)
// Не добавляют useMemo автоматически к каждой строке.
```

#### Разбор примера

Фильтрация показана без обязательного `useMemo`, поскольку активный compiler может оптимизировать подходящий участок. Но этот факт подтверждают конфигурацией и измерением. Удаление всех ручных границ без проверки библиотечных контрактов может изменить стоимость и ожидаемую идентичность входов.

#### Типичная ошибка

Считать наличие пакета compiler доказательством оптимизации любого компонента и внешнего callback-контракта.
