**useFormStatus читает статус отправки ближайшей родительской формы.** Форма, которую возвращает сам компонент с этим хуком, не является его родителем в дереве, поэтому её статус так не получить. Кнопку с хуком выносят в дочерний компонент внутри формы.

- pending полезен для блокировки повторной отправки и индикации ожидания при работе с form Actions. Хук не отслеживает произвольный fetch из любого обработчика: источник статуса должен соответствовать поддерживаемой отправке формы.
