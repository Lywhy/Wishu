**`useFormStatus` читает статус отправки ближайшей родительской формы.** Форма, которую возвращает сам компонент с этим хуком, не является его родителем в дереве, поэтому её статус так не получить. Кнопку с хуком выносят в дочерний компонент внутри формы.

<!-- wishu:answer-block -->

#### Как это работает

pending полезен для блокировки повторной отправки и индикации ожидания при работе с form Actions. Хук не отслеживает произвольный fetch из любого обработчика: источник статуса должен соответствовать поддерживаемой отправке формы.

#### Пример

```tsx
import { useFormStatus } from "react-dom"

function SubmitButton() {
  const { pending } = useFormStatus()
  return (
    <button type="submit" disabled={pending}>
      {pending ? "Отправка..." : "Отправить"}
    </button>
  )
}
// Использование: <form action={saveAction}><SubmitButton /></form>
```

#### Разбор примера

SubmitButton находится ниже формы с Action и поэтому читает её pending. Если вызвать хук в компоненте, который лишь возвращает эту форму, нужного предка ещё нет. Произвольный fetch по `onClick` не становится такой отправкой автоматически.

#### Типичная ошибка

> Вызвать `useFormStatus` в компоненте, который сам возвращает form, и ожидать статус этой формы вместо родительской.
