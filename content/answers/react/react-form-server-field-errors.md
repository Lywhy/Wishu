**Ошибки сервера нужно связать с конкретной попыткой и актуальными значениями формы, а не бесконтрольно применять любой поздний ответ.**

### Механизм и границы

- Проверяйте структуру ответа, сопоставляйте допустимые имена полей и связывайте сообщения через aria-describedby.

- После редактирования поля старую ошибку можно снять по явной политике. Не очищайте пользовательский ввод при неудачной отправке и не выдавайте текст неизвестного сервера за безопасный HTML.

### Пример

```jsx
const attempt = ++latestAttempt.current
const result = await save(values)
if (attempt === latestAttempt.current) setFieldErrors(result.fieldErrors ?? {})
```

### Типичная ошибка

Показать ошибку прошлого email после того, как пользователь уже изменил его и отправил новую попытку.
