**Для удаления записи создайте новый массив через filter, сравнивая стабильный ID.**

<!-- wishu:answer-block -->

#### Как это работает

Функциональный updater читает актуальный предыдущий снимок. Остальные объекты можно сохранить по ссылке: их данные не изменились. Индекс отображаемого отсортированного списка не обязательно совпадает с индексом исходного массива.

#### Пример

```jsx
setRows((previous) => previous.filter((row) => row.id !== removedId))
```

#### Разбор примера

Filter исключает только запись с removedId и сохраняет остальные объекты по ссылке. Новый массив сообщает о новом составе списка. Если отображение было отсортировано, стабильный ID по-прежнему выбирает нужную запись, в отличие от номера видимой строки.

#### Типичная ошибка

Использовать splice над прежним state или удалять запись по индексу другой сортировки.
