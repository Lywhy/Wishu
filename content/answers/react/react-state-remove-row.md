**Для удаления записи создайте новый массив через filter, сравнивая стабильный ID.**

<!-- wishu:answer-block -->

### Механизм и границы

- Функциональный updater читает актуальный предыдущий снимок. Остальные объекты можно сохранить по ссылке: их данные не изменились.

- Индекс отображаемого отсортированного списка не обязательно совпадает с индексом исходного массива.

### Пример

```jsx
setRows((previous) => previous.filter((row) => row.id !== removedId))
```

### Типичная ошибка

Использовать splice над прежним state или удалять запись по индексу другой сортировки.
