**Внешняя подписка может обновлять служебную интеграцию без React-render на каждое частое изменение, если владение DOM строго определено.**

<!-- wishu:answer-block -->

#### Как это работает

Это полезно для координат стороннего canvas или другой императивной системы. Подписку освобождают в cleanup и устанавливают первоначальное значение до ожидания следующего события. Не изменяйте через подписку те же React-owned children или style, которыми независимо управляет render.

#### Пример

```jsx
useEffect(() => {
  const update = (state) => canvasApi.setPosition(state.position)
  update(store.getState())
  return store.subscribe(update)
}, [store, canvasApi])
```

#### Разбор примера

Эффект сразу передаёт текущие координаты canvasApi, затем подписывается на будущие изменения и возвращает unsubscribe. React остаётся владельцем оболочки, а внешний движок - содержимого своей области. Такой подход может убрать лишние React-рендеры для частых координат, но требует согласованного владения ресурсом. Он не оправдывает независимую запись в тот же style или children, которые обновляет React.

#### Типичная ошибка

Обойти React для удобства и получить две конкурирующие системы управления одним DOM.
