**Переход Link обрабатывает уже загруженный клиент, а обновление адреса сначала запрашивает этот путь у HTTP-хостинга.**

<!-- wishu:answer-block -->

### Механизм и границы

- Для history-based SPA сервер обычно должен возвращать документ приложения для допустимых клиентских маршрутов.

- Не направляйте на HTML все API и отсутствующие ресурсы: у них свой HTTP-контракт. Hash-маршрутизация имеет иные компромиссы.

### Пример

```jsx
// Клиентский путь: /questions/42
// Хостинг отдаёт index.html, после чего router выбирает экран.
// /api/questions/42 остаётся серверным API.
```

### Типичная ошибка

Исправлять React-компонент, когда 404 произошёл ещё до загрузки JavaScript.
