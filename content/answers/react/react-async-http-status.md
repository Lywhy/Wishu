**Fetch обычно отклоняет Promise при сетевой ошибке, но ответ HTTP 404/500 нужно проверять отдельно.**

<!-- wishu:answer-block -->

#### Как это работает

Проверьте response.ok либо допустимые статусы, затем обработайте тело по контракту API. Ошибка JSON-парсинга - ещё один сценарий. В React переведите операцию в состояние ошибки и не оставляйте прежний loading.

#### Пример

```jsx
const response = await fetch("/api/items")
if (!response.ok) throw new Error("Не удалось загрузить данные")
const rows = await response.json()
```

#### Разбор примера

Response.ok проверяется до разбора тела, поэтому HTTP-ошибка получает отдельный путь обработки. Даже успешный JSON-разбор не подтверждает форму rows. Состояние React обновляют только после нужных проверок и с учётом актуальности попытки.

#### Типичная ошибка

Считать любой resolved fetch успешным прикладным результатом.
