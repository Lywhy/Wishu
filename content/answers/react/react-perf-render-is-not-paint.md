**Вызов компонента вычисляет описание UI и не доказывает ни изменение DOM, ни paint браузера.**

<!-- wishu:answer-block -->

### Механизм и границы

- React может применить только минимальные изменения или отбросить вычисление.

- Console.log особенно шумен в разработке со `StrictMode`. Измеряйте задержку конкретного взаимодействия, а не количество сообщений.

### Пример

```jsx
function Label({ text }) {
  console.log("render")
  return <span>{text}</span>
}
```

### Типичная ошибка

Назвать каждый log полной перерисовкой страницы браузером.
