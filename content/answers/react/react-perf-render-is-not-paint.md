**Вызов компонента вычисляет описание UI и не доказывает ни изменение DOM, ни paint браузера.**

<!-- wishu:answer-block -->

#### Как это работает

React может применить только минимальные изменения или отбросить вычисление. Console.log особенно шумен в разработке со `StrictMode`. Измеряйте задержку конкретного взаимодействия, а не количество сообщений.

#### Пример

```jsx
function Label({ text }) {
  console.log("render")
  return <span>{text}</span>
}
```

#### Разбор примера

Сообщение render появляется при вычислении Label даже тогда, когда text остался прежним. DOM может не потребовать изменения, а попытка может вообще не дойти до commit. Для визуальной задержки нужна метрика видимого результата, а не подсчёт console.log.

#### Типичная ошибка

Назвать каждый log полной перерисовкой страницы браузером.
