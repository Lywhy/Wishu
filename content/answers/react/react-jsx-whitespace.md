**Переносы исходного JSX не являются надёжным способом задать нужный пробел между соседними узлами.**

<!-- wishu:answer-block -->

#### Как это работает

Когда пробел важен, задайте его явно как строковое содержимое. Для визуального расстояния между кнопками используйте макет и gap, а не случайные текстовые пробелы. Текстовый пробел и расстояние в layout решают разные задачи.

#### Пример

```jsx
<p>
  <strong>React</strong> для интервью
</p>
```

#### Разбор примера

Между выделенным названием и продолжением нужен настоящий текстовый пробел. Явное строковое содержимое сохраняет этот смысл независимо от разбиения JSX по строкам. Расстояние между отдельными кнопками, напротив, следует задавать layout-свойствами.

#### Типичная ошибка

Ожидать, что форматтер сохранит смысл пробелов между inline-узлами без явного текста.
