**Server Components выполняются в отдельной серверной среде, в том числе при сборке или обработке запроса, и передают результат в клиентское дерево.** Их код не требуется отправлять в браузер. Они могут обращаться к серверным данным, но не используют клиентское состояние и эффекты.

<!-- wishu:answer-block -->

- SSR формирует HTML и является отдельным механизмом: Client Components тоже могут предварительно рендериться на сервере. Директива "use client" обозначает границу клиентского графа модулей, а не обещание выполнения только в браузере. Для RSC нужна поддержка сборщика или фреймворка; обычное Vite SPA не получает её автоматически.
