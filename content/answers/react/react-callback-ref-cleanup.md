Callback ref получает DOM-узел при привязке. В React 19 он может вернуть функцию очистки, которую React вызовет при снятии ref. Это удобно для реестра узлов по ID или ресурса, связанного с конкретным узлом.

<!-- wishu:answer-block -->

Когда меняется сама ref-функция, React может снять прежнюю и установить новую. Поэтому учитывайте её идентичность и не создавайте дорогую регистрацию при каждом рендере без необходимости. В StrictMode выполняются дополнительные проверки ref-cleanup в разработке.

Не возвращайте результат Map.set случайно вместо cleanup. Изменение реестра в ref не является запросом рендера: для видимых данных нужен state.
