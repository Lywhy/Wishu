**Для цикла обычно нужны два звена: эффект обновляет state, а обновление меняет его зависимость или запускает его снова.**

<!-- wishu:answer-block -->

#### Как это работает

Сначала проверьте, есть ли вообще внешняя система. Производное значение часто нужно вычислить прямо в render. Затем найдите изменяющуюся зависимость: новый объект, функция или сам изменяемый state. Устраните причину, а не поставьте [] с устаревшими значениями.

#### Пример

```jsx
// Лишний цикл синхронизации:
// useEffect(() => setFiltered(items.filter(matches)), [items, matches])
const filtered = items.filter(matches)
```

#### Разбор примера

Filtered получается напрямую из текущих данных без записи производного результата обратно в state. Это разрывает ненужную петлю обновлений. Если фильтрация дорогая, сначала измеряют её стоимость и лишь затем рассматривают мемоизацию.

#### Типичная ошибка

Заглушить exhaustive-deps, не разобрав вторую половину цикла.
