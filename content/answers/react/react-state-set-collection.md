**Set нужно скопировать перед изменением и передать React новый экземпляр.**

<!-- wishu:answer-block -->

#### Как это работает

Add и delete меняют существующий Set. Та же ссылка после мутации может не вызвать ожидаемое обновление. Для проверки выбора используйте has(id); очищайте устаревшие ID по бизнес-правилам при удалении записей.

#### Пример

```jsx
setSelected((previous) => {
  const next = new Set(previous)
  next.has(id) ? next.delete(id) : next.add(id)
  return next
})
```

#### Разбор примера

Next копирует прежний набор, затем переключает присутствие id и возвращается как новое значение. Старый Set не меняется и остаётся корректным снимком. Тот же принцип применяется к Map и другим изменяемым контейнерам.

#### Типичная ошибка

Вызвать selected.add(id), затем setSelected(selected).
