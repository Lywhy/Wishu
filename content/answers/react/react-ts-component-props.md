**Props функции-компонента типизируют как обычный параметр объекта, отмечая необязательные поля через ?.**

<!-- wishu:answer-block -->

#### Как это работает

Значение по умолчанию позволяет функции работать с пропущенным параметром, но не делает обязательный prop необязательным для вызывающего кода. Типы проверяют сборку, а не внешние runtime-данные. Для произвольного JSON нужна отдельная проверка.

#### Пример

```tsx
type Props = { title: string; compact?: boolean }
function Card({ title, compact = false }: Props) {
  return <h2>{compact ? title.slice(0, 12) : title}</h2>
}
```

#### Разбор примера

Title обязателен в Props, а compact можно пропустить и получить false. Проверка происходит у типизированного вызывающего кода. Сам компонент всё равно должен получить подходящие реальные данные: TypeScript не превратит произвольный JSON в корректные props.

#### Типичная ошибка

Использовать any для всех props и потерять проверку обязательных полей.
