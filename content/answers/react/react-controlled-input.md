**Управляемое поле получает value или checked из состояния, а onChange синхронно обновляет его.** У неуправляемого поля текущее значение хранится в DOM, defaultValue или defaultChecked задаёт только начальное значение; прочитать данные можно через FormData или ref.

<!-- wishu:answer-block -->

- Не следует переключать один input между этими режимами в течение его жизни. Для управляемой строки используют начальное "", а не `undefined`; для checkbox передают checked и читают event.target.checked. Value без onChange делает редактируемое поле фактически недоступным для изменения.

### Границы управления
DefaultValue задаёт начальное DOM-значение, а не постоянно синхронизируемое текущее. Файловый input имеет особые ограничения платформы: нельзя управлять выбранным файлом как обычной строкой value. Для повторно используемого контрола заранее определите controlled/uncontrolled-контракт и не копируйте оба источника в два независимых состояния.
