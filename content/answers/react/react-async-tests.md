**В Testing Library getBy ищет элемент сразу и бросает ошибку при отсутствии, queryBy возвращает `null` при отсутствии, findBy возвращает Promise и ожидает появления.** Для исчезновения используют подходящее ожидание, а не фиксированную паузу произвольной длительности.

- Обновления React должны завершиться перед проверкой результата. await act из React помогает обработать связанные обновления; многие операции Testing Library уже используют его. Следует ожидать асинхронные действия и проверять содержимое после завершения, а не скрывать предупреждения act или увеличивать таймер без причины.
