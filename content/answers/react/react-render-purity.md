**Рендер должен вычислять интерфейс из текущих props, state и Context, не изменяя внешнюю среду.** React может повторить или отбросить вычисление, поэтому результат не должен зависеть от того, сколько раз вызвали компонент.

### Как это работает

- Не изменяйте props, ранее сохранённый state, глобальные счётчики и DOM во время рендера.

- Локальная мутация допустима: можно создать новый массив, заполнить его и вернуть элементы. Важно, что этот массив не существовал до текущего вызова.

- Действие пользователя выполняют в обработчике. Подписку на внешний ресурс синхронизируют эффектом. Нечистое вычисление внутри `useMemo` не становится безопасным.

### Пример

```jsx
function Receipt({ items }) {
  const total = items.reduce((sum, item) => sum + item.price, 0)
  return <p>Итого: {total}</p>
}
```

### Типичная ошибка

Увеличивать глобальный счётчик заказов или отправлять оплату внутри компонента: повторный рендер не является новой покупкой.
