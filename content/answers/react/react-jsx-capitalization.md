**Строчный JSX-тег обозначает встроенный элемент, а имя с заглавной буквы - переменную с типом компонента.**

<!-- wishu:answer-block -->

### Механизм и границы

- В `<button />` имя становится именем DOM-тега; в `<Button />` React использует значение переменной Button.

- Динамический тип сохраняют в переменную с заглавным именем. Строка с названием вашей функции не ищет функцию автоматически.

### Пример

```jsx
const Tag = compact ? SmallCard : LargeCard
return <Tag title="Отчёт" />
```

### Типичная ошибка

Написать `<tag />` и ожидать вызова переменной tag.
