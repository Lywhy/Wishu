**Строчный JSX-тег обозначает встроенный элемент, а имя с заглавной буквы - переменную с типом компонента.**

<!-- wishu:answer-block -->

#### Как это работает

В `<button />` имя становится именем DOM-тега; в `<Button />` React использует значение переменной Button. Динамический тип сохраняют в переменную с заглавным именем. Строка с названием вашей функции не ищет функцию автоматически.

#### Пример

```jsx
const Tag = compact ? SmallCard : LargeCard
return <Tag title="Отчёт" />
```

#### Разбор примера

Tag хранит выбранный тип компонента, и JSX использует именно это значение. Запись со строчным tag означала бы встроенный тег с таким именем. Изменение регистра здесь влияет на интерпретацию программы, а не является только стилем именования.

#### Типичная ошибка

Написать `<tag />` и ожидать вызова переменной tag.
