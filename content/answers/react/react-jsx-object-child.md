**Обычный объект не является отображаемым React-содержимым; выберите его поле или преобразуйте данные в нужное представление.**

<!-- wishu:answer-block -->

#### Как это работает

Элемент React тоже представлен объектом, но создан по специальному контракту и не равен произвольной записи данных. Для отладки можно использовать `JSON.stringify`, однако это не готовый пользовательский интерфейс и может раскрыть лишние поля.

#### Пример

```jsx
function UserName({ user }) {
  return <p>{user.name}</p>
}
// <p>{user}</p> передал бы объект вместо отображаемого значения.
```

#### Разбор примера

UserName выбирает name как представление записи, поэтому React получает отображаемое значение. Передача user целиком не объяснила бы, какие поля нужно показывать. `JSON.stringify` может помочь отладке, но для интерфейса лучше явно спроектировать содержимое.

#### Типичная ошибка

Передать результат API целиком в children и искать проблему в CSS.
