**`useMemo` кеширует результат чистого вычисления, `useCallback` - ссылку на функцию.** Зависимости сравниваются через `Object.is`. Вызов сохранённого callback всё равно выполняет его тело; `useCallback` не кеширует результат вызова.

- Мемоизация оправдана для дорогого вычисления или стабильного входа мемоизированного потребителя. Она добавляет зависимости и стоимость сопровождения. React вправе сбросить кеш, поэтому на нём нельзя основывать корректность состояния. Мутации зависимостей также ломают ожидаемое поведение.
