**Radio одного выбора связывают общим name и сравнивают каждый value с одним состоянием выбранного значения.**

<!-- wishu:answer-block -->

#### Как это работает

Каждый `onChange` сохраняет своё значение. Общий name обеспечивает нативное групповое поведение; одинаковое имя у независимых групп может непреднамеренно связать их.

#### Пример

```jsx
<input
  type="radio"
  name="level"
  value="basic"
  checked={level === "basic"}
  onChange={(event) => setLevel(event.target.value)}
/>
```

#### Разбор примера

Level хранит один выбранный вариант, поэтому сравнение включает только соответствующий radio. Общий name согласует группу с браузером. У независимых экземпляров поля нужен отдельный scope имени, чтобы они не мешали выбору друг друга.

#### Типичная ошибка

Завести независимый boolean на каждый radio и допустить противоречие выбранных значений.
