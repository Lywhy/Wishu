**Обычные хуки вызывают на верхнем уровне функционального компонента или пользовательского хука, сохраняя порядок между рендерами.** Они должны находиться до условного раннего return.

<!-- wishu:answer-block -->

### Как это работает

- Не вызывайте `useState`/`useEffect` в условии, цикле, обработчике, callback `useMemo` или обычной служебной функции.

- Для условной подписки вызов эффекта оставляют безусловным, а условие проверяют внутри setup. Либо выделяют дочерний компонент, который монтируется условно.

- Пользовательский хук начинается с use и тоже соблюдает правила. Такое имя не делает произвольный вызов из обработчика разрешённым.

- API use имеет отдельное исключение: его допускается вызывать условно и в циклах внутри компонента или хука. При чтении приостанавливаемого ресурса его не оборачивают в try/catch; для ошибок и ожидания используют соответствующие границы.

### Пример

```jsx
function Status({ enabled }) {
  useEffect(() => {
    if (!enabled) return
    const unsubscribe = subscribe()
    return unsubscribe
  }, [enabled])
  if (!enabled) return null
  return <p>Подписка активна</p>
}
// subscribe - API внешнего источника приложения.
```

### Типичная ошибка

Поставить `useEffect` после if (!enabled) return null и изменить число хуков между рендерами.
