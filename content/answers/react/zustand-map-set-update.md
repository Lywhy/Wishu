**Map и Set изменяемы, поэтому обычное обновление Zustand должно создавать новые экземпляры коллекций.**

<!-- wishu:answer-block -->

### Механизм и границы

- Selectors сравнивают результаты по выбранному контракту идентичности. Мутация прежней коллекции способна оставить потребителя без ожидаемого обновления.

- При persist JSON требует отдельного представления Map/Set. Иммутабельное обновление и сериализация - две самостоятельные задачи.

### Пример

```jsx
set((state) => ({
  selected: new Set(state.selected).add(id),
}))
```

### Типичная ошибка

Считать добавление нового ключа в прежний Map созданием нового снимка.
