**Параметр URL является строкой, а его наличие и формат требуют проверки перед прикладным использованием.**

<!-- wishu:answer-block -->

#### Как это работает

TypeScript-тип не превращает сегмент URL в число и не доказывает существование записи. Для числового ID обработайте отсутствие, некорректную запись и диапазон; при ошибке покажите корректный маршрутный результат.

#### Пример

```jsx
const { id } = useParams()
const numericId = Number(id)
const valid = id !== undefined && Number.isSafeInteger(numericId) && numericId > 0
```

#### Разбор примера

Number выполняет реальное преобразование, а SafeInteger и положительность проверяют выбранный числовой контракт. Если API допускает только десятичные цифры, отдельно проверяют исходную строку. Успешное преобразование ещё не доказывает существование или доступность пользователя.

#### Типичная ошибка

Передать непроверенный id в расчёт и считать URL доверенными данными.
