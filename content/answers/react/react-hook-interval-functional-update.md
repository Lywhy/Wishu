**Интервал может передавать в setter чистый updater, не читая захваченный count из первого рендера.**

<!-- wishu:answer-block -->

#### Как это работает

Тогда изменение count не становится причиной пересоздания самого интервала. Другие читаемые props, например шаг или скорость, всё равно требуют корректного контракта зависимостей. Не исключайте их только ради [].

#### Пример

```jsx
useEffect(() => {
  const timer = setInterval(() => setCount((value) => value + 1), delay)
  return () => clearInterval(timer)
}, [delay])
```

#### Разбор примера

Delay определяет расписание интервала и честно включён в зависимости. Count читается через аргумент updater, поэтому его изменение не пересоздаёт таймер. Это точечное устранение одной зависимости, а не универсальное оправдание пустого массива.

#### Типичная ошибка

Оставить setCount(count + 1) в эффекте с [] и зафиксировать первое значение.
