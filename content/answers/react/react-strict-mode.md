**StrictMode включает дополнительные проверки в разработке: React повторно вызывает чистые вычисления и выполняет дополнительный цикл setup/cleanup эффектов там, где применима эта проверка.** Это помогает обнаружить мутации и утечки подписок.

<!-- wishu:answer-block -->

- Это не требование выполнять бизнес-операцию дважды в production. Если эффект создаёт дублирующиеся соединения, исправляют cleanup. Ref-флаг «уже запускали» обычно скрывает проблему, а не делает повторное монтирование безопасным.
