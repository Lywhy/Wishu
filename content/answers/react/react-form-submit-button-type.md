**У нативной button внутри формы тип по умолчанию обычно submit; вспомогательной кнопке явно нужен type="button".**

<!-- wishu:answer-block -->

#### Как это работает

В React это поведение платформы сохраняется. Обёртка Button тоже должна осмысленно передавать type. Отправку лучше обрабатывать на form, чтобы работали Enter и доступные способы запуска.

#### Пример

```jsx
<form onSubmit={save}>
  <button type="button" onClick={openHelp}>
    Подсказка
  </button>
  <button type="submit">Сохранить</button>
</form>
```

#### Разбор примера

Подсказка имеет type button и выполняет только openHelp. Сохранить является submit и запускает общую отправку формы. Такая граница сохраняется даже при помещении кнопок в переиспользуемые компоненты-обёртки.

#### Типичная ошибка

Привязать отправку только к `onClick` одной кнопки и забыть нативную отправку формы.
