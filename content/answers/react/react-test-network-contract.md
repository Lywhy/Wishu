**Mock на сетевой границе позволяет оставить реальную логику загрузки, статусов и преобразования ответа внутри компонента или хука.**

<!-- wishu:answer-block -->

#### Как это работает

Опишите успешный ответ, прикладную ошибку и задержку именно как вход интеграции. Мок внутреннего хука уместен для узкого теста UI, но не доказывает совместимость этой UI с реальным механизмом данных. Выбирайте границу по цели теста.

#### Пример

```jsx
// Тестовый сервер возвращает 500 для /api/profile.
render(<Profile />)
expect(await screen.findByRole("alert")).toHaveTextContent("Не удалось загрузить")
```

#### Разбор примера

Ответ 500 поступает на границе сети, поэтому реальный код Profile должен перевести его в alert. Готовый мок внутреннего хука со статусом error проверил бы только ветвь отображения. Это допустимо для другой цели, но не доказывает интеграцию запроса.

#### Типичная ошибка

Всегда возвращать из мока готовый success и считать, что проверены loading и ошибка.
