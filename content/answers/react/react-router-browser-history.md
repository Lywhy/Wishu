**BrowserRouter согласует React-маршруты с History API браузера, позволяя менять экран без полной загрузки документа.**

<!-- wishu:answer-block -->

#### Как это работает

React Router - отдельная библиотека, не встроенный API ядра React. Для нового документа и внешнего сайта остаются обычные ссылки. Сервер хостинга должен поддерживать открытие клиентского пути напрямую.

#### Пример

```jsx
<BrowserRouter>
  <Routes>
    <Route path="/learn" element={<Learn />} />
  </Routes>
</BrowserRouter>
```

#### Разбор примера

Путь /learn выбирает Learn внутри уже загруженного дерева. При прямом открытии этого адреса браузер сначала обращается к хостингу, а не к BrowserRouter. Поэтому настройка маршрута клиента и отдача документа сервером должны быть согласованы.

#### Типичная ошибка

Считать, что BrowserRouter сам настраивает HTTP-сервер или API-маршруты.
