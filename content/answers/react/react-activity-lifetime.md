Activity позволяет скрыть поддерево, сохранив его состояние и DOM. При hidden React очищает его Effects, а при возвращении visible создаёт их снова. Это отличается и от удаления компонента, и от одной CSS-прозрачности.

#### Как это работает

Скрытые дети могут продолжать получать обновления props с более низким приоритетом. Activity не обещает, что поддерево больше не занимает память или никогда не рендерится. Cleanup обязан корректно освобождать подписки, а setup - восстанавливать их.

Это полезно для возвращения к уже подготовленной панели с сохранённым вводом. Не используйте скрытие как безопасность данных и не размещайте обязательную постоянно работающую бизнес-операцию в эффекте, который должен отключаться вместе с панелью.

Сохранённый DOM может иметь собственные эффекты платформы: например, воспроизведение media не обязано остановиться от одного скрытия. Явно согласуйте pause/cleanup со сроком активности панели.

#### Пример

```tsx
import { Activity } from "react"
function Details({ visible, children }) {
  return <Activity mode={visible ? "visible" : "hidden"}>{children}</Activity>
}
```

#### Разбор примера

Details переключает режим Activity, сохраняя состояние скрытой панели. Подписки её эффектов при скрытии очищаются и должны корректно восстанавливаться при показе. Следовательно, скрытая форма может помнить ввод, но её сетевой listener нельзя считать постоянно работающим фоном.

#### Типичная ошибка

> Считать hidden-вкладку полностью работающим фоном или эквивалентом размонтирования.
