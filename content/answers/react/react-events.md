**В обработчик JSX передают функцию, которую React должен вызвать при событии.** Вызов handleClick() внутри JSX выполняется уже во время рендера и передаёт результат этого вызова.

<!-- wishu:answer-block -->

#### Как это работает

Для аргумента используйте обёртку () => handleClick(id). Наличие такой функции само по себе не доказывает проблему производительности. Пользовательский prop `onSave` - контракт компонента: компонент должен сам вызвать его в подходящий момент. Он не превращается автоматически в событие DOM.

`preventDefault` отменяет стандартное действие браузера, а `stopPropagation` останавливает распространение события. Одна операция не заменяет другую. Кнопке внутри формы явно задавайте type, если она не должна отправлять форму. Сетевую ошибку асинхронного обработчика обрабатывайте в его собственном потоке.

#### Пример

```jsx
function Row({ id, onRemove }) {
  return (
    <button type="button" onClick={() => onRemove(id)}>
      Удалить
    </button>
  )
}
// onClick={onRemove(id)} вызвал бы удаление при рендере.
```

#### Разбор примера

Обёртка сохраняет id конкретной строки и вызывает onRemove только после клика. Во время render создаётся описание действия, а не выполняется удаление. Type button дополнительно предотвращает неожиданную отправку формы, если строка окажется внутри неё.

#### Типичная ошибка

Выполнять отправку при построении JSX либо считать `stopPropagation` способом отмены перехода ссылки.
