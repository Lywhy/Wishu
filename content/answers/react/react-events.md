**onClick={handleClick} передаёт функцию, которую React вызовет при событии.** onClick={handleClick()} вызывает её во время рендера и передаёт результат; это обычно ошибка, способная вызвать побочный эффект или цикл обновления.

<!-- wishu:answer-block -->

- Для аргументов используют обёртку () => handleClick(id). stopPropagation останавливает распространение события, preventDefault отменяет стандартное действие браузера; эти операции решают разные задачи. Сама по себе стрелочная функция в JSX не является доказательством проблемы производительности.
