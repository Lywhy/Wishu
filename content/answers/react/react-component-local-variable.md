**Обычная локальная переменная создаётся при вызове компонента заново и не сообщает React о необходимости обновить UI.**

<!-- wishu:answer-block -->

#### Как это работает

Замыкание обработчика может изменить свою переменную, но это не запрашивает новый render. Для отображаемых данных нужен state. Для служебного значения, переживающего render без обновления UI, подходит ref.

#### Пример

```jsx
function Counter() {
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount((n) => n + 1)}>{count}</button>
}
```

#### Разбор примера

SetCount сохраняет следующее значение в памяти React и запрашивает обновление представления. Обычное count++ изменило бы лишь захваченную переменную без такого уведомления. При следующем вызове компонента локальное объявление снова выполнилось бы с исходным значением.

#### Типичная ошибка

Увеличивать let count внутри `onClick` и ждать обновления числа на странице.
