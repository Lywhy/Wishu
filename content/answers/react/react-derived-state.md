**Если значение однозначно получается из текущих props или state, его обычно вычисляют при рендере.** Отдельное состояние для полной строки имени или отфильтрованного списка создаёт второй источник истины, который легко забыть обновить.

- Эффект, копирующий результат вычисления в state, сначала показывает старое значение и инициирует дополнительный рендер. Дорогое чистое вычисление можно мемоизировать при подтверждённой необходимости. Независимый пользовательский черновик при этом действительно может требовать собственного состояния.
