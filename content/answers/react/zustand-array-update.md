**Массив в обычном Zustand-state обновляют новым массивом, заменяя изменённый элемент новым объектом.**

<!-- wishu:answer-block -->

#### Как это работает

Set объединяет верхний уровень объекта, но не копирует автоматически массив и вложенные записи. Immer middleware предоставляет другой updater-контракт; не переносите его мутационный синтаксис в обычный store.

#### Пример

```jsx
set((state) => ({
  rows: state.rows.map((row) => (row.id === id ? { ...row, title } : row)),
}))
```

#### Разбор примера

map создаёт новый массив, а spread создаёт новый объект только для изменяемой строки. Остальные строки сохраняют ссылки, поэтому selectors по ID могут пропустить несвязанные обновления. Верхнеуровневый set заменяет `rows` и сохраняет остальные поля store. Если изменить title у старого объекта, новые подписки и прежние снимки будут разделять уже испорченное значение.

#### Типичная ошибка

Изменить state.rows[index].title и вернуть прежний массив при обычном set.
