**Ref хранит служебный ID таймера отдельно для каждого экземпляра компонента и переживает его рендеры.**

<!-- wishu:answer-block -->

#### Как это работает

Глобальная переменная может связать независимые экземпляры: один очистит таймер другого. Ref не выполняет cleanup автоматически. Ресурс нужно отменить при остановке и размонтировании.

#### Пример

```jsx
timerRef.current = setTimeout(run, 500)
// При остановке:
clearTimeout(timerRef.current)
timerRef.current = null
```

#### Разбор примера

ID относится к одному экземпляру компонента, а очистка завершает именно его таймер. Сброс current в null показывает отсутствие активной регистрации. Если перезаписывать ID без отмены прежнего таймера, старый ресурс продолжит жить независимо от нового значения ref.

#### Типичная ошибка

Считать ref автоматически управляемым временем жизни таймера.
