**Браузер может исправить недопустимую HTML-структуру ещё при парсинге, поэтому реальный DOM перестанет совпадать с ожидаемым React-деревом.**

<!-- wishu:answer-block -->

#### Как это работает

Например, блочный div внутри p или вложенные интерактивные элементы меняют семантику и могут приводить к hydration mismatch. Эффект выполняется слишком поздно, чтобы сделать исходную структуру корректной. Исправляйте HTML-композицию, включая вложенные компоненты библиотеки.

#### Пример

```jsx
// Неверно: <p><div>Блок</div></p>
return (
  <section>
    <p>Пояснение</p>
    <div>Блок</div>
  </section>
)
```

#### Разбор примера

Section содержит p и div как соседей, поэтому браузеру не требуется закрывать абзац неожиданным образом. Проверять нужно итоговую композицию компонентов: корректный отдельный компонент может оказаться внутри недопустимого родителя.

#### Типичная ошибка

Подавить предупреждение гидратации, не заметив, что браузер уже перестроил DOM.
