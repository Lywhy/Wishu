**Частый state ввода стоит держать у ближайшего владельца, которому он действительно нужен, вместо верхней оболочки всей страницы.**

<!-- wishu:answer-block -->

### Механизм и границы

- Передавайте наверх только необходимый результат или команду, если остальное дерево не зависит от каждого символа.

- Локализация не должна создавать два несогласованных источника одного значения. URL-фильтр остаётся отдельным выбранным владельцем.

### Пример

```jsx
function SearchBox() {
  const [query, setQuery] = useState("")
  return <input value={query} onChange={(event) => setQuery(event.target.value)} />
}
```

### Типичная ошибка

Размещать state каждого поля в App и затем оборачивать всё дерево в memo.
