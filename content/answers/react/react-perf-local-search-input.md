**Частый state ввода стоит держать у ближайшего владельца, которому он действительно нужен, вместо верхней оболочки всей страницы.**

<!-- wishu:answer-block -->

#### Как это работает

Передавайте наверх только необходимый результат или команду, если остальное дерево не зависит от каждого символа. Локализация не должна создавать два несогласованных источника одного значения. URL-фильтр остаётся отдельным выбранным владельцем.

#### Пример

```jsx
function SearchBox() {
  const [query, setQuery] = useState("")
  return <input value={query} onChange={(event) => setQuery(event.target.value)} />
}
```

#### Разбор примера

Query принадлежит SearchBox, поэтому соседнее дерево не становится его владельцем по умолчанию. Если результат поиска нужен другим компонентам, передают осмысленный контракт наверх. Изоляция состояния не должна скрывать необходимость реального общего источника.

#### Типичная ошибка

Размещать state каждого поля в App и затем оборачивать всё дерево в memo.
