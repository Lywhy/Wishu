**Потребитель получает значение ближайшего провайдера того же Context выше в React-дереве.**

<!-- wishu:answer-block -->

#### Как это работает

Вложенный провайдер переопределяет значение для своего поддерева. Default используется при отсутствии провайдера, а не как запасной вариант любого пустого value.

#### Пример

```jsx
<Theme.Provider value="light">
  <Page />
  <Theme.Provider value="dark">
    <Preview />
  </Theme.Provider>
</Theme.Provider>
```

#### Разбор примера

Page находится под внешним light, а Preview дополнительно под внутренним dark. Поэтому они могут прочитать разные темы одновременно. Физическое перемещение DOM через Portal не меняет этот поиск по React-предкам.

#### Типичная ошибка

Ожидать, что внешний провайдер победит внутренний или что поиск зависит от DOM-вложенности портала.
