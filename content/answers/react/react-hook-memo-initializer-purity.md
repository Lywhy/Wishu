**`useMemo` и ленивый инициализатор выполняют вычисление во время render и не превращают запрос в безопасный побочный эффект.**

<!-- wishu:answer-block -->

#### Как это работает

Их вычисления должны оставаться чистыми и допускающими повтор. Для пользовательской команды нужен обработчик, для внешней синхронизации - эффект или загрузчик данных интеграции. Кеш мемоизации не является надёжным журналом «запрос уже отправлен».

#### Пример

```jsx
const total = useMemo(() => rows.reduce((sum, row) => sum + row.price, 0), [rows])
// Отправка POST не должна находиться в этом callback.
```

#### Разбор примера

Callback `useMemo` только вычисляет сумму строк. Его можно безопасно повторить, не публикуя новую покупку или сетевую команду. Кеширование результата помогает стоимости render, но не является гарантией единственного выполнения бизнес-действия.

#### Типичная ошибка

Отправить покупку в `useMemo` и считать зависимость [] гарантией единственной покупки.
