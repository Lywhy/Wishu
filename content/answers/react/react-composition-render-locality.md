**Частое состояние можно поместить в обёртку, а независимое тяжёлое содержимое передать ей через children.** При собственном обновлении обёртка получает прежнее описание детей из неизменившегося родителя.

<!-- wishu:answer-block -->

### Как это работает

- Если дорогое JSX создаётся внутри владельца частого state, он вычисляет его заново вместе со своим рендером.

- Переданные извне children могут сохранить ссылку между обновлениями самой обёртки. Это структурная оптимизация, а не гарантия отсутствия любых рендеров потомка.

- Собственный state ребёнка, используемый Context или новый рендер внешнего владельца всё равно могут обновить его. Сначала проверьте расположение state, затем необходимость memo.

### Пример

```jsx
function Expandable({ children }) {
  const [open, setOpen] = useState(true)
  return (
    <section>
      <button onClick={() => setOpen((v) => !v)}>Свернуть</button>
      <div hidden={!open}>{children}</div>
    </section>
  )
}
// В родителе: <Expandable><ExpensiveReport /></Expandable>
```

### Типичная ошибка

Обещать, что children никогда не рендерится, или скрывать его через удаление, забыв о сбросе локального состояния.
