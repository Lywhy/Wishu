**`selectFromResult` позволяет компоненту получать только нужную часть query-результата; стабильные ссылки результата важны для пропуска обновлений.**

<!-- wishu:answer-block -->

#### Как это работает

Не создавайте новый пустой массив на каждом вызове, если его стабильность важна. Это выборка из существующей query-подписки, а не новый серверный endpoint. Убедитесь, что обработаны отсутствие данных и смена аргумента.

#### Пример

```jsx
const empty = []
const { items } = useGetPostsQuery(topic, {
  selectFromResult: (result) => ({ items: result.data ?? empty }),
})
```

#### Разбор примера

Константу empty здесь важно объявить вне компонента, чтобы её ссылка не менялась при каждом рендере. `selectFromResult` возвращает объект с выбранными полями, и React Redux-связка RTK Query сравнивает его верхний уровень. Стабильность вложенного массива помогает пропустить несвязанные изменения query-state. Если требуется filter, производный результат стоит мемоизировать относительно исходных данных.

#### Типичная ошибка

Возвращать заново отфильтрованный массив для каждого вызова без оценки стабильности.
