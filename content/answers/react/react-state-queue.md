**Три setCount(count + 1) в одном обработчике используют один снимок count и запрашивают одно и то же значение.** Функциональная форма setCount(previous => previous + 1) получает предыдущее значение из очереди, поэтому три таких обновления увеличат счётчик на три.

- React группирует обновления, чтобы избежать лишних промежуточных рендеров. Updater должен быть чистым: в нём нельзя отправлять запросы или изменять внешние переменные. В режиме разработки React может повторно вызвать updater для обнаружения нечистого кода.

### Группировка не равна немедленной мутации
Современный React группирует обновления в большем числе сценариев, включая подходящие Promise- и timer-callback. Это не обещает единственного рендера для любого взаимодействия и не превращает setter в awaitable Promise. Отдельные намеренные действия пользователя должны сохранять корректные границы обработки. Корректность проверяйте по результату, а не по универсальному числу вызовов компонента.
