**Для проверки отсутствия элемента подходит queryBy: он возвращает null вместо ошибки при отсутствии совпадения.**

<!-- wishu:answer-block -->

### Механизм и границы

- GetBy нужен, когда элемент обязан существовать прямо сейчас; findBy ожидает появление.

- Если элемент исчезает асинхронно, сначала дождитесь соответствующего перехода, а не проверяйте преждевременно.

### Пример

```jsx
expect(screen.queryByRole("alert")).not.toBeInTheDocument()
```

### Типичная ошибка

Вызвать getByRole для элемента, отсутствие которого и является ожидаемым результатом.
