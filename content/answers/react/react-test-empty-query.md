**Для проверки отсутствия элемента подходит queryBy: он возвращает null вместо ошибки при отсутствии совпадения.**

<!-- wishu:answer-block -->

#### Как это работает

GetBy нужен, когда элемент обязан существовать прямо сейчас; findBy ожидает появление. Если элемент исчезает асинхронно, сначала дождитесь соответствующего перехода, а не проверяйте преждевременно.

#### Пример

```jsx
expect(screen.queryByRole("alert")).not.toBeInTheDocument()
```

#### Разбор примера

QueryByRole возвращает null при отсутствии alert, что и является ожидаемым исходом assertion. При нескольких совпадениях одиночный query по-прежнему может бросить ошибку. Асинхронное исчезновение нужно сначала дождаться, а не проверять в произвольный момент.

#### Типичная ошибка

Вызвать getByRole для элемента, отсутствие которого и является ожидаемым результатом.
