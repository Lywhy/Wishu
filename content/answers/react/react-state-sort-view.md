**sort меняет массив на месте, поэтому сортировать props или прежний state напрямую нельзя.**

<!-- wishu:answer-block -->

#### Как это работает

Используйте toSorted либо сначала копию массива. Если порядок является производным представлением, вычисляйте его из исходных данных и выбора пользователя, а не храните второй несинхронный массив.

#### Пример

```jsx
const sorted = [...rows].sort((a, b) => a.price - b.price)
return sorted.map((row) => <Row key={row.id} row={row} />)
```

#### Разбор примера

Сортируется новая внешняя коллекция, поэтому порядок `rows` у родителя остаётся прежним. Ссылки самих записей не меняются, а key продолжает связывать их с состоянием строк. Если порядок является частью сохранённых данных, его обновление оформляют отдельной командой.

#### Типичная ошибка

В дочернем render вызвать rows.sort и неожиданно изменить данные родителя.
