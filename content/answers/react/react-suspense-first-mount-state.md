**Если дерево приостановилось до первого успешного mount, React не сохраняет созданное в этой попытке локальное состояние.** Когда ресурс будет готов, первоначальный рендер пробуется заново.

<!-- wishu:answer-block -->

### Как это работает

- Не используйте локальный `useMemo` как единственное хранилище Promise, от которого зависит завершение первого рендера.

- Ресурс должен иметь стабильное владение вне повторяемой незафиксированной попытки: обычно этим занимается поддерживающий Suspense фреймворк или библиотека данных.

- Повторная приостановка уже показанного дерева - другой сценарий. На видимость прежнего содержимого влияют границы и transition; не переносите правило первого mount на все обновления.

### Пример

```jsx
// Ресурс передан интеграцией и сохраняет идентичность между попытками.
function Profile({ userPromise }) {
  const user = use(userPromise)
  return <h2>{user.name}</h2>
}
;<Suspense fallback={<p>Загрузка…</p>}>
  <Profile userPromise={userPromise} />
</Suspense>
```

### Типичная ошибка

Создавать новый Promise при каждой попытке рендера и рассчитывать, что незакоммиченный `useMemo` навсегда его закеширует.
