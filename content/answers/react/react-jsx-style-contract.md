**style получает объект с camelCase-свойствами; числовые значения обычно означают px, кроме безразмерных свойств.**

<!-- wishu:answer-block -->

#### Как это работает

Например, padding: 8 задаёт длину, а opacity: 0.5 остаётся безразмерной. Для rem или процентов нужна строка. CSS custom properties сохраняют исходное имя с --; в TypeScript для собственного контракта может понадобиться расширение CSSProperties.

#### Пример

```jsx
<>
  <div style={{ padding: 8, width: "50%", opacity: 0.8 }} />
  <div style={{ "--accent": "brown" }} />
</>
```

#### Разбор примера

Padding получает пиксельную длину, width сохраняет проценты, а opacity остаётся долей. Custom property записывается под исходным именем --accent. Для фиксированного оформления часто удобнее классы, а style полезен для значений, действительно вычисляемых во время работы.

#### Типичная ошибка

Передать CSS-строку вместо объекта или считать каждое числовое свойство пикселями.
