**Мемоизация полезна, когда экономия повторного вычисления превышает стоимость зависимостей, сравнения и хранения результата.**

<!-- wishu:answer-block -->

### Механизм и границы

- Дешёвое выражение может не нуждаться в `useMemo`; нестабильная зависимость может обнулять выигрыш.

- Измеряйте конкретный сценарий. Не добавляйте глубокий comparator поверх большой структуры без оценки худшего случая.

### Пример

```jsx
const fullName = firstName + " " + lastName
// Обычно это простое вычисление, а не повод для отдельного useMemo.
```

### Типичная ошибка

Считать любое наличие `useMemo` ускорением независимо от размера данных.
