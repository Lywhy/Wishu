**Мемоизация полезна, когда экономия повторного вычисления превышает стоимость зависимостей, сравнения и хранения результата.**

<!-- wishu:answer-block -->

#### Как это работает

Дешёвое выражение может не нуждаться в `useMemo`; нестабильная зависимость может обнулять выигрыш. Измеряйте конкретный сценарий. Не добавляйте глубокий comparator поверх большой структуры без оценки худшего случая.

#### Пример

```jsx
const fullName = firstName + " " + lastName
// Обычно это простое вычисление, а не повод для отдельного useMemo.
```

#### Разбор примера

Склейка двух строк обычно слишком дешева, чтобы оправдать отдельный кеш. Если проблема находится в огромной фильтрации, измеряют именно её и стабильность входов. Один и тот же приём не имеет одинаковой окупаемости для любой операции.

#### Типичная ошибка

Считать любое наличие `useMemo` ускорением независимо от размера данных.
