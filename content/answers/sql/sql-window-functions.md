**Group by сворачивает строки в группы результата.** Оконная функция вычисляет значение по окну, сохраняя детализацию строк. Partition by задаёт разделы, order by внутри OVER - порядок вычисления.

- Row_number нумерует строки, rank учитывает равные позиции с пропусками. Для накопительных агрегатов важен frame: его значение по умолчанию может включать строки с равным ключом сортировки. Для детерминированного порядка добавляют уникальный критерий.
