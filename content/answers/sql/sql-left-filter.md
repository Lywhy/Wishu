**После left join строки без пары имеют NULL в правых столбцах.** Условие WHERE o.status = ... отбрасывает такие строки, поэтому ожидаемое сохранение всех пользователей пропадает.

- Если нужно сохранить всех пользователей и присоединить только подходящие заказы, условие размещают в ON. Если нужны только пользователи с подходящими заказами, фильтрация может быть намеренной. Решение зависит от требуемого набора строк.
