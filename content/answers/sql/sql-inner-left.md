**Inner join оставляет сочетания строк, для которых выполнено условие соединения.** Left join дополнительно сохраняет строки левой таблицы без совпадения, заполняя столбцы правой стороны NULL.

<!-- wishu:answer-block -->

- Соединение может увеличить число строк, если справа несколько совпадений. Поэтому нельзя считать, что join только добавляет столбцы без изменения кратности. Отношение один ко многим нужно учитывать при подсчётах и пагинации.
