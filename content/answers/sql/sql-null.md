**NULL обозначает отсутствие известного значения.** Обычное сравнение с NULL даёт `unknown`, а WHERE сохраняет только строки с истинным условием. Для проверки используют IS NULL и IS NOT NULL.

- Unknown влияет на AND, OR и NOT. Особенно осторожно используют NOT IN, если подзапрос может вернуть NULL: результат может оказаться `unknown` вместо ожидаемого true. Для проверки отсутствия связи часто яснее NOT EXISTS.
