**Count(*) считает строки входного набора.** Count(column) считает строки, где выражение column не NULL. Count(DISTINCT column) считает различные непустые значения по правилам сравнения.

- После left join count(*) включает сохранённую строку родителя даже без дочерней записи. Для числа детей обычно считают непустой ключ дочерней таблицы. Это не повод считать, что count(1) принципиально выражает другой набор строк, чем count(*).
