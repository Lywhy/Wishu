**Hono - HTTP-фреймворк JavaScript/TypeScript, построенный вокруг стандартных `Request` и Response. Приложение обрабатывает запросы, а способ прослушивания сети зависит от среды.**

<!-- wishu:answer-block -->

#### Как это работает

На Node.js функцию `app.fetch` подключают через адаптер @hono/node-server. В Worker или другом runtime контракт входа отличается. Совместимый обработчик не делает доступными все Node-модули в edge-среде: драйверы, файловая система и переменные окружения требуют отдельной проверки. Сам Hono не заменяет runtime и не добавляет автоматический DI-контейнер.

#### Пример

```typescript
import { Hono } from "hono"
import { serve } from "@hono/node-server"
const app = new Hono()
app.get("/health", (c) => c.json({ ok: true }))
// Node.js, после установки адаптера:
serve({ fetch: app.fetch, port: 3000 })
```

#### Разбор примера

Маршрут описывает ответ, serve связывает его с HTTP-сервером Node.js. В других средах меняется именно интеграция запуска. Это учебный пример, его не нужно исполнять для понимания контракта.

#### Типичная ошибка

> Считать, что одинаковый Hono-код гарантирует совместимость любой зависимости со всеми runtime.
