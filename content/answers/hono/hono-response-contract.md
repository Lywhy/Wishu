**Обработчик возвращает `Response` или Promise с Response. Методы `c.json`, `c.text` и `c.redirect` помогают сформировать тело, заголовки и HTTP-статус.**

<!-- wishu:answer-block -->

#### Как это работает

Статус описывает исход операции для клиента, поэтому ошибка в JSON со статусом 200 остаётся успешным HTTP-ответом. В асинхронном обработчике нужно дождаться необходимых действий и вернуть результат. После отправки ответа поздняя ошибка не может переписать уже доставленный статус; фоновая работа требует явного механизма конкретной среды.

#### Пример

```typescript
app.post("/notes", async (c) => {
  const note = await createNote() // Сервис приложения.
  c.header("Location", "/notes/" + note.id)
  return c.json(note, 201)
})
```

#### Разбор примера

201 обозначает создание ресурса, Location указывает его адрес. createNote здесь является отдельным сервисом с собственными проверками и обработкой отказа. Пример не заменяет валидацию тела и авторизацию.

#### Типичная ошибка

> Вызвать `c.json` без return и оставить обработчик без корректного результата.
