**hc использует тип маршрутов Hono для подсказок и проверки клиентских вызовов TypeScript. Это общий статический контракт, а не автоматическая проверка всех сетевых данных.**

<!-- wishu:answer-block -->

#### Как это работает

Для вывода типов маршруты определяют цепочкой и экспортируют typeof полученного приложения. Клиент импортирует только тип, поэтому серверные секреты и исполняемый код не должны попадать в его bundle. Ошибка сети, устаревший сервер, несовместимая версия и авторизация требуют собственной обработки независимо от успешной компиляции.

#### Пример

```typescript
// Серверный модуль
const app = new Hono().get("/health", (c) => c.json({ ok: true }))
export type AppType = typeof app
// Клиентский модуль
// import type {AppType} from "./server-contract"
import { hc } from "hono/client"
const client = hc<AppType>("https://api.example.com")
const response = await client.health.$get()
```

#### Разбор примера

Тип цепочки содержит путь health и допустимый метод. Реальная связь всё равно проходит по HTTP: клиент проверяет response.ok и обрабатывает отказ. Пример показывает два модуля одной схемой, а не готовый единый клиент-серверный файл.

#### Типичная ошибка

> Импортировать серверный модуль как runtime-зависимость браузера или считать hc гарантией актуальности развёрнутой версии.
