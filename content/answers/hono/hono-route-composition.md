**Дочернее приложение можно подключить к префиксу через app.route. Это композиция маршрутов, а не создание независимого сетевого сервера.**

<!-- wishu:answer-block -->

#### Как это работает

Модуль описывает локальные пути, а корневое приложение определяет внешний префикс и общий middleware. Подключать нужно уже определённые маршруты: порядок регистрации имеет значение. При экспорте типов для RPC дополнительно важно сохранить выведенный тип цепочки определения маршрутов.

#### Пример

```typescript
const users = new Hono().get("/:id", (c) => c.json({ id: c.req.param("id") }))
const app = new Hono().route("/users", users)
// GET /users/42 обрабатывается дочерним /:id.
```

#### Разбор примера

Префикс users не нужно повторять внутри дочернего приложения. Несколько модулей остаются частями одного обработчика. Общую проверку доступа можно зарегистрировать до подключения защищённой группы.

#### Типичная ошибка

> Подключить пустое дочернее приложение и рассчитывать, что позднейшая регистрация автоматически перепишет родительские маршруты.
