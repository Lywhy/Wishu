**Используйте переменные текущего `Context` через `c.set` и `c.get` либо c.var. Их тип описывается в `Variables`, а значение устанавливается во время конкретного запроса.**

<!-- wishu:answer-block -->

#### Как это работает

Модульная переменная текущего пользователя смешала бы параллельные запросы. Объявление типа `Variables` только помогает TypeScript и само не заполняет данные: middleware должно выполниться на нужном пути. Для пользователя требуется проверенная сессия или токен; клиентский заголовок с ID не является подтверждением личности.

#### Пример

```typescript
type Env = { Variables: { requestId: string } }
const app = new Hono<Env>()
app.use("*", async (c, next) => {
  c.set("requestId", crypto.randomUUID())
  await next()
})
app.get("/id", (c) => c.json({ id: c.var.requestId }))
```

#### Разбор примера

Каждый запрос получает собственный идентификатор до входа в маршрут. Generic связывает имя и тип, но корректность порядка обеспечивается регистрацией middleware, а не аннотацией.

#### Типичная ошибка

> Сохранить currentUser вне `Context` и получить утечку данных между запросами.
