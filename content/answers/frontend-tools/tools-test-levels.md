**Unit-тест изолирует небольшую логику, интеграционный проверяет взаимодействие частей, end-to-end проходит пользовательский сценарий через существенные границы системы.** Название уровня определяется охватом, а не только инструментом запуска.

- Много мелких тестов не заменяет один важный сценарий сохранения данных. При этом все проверки через браузер дороги и затрудняют поиск причины. Набор выбирают по рискам и полезной обратной связи, не копируя каждую деталь реализации.
