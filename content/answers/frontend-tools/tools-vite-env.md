**Переменные, доступные клиентскому коду Vite через import.meta.env и разрешённый префикс, встраиваются в результат преобразования.** Пользователь может прочитать их в браузере или собранных файлах.

- Публичный URL API подходит для такого механизма, пароль базы или приватный токен - нет. Серверные секреты хранят на сервере. Изменение переменной после сборки не обязательно изменит уже созданный статический bundle.
