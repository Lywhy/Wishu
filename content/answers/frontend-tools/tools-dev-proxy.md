**Dev-proxy перенаправляет подходящий путь, например /api, с адреса frontend на backend во время разработки.** Браузер видит запрос к своему origin, что упрощает локальную работу с cookie и адресами.

<!-- wishu:answer-block -->

- Настройка dev-сервера не переносится автоматически в production. После публикации нужен соответствующий reverse proxy или явный адрес API с согласованными CORS и cookie. Proxy не заменяет серверную аутентификацию и проверку доступа.
