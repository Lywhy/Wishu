**Транспиляция может удалить аннотации и преобразовать синтаксис без полной проверки совместимости типов.** Поэтому сборщик способен выдать JavaScript для программы, которую TypeScript checker считает некорректной.

<!-- wishu:answer-block -->

- Проверку типов подключают отдельным шагом или скриптом сборки проекта. Runtime-валидация внешних данных остаётся необходимой даже при успешном tsc: ответы API и пользовательский ввод не получают гарантий от аннотации.
