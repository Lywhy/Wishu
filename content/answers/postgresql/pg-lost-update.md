**Схема SELECT count, вычисление в приложении, UPDATE готовым значением может перезаписать результат другого клиента.** Для счётчика выражение SET count = count + 1 выполняет изменение непосредственно на актуальной строке в рамках SQL-команды.

- Для сложного редактирования используют условие версии и проверку числа изменённых строк либо блокировку SELECT FOR UPDATE внутри короткой транзакции. Выбор должен учитывать отказ и повтор; одна проверка в JavaScript не защищает от параллельного клиента.
