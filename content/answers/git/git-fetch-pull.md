**Fetch получает объекты и обновляет соответствующие remote-tracking ссылки, не объединяя их автоматически с текущей веткой.** Pull объединяет получение с интеграцией по выбранному режиму, например merge или rebase.

<!-- wishu:answer-block -->

- Поэтому fetch удобен для предварительного просмотра изменений. Перед pull полезно понимать upstream, состояние рабочего дерева и принятую политику истории. Remote-tracking ветка - локальное представление удалённой ссылки, а не постоянно живое состояние сервера.
