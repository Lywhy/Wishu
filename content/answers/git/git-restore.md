**Restore возвращает содержимое выбранных файлов из источника в рабочее дерево, индекс или оба места по параметрам.** Например, --staged обычно снимает подготовку, сохраняя рабочие изменения, а восстановление рабочего дерева может их уничтожить.

- Перед операцией смотрят status и diff и понимают, откуда берётся версия. Restore не предназначен для создания обратного коммита опубликованной истории. Нельзя считать любое действие со словом restore безопасным сохранением текущих файлов.
