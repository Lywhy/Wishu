**Gitignore управляет тем, какие неотслеживаемые файлы Git обычно предлагает добавлять.** Если файл уже находится в истории и индексе, правило игнорирования не прекращает его отслеживание.

<!-- wishu:answer-block -->

- Для прекращения отслеживания нужен отдельный осознанный шаг с индексом. Если файл содержал секрет, удаление из текущего снимка не убирает его из истории: секрет заменяют, а очистку истории планируют отдельно с командой.
