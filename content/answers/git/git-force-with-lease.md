**Force push может перезаписать удалённую ссылку, не требуя fast-forward.** Force-with-lease дополнительно проверяет ожидаемое прежнее значение, чтобы не затереть неизвестное обновление другого участника.

<!-- wishu:answer-block -->

- Это не полная гарантия безопасности переписывания общей истории. Неявное ожидание может зависеть от remote-tracking ссылки, которую изменил фоновый fetch. Для критичного случая явно задают ожидаемый коммит и согласуют изменение с командой.
