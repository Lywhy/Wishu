**Обычный git diff показывает различия рабочего дерева и индекса.** Git diff --staged сравнивает индекс с HEAD, то есть показывает, что попадёт в следующий обычный коммит.

<!-- wishu:answer-block -->

- Новые неотслеживаемые файлы не появляются в обычном diff как уже отслеживаемое содержимое; их видно в status. Отсутствие вывода одного diff не доказывает, что все изменения проверены.
