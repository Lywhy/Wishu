**Конфликт означает, что Git не смог автоматически объединить определённые изменения.** Нужно изучить обе стороны и общий контекст, отредактировать согласованный результат и отметить файл разрешённым.

- Удаление маркеров без понимания не гарантирует корректности. После объединения проверяют поведение затронутого сценария. При rebase значения ours и theirs могут восприниматься непривычно из-за роли базы и переносимого коммита; выбирают по содержимому, а не названию кнопки.
