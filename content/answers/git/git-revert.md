**Revert создаёт новый коммит, отменяющий изменения выбранного прежнего коммита.** Это позволяет сохранить опубликованную линию истории и показать факт отмены, не передвигая чужие основания работы.

<!-- wishu:answer-block -->

- Отмена может конфликтовать с последующими изменениями и требует проверки результата. Для merge-коммита нужно выбрать основную родительскую линию и понимать последствия для дальнейших слияний. Revert не стирает исходные данные из истории.
