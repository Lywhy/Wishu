**Рабочее дерево содержит редактируемые файлы.** Индекс хранит подготовленное содержимое будущего коммита. Коммит фиксирует снимок и связи истории. Git add обновляет индекс текущим содержимым, а не обещает включить все будущие изменения файла.

<!-- wishu:answer-block -->

- Если после add ещё изменить файл, часть изменений будет staged, часть unstaged. Это позволяет готовить небольшие осмысленные коммиты. Перед фиксацией полезно отдельно просмотреть оба набора изменений.
