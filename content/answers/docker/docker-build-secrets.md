**Build arguments и переменные окружения не предназначены для безопасного хранения приватных токенов: значения могут попасть в историю, метаданные или итоговые слои.** Их не стоит использовать для постоянного секрета менеджера пакетов.

- BuildKit secret mount предоставляет значение конкретному шагу без обычного включения в образ. Команда не должна записывать его в артефакты или логи. Runtime-секреты передаются отдельным механизмом при запуске.
