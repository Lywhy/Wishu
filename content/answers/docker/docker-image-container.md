**Образ содержит слои файловой системы и конфигурацию запуска.** Контейнер - экземпляр с процессами, изоляцией и собственным записываемым слоем поверх образа. Из одного образа можно создать несколько независимых контейнеров.

<!-- wishu:answer-block -->

- Изменение файлов в контейнере не меняет исходный образ. После пересоздания несохранённые снаружи данные могут исчезнуть. На Linux контейнеры разделяют ядро хоста; Docker Desktop может использовать дополнительную виртуальную среду.
