**Localhost обозначает текущий сетевой namespace.** Из отдельного API-контейнера он не является адресом соседней базы. В общей сети Compose сервисы обычно находят друг друга по имени, например postgres.

<!-- wishu:answer-block -->

- Между контейнерами используют внутренний порт сервиса, например 5432. Для подключения с хоста нужен опубликованный host-порт, который может быть другим, например 15432. Эти два адреса описывают разные пути подключения.
