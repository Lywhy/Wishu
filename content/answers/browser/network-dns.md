**DNS позволяет получить адреса и другие сведения по доменному имени перед установлением нового соединения.**

<!-- wishu:answer-block -->

### Механизм и границы

- Результат может приходить из кеша браузера, ОС или резолвера. Для уже открытого соединения отдельное разрешение имени не требуется.

- DNS не подтверждает подлинность содержимого сайта: имя сервера проверяется в TLS по отдельному контракту.

### Сценарий

В waterfall первого обращения виден DNS, а у следующего ресурса по готовому соединению этого этапа может не быть.

### Типичная ошибка

Считать каждый HTTP-запрос полным новым циклом DNS, TCP и TLS.
