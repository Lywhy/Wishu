**Обычная навигация может создать другой документ, reload повторно загружает текущий, а fragment-переход часто меняет положение внутри того же документа.**

<!-- wishu:answer-block -->

### Механизм и границы

- Клиентская маршрутизация через History API тоже может оставаться same-document.

- Поведение кеша при reload не сводится к универсальному «всё заново из сети»: влияют тип перезагрузки, заголовки и инструменты браузера.

### Сценарий

Переход с /guide на /guide#cache обычно не запрашивает новый HTML для fragment.

### Типичная ошибка

Считать изменение адресной строки обязательным созданием новой страницы.
