**Деплой должен согласовать обновляемый документ с доступностью всех ресурсов, на которые он или уже открытые версии ссылаются.**

### Механизм и границы

- Короткая политика HTML и долгий кеш хешированных файлов решают разные задачи.

- Держите старые чанки достаточно долго по стратегии релиза; invalidation CDN и обновление Service Worker имеют отдельные шаги.

### Сценарий

Старая вкладка позже импортирует lazy-чанк предыдущего релиза: файл ещё должен быть доступен либо UI должен предложить восстановление.

### Типичная ошибка

Сразу удалить старую версию файлов и считать успешный показ главной страницы полной проверкой деплоя.
