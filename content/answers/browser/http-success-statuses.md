**200 сообщает об успехе по семантике метода, 201 - о создании, 202 - о принятии к обработке, 204 - об успехе без содержимого.**

<!-- wishu:answer-block -->

### Механизм и границы

- Для созданного ресурса полезен Location по контракту API. При 202 нужен способ наблюдать дальнейший результат.

- Ответ 204 не должен использоваться как носитель обязательного JSON-тела.

### Сценарий

Создание отчёта отвечает 202 и ссылкой на статус; клиент не объявляет файл уже готовым.

### Типичная ошибка

Безусловно вызывать response.json() после любого 2xx.
