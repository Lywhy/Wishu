**Fetch подходит для большинства запросов и потокового чтения ответа, а XHR может быть полезен для имеющегося кода или требуемого upload-progress API.**

<!-- wishu:answer-block -->

### Механизм и границы

- Выбор делают по нужному событию и поддержке целевой среды.

- Обе технологии подчиняются браузерным ограничениям origin, credentials и безопасности. Замена API не обходит CORS.

### Сценарий

Если интерфейсу нужен стандартный XHR upload progress, это может быть осмысленной причиной выбрать XHR для конкретной загрузки.

### Типичная ошибка

Считать XHR небраузерным клиентом, которому доступен любой междоменный ответ.
