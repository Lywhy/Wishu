**Домен - имя в системе DNS, IP - сетевой адрес, порт - точка назначения транспорта, а host в URL задаёт адресуемый узел.**

<!-- wishu:answer-block -->

### Механизм и границы

- Один IP может обслуживать много доменных имён, а одно имя - несколько адресов.

- `Origin` учитывает схему, хост и порт, поэтому одинаковый домен с другим портом может означать другую браузерную границу.

### Сценарий

https://example.com и https://example.com:8443 могут обращаться к разным сервисам и иметь разные origin.

### Типичная ошибка

Считать IP и доменное имя взаимозаменяемыми идентификаторами сайта для TLS и браузера.
