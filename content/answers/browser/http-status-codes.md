**401 указывает на отсутствие подходящих credentials, 403 - отказ в доступе, 404 - отсутствие доступного ресурса, 409 - конфликт состояния.**

<!-- wishu:answer-block -->

### Механизм и границы

- Для 401 определён WWW-Authenticate; механика сессии приложения не должна подменять семантику кода.

- Сервер иногда использует 404, чтобы не раскрывать существование запрещённой сущности. Конфликт версии следует отличать от аварийной ошибки 500.

### Сценарий

Редактор пытается сохранить устаревшую версию: API возвращает конфликт с машинным кодом, а не произвольный HTML с 200.

### Типичная ошибка

При любом 403 бесконечно обновлять токен, хотя аутентификация уже есть, а права недостаточны.
