**`Vary` перечисляет заголовки запроса, которые влияли на выбор представления и должны учитываться при повторном использовании кеша.**

<!-- wishu:answer-block -->

### Механизм и границы

- Например, языковой вариант или сжатие нельзя смешивать, если сервер действительно выбирает по соответствующему заголовку.

- `Vary` не добавляет авторизацию и не исправляет любой некорректный CDN cache key. Чрезмерное число вариантов снижает эффективность кеша.

### Сценарий

При `Vary`: `Accept-Encoding` кеш различает сжатые варианты для поддерживающих их клиентов.

```http
HTTP/1.1 200 OK
Content-Type: application/json
Cache-Control: public, max-age=60
Vary: Accept-Language

{"greeting":"Привет"}
```

Такой публичный ответ допустим только для действительно общих данных. Для разных значений языка кеш должен различать варианты; персональные данные требуют другой политики.

### Типичная ошибка

Сохранить один вариант по URL и выдать его клиенту с несовместимыми параметрами.
