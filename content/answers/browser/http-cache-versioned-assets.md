**Хеш содержимого в имени ресурса меняет URL при изменении файла, позволяя долго кешировать неизменяемую версию.**

<!-- wishu:answer-block -->

### Механизм и границы

- HTML должен ссылаться на согласованные версии файлов и иметь подходящую политику обновления.

- Immutable полезен для действительно версионированного URL. Перезапись нового содержимого под тем же долгоживущим именем нарушает контракт.

### Сценарий

app.a1b2.js остаётся доступным для старой страницы, а новая получает app.c3d4.js.

```text
index.html       -> проверять актуальность перед повторным использованием
app.a91c8f.js    -> public, max-age=31536000, immutable
app.f0d24a.js    -> новый адрес после изменения содержимого

Старый app.a91c8f.js сохраняют на срок поддержки открытых клиентов.
```

### Типичная ошибка

Удалить все старые чанки сразу при деплое и сломать уже открытые страницы.
