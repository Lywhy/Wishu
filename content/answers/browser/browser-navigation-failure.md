**HTTP-ошибка означает, что HTTP-ответ получен, а сбой DNS или соединения может не дать ответа сервера вообще.**

<!-- wishu:answer-block -->

### Механизм и границы

- Сервер способен вернуть собственный HTML с 404 или 500. Сетевой сбой браузер может показать своим экраном ошибки.

- При запросе ресурса из JS результат дополнительно зависит от API: resolved fetch с 404 отличается от rejected fetch при сетевом сбое.

### Сценарий

Адрес существующего сервера /missing возвращает 404; неразрешимое имя не имеет серверного HTTP-статуса.

### Типичная ошибка

Приписывать DNS-сбою статус 500, который сервер не отправлял.
