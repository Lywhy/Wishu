**Storage event подходит для наблюдения за соответствующими изменениями Web Storage, а `BroadcastChannel` - для явного обмена сообщениями между допустимыми контекстами.**

<!-- wishu:answer-block -->

### Механизм и границы

- Storage event не является локальным callback каждой записи в том же окне.

- Сообщение не делает операции вкладок атомарными: задайте ID, версии и восстановление пропущенного состояния. Канал и соединения нужно освобождать.

### Сценарий

После logout вкладки получают уведомление и отдельно перепроверяют сессию и очищают приватный UI.

### Типичная ошибка

Считать доставку одного сообщения надёжным журналом всех изменений навсегда.
