**400 обычно обозначает некорректный запрос, 415 - неподдерживаемый формат содержимого, 422 - невозможность обработать инструкции при понятном формате.**

<!-- wishu:answer-block -->

### Механизм и границы

- Границу детализации нужно согласовать в API, сохраняя стабильный машинный код ошибки.

- Не превращайте всё в 500 и не определяйте статус только по названию клиентской библиотеки.

### Сценарий

JSON синтаксически корректен, но дата окончания раньше начала: API может вернуть структурированную ошибку 422.

### Типичная ошибка

Показать пользователю технический stack trace вместо исправимых ошибок полей.
