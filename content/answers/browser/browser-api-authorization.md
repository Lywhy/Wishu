**Клиентский UI не является доверенной границей: пользователь может изменить код, адрес и тело запроса.**

### Механизм и границы

- Сервер проверяет сессию, схему входа и доступ к конкретному ресурсу при каждой чувствительной операции.

- Скрытие кнопки улучшает UX, но не запрещает вызов endpoint. Наличие валидного userId не подтверждает право читать его данные.

### Сценарий

Запрос на чужой projectId должен получить отказ независимо от того, показывала ли страница ссылку.

### Типичная ошибка

Отдать все приватные записи и затем отфильтровать их только на клиенте.
