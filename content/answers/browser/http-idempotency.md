**Идемпотентность означает, что несколько одинаковых запросов имеют тот же предполагаемый эффект на сервере, что один.** Например, PUT и DELETE имеют такую семантику; GET дополнительно считается безопасным, то есть не запрашивает изменение состояния.

- Ответы при повторе могут различаться: удалённый ресурс во второй раз может дать 404. POST не является идемпотентным по определению, но API может реализовать ключ идемпотентности. Нельзя автоматически повторять оплату, полагаясь только на сбой соединения.
