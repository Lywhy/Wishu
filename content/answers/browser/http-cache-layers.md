**Ресурс может обслуживаться браузерным HTTP-кешем, общим proxy/CDN, Service Worker или прикладным хранилищем данных.**

### Механизм и границы

- Эти слои имеют разные ключи, сроки жизни и способы очистки.

- Попадание одного слоя не доказывает актуальность другого. Cache API не является просто ручкой управления автоматическим HTTP-кешем.

### Сценарий

Удаление записи query-библиотеки не обязательно заставит CDN получить новый ответ origin.

### Типичная ошибка

Считать кнопку Clear cache универсальной очисткой всех состояний приложения и сети.
