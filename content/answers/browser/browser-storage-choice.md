**Выбор хранилища зависит от формата, размера, синхронности, срока жизни и необходимости участия данных в HTTP.**

<!-- wishu:answer-block -->

### Механизм и границы

- Cookies могут отправляться запросами, Web Storage хранит строки синхронно, `IndexedDB` поддерживает структурированные данные и транзакции, Cache API - `Request`/`Response`.

- Ни одно клиентское хранилище не является серверным доказательством права доступа или гарантированно вечным backup.

### Сценарий

Тема UI подходит небольшому storage-контракту, а коллекция offline-записей с индексами может требовать `IndexedDB`.

### Типичная ошибка

Выбирать `localStorage` для всего только потому, что API короткий.
