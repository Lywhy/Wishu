**Stale-while-revalidate разрешает в заданном окне использовать несвежий ответ, пока кеш обновляет его в фоне по своему контракту.**

<!-- wishu:answer-block -->

### Механизм и границы

- Пользователь быстрее получает данные, но должен быть приемлем их ограниченный возраст.

- Это не гарантия успешного обновления и не стратегия для любых чувствительных данных. Различайте эту HTTP-директиву и одноимённую стратегию кода Service Worker.

### Сценарий

Публичный каталог может показать недавний список, пока выполняется проверка обновления.

### Типичная ошибка

Применять фоновую устарелость к критичному результату авторизации без анализа риска.
