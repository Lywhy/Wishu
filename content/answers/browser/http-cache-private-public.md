**Private ограничивает хранение ответа частным кешем, а public явно допускает общий кеш при остальных выполненных условиях.**

<!-- wishu:answer-block -->

### Механизм и границы

- Персональный ответ нельзя делать общим без корректного разделения и проверки его назначения.

- Private не шифрует ответ и не делает браузер безопасным хранилищем секретов. No-store выбирают по отдельной политике хранения.

### Сценарий

Страница личного кабинета не должна попасть в общий CDN-кеш как одинаковый ответ для всех.

### Типичная ошибка

Считать public безопасным для любого GET, поскольку метод только читает данные.
