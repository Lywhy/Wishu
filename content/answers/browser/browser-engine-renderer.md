**JavaScript-движок исполняет код, а движок рендеринга строит и отображает документ с его стилями и геометрией.**

### Механизм и границы

- DOM и браузерные API предоставляет среда, а не сам язык JavaScript.

- Тяжёлый код может задерживать задачи главного потока, но стоимость layout и paint не равна времени выполнения JavaScript.

### Сценарий

Изменение ширины элемента запускает работу макета после выполнения JS; сам setter стиля не описывает всю стоимость кадра.

### Типичная ошибка

Считать V8 названием всей системы отображения Chrome.
