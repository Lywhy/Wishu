**Same-document navigation сохраняет текущий Document, а cross-document переходит к другому документу, в том числе восстановленному из истории.**

<!-- wishu:answer-block -->

### Механизм и границы

- PushState и fragment могут менять URL без замены документа. При cross-document браузер может восстановить прежний Document из bfcache вместо создания нового.

- Жизненный цикл, обработчики и состояние требуют соответствующего механизма восстановления.

### Сценарий

SPA меняет фильтр через History API и сохраняет дерево; полная ссылка на другую страницу запускает другой навигационный контракт.

### Типичная ошибка

Считать любой Back новым первоначальным выполнением всех скриптов.
