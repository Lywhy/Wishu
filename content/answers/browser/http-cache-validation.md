**Клиент передаёт валидатор сохранённого представления; сервер может ответить 304, если допустимо переиспользовать прежнее тело.**

<!-- wishu:answer-block -->

### Механизм и границы

- `If-None-Match` работает с `ETag`, `If-Modified-Since` - с датой `Last-Modified`; при совместном использовании учитываются правила приоритета HTTP.

- 304 не содержит новую копию представления: клиенту нужна подходящая сохранённая версия и корректное обновление её метаданных.

### Сценарий

GET с `If-None-Match`: "v7" получает 304, и браузер использует имеющееся тело версии v7.

```http
GET /profile HTTP/1.1
Host: example.com
If-None-Match: "profile-v4"

HTTP/1.1 304 Not Modified
ETag: "profile-v4"
Cache-Control: private, no-cache
```

### Типичная ошибка

Пытаться прочитать новое JSON-тело из 304 или называть его обычным редиректом.
