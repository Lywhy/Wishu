### Механизм и границы

- JSON разбирается как данные, текст декодируется в строку, бинарный ответ читают, например, как Blob или ArrayBuffer.

- Успешный разбор JSON не подтверждает его прикладную схему. Ошибочный `Content-Type` может мешать обработке и защите от MIME-sniffing.

### Сценарий

API вернул HTML-страницу ошибки вместо JSON; ошибка парсинга не объясняет первичный HTTP-сбой.

### Типичная ошибка

Считать расширение URL достаточным описанием содержимого ответа.
