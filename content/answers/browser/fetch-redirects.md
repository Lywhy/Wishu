**Fetch может следовать редиректам, поэтому исходный URL запроса и конечный response.url способны различаться.**

<!-- wishu:answer-block -->

### Механизм и границы

- Метод и credentials оцениваются по правилам редиректа и нового адреса.

- Режим manual в браузере не гарантирует обычного чтения всех redirect-данных: фильтрация ответа имеет свой контракт. Для диагностики полезна цепочка Network.

### Сценарий

API перенаправил запрос на страницу входа, вернув HTML вместо ожидаемого JSON.

### Типичная ошибка

Диагностировать только финальную ошибку JSON, не заметив редирект авторизации.
