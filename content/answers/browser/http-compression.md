**`Accept-Encoding` описывает приемлемые кодирования, а `Content-Encoding` указывает фактически применённое сжатие представления.**

<!-- wishu:answer-block -->

### Механизм и границы

- Это не `Content-Type`: JSON остаётся JSON после gzip-декодирования.

- Сжатие экономит передачу ценой CPU; уже сжатые изображения часто мало выигрывают. Общий кеш должен различать варианты, когда они зависят от `Accept-Encoding`.

### Сценарий

Один вариант CSS передаётся с br, другой с gzip; `Vary` помогает не смешать их для разных клиентов.

### Типичная ошибка

Перепутать архив-файл application/gzip с `Content-Encoding`: gzip обычного документа.
