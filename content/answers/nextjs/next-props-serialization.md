**Props, пересекающие серверную и клиентскую границу, должны поддерживаться сериализацией React.** Простые данные и поддерживаемые встроенные значения передаются, произвольная обычная функция и экземпляр пользовательского класса - не универсальный транспортный формат.

<!-- wishu:answer-block -->

- Обработчик события обычно создают на клиенте. Server Function передаётся по специальному поддерживаемому контракту, а не как произвольное замыкание с серверными ресурсами. Переданные клиенту данные доступны пользователю, поэтому в props нельзя включать секреты.

### Это не просто JSON
Текущий протокол React поддерживает определённые значения, включая Date, Map, Set и Promise, а не только то, что переносит JSON.stringify. При этом обычные произвольные функции и экземпляры пользовательских классов нельзя считать универсально переносимыми. Server Functions и JSX имеют собственные поддерживаемые контракты. Типовая аннотация не делает любой объект сериализуемым. Передавайте минимальные публичные данные.
