**Server Action выполняет серверную операцию, инициированную клиентом.** Скрытая или отключённая кнопка не является контролем доступа: входные данные и полномочия нужно проверить в серверной точке изменения.

<!-- wishu:answer-block -->

- Валидация формы, аутентификация и авторизация имеют разные задачи. После успешного изменения согласуют кеш и отображение; ожидаемые ошибки можно вернуть как данные. Директива use server не делает произвольную бизнес-операцию безопасной автоматически.

### Граница Server Function
Use server обозначает вызываемую серверную функцию в поддерживаемой React/RSC-среде, а не служит универсальной директивой всех Server Components. Перед записью отдельно проверьте типы входа, аутентификацию и право на конкретный объект. Повторы и параллельные отправки требуют бизнес-контракта, например ключа идемпотентности или проверки версии. Передавайте наружу только публичный результат.
