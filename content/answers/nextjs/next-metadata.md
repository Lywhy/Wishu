**Статический metadata описывает известные заранее title, description и другие поля.** GenerateMetadata вычисляет их по данным и параметрам маршрута. Metadata API используется в серверных page и layout.

- Метаданные должны соответствовать содержимому и каноническому адресу. Не нужно одновременно реализовывать конфликтующие способы генерации для одного сегмента. Наличие title и Open Graph не гарантирует позицию в поиске и не заменяет доступный содержательный HTML.
