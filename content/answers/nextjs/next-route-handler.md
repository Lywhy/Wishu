**Route Handler описывает обработку HTTP-методов через стандартные Request и Response и расширения Next.js.** Он подходит для webhook, JSON API или ответа другого формата. Page описывает UI маршрута, а не произвольный HTTP endpoint.

<!-- wishu:answer-block -->

- В одном сегменте route и page конкурируют за один адрес и не используются как два независимых ответа того же пути. Обработчику нужны явные проверки метода, входа и прав; GET с ответом не следует автоматически считать публичным или безопасным для общего кеша.
