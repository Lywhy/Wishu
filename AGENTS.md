# Правила проекта

- В новых и изменяемых текстах использовать дефис вместо длинного тире.
- Сохранять существующие ID и прогресс. Применённые SQL-миграции не менять.
- Интерфейс: Tailwind и подходящие компоненты shadcn; сначала искать существующий блок.
- Агенту разрешены content:* инструменты поиска, подготовки, сборки и проверки. Приложение, Docker, сборку/проверки UI и сервера, миграции, seed и код примеров запускает пользователь.
- Перед правкой читать актуальный файл. Хеш или индекс не разрешает слепую перезапись.

## Навигация

Для кода: нужная область в docs/project-map.md; подробный шаблон - docs/development-recipes.md. Для контента: content/AGENTS.md. Для CLI: scripts/questions/AGENTS.md.

По умолчанию использовать краткие content:find/context и только текущий пакет. Ответы открывать по ID через content:show. Подробные правила читать только для затронутой области. Источник токен-экономного процесса: docs/lean-content-workflow.md.
