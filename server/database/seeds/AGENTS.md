# Собранный каталог вопросов

`questions.json` теперь является артефактом из `content/questions`. Вручную ответы здесь не редактировать. Перед изменением вопросов читать [правила контента](../../../content/AGENTS.md) и [рабочий процесс](../../../docs/question-content-workflow.md).

Существующий формат и ID сохраняются для upsert и прогресса. Контентные сборка и проверки разрешены агенту пользователем от 2026-11-07. Seed, сервер, Docker и миграции запускает пользователь. Не менять применённые SQL-миграции. Для первичного перехода на новую структуру разрешён перенос существующего каталога без изменения ответов.
