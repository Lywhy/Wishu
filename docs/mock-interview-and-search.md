# Пробные собеседования, повторение и поиск

Изменения от 2026-11-07.

## Что добавлено

- `/mock-interview`: выбор тем, сложности и количества вопросов, случайная подборка, скрытый ответ и самооценка. Таймера и отсчёта времени нет. Текущая подборка сохраняется в браузере. Вход - со страницы «Короткая подготовка» или из общего поиска.
- Глобальный поиск в шапке и по Ctrl/Cmd + K. Использует shadcn Command/cmdk и существующий Dialog. Стрелки и Enter переключают результаты. Поиск охватывает вопросы, задачи и названия лекций; каталог обновляется при открытии поиска. Подключена зависимость cmdk, существующие Button и Dialog не перезаписывались.
- Подборка вопросов «На сегодня». После успешного сохранения отметки создаётся локальная дата следующего повторения: 1, 3, 7, 14 и 30 дней. «Повторить» возвращает интервал к одному дню. Повторные отметки в тот же день не перескакивают несколько интервалов. «Пропустить» не закрывает уже назначенное повторение. Undo восстанавливает предыдущую дату. Старые вопросы со статусом «Повторить» без расписания считаются требующими повторения сегодня.
- Разбор реальной встречи в трекере: что спрашивали, сложности, выводы и план. План можно добавить к существующей заметке, не затирая её. Прикреплённые вопросы запускаются как подборка повторения с возвратом к записи собеседования. Данные разбора включаются в резервную копию записи.
- Кнопка «Поделиться подборкой» у вопросов и задач копирует URL с текущими фильтрами. Если Clipboard API недоступен, появляется поле для ручного копирования. Личные отметки, избранное и расписание другого человека не передаются: получатель открывает те же фильтры для своего прогресса.

Расписание и пробное собеседование пока хранятся в браузере; сервер хранит обычные отметки вопросов. Новых таблиц, миграций, seed или API не требуется. История решений, свои тесты и карта подготовки не добавлялись.

## Правки страницы вопроса

- В режиме фокуса панель отметок имеет высоту 40 px, как Select рядом. Внутренние кнопки вписаны в эту высоту.
- Убрана пустая область состояния сохранения под кнопками. Объявление для экранного диктора осталось; ошибки и повторное сохранение доступны в общем уведомлении.
- У блока «Как работают отметки» убраны внешний верхний отступ и padding.
- Кнопки перехода к предыдущему и следующему вопросу имеют общий outline-стиль.

## WebGL

В `GradientASCII.tsx`, `sizeTarget` после выделения текстур включаются все цветовые вложения через drawBuffers и явно очищаются прозрачным цветом через clearBufferfv. Раньше texImage2D с null оставлял браузеру ленивую инициализацию при первом использовании, в том числе для halo при glow=0. Новая очистка выполняется при создании/изменении размера, а не на каждом кадре. Пользовательские значения оформления не менялись.

Источники API: [clearBufferfv](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/clearBuffer), [texImage2D](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/texImage2D). Исчезновение предупреждения в целевом браузере должен подтвердить пользователь: агент приложение и проверки не запускал.

## Проверка пользователем

Агент выполнил форматирование oxfmt. Приложение, линтер, TypeScript, сборка, примеры и тестовые решения не запускались. Скриншоты не создавались.

```sh
pnpm check:ui
```

Ручные сценарии:

1. Включить общее раскрытие ответов, открыть пробное собеседование и проверить, что ответ всё равно скрыт. Пройти, прервать и восстановить подборку после обновления страницы. Проверить итоги и неоценённые вопросы.
2. Поставить «Изучил» и «Повторить», дождаться сохранения. Проверить запись локального расписания и отмену отметки. В «На сегодня» должны попадать только наступившие даты или старые повторения без расписания.
3. Поиск: Ctrl/Cmd + K, кнопка в шапке, стрелки, Enter, Esc. Проверить вопросы, задачи и лекции, сетевую ошибку и повторную загрузку.
4. Сохранить разбор встречи, закрыть/открыть запись, обновить страницу, перенести план в непустую заметку. Запустить прикреплённые вопросы, перейти к следующему и вернуться к записи с сохранёнными фильтрами.
5. Скопировать URL с поиском, сложностью, темой и страницей задач. Проверить ручное копирование при недоступном Clipboard API и сброс подписи после смены фильтров.
6. Проверить выравнивание отметок в режиме фокуса, отсутствие пустого блока, наведение на раскрытие прогресса и одинаковый стиль стрелок.
7. В консоли проверить предупреждение WebGL при первом открытии, переключении темы, изменении размера и значений glow/dpr. Если предупреждение остаётся, определить canvas-источник: приложение также содержит Monaco, поэтому по одному сообщению нельзя гарантировать, что любой такой warning относится к фону.
