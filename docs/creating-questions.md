# Добавление вопросов

Кнопка «Добавить вопрос» доступна в каталоге и в подразделе. Форма /questions/new позволяет выбрать существующий доступный раздел и подраздел, сложность, популярность, описание карточки, короткий ответ, Markdown-разбор, код, типичную ошибку и главную мысль. Справа находится живой предпросмотр; на узких экранах он расположен после формы.

POST /api/questions требует текущую cookie-сессию и проверяет Origin. Поля валидируются сервером. Раздел и подраздел проверяются вместе, topic и moduleId берутся из каталога. Вопрос сохраняется в PostgreSQL и добавляется в загруженный каталог без сброса прогресса. После сохранения открывается его страница. Новые вопросы общие для этой установки, авторизация и модерация пока отсутствуют.

requestId UUID сохраняется на время работы с формой. Повторная отправка того же содержимого возвращает уже созданный вопрос. Изменённое содержимое с использованным requestId возвращает конфликт. Название проверяется на точное совпадение без учёта регистра в рамках подраздела. Семантически похожие вопросы автоматически не объединяются.

Новые ID имеют префикс custom-, не пересекаются с seed. Seed выполняет upsert своих записей и не удаляет пользовательские вопросы. Миграция не требуется.

Ручная проверка: создать вопрос из подраздела, проверить предвыбор темы, Markdown и код; сохранить и обновить страницу; найти вопрос в поиске и проверить отметки. Проверить пустые поля, совпадающее название, повторную отправку и ошибку сети (содержимое формы остаётся до ухода со страницы). Несохранённый черновик не восстанавливается после обновления страницы. Команда «Отмена» подтверждает уход при заполненных полях.

Приложение, миграции, lint, сборка и тесты агентом не запускались.

## Редакторское наполнение из файлов

Для массового наполнения используется отдельный [процесс подготовки контента](question-content-workflow.md): исходники по подразделам, индекс целей, карта покрытия и сборка seed. Форма в интерфейсе по-прежнему сохраняет вопросы только в PostgreSQL; автоматического экспорта пользовательских записей в исходники нет.
