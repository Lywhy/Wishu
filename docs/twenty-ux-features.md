## Хранение и ограничения

Новые настройки, заметки, история попыток и короткая сессия хранятся в этом браузере (wishu-workspace, wishu-short-session). Они не синхронизируются между устройствами. При недоступном localStorage настройки/заметки/попытки workspace продолжают работать в памяти текущей страницы, но после закрытия могут потеряться. Существующие отметки и черновики не удалялись.

Первый уровень подсказки использует ограничение задачи; второй - существующее объяснение подхода. Новые независимые подсказки к каждому алгоритму не выдумывались. История показывает код и результат проверки, а не является серверным журналом сдач.

Для сообщения о проблеме добавлена новая миграция 004_content_feedback.sql. Уже применённые миграции не менялись. Отчёты сохраняются в таблицу content_feedback; отдельный административный интерфейс обработки отчётов не добавлен.

## Ответы вопросов

Исходный JSON каталога содержит 478 вопросов. Форматирование затрагивает тексты answer: выделение основной мысли, оформление технических обозначений как inline code, пояснения в виде Markdown-пунктов. Сохранены все ID, связи, порядок, summary, takeaway, pitfall и 323 существующих примера code. Формат API и схема вопросов не менялись.

На странице остаётся последовательность: краткий ответ, подробности, пример, частая ошибка, главная мысль. Это оформление существующего содержания, а не заново проведённая техническая экспертиза всех ответов. Для остальных 155 вопросов искусственные примеры не генерировались. Если потребуется новое содержательное объяснение или пример, его нужно готовить по теме вопроса, а не добавлять одинаковый шаблон.

## Применение пользователем

Из корня проекта:

```powershell
pnpm db:migrate
pnpm db:seed
```

Первая команда создаёт таблицу сообщений, вторая обновляет Markdown-тексты вопросов в PostgreSQL. После этого обновить страницу браузера, чтобы сбросился клиентский кеш каталога.

Эти команды агентом не выполнялись. Сервер, Docker, приложение, сборка, компилятор, линтер, миграции, seed и тестовые решения не запускались. Выполнены чтение исходников и форматирование oxfmt. Поведение всех новых сценариев требует ручной проверки, включая сессию, отмену отметки, восстановление попытки, заблокированный localStorage, ошибки API и обе темы.
