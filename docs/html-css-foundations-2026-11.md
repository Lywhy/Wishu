## Сопоставление и повторы

- Отдельное сравнение flex: none, auto и 1 -> css-flex-space. Расширена единая модель basis/grow/shrink вместо похожего определения.
- Отдельное определение object-position -> css-image-fitting. Кадрирование добавлено к существующему контракту изображения с примером.
- Новый вопрос про autocomplete=off -> html-input-hints. Оговорка об автозаполнении относится к уже существующему назначению поля.
- Повтор о thead, tbody и scope -> html-table-relations. Добавлен связный пример к каноническому вопросу отношений таблицы.
- Новый базовый пример has -> css-selector-functions. Состояние родителя показано в существующем вопросе функций селекторов.
- Отдельный вопрос о пробеле inline-block -> css-white-space-contract. Сохранение и схлопывание пробелов объясняется в одном каноническом ответе.
- Повторное определение reset формы -> form-reset. Канонический JavaScript-вопрос уже объясняет восстановление defaultValue/defaultChecked; дубль не создан.
- Ещё одно объяснение button против ссылки и div -> semantic-button. Базовый нативный выбор уже раскрыт; новые карточки ссылаются на него.
- Новая карточка про line-height с единицей и без неё -> css-line-height-inheritance. Есть отдельный сравнительный ответ с численным примером; повтор не нужен.

Ранее опубликованные ID не удалялись и не сливались. Объединялись кандидаты до создания карточек. Новые базовые вопросы раскрывают термин и назначение, средние требуют объяснить конкретный сценарий и границы. Отдельные напоминания и похожие фрагменты примера допустимы для закрепления, если учебная цель отличается.

В частности, alt рассматривает типы альтернатив, DPR - отношение логических и физических пикселей, а srcset остаётся канонической моделью выбора файла. Axes описывает исходную модель Flexbox, alignment - различие групп свойств, scroll pane - цепочку ограничений практической раскладки.
