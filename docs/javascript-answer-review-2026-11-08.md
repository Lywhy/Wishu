# Редактура ответов JavaScript

Область: 346 существующих вопросов в 20 подразделах. В предыдущем проходе переработаны 12 ответов; текущий проход расширяет оставшиеся 334. Новых вопросов, удалений и слияний нет. Все ID сохранены, поэтому связи прогресса и избранного не меняются.

Для каждого из 334 ответов подготовлен индивидуальный разбор примера или дополнительный шаг рассуждения в упражнениях на чтение кода. Короткий ответ сопровождается механизмом, результатом примера, границами применения и важными ошибками. Изолированные факты объединены в абзацы; таблицы сравнений, последовательности действий и родственные вопросы сохранены. Убраны пустые заголовки и повторное отображение примеров: обычный код включён в Markdown ответа, условие упражнения на чтение кода осталось отдельно.

Исправлены кавычки учебного JSON-примера в eval-risks, вложенное жирное выделение в условиях разбора и повреждённые подписи источников. Уточнены ссылки на документацию; checkedAt обновляется только для действительно просмотренных источников. Новые возможности сопровождаются оговорками о среде и поддержке. В частности, сверены актуальная документация for await...of, Array.fromAsync, Iterator helpers, explicit resource management, import attributes, RegExp.escape, Atomics.waitAsync и AbortSignal.timeout.

Ответы написаны самостоятельно. ITBooster использовался ранее только для сопоставления названий тем; ответы сайта не читались и не заимствовались.

Код примеров не выполнялся. Проверяются форматирование, целостность каталога, ссылки и сборка контента. Приложение, UI/server проверки, Docker, миграции и seed не запускаются агентом. После завершения сборки и полной content:check обновлённый каталог пользователь переносит в свою БД командой pnpm db:seed.

Количество вопросов и редакторский статус не гарантируют охват всех возможных собеседований.
