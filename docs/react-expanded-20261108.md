## Редакторский подход

Первый проход сопоставил 128 существующих карточек и зафиксировал границы новых прикладных сценариев. Общие определения state, effects, key, Context, memo и подписок не размножались дословно: новые сценарии ссылаются на соответствующий канонический вопрос. Например, immutability остаётся общим правилом, а удаление записи по ID, изменение одной ветки и работа с Set проверяют разные операции применения.

Ответ содержит короткий вывод, механизм и существенные границы, пример, типичную ошибку, ссылки для закрепления и источник. Названия связанных вопросов взяты из действующего каталога. Примеры JSX и настроек оформлены как кодовые блоки; повторного отдельного code-поля нет. takeaways хранятся в карточке как прежде.

## База Redux

Закрыты основные учебные контракты store/action/reducer, action creators/payload, инициализация и неизвестное действие, root state, несколько slices, prepare, правила Immer, dispatch/getState, selectors, выбор локального состояния, preloadedState и диагностика. Средний уровень включает thunks, отмену и requestId, ошибки, RTK Query, подписки, теги, запуск запроса, состояния загрузки и срок кеша. Продвинутые вопросы: listener cancellation, перекрывающийся optimistic rollback, code splitting, combineSlices, streaming cache lifecycle и границы нормализации.

## База Zustand

Закрыты основные учебные контракты create/createStore, set/get/api, функциональное обновление, merge/replace, actions, selectors по ID, React-подписка vanilla-store, начальный снимок, массивы и примитивный state, область экземпляра и выбор локального состояния. Средний уровень включает persist/partialize/storage/merge/готовность восстановления, devtools, slices, Map/Set и внешние частые обновления. Продвинутые вопросы: SSR-гидратация, middleware-типы, изоляция тестов и стабильность selector в Zustand 5. Ранее существовавшие вопросы async actions, миграции, scoped-store и reset сохранены.

Это покрытие заявленной карты базовых навыков и основных более сложных сценариев, а не обещание наличия каждого API или всех вопросов любого собеседования. Обзорные core-цели не помечены автоматически полностью reviewed. 59 прежних imported-ответов React сохраняют свой статус и могут быть отдельно углублены без новых дублирующих карточек.

## Источники и условия примеров

Использованы первичные источники React, React Router, Redux/Toolkit/React-Redux, Zustand, Testing Library и MDN. Примеры ориентированы на React 19, React Router 7 с явно различённым режимом, Redux Toolkit 2/React-Redux 9 и Zustand 5. Общие условия записаны в caveats подразделов, существенные оговорки - в самих ответах.

Ссылки API React Router привязаны к версии 7 там, где страница доступна. Общие объяснения гонок, сессий и SPA могут ссылаться на актуальную официальную документацию: они не используются для утверждения, что новый API доступен в версии 7. checkedAt установлен только для действительно открытых и проверенных в текущем проходе URL; null не заменён формальной датой. Контентная проверка валидирует форму URL, но не проверяет HTTP-доступность каждой страницы.
