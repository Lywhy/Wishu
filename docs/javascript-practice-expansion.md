## Практические задачи

- 023 / js-throttle: Throttle без отложенного вызова
- 024 / js-simple-bind: Привязка контекста и аргументов
- 025 / js-promise-all: Своя агрегация Promise.all
- 026 / js-async-pool: Ограничитель параллельных операций
- 027 / js-event-emitter: EventEmitter с отпиской
- 028 / js-retry: Повторные попытки с backoff

Существующий debounce сохранён. Всего задач 28, JavaScript 13. У каждой новой задачи пять runtime-сценариев: два фиксированных базовых, два средних со случайными параметрами, один сложный со случайными параметрами. Входы и результаты используют существующий отчёт и консоль. Проверяются контекст, аргументы, границы, независимость экземпляров, порядок, обработка ошибок и прекращение очереди. Случайность не является защитой от обхода локального judge.

Throttle - leading без trailing; bind - явно упрощённый, без new и метаданных; promiseAll принимает массив, не полный iterable-контракт. Retry использует внедрённый sleep, проверяет экспоненциальные задержки без реального ожидания; production-политика требует идемпотентности, jitter, отмены и deadline. Для Promise-задач тестер пропускает ограниченное число микрозадач, операции должны координироваться без polling-таймеров. Проверка позднего unhandledrejection у пула дополнительно уступает одну задачу браузеру.

Запрет использования нативного bind и комбинаторов Promise является учебным ограничением и требует просмотра решения. Поведенческие тесты сами по себе не доказывают соблюдение этого ограничения или корректность на любых входах.

## Интерфейс

На странице JavaScript появилась последовательность: основа → разбор кода → самостоятельное решение. Подборка содержит семь задач с учётом debounce и показывает локально решённые. WeakRef, FinalizationRegistry, SharedArrayBuffer и Temporal отмечены «Дополнительно» на карточках и в вопросе. Execution context остаётся важной основой. Вопросы связаны с задачами; блок самопроверки просит объяснить механизм, вариант входа, крайние случаи и ограничения. Это не новая автоматическая оценка готовности.
