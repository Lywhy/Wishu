# UX подготовки: настройки, рабочее состояние и планы

Изменения от 2026-11-07.

- В шапке появилась кнопка настроек интерфейса. Фон: анимация, статичный ASCII, выключен. Для Markdown-ответов и лекций доступны размер текста и интервал. Предпочтение уменьшенного движения системы имеет приоритет над анимацией.
- Каталог вопросов получил подборки новых, популярных, избранных и отмеченных для повторения. Переход между подборками сохраняет поиск и сложность. Ссылка в шапке восстанавливает последние фильтры. Результаты показываются порциями по 24; раскрытое количество сохраняется для последних 60 подборок, чтобы возврат из вопроса не обрезал список.
- Итог занятия показывает изученные, требующие повторения, пропущенные и оставшиеся вопросы, состояние задачи и конкретный следующий вопрос. Новая сессия выбирает нерешённую задачу; если их нет, создаётся подборка только вопросов.
- Monaco сохраняет курсор, выделение и прокрутку для последних 40 задач. Вкладка тестов/консоли тоже сохраняется. Последние результаты проверок для 12 задач остаются только в памяти вкладки и восстанавливаются при совпадении кода. Изменение кода, новая проверка или её отмена удаляют старый результат.
- JSON-результаты раскрываются по вложенным полям, длинные коллекции показываются порциями. Короткие массивы остаются компактными. Отличающиеся значения, отсутствующие поля и разница типов выделяются в самих данных. Строки, которые не являются JSON, остаются текстом.
- У записи собеседования появился план: темы, прикреплённые вопросы и задачи. Для каждого материала есть переход и ссылка возврата к выбранной записи с её фильтрами. Старые записи совместимы: поле preparation необязательное. Резервная копия включает план вместе с остальной записью.
- Серверная очередь отметок сохраняет неотправленные действия при ошибке. Можно повторить очередь или явно отменить её первое несохранённое действие. Уведомление не сообщает об успехе, пока запрос не завершён. Это очередь в памяти текущей вкладки; перезагрузка не сохраняет неотправленные запросы.
- Для новых локальных настроек, состояния редактора, сессии и черновиков есть обработка недоступного хранилища с сохранением последнего значения в памяти и повторной попыткой. Для записей собеседований добавлена повторная запись текущего состояния.

## Ручная проверка пользователем

Агент не запускал приложение, линтер, TypeScript, сборку или решения задач. Скриншоты не создавались. Изменённые файлы отформатированы oxfmt.

```sh
pnpm check:ui
```

Проверить после запуска:

1. Изменить фон, размер и интервал, обновить страницу. В статичном режиме нет непрерывной анимации. При системном reduced motion фон неподвижен и в режиме анимации.
2. Включить подборку новых вопросов, ввести поиск и сложность, раскрыть ещё записи. Открыть вопрос, вернуться назад и через шапку. Проверить фильтры, количество раскрытых карточек и прокрутку.
3. В задаче изменить курсор/выделение/прокрутку, открыть консоль, перейти к другой задаче и вернуться. После перезагрузки сохраняется положение и вкладка, но не результаты проверки.
4. Проверить правильное и ошибочное решение. Сравнить вложенные объекты, массивы разной длины, отсутствующий результат и null. Вернуться к задаче после перехода, затем изменить код и убедиться, что старые результаты очищены.
5. Завершить и прервать короткую сессию, проверить подсчёт и ссылки следующего шага. Дождаться сохранения отметок перед завершением.
6. В существующей и новой записи собеседования выбрать темы, прикрепить/убрать вопросы и задачи. Перейти к материалу, вернуться к записи, обновить страницу и скачать резервную копию.
7. При сетевой ошибке повторить сохранение нескольких отметок и проверить порядок. При постоянной ошибке отменить первое несохранённое действие. При блокировке/переполнении localStorage проверить сообщения и повторную запись после восстановления доступа.

Схема PostgreSQL, миграции, ID контента и seed не изменялись. Дополнительных команд для базы не требуется.
