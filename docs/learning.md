# Обучение

Каталог использует группы, разделы, инициалы и цвета каталога вопросов. Рамка окрашена у обозначения с инициалами; остальные рамки остаются нейтральными. Сохраняются поиск и «Мой план».

Маршруты: /learn, /learn/:sectionId, /learn/:sectionId/:stepId. Без этапа курс открывает первый непройденный. Боковое содержание показывает этапы и прогресс; переходы свободные. На узком экране содержание расположено над материалом. Внизу каждого материала есть «Основы» со ссылками на лекции и переходы между этапами. Подвал на вложенных маршрутах не отображается.

Для JavaScript подготовлены 4 пары «лекция - практика», для TypeScript и React - по 2 пары. В них распределена 21 существующая задача по изучаемым темам. Другие доступные разделы используют лекционные выжимки из первых трёх вопросов каждого подраздела; практические блоки для них пока не подготовлены. Разделы в разработке недоступны.

Markdown поддерживает заголовки, выделения, цитаты, списки, таблицы, код и сноски через react-markdown и remark-gfm. Произвольный HTML не исполняется.

Каждое учебное задание использует общий Monaco и механизм проверки задач, но выполняет только один случайный сценарий по материалу. Для TypeScript результат также учитывает контракт типов внутри того же теста. Обычные задачи сохраняют пять runtime-сценариев. Результаты, входы и консоль доступны в обеих версиях.

Лекции отмечаются вручную, с возможностью снять отметку. Практический этап считается пройденным только после принятия всех его заданий. Редактирование принятого решения снимает отметку задания и этапа. Черновики и прогресс обучения сохраняются отдельно в localStorage (wishu-learning-progress), серверная синхронизация пока не подключена.

Зависимости установлены без package scripts. Выполнено форматирование. Приложение, сервер, сборка, линтер, компилятор и тестовые решения не запускались; визуальная проверка не проводилась.

Ручная проверка: загрузка/ошибка каталога, группы и инициалы в обеих темах, поиск и план, прямые ссылки на этапы, сноски, боковое меню и «Основы», отметки лекций, принятие всех заданий этапа, редактирование принятого решения, сохранение после обновления, переход во время проверки, узкое окно и клавиатура. Отдельно проверить, что в обычных задачах осталось пять тестов.
