Для data-types и equality подготовлены примеры под новое объяснение. ID, названия, сложность и связь с прогрессом сохранены.

Источники зарегистрированы на уровне подраздела через sourceRefs. Дата checkedAt установлена для проверенных URL. Общие учебные цели не объявлены полностью пересмотренными. Планы находятся в content/batches/js-connected-20261108-*.json, решения expand - в content/decisions.json.
