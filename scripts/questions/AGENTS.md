# Контентные CLI

Краткий вывод - стандарт; --json/--verbose или тематические параметры включают подробности явно. Ошибки не сокращать до молчаливого успеха.

Catalog отвечает за структуру и сборку, source-registry за sourceRefs, fingerprints за снимки. Find/context сначала используют lookup без ответов. Show читает актуальный исходник по выбранному ID. Planning/batch хранят компактное состояние; report проверяет пересечения только изменений по умолчанию.

При изменении генерации согласовать build/check и outputs, сохранить формат серверного seed и все ID. Полный content:check обязателен; приложение, миграции, seed и код примеров не запускать. Подробнее: docs/lean-content-workflow.md из корня.
